## 2. Fork 和克隆项目

### 2.1 Fork 项目

1. 访问 https://github.com/agentscope-ai/QwenPaw
2. 点击右上角「Fork」按钮
3. 创建你的副本到自己的 GitHub 账户

### 2.2 克隆项目

```bash
# 克隆你 Fork 的仓库
git clone https://github.com/你的用户名/QwenPaw.git

# 进入项目目录
cd QwenPaw

# 添加上游仓库（原始仓库）
git remote add upstream https://github.com/agentscope-ai/QwenPaw.git

# 查看远程仓库
git remote -v
```

### 2.3 同步最新代码

```bash
# 获取上游最新代码
git fetch upstream

# 切换到 main 分支
git checkout main

# 合并上游代码
git merge upstream/main

# 推送到你自己的仓库
git push origin main
```

## 3. 创建开发分支

### 3.1 分支命名规范

| 类型 | 命名示例 | 说明 |
|------|----------|------|
| 功能 | `feature/add-translator-skill` | 新功能 |
| 修复 | `fix/login-timeout-error` | Bug 修复 |
| 文档 | `docs/update-readme` | 文档更新 |
| 重构 | `refactor/channel-manager` | 代码重构 |

### 3.2 创建分支

```bash
# 创建并切换到新分支
git checkout -b feature/my-new-feature

# 确认当前分支
git branch
```

### 3.3 工作流程

```
main (稳定分支)
  │
  ├── feature/add-search (你的功能分支)
  │
  └── bugfix/fix-error (其他修复)
```

## 4. 配置开发环境

### 4.1 创建虚拟环境

```bash
# 创建虚拟环境
python -m venv .venv

# 激活环境
# Linux/macOS:
source .venv/bin/activate

# Windows:
.venv\Scripts\activate

# 安装依赖
pip install -e ".[dev,full]"
```

### 4.2 安装 Pre-commit

```bash
# 安装 pre-commit 钩子
pip install pre-commit

# 安装 Git 钩子
pre-commit install

# 测试钩子
pre-commit run --all-files
```

### 4.3 前端构建

```bash
# 进入 console 目录
cd console

# 安装依赖
npm ci

# 构建
npm run build

# 复制到包目录
cd ..
mkdir -p src/qwenpaw/console
cp -R console/dist/. src/qwenpaw/console/
```

## 5. 使用 VS Code

### 5.1 推荐插件

| 插件 | 说明 |
|------|------|
| **Python** | Python 语言支持 |
| **Pylance** | 类型检查和代码导航 |
| **GitLens** | Git 可视化 |
| **Python Debugger** | 调试支持 |
| **REST Client** | API 测试 |

### 5.2 配置

创建 `.vscode/settings.json`：

```json
{
    "python.defaultInterpreterPath": ".venv/bin/python",
    "python.linting.enabled": true,
    "python.linting.pylintEnabled": false,
    "python.linting.flake8Enabled": true,
    "python.formatting.provider": "black",
    "editor.formatOnSave": true,
    "editor.codeActionsOnSave": {
        "source.organizeImports": true
    }
}
```

### 5.3 调试配置

创建 `.vscode/launch.json`：

```json
{
    "version": "0.2.0",
    "configurations": [
        {
            "name": "Python: QwenPaw",
            "type": "python",
            "request": "launch",
            "module": "qwenpaw",
            "args": ["app"],
            "cwd": "${workspaceFolder}",
            "env": {
                "QWENPAW_HOME": "${workspaceFolder}"
            }
        }
    ]
}
```

## 6. 运行测试

### 6.1 运行所有测试

```bash
# 运行 pytest
pytest

# 带覆盖率
pytest --cov=src/qwenpaw --cov-report=html

# 运行特定测试
pytest tests/test_agents.py
```

### 6.2 运行特定测试

```bash
# 运行单个测试文件
pytest tests/test_react_agent.py

# 运行单个测试函数
pytest tests/test_react_agent.py::test_agent_init

# 按标记运行
pytest -m "not slow"
```

### 6.3 测试规范

```python
# tests/test_example.py

import pytest

class TestExample:
    """测试示例"""

    def test_basic(self):
        """基本测试"""
        assert 1 + 1 == 2

    @pytest.mark.asyncio
    async def test_async(self):
        """异步测试"""
        result = await some_async_function()
        assert result is not None
```

## 7. 代码检查

### 7.1 Linting

```bash
# 使用 Ruff（推荐，比 flake8 快 10-100 倍）
ruff check src/

# 自动修复
ruff check --fix src/
```

### 7.2 格式化

```bash
# 使用 Black
black src/

# 检查格式
black --check src/
```

### 7.3 类型检查

```bash
# 使用 mypy
mypy src/

# 严格模式
mypy --strict src/
```

### 7.4 一键检查

```bash
# 运行所有检查
make lint

# 或
ruff check src/ && black --check src/ && mypy src/
```
