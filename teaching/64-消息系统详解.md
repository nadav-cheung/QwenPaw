# 消息系统详解

## 概述

QwenPaw 的消息系统处理 AgentScope Msg 与运行时消息格式之间的转换，支持媒体块处理、工具消息清理和跨提供商规范化。核心清理逻辑位于 `tool_message_utils.py`，解决 AgentScope 1.0.16dev 中的工具消息配对、重复和排序问题。

## 3. 工具消息清理详解

源码路径：`src/qwenpaw/agents/utils/tool_message_utils.py`

### 3.1 问题背景

AgentScope 1.0.16dev 存在以下工具消息问题：

| 问题 | 原因 | 后果 |
|------|------|------|
| 空 input | `stream_tool_parsing` 解析失败 | API 报错 |
| 重复 tool_use | 同一 ID 出现多次 | 配对错误 |
| 无效 id/name | 块缺少必要字段 | API 拒绝 |
| 乱序 | tool_result 在 tool_use 之前 | 上下文错乱 |
| 未配对 | tool_use 无对应 result | API 报错 |

### 3.2 清理管道

```python
# src/qwenpaw/agents/utils/tool_message_utils.py:322
def _sanitize_tool_messages(msgs: list) -> list:
    """Ensure tool_use/tool_result messages are properly paired and ordered.

    Returns the original list unchanged if no fix is needed.
    """
    # Step 1: 修复空 input 但有 raw_input 的块
    msgs = _repair_empty_tool_inputs(msgs)
    # Step 2: 移除无效块（空 id、None name）
    msgs = _remove_invalid_tool_blocks(msgs)
    # Step 3: 移除重复 tool_use 块
    msgs = _dedup_tool_blocks(msgs)

    # Step 4: 检查是否需要排序/配对修复
    pending: dict[str, int] = {}
    needs_fix = False
    for msg in msgs:
        msg_uses, msg_results = extract_tool_ids(msg)
        for rid in msg_results:
            if pending.get(rid, 0) <= 0:
                needs_fix = True
                break
            pending[rid] -= 1
            if pending[rid] == 0:
                del pending[rid]
        if needs_fix:
            break
        if pending and not msg_results:
            needs_fix = True
            break
        for uid in msg_uses:
            pending[uid] = pending.get(uid, 0) + 1
    if not needs_fix and not pending:
        return msgs

    logger.debug("Sanitizing tool messages: fixing order/pairing issues")
    return _remove_unpaired_tool_messages(_reorder_tool_results(msgs))
```

**管道执行顺序**：修复空 input → 移除无效 → 去重 → 检查排序/配对 → 排序/移除未配对

### 3.3 清理管道图解

```
原始消息列表
    │
    ▼
_repair_empty_tool_inputs()
    │  修复空 input 但有 raw_input 的块
    ▼
_remove_invalid_tool_blocks()
    │  移除空 id 或无 name 的块
    ▼
_dedup_tool_blocks()
    │  移除同一 ID 的重复 tool_use
    ▼
检查排序/配对
    │
    ├── 无需修复 → 返回
    │
    └── 需要修复
            │
            ▼
        _reorder_tool_results()
            │  移动 tool_result 到 tool_use 之后
            ▼
        _remove_unpaired_tool_messages()
            │  移除未配对的 tool_use/result
            ▼
        返回清理后的消息列表
```

### 4.1 extract_tool_ids

从单条消息中提取 tool_use 和 tool_result 的 ID 集合：

```python
# src/qwenpaw/agents/utils/tool_message_utils.py:13
def extract_tool_ids(msg) -> tuple[set[str], set[str]]:
    """Return (tool_use_ids, tool_result_ids) found in a single message.

    Args:
        msg: A Msg object whose content may contain tool blocks.

    Returns:
        A tuple of two sets: (tool_use IDs, tool_result IDs).
    """
    uses: set[str] = set()
    results: set[str] = set()
    if isinstance(msg.content, list):
        for block in msg.content:
            if isinstance(block, dict) and block.get("id"):
                btype = block.get("type")
                if btype == "tool_use":
                    uses.add(block["id"])
                elif btype == "tool_result":
                    results.add(block["id"])
    return uses, results
```

**示例输入**：

```python
msg.content = [
    {"type": "tool_use", "id": "tool_001", "name": "read_file"},
    {"type": "tool_result", "id": "tool_001", "content": "..."},
]
# → ({"tool_001"}, {"tool_001"})
```

### 5.1 check_valid_messages

验证所有 tool_use 都有对应的 tool_result：

```python
# src/qwenpaw/agents/utils/tool_message_utils.py:35
def check_valid_messages(messages: list) -> bool:
    """
    Check if the messages are valid by ensuring all tool_use blocks have
    corresponding tool_result blocks.

    Args:
        messages: List of Msg objects to validate.

    Returns:
        bool: True if all tool_use IDs have matching tool_result IDs,
              False otherwise.
    """
    use_ids: set[str] = set()
    result_ids: set[str] = set()
    for msg in messages:
        u, r = extract_tool_ids(msg)
        use_ids |= u
        result_ids |= r
    return use_ids == result_ids
```

**验证逻辑**：tool_use IDs 集合必须等于 tool_result IDs 集合

**使用场景**：在发送请求到 LLM API 前验证消息格式正确性

## 6. 排序与配对函数

### 6.1 _reorder_tool_results

源码路径：`src/qwenpaw/agents/utils/tool_message_utils.py:56`

将 tool_result 移到对应 tool_use 之后，处理重复 ID 的 FIFO 消费：

```python
# src/qwenpaw/agents/utils/tool_message_utils.py:56
def _reorder_tool_results(msgs: list) -> list:
    """Move tool_result messages right after their corresponding tool_use.

    Handles duplicate tool_call_ids by consuming results FIFO.
    """
    results_by_id: dict[str, list[object]] = {}
    result_msg_ids: set[int] = set()
    for msg in msgs:
        if isinstance(msg.content, list):
            for block in msg.content:
                if (
                    isinstance(block, dict)
                    and block.get("type") == "tool_result"
                    and block.get("id")
                ):
                    results_by_id.setdefault(block["id"], []).append(msg)
                    result_msg_ids.add(id(msg))

    consumed: dict[str, int] = {}
    reordered: list = []
    placed: set[int] = set()
    for msg in msgs:
        if id(msg) in result_msg_ids:
            continue  # 跳过独立的 result 消息（将在后面放置）
        reordered.append(msg)
        if not isinstance(msg.content, list):
            continue
        for block in msg.content:
            if not (
                isinstance(block, dict)
                and block.get("type") == "tool_use"
                and block.get("id")
            ):
                continue
            bid = block["id"]
            candidates = results_by_id.get(bid, [])
            ci = consumed.get(bid, 0)
            if ci >= len(candidates):
                continue
            rm = candidates[ci]
            consumed[bid] = ci + 1
            if id(rm) not in placed:
                reordered.append(rm)
                placed.add(id(rm))

    return reordered
```

**算法**：
1. 收集所有 tool_result 按 ID 分组
2. 遍历消息，跳过独立 result 消息
3. 遇到 tool_use 时，查找对应 ID 的 result（FIFO）
4. 相同 ID 有多个 result 时，按顺序消费

**示例**：

```
输入: [A, result_1, B, result_2, result_1]  (A/B 是 tool_use, result_1/2 是 tool_result)
处理: A 的 result → result_1, B 的 result → result_2
输出: [A, result_1, B, result_2, result_1]  (第一个 result_1 被 A 消费，保留第二个 result_1)
```

### 6.2 _remove_unpaired_tool_messages

源码路径：`src/qwenpaw/agents/utils/tool_message_utils.py:104`

移除未配对的 tool_use/tool_result 消息：

```python
# src/qwenpaw/agents/utils/tool_message_utils.py:104
def _remove_unpaired_tool_messages(msgs: list) -> list:
    """Remove tool_use/tool_result messages that aren't properly paired.

    Each tool_use must be immediately followed by tool_results for all
    its IDs.  Unpaired messages and orphaned results are removed.
    """
    to_remove: set[int] = set()

    i = 0
    while i < len(msgs):
        use_ids, _ = extract_tool_ids(msgs[i])
        if not use_ids:
            i += 1
            continue
        required = set(use_ids)
        j = i + 1
        result_indices: list[int] = []
        while j < len(msgs) and required:
            _, r = extract_tool_ids(msgs[j])
            if not r:
                break
            required -= r
            result_indices.append(j)
            j += 1
        if required:  # 有未满足的 required ID
            to_remove.add(i)
            to_remove.update(result_indices)
            i += 1
        else:
            i = j

    # 过滤：移除任何引用已删除 use ID 的 result
    surviving_use_ids: set[str] = set()
    for idx, msg in enumerate(msgs):
        if idx not in to_remove:
            u, _ = extract_tool_ids(msg)
            surviving_use_ids |= u
    for idx, msg in enumerate(msgs):
        if idx in to_remove:
            continue
        _, r = extract_tool_ids(msg)
        if r and not r.issubset(surviving_use_ids):
            to_remove.add(idx)

    return [msg for idx, msg in enumerate(msgs) if idx not in to_remove]
```

**算法**：从 tool_use 向后查找匹配的 result，未找到则标记删除

# src/qwenpaw/agents/utils/tool_message_utils.py:150
def _dedup_tool_blocks(msgs: list) -> list:
    """Remove duplicate tool_use blocks (same ID) within a single message."""
    changed = False
    result: list = []
    for msg in msgs:
        if not isinstance(msg.content, list):
            result.append(msg)
            continue
        seen_ids: set[str] = set()
        new_blocks: list = []
        deduped = False
        for block in msg.content:
            if (
                isinstance(block, dict)
                and block.get("type") == "tool_use"
                and block.get("id")
            ):
                if block["id"] in seen_ids:  # 重复
                    deduped = True
                    continue
                seen_ids.add(block["id"])
            new_blocks.append(block)
        if deduped:
            msg.content = new_blocks
            changed = True
        result.append(msg)
    return result if changed else msgs
```

# src/qwenpaw/agents/utils/tool_message_utils.py:179
def _remove_invalid_tool_blocks(msgs: list) -> list:
    """Remove tool_use/tool_result blocks with invalid id/name.

    A valid tool_use block must have:
    - Non-empty, non-None id
    - Non-empty, non-None name

    A valid tool_result block must have:
    - Non-empty, non-None id
    """
    changed = False
    result: list = []

    for msg in msgs:
        if not isinstance(msg.content, list):
            result.append(msg)
            continue

        new_blocks: list = []
        removed = False

        for block in msg.content:
            if not isinstance(block, dict):
                new_blocks.append(block)
                continue

            block_type = block.get("type")

            if block_type in ("tool_use", "tool_result"):
                block_id = block.get("id")
                block_name = block.get("name")

                if not block_id:  # 无效 ID
                    logger.warning(
                        "Removing %s with invalid id: id=%r, name=%r",
                        block_type, block_id, block_name,
                    )
                    removed = True
                    continue

                if block_type == "tool_use" and not block_name:  # tool_use 无 name
                    logger.warning(
                        "Removing tool_use with invalid name: id=%r, name=%r",
                        block_id, block_name,
                    )
                    removed = True
                    continue

            new_blocks.append(block)

        if removed:
            msg.content = new_blocks
            changed = True

        result.append(msg)

    return result if changed else msgs
```

### 7.3 _repair_empty_tool_inputs

# src/qwenpaw/agents/utils/tool_message_utils.py:250
def _repair_empty_tool_inputs(msgs: list) -> list:
    """Repair tool_use blocks with empty input but valid raw_input.

    This fixes a bug in AgentScope 1.0.16dev where stream_tool_parsing
    may fail to parse arguments correctly, leaving input={} while
    raw_input contains valid JSON.
    """
    changed = False
    result: list = []

    for msg in msgs:
        if not isinstance(msg.content, list):
            result.append(msg)
            continue

        new_blocks: list = []
        repaired = False

        for block in msg.content:
            if not isinstance(block, dict):
                new_blocks.append(block)
                continue

            if block.get("type") == "tool_use":
                input_field = block.get("input", {})
                raw_input = block.get("raw_input", "")

                # input={} 但 raw_input 有有效内容
                if not input_field and raw_input and raw_input != "{}":
                    try:
                        parsed = json.loads(raw_input)
                        if isinstance(parsed, dict) and parsed:
                            block["input"] = parsed
                            repaired = True
                            logger.info(
                                "Repaired tool_use input from raw_input: "
                                "id=%s, name=%s, keys=%s",
                                block.get("id"), block.get("name"),
                                list(parsed.keys()),
                            )
                    except (json.JSONDecodeError, TypeError) as e:
                        logger.warning(
                            "Failed to repair tool_use input from raw_input: "
                            "id=%s, name=%s, error=%s",
                            block.get("id"), block.get("name"), e,
                        )

            new_blocks.append(block)

        if repaired:
            msg.content = new_blocks
            changed = True

        result.append(msg)

    return result if changed else msgs
```

**Bug 场景**：AgentScope 1.0.16dev 的 `stream_tool_parsing` 解析参数失败，导致 `input={}` 但 `raw_input="{\"path\": \"/etc/passwd\"}"`

def _truncate_text(text: str, max_length: int) -> str:
    """Truncate text to max length, keeping head and tail portions."""
    text = str(text) if text else ""
    if not text:
        return text

    if len(text) <= max_length:
        return text

    half_length = max_length // 2
    truncated_chars = len(text) - max_length
    logger.info(
        "Text truncated: original %d chars, kept head %d + tail %d, "
        "removed %d chars.",
        len(text), half_length, half_length, truncated_chars,
    )
    return (
        f"{text[:half_length]}\n\n[...truncated {truncated_chars} "
        f"chars...]\n\n{text[-half_length:]}"
    )
```

**格式**：保留前 `max_length/2` + `[...truncated N chars...]` + 后 `max_length/2`

**设计意图**：截断长文本时保留首尾，方便人工审查中间被截断的部分。

## 13. 常见问题

**解决**：
