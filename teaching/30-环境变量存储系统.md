## 双层持久化架构

**文件**: `src/qwenpaw/envs/store.py:1-8`

```
两层存储策略：

1. **envs.json** – canonical store, survives process restarts.
2. **os.environ** – injected into the current Python process so that
   ``os.getenv()`` and child subprocesses (``subprocess.run``, etc.)
   can read them immediately.
```

### 🐍 来自 Java 的你

| Java | Python | 说明 |
|------|--------|------|
| `System.getenv("KEY")` | `os.getenv("KEY")` 或 `os.environ["KEY"]` | 获取环境变量 |
| `System.getenv()` 返回 `Map<String,String>` | `os.environ` 是 `dict` | Java 返回只读 Map，Python 的 dict 可修改 |
| `System.setProperty("key", "value")` | `os.environ["KEY"] = "value"` | 设置环境变量 |
| `System.getenv()` 读取启动时快照 | `os.environ` 实时反映当前进程修改 | Java 不会看到进程内修改，Python 会 |
| `System.getenv("HOME")` | `Path.home()` 或 `os.environ["HOME"]` | 获取用户目录 |
| Properties 文件 / `.env` 手动加载 | `python-dotenv` 库自动加载 `.env` | Python 需要第三方库支持 .env 文件 |

**关键差异：** Java 的 `System.getenv()` 在 JVM 启动时读取一次，后续进程内修改 `System.setProperty()` 不会影响已启动的进程。Python 的 `os.environ` 可以随时修改，且对子进程立即可见。

## 加密机制

与 `secret_store.py` 集成，使用 Fernet 对称加密。

### 加密/解密函数

**文件**: `src/qwenpaw/security/secret_store.py:183-209`

```python
def encrypt(plaintext: str) -> str:
    """Encrypt *plaintext* and return ``ENC:<base64-ciphertext>``."""
    if not plaintext:
        return plaintext
    f = _get_fernet()
    token = f.encrypt(plaintext.encode("utf-8"))
    return _ENC_PREFIX + token.decode("ascii")

def decrypt(value: str) -> str:
    """Decrypt *value* if it carries the ``ENC:`` prefix; pass through
    otherwise."""
    if not value or not value.startswith(_ENC_PREFIX):
        return value
    try:
        f = _get_fernet()
        token = value[len(_ENC_PREFIX) :].encode("ascii")
        return f.decrypt(token).decode("utf-8")
    except Exception:
        logger.warning("Failed to decrypt value...")
        return value

def is_encrypted(value: str) -> bool:
    """Return ``True`` when *value* looks like an encrypted token."""
    return bool(value) and value.startswith(_ENC_PREFIX)
```

```python
def load_envs(path: Optional[Path] = None) -> dict[str, str]:
    # 1. 读取 JSON 文件
    with open(path, "r", encoding="utf-8") as fh:
        data = json.load(fh)
    # 2. 检测是否有明文值（遗留数据迁移）
    has_plaintext = any(v and not is_encrypted(v) for v in raw.values())
    # 3. 透明解密所有值
    decrypted = {k: decrypt(v) for k, v in raw.items()}
    # 4. 发现明文时重新加密并写回（迁移）
    if has_plaintext:
        _rewrite_encrypted(path, decrypted)
    return decrypted
```

```python
def save_envs(envs: dict[str, str], path: Optional[Path] = None) -> None:
    # 1. 加密所有值
    encrypted = {
        k: encrypt(v) if v and not is_encrypted(v) else v
        for k, v in envs.items()
    }
    # 2. 写入 JSON 文件
    with open(path, "w", encoding="utf-8") as fh:
        json.dump(encrypted, fh, indent=2, ensure_ascii=False)
```

## 启动时加载环境变量

**文件**: `src/qwenpaw/envs/store.py:217-237`

```python
def load_envs_into_environ() -> dict[str, str]:
    """Load envs.json and apply bootstrap-safe entries to ``os.environ``.

    Call this once at application startup so that environment
    variables persisted from a previous session are available
    immediately. Protected keys are excluded from injection, and
    existing process/system env vars are preserved."""
    envs = load_envs()
    # 排除受保护的系统级密钥
    bootstrap_envs = {
        key: value
        for key, value in envs.items()
        if key not in _PROTECTED_BOOTSTRAP_KEYS
    }
    # 不覆盖显式运行时/系统环境变量
    _apply_to_environ(bootstrap_envs, overwrite=False)
    return envs
```

```python
def _migrate_legacy_envs_json(path: Path) -> None:
    """Copy old envs.json into secret dir once (best effort)."""
    for legacy in _LEGACY_ENVS_JSON_CANDIDATES:
        if not legacy.is_file() or _same_path(legacy, path):
            continue
        try:
            _prepare_secret_parent(path)
            shutil.copy2(legacy, path)
            _chmod_best_effort(path, 0o600)
            return
        except OSError as exc:
            logger.warning("Failed to migrate legacy envs.json...", exc)
```

## 文件权限安全

**文件**: `src/qwenpaw/envs/store.py:28-39`

```python
def _chmod_best_effort(path: Path, mode: int) -> None:
    try:
        os.chmod(path, mode)
    except OSError:
        # Some systems/filesystems may not support chmod semantics.
        pass

def _prepare_secret_parent(path: Path) -> None:
    path.parent.mkdir(parents=True, exist_ok=True)
    _chmod_best_effort(path.parent, 0o700)  # 目录权限 700
```

## 核心逻辑总结

```
┌─────────────────────────────────────────────────────────────┐
│                    envs.json (持久化)                        │
│  { "OPENAI_API_KEY": "ENC:xxxxx", "MODEL": "gpt-4" }       │
└─────────────────────┬───────────────────────────────────────┘
                      │ encrypt/decrypt (透明)
                      ▼
┌─────────────────────────────────────────────────────────────┐
│                    os.environ (进程内)                       │
│  启动时 load_envs_into_environ() 注入                        │
└─────────────────────────────────────────────────────────────┘

密钥管理优先级:
  1. 进程缓存 (_cached_master_key)
  2. OS keyring (keyring 库)
  3. SECRET_DIR/.master_key 文件
  4. 生成新密钥

加密算法: Fernet (AES-128-CBC + HMAC-SHA256)
加密前缀: "ENC:"
```
