## 概述

模板系统定义了智能体的初始配置和技能集合，模型工厂负责创建和包装 LLM 模型实例，钩子系统则在智能体推理的关键节点注入额外逻辑。三者共同构成了智能体的"出生-成长-运行"基础设施。

```python
def create_model_and_formatter(
    agent_id: Optional[str] = None,
) -> Tuple[ChatModelBase, FormatterBase]:
    """创建模型和格式化器实例"""

    # 确定 agent_id (参数 > context > None)
    if agent_id is None:
        try:
            agent_id = get_current_agent_id()
        except Exception:
            pass

    # 获取 agent 特定的模型配置
    if agent_id:
        agent_config = load_agent_config(agent_id)
        model_slot = agent_config.active_model
        retry_config = RetryConfig(
            enabled=agent_config.running.llm_retry_enabled,
            max_retries=agent_config.running.llm_max_retries,
            backoff_base=agent_config.running.llm_backoff_base,
            backoff_cap=agent_config.running.llm_backoff_cap,
        )
        rate_limit_config = RateLimitConfig(
            max_concurrent=agent_config.running.llm_max_concurrent,
            max_qpm=agent_config.running.llm_max_qpm,
        )

    # 创建 chat model
    if model_slot and model_slot.provider_id and model_slot.model:
        manager = ProviderManager.get_instance()
        provider = manager.get_provider(model_slot.provider_id)
        model = provider.get_chat_model_instance(model_slot.model)
    else:
        model = ProviderManager.get_active_chat_model()

    # 创建 formatter
    formatter = _create_formatter_instance(model.__class__)

    # 用 RetryChatModel 包装
    wrapped_model = TokenRecordingModelWrapper(provider_id, model)
    wrapped_model = RetryChatModel(
        wrapped_model,
        retry_config=retry_config,
        rate_limit_config=rate_limit_config,
    )

    return wrapped_model, formatter
```

```python
class RetryChatModel(ChatModelBase):
    """透明的重试包装器，处理瞬时 LLM API 故障"""

    def __init__(self, inner: ChatModelBase,
                 retry_config: RetryConfig | None = None,
                 rate_limit_config: RateLimitConfig | None = None) -> None:
        super().__init__(model_name=inner.model_name, stream=inner.stream)
        self._inner = inner
        self._retry_config = _normalize_retry_config(retry_config)
        self._rate_limit_config = _normalize_rate_limit_config(rate_limit_config)
```

**重试配置** (第59-67行):

```python
@dataclass(frozen=True, slots=True)
class RetryConfig:
    """瞬时 LLM API 故障的重试策略"""
    enabled: bool = LLM_MAX_RETRIES > 0
    max_retries: int = max(LLM_MAX_RETRIES, 1)
    backoff_base: float = LLM_BACKOFF_BASE
    backoff_cap: float = LLM_BACKOFF_CAP
```

**核心调用逻辑** (第269-354行):

```python
async def __call__(self, *args, **kwargs) -> ChatResponse | AsyncGenerator:
    limiter = await get_rate_limiter(...)

    for attempt in range(1, attempts + 1):
        acquired = False
        try:
            await asyncio.wait_for(limiter.acquire(), timeout=...)
            acquired = True
            result = await self._inner(*args, **kwargs)

            if isinstance(result, AsyncGenerator):
                return self._wrap_stream(result, args, kwargs, attempt, attempts, limiter)
            return result

        except Exception as exc:
            if _is_retryable(exc) and _is_rate_limit(exc):
                await limiter.report_rate_limit(_extract_retry_after(exc))

            if not _is_retryable(exc) or attempt >= attempts:
                raise

            delay = _compute_backoff(attempt, self._retry_config)
            await asyncio.sleep(delay)
```

```python
class TokenRecordingModelWrapper:
    """记录 Token 使用量的包装器"""

    def __init__(self, provider_id: str, model: ChatModelBase):
        self.provider_id = provider_id
        self._model = model
```

## 来自 Java 的你

### 核心概念对照

| Java | Python / QwenPaw | 说明 |
|------|-------------------|------|
| Spring AOP `@Before` / `@After` | Hook (`pre_reasoning`) | QwenPaw 钩子通过 `register_instance_hook()` 注册，支持在推理前注入逻辑 |
| `@Interceptors` | `_wrap_with_hooks` | QwenPaw 的钩子是显式注册的函数调用，而非注解驱动的拦截器链 |
| Bean Factory | Model Factory | QwenPaw 的 `create_model_and_formatter()` 根据配置创建模型实例，类似 FactoryBean |
| `@Retryable` | `RetryChatModel` | QwenPaw 用装饰器模式包装模型实现重试，而非 Spring Retry 注解 |

### 关键差异

Spring AOP 基于动态代理和注解，开发者用 `@Aspect` 声明切面。QwenPaw 的钩子是显式注册的函数，没有代理字节码生成。RetryChatModel 使用装饰器模式逐层包装模型，类似 Java 的 Filter Chain 但更轻量。
