# 智能体钩子系统

## 概述

QwenPaw 的智能体（Agent）系统基于 AgentScope 框架构建，提供了灵活的**钩子（Hook）机制**，允许开发者在 Agent 核心推理流程的关键节点注入自定义逻辑。钩子是一种无侵入式的扩展方式，可以在不修改核心代码的情况下改变 Agent 的行为。

本文档详细介绍 QwenPaw 中钩子系统的架构、现有实现以及自定义钩子的方法。

**源码路径**: `src/qwenpaw/agents/hooks/`

---

## 1. 钩子系统架构

### 1.1 钩子类型

AgentScope 支持以下钩子类型，按触发时机分为两大类：

**AgentBase 层钩子**（在 `agentscope/agent/_agent_base.py` 中定义）：

| 钩子类型 | 触发时机 |
|----------|----------|
| `pre_reply` | `reply()` 方法执行前 |
| `post_reply` | `reply()` 方法执行后 |
| `pre_print` | `print()` 方法执行前 |
| `post_print` | `print()` 方法执行后 |
| `pre_observe` | `observe()` 方法执行前 |
| `post_observe` | `observe()` 方法执行后 |

**ReActAgent 层钩子**（在 `agentscope/agent/_react_agent_base.py` 中定义）：

| 钩子类型 | 触发时机 |
|----------|----------|
| `pre_reasoning` | `_reasoning()` 核心推理方法执行前 |
| `post_reasoning` | `_reasoning()` 核心推理方法执行后 |
| `pre_acting` | `_acting()` 工具执行方法执行前 |
| `post_acting` | `_acting()` 工具执行方法执行后 |

### 1.2 钩子执行流程

QwenPaw Agent 的标准调用链如下：

```
用户消息
    ↓
reply()  ←─ pre_reply hooks
    ↓
┌───────────────────────────────────────┐
│  _reasoning()                         │
│      ↑ pre_reasoning hooks            │
│      ↓                                │
│  [BootstrapHook] ── 检测 BOOTSTRAP.md  │
│  [MemoryCompactionHook] ── 上下文压缩  │
│      ↓                                │
│  _reasoning 核心推理                   │
│      ↓                                │
│  _acting() ── pre_acting hooks        │
│      ↓                                │
│  [执行工具]                           │
│      ↓ post_acting hooks              │
│      ↓                                │
│  _reasoning 返回                      │
└───────────────────────────────────────┘
    ↓
post_reasoning hooks
    ↓
reply() 返回  ←─ post_reply hooks
    ↓
响应消息
```

### 1.3 元类包装机制

钩子的自动注入依赖于 `_ReActAgentMeta` 元类（在 `agentscope/agent/_agent_meta.py` 第 145-167 行）：

```python
class _ReActAgentMeta(_AgentMeta):
    """The ReAct metaclass that adds pre- and post-hooks for the _reasoning
    and _acting functions."""

    def __new__(mcs, name: Any, bases: Any, attrs: Dict) -> Any:
        """Wrap the ReAct agent's _reasoning and _acting functions with
        hooks."""

        for func_name in [
            "_reasoning",
            "_acting",
        ]:
            if func_name in attrs:
                attrs[func_name] = _wrap_with_hooks(attrs[func_name])

        return super().__new__(mcs, name, bases, attrs)
```

`_wrap_with_hooks` 装饰器（在 `agentscope/agent/_agent_meta.py` 第 27-104 行）将原函数包装为：

1. 调用所有 `pre_hooks`
2. 执行原函数
3. 调用所有 `post_hooks`

关键的重入保护机制（防止元类多层包装导致钩子重复执行）：

```python
# agentscope/agent/_agent_meta.py, 第 47-54 行
func_name = original_func.__name__.replace("_", "")

hook_guard_attr = f"_hook_running_{func_name}"

async def async_wrapper(self: AgentBase, *args: Any, **kwargs: Any) -> Any:
    # Guard against re-entrant hook execution when multiple classes
    # in the MRO define the same method (each wrapped independently
    # by the metaclass). Only the outermost wrapper runs hooks.
    if getattr(self, hook_guard_attr, False):
        return await original_func(self, *args, **kwargs)
```

## 2. QwenPaw 内置钩子实现

### 2.1 BootstrapHook

**文件**: `src/qwenpaw/agents/hooks/bootstrap.py`

**用途**: 在用户首次交互时检测工作目录中的 `BOOTSTRAP.md` 文件，并自动插入引导文本，帮助用户了解 Agent 的身份配置和偏好设置。

#### 核心代码

```python
# src/qwenpaw/agents/hooks/bootstrap.py, 第 33-75 行
class BootstrapHook:
    """Hook for bootstrap guidance on first user interaction."""

    def __init__(
        self,
        working_dir: Path,
        language: str = "zh",
    ):
        self.working_dir = working_dir
        self.language = language

    async def __call__(
        self,
        agent,
        kwargs: dict[str, Any],
    ) -> dict[str, Any] | None:
        """Check and load BOOTSTRAP.md on first user interaction."""
        try:
            bootstrap_path = self.working_dir / "BOOTSTRAP.md"
            bootstrap_completed_flag = (
                self.working_dir / ".bootstrap_completed"
            )

            # Check if bootstrap has already been triggered before
            if bootstrap_completed_flag.exists():
                return None

            if not bootstrap_path.exists():
                return None

            messages = await agent.memory.get_memory()
            if not is_first_user_interaction(messages):
                return None

            # ... prepend guidance to first user message ...

            # Create completion flag to prevent repeated triggering
            bootstrap_completed_flag.touch()

        except Exception as e:
            logger.error("Failed to process bootstrap: %s", e)
```

#### 触发条件

1. 工作目录存在 `BOOTSTRAP.md` 文件
2. 不存在 `.bootstrap_completed` 标记文件
3. 当前消息是用户的首次交互（通过 `is_first_user_interaction()` 判断）

#### 防护机制

BootstrapHook 使用 `.bootstrap_completed` 文件作为防重复触发标记。一旦触发，该文件会被创建（`touch()`），确保引导文本只会在首次交互时插入，不会每次都重复添加。

### 2.2 MemoryCompactionHook

**文件**: `src/qwenpaw/agents/hooks/memory_compaction.py`

**用途**: 当 Agent 的上下文窗口接近上限时，自动压缩旧消息，生成摘要，以保持对话的连续性。

#### 核心代码

```python
# src/qwenpaw/agents/hooks/memory_compaction.py, 第 60-98 行
class MemoryCompactionHook:
    """Hook for automatic memory compaction when context is full."""

    _REENTRANCY_ATTR = "_memory_compact_hook_running"

    async def __call__(
        self,
        agent: ReActAgent,
        kwargs: dict[str, Any],
    ) -> dict[str, Any] | None:
        # Guard against duplicate execution caused by the metaclass
        # wrapping _reasoning at multiple levels of the class hierarchy
        if getattr(agent, self._REENTRANCY_ATTR, False):
            return None
        setattr(agent, self._REENTRANCY_ATTR, True)

        try:
            agent_config = load_agent_config(self.memory_manager.agent_id)
            running_config = agent_config.running
            token_counter = get_token_counter(agent_config)

            system_prompt = agent.sys_prompt
            compressed_summary = memory.get_compressed_summary()

            # 计算剩余可用 token
            left_compact_threshold = (
                running_config.memory_compact_threshold - str_token_count
            )

            # ... check messages and compact if needed ...

            if messages_to_compact:
                self.memory_manager.add_async_summary_task(
                    messages=messages_to_compact,
                )
                await self._print_status_message(
                    agent,
                    "🔄 Context compaction started...",
                )
                # 执行压缩
                compact_content = await self.memory_manager.compact_memory(...)
        finally:
            setattr(agent, self._REENTRANCY_ATTR, False)

        return None
```

#### 配置参数

| 参数 | 来源 | 说明 |
|------|------|------|
| `memory_compact_threshold` | `AgentProfileConfig.running` | 开始压缩的 token 上限 |
| `memory_compact_reserve` | `AgentProfileConfig.running` | 压缩后保留的 token 余量 |
| `tool_result_compact` | `AgentProfileConfig.running` | 工具结果压缩配置 |

#### 重入保护

MemoryCompactionHook 使用 `_memory_compact_hook_running` 实例属性防止重复执行。这是必要的，因为 QwenPawAgent 继承层次中 `QwenPawAgent._reasoning` 和 `ReActAgent._reasoning` 都被元类包装，可能导致钩子在单次 `_reasoning` 调用中被触发两次。

## 3. 钩子注册机制

### 3.1 实例级注册

在 `QwenPawAgent.__init__()` 中调用 `_register_hooks()` 方法（`src/qwenpaw/agents/react_agent.py`, 第 327-349 行）：

```python
def _register_hooks(self) -> None:
    """Register pre-reasoning and pre-acting hooks."""
    # Bootstrap hook - checks BOOTSTRAP.md on first interaction
    working_dir = (
        self._workspace_dir if self._workspace_dir else WORKING_DIR
    )
    bootstrap_hook = BootstrapHook(
        working_dir=working_dir,
        language=self._language,
    )
    self.register_instance_hook(
        hook_type="pre_reasoning",
        hook_name="bootstrap_hook",
        hook=bootstrap_hook.__call__,
    )

    # Memory compaction hook - auto-compact when context is full
    if self._enable_memory_manager and self.memory_manager is not None:
        memory_compact_hook = MemoryCompactionHook(
            memory_manager=self.memory_manager,
        )
        self.register_instance_hook(
            hook_type="pre_reasoning",
            hook_name="memory_compact_hook",
            hook=memory_compact_hook.__call__,
        )
```

### 3.2 register_instance_hook 方法

定义在 `agentscope/agent/_agent_base.py`, 第 533-555 行：

```python
def register_instance_hook(
    self,
    hook_type: AgentHookTypes,
    hook_name: str,
    hook: Callable,
) -> None:
    """Register a hook to the agent instance.

    Args:
        hook_type: The type of the hook (pre_reasoning, post_reasoning, etc.)
        hook_name: The unique name of the hook
        hook: The hook function
    """
    hooks = getattr(self, f"_instance_{hook_type}_hooks")
    hooks[hook_name] = hook
```

### 3.3 支持的 Hook 类型常量

定义在 `agentscope/types/_hook.py`，可用的 hook_type 值：

```python
AgentHookTypes = Literal[
    "pre_reply", "post_reply",
    "pre_print", "post_print",
    "pre_observe", "post_observe",
    "pre_reasoning", "post_reasoning",
    "pre_acting", "post_acting",
]
```

## 4. 如何自定义钩子

### 4.1 钩子函数签名

**Pre-Hook 签名**:
```python
async def my_pre_hook(
    agent,           # Agent 实例
    kwargs: dict,   # 归一化的关键字参数
) -> dict | None:
    """返回修改后的 kwargs，或返回 None 表示不修改"""
    return kwargs
```

**Post-Hook 签名**:
```python
async def my_post_hook(
    agent,           # Agent 实例
    kwargs: dict,    # 归一化的关键字参数
    output: Any,     # 原函数的输出
) -> Any | None:
    """返回修改后的输出，或返回 None 表示不修改"""
    return output
```

### 4.2 自定义钩子示例

#### 示例 1: Pre-Reasoning 日志钩子

```python
import logging
from typing import Any

logger = logging.getLogger(__name__)

class LoggingHook:
    """记录每次推理前的状态"""

    async def __call__(
        self,
        agent,
        kwargs: dict[str, Any],
    ) -> dict[str, Any] | None:
        messages = await agent.memory.get_memory()
        logger.info(
            f"推理前: Agent={agent.name}, "
            f"消息数={len(messages)}, "
            f"max_iters={agent.max_iters}"
        )
        return None  # 不修改 kwargs

# 注册钩子
agent.register_instance_hook(
    hook_type="pre_reasoning",
    hook_name="logging_hook",
    hook=LoggingHook().__call__,
)
```

#### 示例 2: 修改推理参数的 Pre-Hook

```python
class ModifyReasoningHook:
    """动态修改 tool_choice 参数"""

    async def __call__(
        self,
        agent,
        kwargs: dict[str, Any],
    ) -> dict[str, Any] | None:
        # 检查是否需要强制使用工具
        running_config = agent._agent_config.running
        if running_config.force_tool_use:
            kwargs["tool_choice"] = "required"
            logger.debug("Hook: 强制 tool_choice=required")
        return kwargs  # 返回修改后的 kwargs

# 注册钩子
agent.register_instance_hook(
    hook_type="pre_reasoning",
    hook_name="modify_tool_choice",
    hook=ModifyReasoningHook().__call__,
)
```

#### 示例 3: Post-Reasoning 响应修改钩子

```python
class PostProcessingHook:
    """修改推理结果，添加额外文本"""

    async def __call__(
        self,
        agent,
        kwargs: dict[str, Any],
        output: Msg,
    ) -> Msg | None:
        # 仅在特定条件下修改输出
        if output.get_text_content().startswith("我将"):
            original_content = output.content
            if isinstance(original_content, list):
                original_content.append({
                    "type": "text",
                    "text": "\n\n[由钩子添加的备注]"
                })
            return output
        return None  # 不修改输出
```

### 4.3 注册类级别钩子

类级别钩子对所有 Agent 实例生效：

```python
from agentscope.agent import AgentBase

def global_logging_hook(agent, kwargs):
    logger.info(f"Global hook triggered for {agent.name}")
    return None

# 注册到类
AgentBase.register_class_hook(
    hook_type="pre_reasoning",
    hook_name="global_logging",
    hook=global_logging_hook,
)
```

### 4.4 移除钩子

```python
# 移除实例钩子
agent.remove_instance_hook(
    hook_type="pre_reasoning",
    hook_name="my_hook",
)

# 移除类级别钩子
AgentBase.remove_class_hook(
    hook_type="pre_reasoning",
    hook_name="global_logging",
)

# 清空所有钩子
agent.clear_instance_hooks()  # 清空所有实例钩子
AgentBase.clear_class_hooks()  # 清空所有类级别钩子
```

## 6. 实用场景

### 6.1 实现自定义引导流程

参考 BootstrapHook 的实现，可以创建自定义的首次交互引导钩子：

```python
class CustomOnboardingHook:
    def __init__(self, welcome_message: str):
        self.welcome_message = welcome_message
        self.triggered = False

    async def __call__(self, agent, kwargs):
        if self.triggered:
            return None

        messages = await agent.memory.get_memory()
        if len(messages) <= 2:  # 仅 system + 首个 user
            # 插入欢迎消息
            welcome_msg = Msg("assistant", self.welcome_message, "assistant")
            await agent.memory.add(welcome_msg)
            self.triggered = True
        return None
```

### 6.2 实现上下文窗口监控

参考 MemoryCompactionHook，可以创建监控钩子：

```python
class MemoryMonitorHook:
    def __init__(self, warning_threshold: float = 0.8):
        self.warning_threshold = warning_threshold

    async def __call__(self, agent, kwargs):
        config = agent._agent_config.running
        threshold = config.memory_compact_threshold

        messages = await agent.memory.get_memory()
        # 估算当前 token 使用
        estimated_tokens = len(str(messages)) // 4

        usage_ratio = estimated_tokens / threshold
        if usage_ratio >= self.warning_threshold:
            logger.warning(
                f"上下文使用率: {usage_ratio:.1%}, "
                f"建议使用 /compact 压缩"
            )
        return None
```

## 7. 常见问题

### Q1: 钩子与装饰器有什么区别？

**A**: 主要区别在于**拦截方式**和**执行时机**：

| 特性 | 钩子 | 装饰器 |
|------|------|--------|
| 拦截方式 | 通过 MRO 覆盖方法 | 包装函数 |
| 执行时机 | 在原方法前后自动触发 | 需要显式调用包装函数 |
| 对内部调用 | 有效（覆盖原方法） | 可能无效（内部调用不走包装） |
| 注册方式 | 实例注册或类注册 | 函数装饰器语法 |

### Q2: 为什么需要重入保护？

**A**: 由于元类的存在，同一个方法可能被多次包装：

```
QwenPawAgent._reasoning  ← 被元类包装
  → ReActAgent._reasoning  ← 也被元类包装
```

如果钩子没有重入保护，在单次 `_reasoning` 调用中可能被触发多次，导致重复执行（如执行两次压缩）。

### Q3: Pre-Hook 返回值有什么意义？

**A**: Pre-Hook 返回值决定是否修改传递给原函数的参数：
- 返回 `None`：不修改，使用原始 kwargs
- 返回 `dict`：替换 kwargs，使用修改后的版本

### Q4: 如何调试钩子执行？

**A**: 可以通过以下方式：
1. 在钩子中添加日志输出
2. 使用 `logger.setLevel(logging.DEBUG)` 启用详细日志
3. 检查钩子执行前后的状态变化

### Q5: 类级别钩子和实例级别钩子的区别？

**A**: 主要区别在于**作用域**和**优先级**：

| 特性 | 类级别钩子 | 实例级别钩子 |
|------|-----------|-------------|
| 作用域 | 所有 Agent 实例 | 特定实例 |
| 注册方式 | `AgentBase.register_class_hook()` | `agent.register_instance_hook()` |
| 执行优先级 | 先执行 | 后执行 |
| 移除方式 | `AgentBase.remove_class_hook()` | `agent.remove_instance_hook()` |

## 8. 注意事项与最佳实践

### 8.1 重入保护

如果钩子可能因元类多层包装而被重复触发，必须添加重入保护：

```python
class MyHook:
    _REENTRANCY_ATTR = "_my_hook_running"

    async def __call__(self, agent, kwargs):
        if getattr(agent, self._REENTRANCY_ATTR, False):
            return None
        setattr(agent, self._REENTRANCY_ATTR, True)
        try:
            # 钩子逻辑
            pass
        finally:
            setattr(agent, self._REENTRANCY_ATTR, False)
        return None
```

### 8.2 错误处理

钩子中的异常不应中断主流程，应使用 try-except 捕获并记录：

```python
async def __call__(self, agent, kwargs):
    try:
        # 可能失败的逻辑
        risky_operation()
    except Exception as e:
        logger.error(f"Hook failed: {e}", exc_info=True)
    return None  # 即使失败也返回 None
```

### 8.3 返回值约定

- **Pre-Hook**: 返回 `None` 表示不修改 kwargs；返回 `dict` 表示使用修改后的 kwargs
- **Post-Hook**: 返回 `None` 表示不修改输出；返回任意值表示使用修改后的输出

### 8.4 钩子顺序

同一类型的多个钩子按注册顺序执行。如果需要特定顺序，可以在单个钩子中组合多个逻辑。

### 8.5 异步注意事项

钩子运行在异步上下文中，必须使用 `await` 处理异步操作。避免在钩子中执行阻塞 I/O。

## 11. 总结

QwenPaw 的钩子系统建立在 AgentScope 框架之上，通过元类自动包装机制，在 Agent 的关键方法（`_reasoning`, `_acting`, `reply` 等）前后自动触发钩子。内置的 `BootstrapHook` 和 `MemoryCompactionHook` 分别处理首次用户引导和上下文窗口管理两个核心场景。

钩子系统的设计遵循以下原则：

1. **无侵入**: 通过注册机制注入，不需要修改核心 Agent 代码
2. **可组合**: 多个钩子可以注册到同一触发点
3. **可控制**: 支持实例级和类级别的注册与移除
4. **安全**: 提供重入保护机制，防止重复执行

开发者可以通过实现自定义钩子，在不修改框架代码的情况下扩展 Agent 的行为，例如添加日志记录、参数修改、输出后处理等功能。
