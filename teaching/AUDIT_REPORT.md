## 五、共性问题汇总

### 1. Java 开发者适配严重不足
- 仅 ~16/78 章有"来自 Java 的你"对照节
- 缺少统一的 Java→Python 概念映射表
- 建议：为所有章节补充 Java 对照，至少包含核心概念对照表

### 2. 格式不统一
- Insight 格式：部分用 `★ Insight ────`，部分用 `> **一句话概述**`，部分无此格式
- Java 对照节位置：有的在末尾，有的在中间，有的在开头
- 建议：制定统一模板，所有章节遵循相同结构

### 3. 代码引用规范不一致
- 06.1 章已做到标注文件路径 + 函数名（最佳实践）
- 其他章节使用伪代码或简化代码，缺少路径标注
- 建议：统一为"函数/类名 + 文件路径"引用，不标注精确行号

### 4. 知识检查题与练习题重叠
- 多章的"知识检查"和"练习题"问了相同的问题
- 建议：知识检查 = 概念题（3 题），练习题 = 实操题（3-6 题），内容不重叠

### 5. 缺失章节打断学习路径
- 编号 16, 24, 36 等被引用但文件不存在
- 建议：补齐或在引用处标注"本章暂缺"
