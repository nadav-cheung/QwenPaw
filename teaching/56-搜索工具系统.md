本章讲解 QwenPaw 的双重搜索体系 -- 文件搜索（grep/glob）和语义记忆搜索，涵盖搜索限制常量、二进制跳过策略、线程化 I/O 设计和强制记忆搜索机制。

## 概述

QwenPaw 提供文件搜索 (grep/glob) 和语义记忆搜索两种搜索工具，文件搜索支持正则和上下文，记忆搜索基于向量/BM25 混合检索。

本章节详细解析搜索工具的使用方法、限制常量、搜索策略，以及两种搜索方式的设计差异。

## 1. 文件搜索工具

源码路径：`src/qwenpaw/agents/tools/file_search.py`

### 1.1 grep_search

```python
# src/qwenpaw/agents/tools/file_search.py:478
async def grep_search(
    pattern: str,
    path: Optional[str] = None,
    is_regex: bool = False,
    case_sensitive: bool = True,
    context_lines: int = 0,
    include_pattern: Optional[str] = None,
) -> ToolResponse:
    """正则搜索

    参数：
    - pattern: 搜索模式（字符串或正则）
    - path: 搜索路径（默认当前工作区）
    - is_regex: 是否为正则表达式
    - case_sensitive: 是否区分大小写
    - context_lines: 上下文行数
    - include_pattern: 文件名过滤（如 *.py）

    返回：
    - 匹配行列表，包含行号和内容
    """
```

**使用示例：**

```python
# 搜索普通字符串
await grep_search(
    pattern="TODO",
    path="/project/src",
)

# 搜索正则表达式
await grep_search(
    pattern=r"func\s+\w+\(",
    path="/project/src",
    is_regex=True,
)

# 带上下文搜索
await grep_search(
    pattern="class Foo",
    context_lines=3,
)
```

### 1.2 glob_search

```python
# src/qwenpaw/agents/tools/file_search.py:579
async def glob_search(
    pattern: str,
    path: Optional[str] = None,
) -> ToolResponse:
    """Glob 模式文件发现

    支持的 glob 模式：
    - **: 匹配任意路径
    - *: 匹配路径分隔符外的任意字符
    - ?: 匹配单个字符
    - [...]: 匹配字符类
    """
```

**使用示例：**

```python
# 查找所有 Python 文件
await glob_search(
    pattern="**/*.py",
    path="/project",
)

# 查找特定目录下的配置文件
await glob_search(
    pattern="src/**/*.config.*",
)
```

## 2. 搜索限制常量

```python
# src/qwenpaw/agents/tools/file_search.py:97
_MAX_MATCHES = 200              # 最大匹配条目
_MAX_FILE_SIZE = 2 * 1024 * 1024  # 2MB，跳过大文件
_MAX_CONTEXT_LINES = 5         # 最大上下文行数
_MAX_OUTPUT_CHARS = 50_000     # ~50KB 输出限制
_MAX_FILES_SCANNED = 10_000   # 最大扫描文件数
_GREP_TIMEOUT = 30              # 秒
_GLOB_TIMEOUT = 15               # 秒
```

| 常量 | 值 | 说明 |
|------|-----|------|
| `_MAX_MATCHES` | 200 | 单次搜索最大匹配数 |
| `_MAX_FILE_SIZE` | 2MB | 跳过大于此大小的文件 |
| `_MAX_CONTEXT_LINES` | 5 | 上下文行数上限 |
| `_MAX_OUTPUT_CHARS` | 50KB | 输出内容上限 |
| `_MAX_FILES_SCANNED` | 10,000 | 最多扫描文件数 |
| `_GREP_TIMEOUT` | 30s | grep 操作超时 |
| `_GLOB_TIMEOUT` | 15s | glob 操作超时 |

**限制目的：**
- 防止恶意超大文件消耗资源
- 限制输出大小，避免内存溢出
- 超时机制防止长时间阻塞

```python
# src/qwenpaw/agents/tools/memory_search.py:7
def create_memory_search_tool(memory_manager):
    async def memory_search(
        query: str,
        max_results: int = 5,
        min_score: float = 0.1,
    ) -> ToolResponse:
        """语义记忆搜索

        参数：
        - query: 查询字符串
        - max_results: 最大返回结果数
        - min_score: 最低相似度分数

        返回：
        - 按相似度排序的记忆片段
        """
        return await memory_manager.memory_search(
            query=query,
            max_results=max_results,
            min_score=min_score,
        )
    return memory_search
```

## 7. 设计模式

### 7.1 线程化阻塞 I/O

```python
# asyncio.to_thread 避免阻塞事件循环
match_lines, status = await asyncio.wait_for(
    asyncio.to_thread(_worker),
    timeout=_GREP_TIMEOUT,
)
```

**原理：**
- 文件 I/O 是阻塞操作
- `asyncio.to_thread()` 将其放到线程池执行
- 事件循环可以继续处理其他任务

### 7.2 取消信号

```python
# 通过 threading.Event 取消
cancel_event = threading.Event()

async def grep_search(...):
    try:
        await asyncio.wait_for(
            asyncio.to_thread(_worker, cancel_event),
            timeout=_GREP_TIMEOUT,
        )
    except asyncio.CancelledError:
        cancel_event.set()  # 通知 worker 取消
        raise
```

**取消流程：**
- `CancelledError` 捕获
- 设置取消事件
- Worker 检查事件并提前返回

### 7.3 截断消息

```python
# 结果截断时添加消息
if len(results) >= _MAX_MATCHES:
    message += f"\n[Results truncated at {_MAX_MATCHES} matches]"
```

## 9. 常见问题

### Q1: 搜索结果为空？

**可能原因：**
1. 路径不存在
2. 模式无匹配
3. 文件被二进制/目录过滤

**排查步骤：**

```python
# 1. 确认路径存在
import os
assert os.path.exists("/project/src")

# 2. 尝试宽松搜索
await grep_search(pattern=".", path="/project/src")  # 搜索所有

# 3. 检查过滤规则
print(_SKIP_DIRS)  # 确认没有被跳过
print(_BINARY_EXTENSIONS)  # 确认不是二进制
```

### Q2: 搜索超时？

**原因：** 搜索范围太大或文件太多。

**解决：**

```python
# 1. 缩小搜索路径
await grep_search(pattern="TODO", path="/project/src/utils")

# 2. 使用 include_pattern 过滤文件类型
await grep_search(pattern="TODO", include_pattern="*.py")

# 3. 减少超时时间（不推荐，可能截断结果）
```

### Q3: 记忆搜索分数低？

**原因：** 查询与记忆内容语义不匹配。

**解决：**

```python
# 1. 降低 min_score 阈值
await memory_search(query="...", min_score=0.1)

# 2. 增加 max_results 获取更多候选
await memory_search(query="...", max_results=10)

# 3. 使用更具体的查询词
```

### Q4: 正则表达式不工作？

**常见错误：**

```python
# 错误：未启用正则
await grep_search(pattern=r"\d+", is_regex=False)  # 当作普通字符串

# 正确：启用正则
await grep_search(pattern=r"\d+", is_regex=True)
```

```python
# await grep_search(pattern="TODO", path="/")  # 太慢
```

```python

await grep_search(pattern=r"def \w+\(", is_regex=True)
```

## 11. 总结

### 核心要点

| 要点 | 说明 |
|------|------|
| **双重搜索** | 文件搜索（grep/glob）+ 语义记忆搜索 |
| **文件搜索** | 正则匹配、上下文行、文件名过滤 |
| **记忆搜索** | 向量/BM25 混合检索、相似度排序 |
| **限制保护** | 匹配数、输出大小、文件大小、超时限制 |
| **线程化 I/O** | `asyncio.to_thread` 避免阻塞事件循环 |
| **强制记忆** | 配置开启后每次查询自动搜索记忆 |

### 文件搜索 vs 记忆搜索

| 维度 | 文件搜索 | 记忆搜索 |
|------|----------|----------|
| 目标 | 磁盘文件 | 向量数据库 |
| 算法 | 正则/glob | 向量相似度 + BM25 |
| 用途 | 代码/配置搜索 | 对话上下文增强 |
| 实时性 | 实时（最新文件） | 依赖索引更新 |
