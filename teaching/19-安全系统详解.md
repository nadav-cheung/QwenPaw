# 安全系统详解

## 概述

QwenPaw 的安全系统由三大模块构成：

| 模块 | 路径 | 职责 |
|------|------|------|
| `tool_guard` | `security/tool_guard/` | 工具调用前的安全审查 |
| `secret_store` | `security/secret_store.py` | 敏感数据（API Key、JWT Secret）的加密存储 |
| `skill_scanner` | `security/skill_scanner/` | 技能文件的安全扫描 |

这三个模块相互独立但共享安全设计原则。本章通过源码逐行解析，揭示 QwenPaw 安全架构的设计思路。

## 1. 密钥加密存储 — secret_store.py

### 1.1 设计目标

在 QwenPaw 中，API Key、JWT Secret、环境变量等敏感数据必须加密存储在磁盘上。即便攻击者拿到了文件，也无法解密。核心原则：

- **主密钥不存储在磁盘**（除非用户明确要求）
- **分层密钥管理**：OS Keychain（主密钥）→ 文件加密（数据）
- **优雅降级**：无法访问 Keychain 时降级到文件存储

### 1.2 核心算法：Fernet 对称加密

源码路径：`src/qwenpaw/security/secret_store.py:199-212`

```python
# src/qwenpaw/security/secret_store.py:199
def _get_fernet() -> Fernet:
    """返回缓存的 Fernet 实例（延迟初始化）"""
    global _cached_fernet
    if _cached_fernet is None:
        master_key = _get_master_key()         # 获取 32 字节主密钥
        # Fernet 密钥 = base64(urlsafe_b64encode(master_key[:32]))
        fernet_key = base64.urlsafe_b64encode(master_key[:32])
        _cached_fernet = Fernet(fernet_key)
    return _cached_fernet
```

**加密算法**：Fernet = AES-128-CBC（加密）+ HMAC-SHA256（完整性校验）。这是"认证加密"（Authenticated Encryption），同时提供机密性和完整性保护。

### 1.3 主密钥的获取逻辑 — 四层递进

源码路径：`src/qwenpaw/security/secret_store.py:154-188`

```python
# src/qwenpaw/security/secret_store.py:154
def _get_master_key() -> bytes:
    """主密钥解析：进程缓存 → OS Keychain → 文件 → 生成新密钥"""
    global _cached_master_key

    # 第一层：进程内缓存（最快路径，无需加锁）
    if _cached_master_key is not None:
        return _cached_master_key

    # 第二层：双重检查锁定
    with _master_key_lock:
        if _cached_master_key is not None:       # 再次检查
            return _cached_master_key

        # 第三层：尝试从 OS Keychain 读取
        key_hex = _try_keyring_get()
        if key_hex is None:
            # 第四层：从文件读取
            key_hex = _read_key_file()

        if key_hex is None:
            # 兜底：生成新密钥
            key_hex = _generate_master_key()
            _try_keyring_set(key_hex)           # 优先存 Keychain
            _write_key_file(key_hex)             # 同时写文件作为备份

        _cached_master_key = bytes.fromhex(key_hex)
        return _cached_master_key
```

**关键设计模式：双重检查锁定（Double-Checked Locking）**
- 第一层检查无需加锁（多线程安全的快速路径）
- 第二层检查在锁内（确保只初始化一次）
- 避免每次调用都加锁的性能损失

```python
def encrypt(plaintext: str) -> str:
    """加密字符串，返回 'ENC:<base64密文>' 格式"""
    if not plaintext:                       # 空字符串不加密
        return plaintext
    fernet = _get_fernet()
    ciphertext = fernet.encrypt(plaintext.encode("utf-8"))
    return f"{_ENC_PREFIX}{base64.b64encode(ciphertext).decode('ascii')}"

# src/qwenpaw/security/secret_store.py:222
def decrypt(value: str) -> str:
    """解密：如果是 'ENC:' 前缀则解密，否则直接返回（支持明文迁移）"""
    if not is_encrypted(value):
        return value                       # 明文直接返回
    try:
        fernet = _get_fernet()
        raw = base64.b64decode(value[len(_ENC_PREFIX):])
        plaintext = fernet.decrypt(raw).decode("utf-8")
        return plaintext
    except Exception:
        return value                       # 解密失败返回原值（优雅降级）

# src/qwenpaw/security/secret_store.py:244
def is_encrypted(value: str) -> bool:
    """判断值是否已加密"""
    return bool(value and value.startswith(_ENC_PREFIX))
```

**设计亮点**：
- `ENC:` 前缀使加密数据可识别，同时保持对明文数据的向后兼容
- 解密失败不抛异常，返回原值（防止密钥变更导致程序崩溃）

```python
def encrypt_dict_fields(
    data: dict,
    secret_fields: frozenset[str],
) -> dict:
    """返回浅拷贝，仅对指定字段加密"""
    result = dict(data)

            if not is_encrypted(result[field]):

    return result
```

## 2. 工具守卫系统 — tool_guard

### 2.1 设计目标

当 AI 智能体调用工具（如执行 Shell 命令、读写文件）时，tool_guard 在**执行前**审查工具名称和参数，发现威胁则拦截。核心原则：

- **零信任**：即使工具名看起来无害，参数也可能包含恶意内容
- **分层防御**：三层守卫（文件路径守卫 + 规则正则守卫 + Shell 混淆守卫）互补
- **可审计**：所有拦截都生成结构化报告，可供用户查看和申诉

```python
# src/qwenpaw/security/tool_guard/engine.py:54
class ToolGuardEngine:
    """工具守卫引擎 — 单例模式，延迟初始化"""

    def __init__(
        self,
        guarded_tools: list[str] | None = None,  # None = 守卫所有工具
        denied_tools: list[str] | None = None,
        enabled: bool | None = None,
    ):
        self._guardians: list[BaseToolGuardian] = []
        self._guarded_tools: frozenset[str] | None = None
        self._denied_tools: frozenset[str] = frozenset(denied_tools or [])
        self._enabled = enabled                      # None = 使用配置默认值

        # 注册默认三层守卫
        for guardian in self._default_guardians():
            self.register_guardian(guardian)

    # src/qwenpaw/security/tool_guard/engine.py:85
    def _default_guardians(self) -> list[BaseToolGuardian]:
        """三层默认守卫"""
        return [
            FilePathToolGuardian(),        # 路径守卫（always_run=True）
            RuleBasedToolGuardian(),        # 正则规则守卫
            ShellEvasionGuardian(),         # 混淆检测守卫
        ]

    # src/qwenpaw/security/tool_guard/engine.py:163
    def is_denied(self, tool_name: str) -> bool:
        """检查工具是否被无条件拒绝"""
        return tool_name in self._denied_tools

    # src/qwenpaw/security/tool_guard/engine.py:167
    def is_guarded(self, tool_name: str) -> bool:
        """检查工具是否在守卫范围内（None=守卫所有）"""
        if self._guarded_tools is None:     # None 表示守卫所有
            return True
        return tool_name in self._guarded_tools

    # src/qwenpaw/security/tool_guard/engine.py:177
    def guard(
        self,
        tool_name: str,
        tool_args: dict,
        context: dict,
    ) -> ToolGuardResult:
        """
        对工具调用执行所有适用的守卫，返回聚合结果。

        只有 guarded_tools 列表中的工具会运行普通守卫；
        always_run=True 的守卫对所有工具都运行。
        """
        if self.is_denied(tool_name):
            # 无条件拒绝的工具直接返回拒绝结果
            return ToolGuardResult(
                is_safe=False,
                findings=[
                    GuardFinding(
                        id="denied",
                        category=GuardThreatCategory.UNAUTHORIZED_ACCESS,
                        severity=GuardSeverity.HIGH,
                        title="Tool is explicitly denied",
                        tool_name=tool_name,
                        guardian="engine",
                    )
                ],
            )

        all_findings: list[GuardFinding] = []

        for guardian in self._guardians:
            should_run = (
                guardian.always_run               # always_run 守卫始终运行
                or self.is_guarded(tool_name)      # 或工具在守卫范围内
            )
            if not should_run:
                continue

            findings = guardian.guard(tool_name, tool_args, context)
            all_findings.extend(findings)

        return ToolGuardResult(findings=all_findings)
```

```python
@dataclass
class ToolGuardResult:
    """工具调用的聚合安全检查结果"""
    findings: list[GuardFinding] = field(default_factory=list)

    @property
    def is_safe(self) -> bool:
        """CRITICAL 或 HIGH 发现存在时为 False"""
        return not any(
            f.severity in (GuardSeverity.CRITICAL, GuardSeverity.HIGH)
            for f in self.findings
        )

    @property
    def max_severity(self) -> GuardSeverity | None:
        """最高严重级别"""
        if not self.findings:
            return None
        severity_order = [GuardSeverity.CRITICAL, GuardSeverity.HIGH,
                          GuardSeverity.MEDIUM, GuardSeverity.LOW, GuardSeverity.INFO]
        for sev in severity_order:
            if any(f.severity == sev for f in self.findings):
                return sev
        return None

    def get_findings_by_severity(self, severity: GuardSeverity) -> list[GuardFinding]:
        return [f for f in self.findings if f.severity == severity]
```

### 2.10 第三层守卫：Shell 混淆检测

源码路径：`src/qwenpaw/security/tool_guard/guardians/shell_evasion_guardian.py:499-546`

**职责**：检测通过引号逃逸、注释注入、换行混淆等方式绕过正则检测的攻击

**核心原理**：Shell 中，单引号内的内容**完全不解释**（包括 `$()`、`\`），而双引号内会展开。简单正则可能漏掉引号包裹的恶意内容。

```python
# src/qwenpaw/security/tool_guard/guardians/shell_evasion_guardian.py:61
class _QuoteState:
    """字符级引号状态机 — 跟踪我们当前在单引号、双引号还是无引号区域"""
    def __init__(self):
        self.in_single_quote = False
        self.in_double_quote = False
        self.prev_char: str | None = None

    def feed(self, char: str) -> None:
        """处理一个字符，更新引号状态"""
        if char == "'" and not self.in_double_quote:
            self.in_single_quote = not self.in_single_quote
        elif char == '"' and not self.in_single_quote:
            self.in_double_quote = not self.in_double_quote
        elif char == '\\' and (self.in_double_quote or not self.in_single_quote):
            # 转义字符：下一个字符被转义（跳过）
            self.prev_char = char
            return
        self.prev_char = char

    def is_outside_quotes(self) -> bool:
        """是否在引号外部 — 只有这里的内容才真正被执行"""
        return not self.in_single_quote and not self.in_double_quote
```

```python
        self._check_newlines(command),
        self._check_comment_quote_desync(command),
        self._check_quoted_newline(command),
    ]

    for check_result in checks:
        if check_result:
            findings.extend(check_result)

    return findings
```

## 3. 技能安全扫描 — skill_scanner

### 3.1 设计目标

用户安装的技能（Skill）可能是第三方来源，代码中可能藏有恶意逻辑。skill_scanner 在技能**安装前**扫描代码，发现威胁后阻止安装或发出警告。

**三种模式**：
- `block`：发现威胁则阻止安装
- `warn`：发现威胁仅警告，不阻止
- `off`：关闭扫描

### 3.2 扫描器核心

源码路径：`src/qwenpaw/security/skill_scanner/scanner.py:319`

```python
class SkillScanner:
    """技能安全扫描器 — 编排文件发现、规则匹配、报告生成"""

    def __init__(self, policy: ScanPolicy):
        self.policy = policy
        self._analyzers: list[BaseAnalyzer] = [
            PatternAnalyzer(policy),   # 正则模式分析器
            # 未来可扩展：LLMAnalyzer（LLM 语义分析）、ASTAnalyzer（AST 分析）
        ]

    async def scan(self, skill_path: Path) -> ScanResult:
        """扫描技能目录，返回完整报告"""
        # 1. 验证路径边界（防止 symlink 逃逸）
        resolved = skill_path.resolve()
        if not self._is_within_allowed_dir(resolved):
            return ScanResult(blocked=True, reason="path_traversal")

        # 2. 枚举所有文件（跳过隐藏文件和 policy 排除项）
        files = self._discover_files(skill_path)

        # 3. 对每个分析器运行检查
        all_findings: list[Finding] = []
        for analyzer in self._analyzers:
            findings = await analyzer.analyze(skill_path, files)
            all_findings.extend(findings)

        # 4. 与白名单比对（可信技能跳过）
        if self._is_whitelisted(skill_path, all_findings):
            return ScanResult(whitelisted=True)

        return ScanResult(findings=all_findings, blocked=has_blocking)
```

### 3.4 内容哈希与白名单

源码路径：`src/qwenpaw/security/skill_scanner/__init__.py:122`

```python
# src/qwenpaw/security/skill_scanner/__init__.py:122
def compute_skill_content_hash(skill_dir: Path) -> str:
    """计算 skill_dir 中所有常规文件内容的 SHA-256 哈希（排序后）。"""
    h = hashlib.sha256()
    try:
        for p in sorted(skill_dir.rglob("*")):
            if p.is_file() and not p.is_symlink():
                try:
                    h.update(p.read_bytes())
                except OSError:
                    pass
    except OSError:
        pass
    return h.hexdigest()
```

**白名单验证**：当白名单条目有非空 `content_hash` 时，必须与当前目录内容匹配才生效。

```python
# src/qwenpaw/security/skill_scanner/__init__.py:142
def is_skill_whitelisted(skill_name, skill_dir=None, *, cfg=None) -> bool:
    """如果 skill_name 在白名单中则返回 True。"""
    if cfg is None:
        cfg = _load_scanner_config()
    for entry in cfg.whitelist:
        if entry.skill_name != skill_name:
            continue
        if not entry.content_hash:
            return True
        if skill_dir is not None:
            current_hash = compute_skill_content_hash(skill_dir)
            if current_hash == entry.content_hash:
                return True
    return False
```

### 3.6 扫描结果缓存

源码路径：`src/qwenpaw/security/skill_scanner/__init__.py:335`

```python
# 最大缓存条目数
_MAX_CACHE_ENTRIES = 64
_scan_cache: dict[str, tuple[float, ScanResult]] = {}

def _get_cached_result(skill_dir: Path) -> ScanResult | None:
    """如果目录未更改则返回缓存的 ScanResult。"""
    key = str(skill_dir)
    entry = _scan_cache.get(key)
    if entry is None:
        return None
    cached_mtime, cached_result = entry
    current_mtime = _get_dir_mtime(skill_dir)
    if current_mtime == cached_mtime:
        return cached_result
    return None

def _store_cached_result(skill_dir: Path, result: ScanResult) -> None:
    """存储扫描结果到缓存（LRU 驱逐）。"""
    key = str(skill_dir)
    mtime = _get_dir_mtime(skill_dir)
    _scan_cache[key] = (mtime, result)
    while len(_scan_cache) > _MAX_CACHE_ENTRIES:
        oldest = next(iter(_scan_cache))
        del _scan_cache[oldest]
```

**缓存策略**：基于 mtime 的缓存，同一目录在文件未修改时返回缓存结果，最多 64 个条目。

## 4. 安全系统的架构设计思维

### 4.1 纵深防御（Defense in Depth）

tool_guard 的三层守卫体现了纵深防御思想：

```
第1层（FilePathToolGuardian）
  保护范围：文件系统级别
  绕过难度：低（攻击者只需避免访问已知敏感路径）

第2层（RuleBasedToolGuardian）
  保护范围：命令行参数级别
  绕过难度：中（需要构造不触发任何正则的模式）

第3层（ShellEvasionGuardian）
  保护范围：语义级别（引号状态、命令替换、混淆）
  绕过难度：高（即便躲过正则，也难以躲过结构分析）
```

**架构启示**：不要依赖单一安全层。每一层都应该能够独立拦截常见攻击，同时层间互补。

### 4.2 插件化架构（Plugin Architecture）

BaseToolGuardian 是简单的 ABC，定义了最小接口：

```python
class BaseToolGuardian(ABC):
    @abstractmethod
    async def guard(self, tool_name, params, context) -> list[GuardFinding]: ...
```

这意味着未来可以**热插拔**新型守卫：

- `LLMAsJudgeToolGuardian`：用另一个 LLM 判断工具调用是否安全
- `ASTAnalyzerToolGuardian`：用抽象语法树分析而非正则
- `NetworkMonitorToolGuardian`：监控工具是否发起异常网络请求

**架构启示**：在系统边界定义清晰的接口协议，允许未来扩展而不修改核心代码。

### 4.3 认证加密优于普通加密

secret_store 使用 Fernet（AEAD）而非原始 AES。AEAD 的优势：

- 加密和完整性校验一步完成，无法移除校验而保持加密
- 攻击者无法在不知道密钥的情况下修改密文

**架构启示**：在存储安全场景，始终使用认证加密（AEAD），而非裸 AES-CBC。

### 4.4 零信任工具调用

tool_guard 不信任任何工具调用，即便工具名称看起来无害。这是"最小权限"原则的体现：

- 默认拒绝，只放行明确安全的调用
- 高风险工具（如 `execute_shell_command`）默认在 guarded_tools 列表中
- 即使是读取文件操作，也可能通过路径穿越漏洞访问敏感文件

### 4.5 优雅降级

secret_store 的设计在各种环境下都能工作：

| 环境 | 主密钥存储 | 原因 |
|------|-----------|------|
| macOS（有 Keychain） | OS Keychain | 最安全 |
| Linux（有 GUI） | OS Keychain | keyring 库支持 |
| Linux（无 GUI 服务器） | 文件（0o600） | Keychain 不可用 |
| Docker 容器 | 文件 | 容器共享宿主机 Keychain 不合适 |
| CI 环境 | 文件 | CI 通常无 Keychain 访问 |

**架构启示**：考虑所有可能的部署环境，为每种环境设计fallback路径，而不是假设"它总会在我的环境中运行"。

## 8. 总结

### 核心要点

1. **secret_store 密钥加密**: Fernet 对称加密（AEAD）+ 四层主密钥获取 + OS Keychain 优先
2. **tool_guard 三层守卫**: FilePathToolGuardian + RuleBasedToolGuardian + ShellEvasionGuardian
3. **skill_scanner 技能扫描**: block/warn/off 三种模式 + PatternAnalyzer 正则分析
4. **纵深防御**: 每层独立拦截，层间互补，不过度依赖单一安全层
5. **认证加密**: Fernet = AES-128-CBC + HMAC-SHA256，提供机密性和完整性

### 关键设计模式

| 模式 | 应用 | 优势 |
|------|------|------|
| 双重检查锁定 | 主密钥获取 | 线程安全 + 性能优化 |
| 零信任 | 工具守卫 | 最小权限，默认拒绝 |
| 优雅降级 | 密钥存储 | 全环境兼容 |
| 插件化架构 | 工具守卫 | 未来可扩展 |

### 故障排查流程

```
工具守卫拦截了合法操作
    │
    ├─► 检查 findings 详情: 日志中 GuardFinding 信息
    │
    ├─► 禁用特定规则: config.json security.tool_guard.disabled_rules
    │
    └─► 调整阈值: min_score 参数

密钥解密失败
    │
    ├─► 检查密钥文件: ls -la ~/.qwenpaw/.secret/.master_key
    │
    ├─► 恢复备份密钥: 从 .bak 备份恢复
    │
    └─► 重新初始化: 删除密钥文件，系统会自动生成新密钥（但旧数据无法解密）

技能扫描阻止安装
    │
    ├─► 查看扫描报告: 日志中的 ScanResult
    │
    ├─► 添加到白名单: config.json security.skill_scanner.whitelist
    │
    └─► 降低扫描模式: "block" → "warn" → "off"
```
