# 配置热重载机制

## 概述

QwenPaw 通过 **AgentConfigWatcher** 实现配置热重载，监控 `agent.json` 的 mtime 变化，支持渠道、心跳、记忆任务的零停机更新。配合 MCPConfigWatcher 实现 MCP 客户端的热重载。

```python
def _heartbeat_hash(hb: Optional[HeartbeatConfig]) -> int:
    """心跳配置的哈希，用于变更检测。"""
    if hb is None:
        return hash("None")
    return hash(str(hb.model_dump(mode="json")))

# src/qwenpaw/app/agent_config_watcher.py:35
def _memory_job_hash(memory_summary: Optional[Any]) -> int:
    """记忆任务配置的哈希，用于变更检测。"""
    if memory_summary is None:
        return hash("None")
    cron_expr = getattr(memory_summary, "dream_cron", "")
    return hash(str(cron_expr))
```

**用途**：通过哈希比较快速检测配置是否变更，避免深比较的性能损失。

```python
async def _poll_loop(self) -> None:
    """主轮询循环"""
    while True:
        try:
            await asyncio.sleep(self._poll_interval)  # 默认 2.0s
```

```python
# src/qwenpaw/app/agent_config_watcher.py:288
async def _check(self) -> None:
    """检查配置变更并在需要时重载"""
    try:
        mtime = self._config_path.stat().st_mtime  # 检查文件 mtime
    except FileNotFoundError:
        return

    if mtime == self._last_mtime:  # 无变更
        return

    self._last_mtime = mtime  # 更新 mtime

    try:
        agent_config = load_agent_config(self._agent_id)  # 重载配置
    except Exception:
        logger.exception(...)
        return
```

## 3. 渠道热重载

### 3.1 _apply_channel_changes

```python
# src/qwenpaw/app/agent_config_watcher.py:191
async def _apply_channel_changes(self, agent_config: Any) -> None:
    """diff 渠道并重载变更的渠道"""
    if not agent_config.channels:
        return

    new_hash = self._channels_hash(agent_config.channels)
    if new_hash == self._last_channels_hash:  # 无变更
        return

    # 遍历可用渠道，检测变更
    for name in get_available_channels():
        new_ch = getattr(new_channels, name, None)
        old_ch = getattr(old_channels, name, None)
        new_dump = self._channel_dump(new_ch)
        old_dump = self._channel_dump(old_ch)
        if new_dump != old_dump:
            await self._reload_one_channel(name, new_ch, new_channels, old_ch)
```

### 3.2 单渠道重载

```python
# src/qwenpaw/app/agent_config_watcher.py:162
async def _reload_one_channel(
    self, name: str, new_ch: Any, new_channels: Any, old_ch: Any
) -> None:
    """重载单个渠道，失败时回退"""
    try:
        old_channel = await self._channel_manager.get_channel(name)
        new_channel = old_channel.clone(new_ch)  # 用新配置克隆
        await self._channel_manager.replace_channel(new_channel)
        logger.info(f"channel '{name}' reloaded")
    except Exception:
        logger.exception(f"failed to reload channel '{name}'")
        setattr(new_channels, name, old_ch)  # 失败时回退
```

### 3.3 ChannelManager.replace_channel

```python
# src/qwenpaw/app/channels/manager.py:704
async def replace_channel(self, new_channel: BaseChannel) -> None:
    """按名称替换单个渠道"""
    # 1) 在锁外启动新渠道（可能较慢）
    await new_channel.start()

    # 2) 在锁内交换 + 停止旧渠道
    async with self._lock:
        for i, ch in enumerate(self.channels):
            if ch.channel == new_channel.channel:
                self.channels[i] = new_channel  # 原子替换
                await old_channel.stop()  # 优雅停止
```

## 4. 心跳热重载

### 4.1 _apply_heartbeat_change

```python
# src/qwenpaw/app/agent_config_watcher.py:231
async def _apply_heartbeat_change(self, agent_config: Any) -> None:
    """更新心跳哈希并在变更时重新调度"""
    new_hb_hash = _heartbeat_hash(agent_config.heartbeat)
    if new_hb_hash != self._last_heartbeat_hash:
        self._last_heartbeat_hash = new_hb_hash
        try:
            await self._cron_manager.reschedule_heartbeat()
            logger.info("heartbeat rescheduled")
        except Exception:
            logger.exception("failed to reschedule heartbeat")
```

### 4.2 CronManager.reschedule_heartbeat

```python
# src/qwenpaw/app/crons/manager.py:179
async def reschedule_heartbeat(self) -> None:
    """重载心跳配置并更新或移除心跳任务"""
    async with self._lock:
        hb = get_heartbeat_config(self._agent_id)  # 重载配置

        # 移除现有心跳任务
        if self._scheduler.get_job(HEARTBEAT_JOB_ID):
            self._scheduler.remove_job(HEARTBEAT_JOB_ID)

        # 如果启用则添加心跳任务
        if getattr(hb, "enabled", False):
            trigger = self._build_heartbeat_trigger(hb.every)
            self._scheduler.add_job(
                self._heartbeat_callback,
                trigger=trigger,
                id=HEARTBEAT_JOB_ID,
                replace_existing=True,
            )
```

## 8. 完整热重载流程

```
agent.json 变更（mtime 更新）
    ↓
AgentConfigWatcher._poll_loop() [2.0s 轮询]
    ↓
AgentConfigWatcher._check() [mtime 变更检测]
    ↓
load_agent_config() [重新加载配置]
    ↓
_apply_channel_changes() [哈希 diff]
    ↓
_reload_one_channel() [克隆 + 替换]
    ↓
ChannelManager.replace_channel() [原子交换]
    ↓
channel.start() / channel.stop() [生命周期]
```

## 9. 应用场景

### 9.1 Telegram Bot Token 轮换

**场景**：Telegram Bot Token 过期，需要更新而不重启服务。

**流程**：
1. 修改 `agent.json` 中的 `channels.telegram.token`
2. mtime 变化触发 `_check()`
3. `_apply_channel_changes()` 检测到变更
4. `_reload_one_channel()` 克隆并替换渠道
5. 新 Token 立即生效，无需重启

### 9.2 心跳频率调整

**场景**：修改心跳间隔从 60 秒到 30 秒。

**流程**：
1. 修改 `agent.json` 中的 `heartbeat.every`
2. `_apply_heartbeat_change()` 检测到哈希变化
3. `CronManager.reschedule_heartbeat()` 重建调度任务
4. 新频率立即生效

### 9.3 禁用/启用渠道

**场景**：临时禁用 Discord 渠道。

**流程**：
1. 在 `agent.json` 中设置 `channels.discord.enabled: false`
2. 热重载检测变更
3. 渠道优雅停止，不再接收消息

## 11. 常见问题

### Q1: 配置变更未检测到？

**排查**：
1. 确认 `agent.json` 文件的 mtime 确实变化
2. 检查 `AgentConfigWatcher` 是否启动
3. 确认 `poll_interval` 不是过大值
4. 查看 watcher 日志

### Q2: 渠道重载失败？

**常见原因**：
1. 新配置格式错误
2. 新渠道凭证无效
3. 网络连接问题

**解决方案**：查看错误日志确认失败原因，配置回退到旧值。

### Q3: 热重载影响正在处理的消息？

**说明**：不会。热重载只影响后续消息，已在队列中的消息继续处理。

### Q4: 如何强制触发热重载？

**方式**：
1. 手动更新 `agent.json` 的 mtime：`touch agent.json`
2. 调用 `/daemon reload-config` 命令

### Q5: 部分配置更新未生效？

**排查**：
1. 确认变更的部分有对应的热重载处理（如渠道、心跳）
2. 某些配置可能需要完整重启才能生效
3. 检查 `_apply_*` 方法是否覆盖该配置项

## 12. 设计模式总结

### 12.1 mtime 变更检测

```python

    return  # 无变更
```

**优势**：无需解析文件内容，仅比较时间戳。

### 12.2 哈希快速拒绝

```python
new_hash = self._channels_hash(agent_config.channels)
if new_hash == self._last_channels_hash:
    return  # 无变更
```

**优势**：哈希比较 O(1)，避免深比较。

### 12.3 锁外启动

```python

await new_channel.start()
```

**优势**：最小化锁持有时间。
