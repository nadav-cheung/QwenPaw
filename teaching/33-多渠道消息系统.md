# 多渠道消息系统 (Channels)

多渠道消息系统允许 QwenPaw 通过不同平台接收和发送消息，包括 Telegram、Discord、飞书、钉钉等。

### 入队 (行 50-180)

```python
class UnifiedQueueManager:
    """Unified queue manager for all channels and priorities."""

    async def enqueue(
        self,
        channel_id: str,
        session_id: str,
        priority_level: int,
        payload: Any,
    ) -> None:
        """Enqueue a message for processing."""
        queue_key = (channel_id, session_id, priority_level)
        state = await self._get_or_create_queue(queue_key)
        await asyncio.wait_for(state.queue.put(payload), timeout=30.0)
```

## 消息流程

```
外部消息 → Channel Handler (解析)
    → native payload {channel_id, sender_id, content_parts, meta}
    → ChannelManager.enqueue()
    → UnifiedQueueManager.enqueue() [按 QueueKey 路由]
    → _consume_queue() [消费]
    → _process_batch() [批量合并]
    → _consume_one_request()
    → _process() [Agent处理]
    → send_content_parts() [渲染]
    → send() [渠道发送]
```

## TelegramChannel 示例

**文件**: `src/qwenpaw/app/channels/telegram/channel.py`

```python
class TelegramChannel(BaseChannel):
    channel = "telegram"
    uses_manager_queue = True

    async def send(self, to_handle: str, text: str, meta: Optional[dict] = None) -> None:
        """Send text to chat_id."""
        chat_id = meta.get("chat_id") or to_handle
        chunks = self._chunk_text(text)
        for chunk in chunks:
            html_chunk = markdown_to_telegram_html(chunk)
            await bot.send_message(
                chat_id=chat_id,
                text=html_chunk,
                parse_mode=ParseMode.HTML,
            )
```

## Session ID 解析

**文件**: `src/qwenpaw/app/channels/base.py:320-335`

```python
def resolve_session_id(
    self,
    sender_id: str,
    channel_meta: Optional[Dict[str, Any]] = None,
) -> str:
    """Map sender and optional channel meta to session_id."""
    return f"{self.channel}:{sender_id}"
```

各渠道可覆盖，如 Telegram 返回 `telegram:{chat_id}`
