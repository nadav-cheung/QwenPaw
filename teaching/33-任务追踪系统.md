# 任务追踪系统

## 概述

TaskTracker 是 QwenPaw 中**每个 Workspace 独立**的任务管理系统，负责追踪后台运行任务、支持流式传输重连和多订阅者场景。通过 `attach_or_start` 模式实现任务的.attach_or_Start 或重新加入。

```python
class TaskTracker:
    """每个 Workspace 的任务追踪器: run_key -> RunState

    所有 _runs 的变更都在 _lock 保护下进行。
    生产者在 lock 下广播。订阅者使用无界 per-connection 队列；
    断开连接时通过 :meth:`detach_subscriber` 移除。

        self._lock = asyncio.Lock()
        self._runs: dict[str, _RunState] = {}
```

## 2. attach_or_start 模式

源码路径：`src/qwenpaw/app/runner/task_tracker.py:198`

### 2.1 核心方法

```python
# src/qwenpaw/app/runner/task_tracker.py:198
async def attach_or_start(
    self,
    run_key: str,
    payload: Any,
    stream_fn: Callable[..., Coroutine],
) -> tuple[asyncio.Queue, bool]:
    """附加到现有运行或启动新运行。

    返回 (queue, is_new_run)。
    """
    async with self._lock:
        state = self._runs.get(run_key)
        if state is not None and not state.task.done():
            # 附加：现有运行 — 添加订阅者队列，回放缓冲区
            q: asyncio.Queue = asyncio.Queue()
            for sse in state.buffer:
                q.put_nowait(sse)
            state.queues.append(q)
            return q, False

        # 启动：新运行
        my_queue: asyncio.Queue = asyncio.Queue()
        run = _RunState(
            task=asyncio.Future(),
            queues=[my_queue],
            buffer=[],
        )
        self._runs[run_key] = run

        tracker_ref = weakref.ref(self)

        async def _producer() -> None:
            try:
                async for sse in stream_fn(payload):
                    tracker = tracker_ref()
                    if tracker is None:
                        return
                    async with tracker.lock:
                        run.buffer.append(sse)
                        for q in run.queues:
                            q.put_nowait(sse)
            except asyncio.CancelledError:
                ...
            finally:
                ...

        run.task = asyncio.create_task(_producer())
        return my_queue, True
```

### 2.2 关键行为

| 场景 | 行为 |
|------|------|
| **附加到现有** | `run_key` 存在且任务未完成，创建订阅者队列，填充事件缓冲区 |
| **启动新运行** | 创建新的 `_RunState`，生成 `_producer()` 任务，存储在 `run.task` |

### 2.3 弱引用模式

```python
tracker_ref = weakref.ref(self)
```

使用弱引用避免 tracker 被销毁时的内存泄漏。

```python
async def request_stop(self, run_key: str) -> bool:
    """取消运行。如果正在运行则返回 True"""
    async with self._lock:
        state = self._runs.get(run_key)
        if state is None or state.task.done():
            return False
        state.task.cancel()
        return True
```

### 3.4 stream_from_queue

```python
# src/qwenpaw/app/runner/task_tracker.py:266
async def stream_from_queue(
    self,
    queue: asyncio.Queue,
    run_key: str,
) -> AsyncGenerator[str, None]:
    """Yield SSE strings from *queue* until the sentinel ``None``.

    Always detaches *queue* from *run_key* when this stream ends or is
    closed (including client disconnect), so reconnects do not leak queues.
    """
    try:
        while True:
            try:
                event = await queue.get()
                if event is _SENTINEL:
                    break
                yield event
            except asyncio.CancelledError:
                break
    finally:
        await self.detach_subscriber(run_key, queue)
```

## 7. 任务附件模型流程

```
1. attach_or_start(run_key, payload, stream_fn)
       │
       ├── run_key 存在且未完成 → 附加到现有
       │     返回 (queue, False)
       │
       └── run_key 不存在或已完成 → 启动新运行
             创建 _RunState
             生成 _producer() 后台任务
             返回 (queue, True)

2. 如果 is_new=True:
       消费者从 queue 迭代事件
       事件同时写入 buffer 和所有订阅者队列

3. 同一 run_key 的新请求:
       附加到现有（不回放 buffer）
       防止重复处理
```

## 8. 应用场景

### 8.1 WebSocket 重连恢复

**场景**：用户通过 WebSocket 接收流式响应，网络断开后重连。

**实现**：
1. 首次连接：`attach_or_start(run_key, payload, stream_fn)` 返回 `(queue, True)`
2. 事件写入 `state.buffer` 缓冲区
3. 断开时保留 `state`（任务继续运行）
4. 重连时：`attach_or_start(run_key, payload, stream_fn)` 返回 `(queue, False)`
5. 缓冲区内容立即回放给新订阅者
6. 后续事件继续实时推送

### 8.2 多订阅者场景

**场景**：同一任务需要同时推送给多个消费者（如监控面板 + 日志记录）。

**实现**：
```python
# 订阅者 1
queue1, is_new = await tracker.attach_or_start(run_key, payload, stream_fn)

# 订阅者 2（同一 run_key）
queue2, is_new = await tracker.attach_or_start(run_key, payload, stream_fn)
# is_new=False，附加到现有订阅者队列

# 事件自动广播到所有队列
async with tracker.lock:
    run.buffer.append(sse)
    for q in run.queues:
        q.put_nowait(sse)
```

### 8.3 任务取消

**场景**：用户发送 `/stop` 命令取消正在运行的任务。

**实现**：
```python
# StopHandler 中
stopped = await workspace.task_tracker.request_stop(chat_id)
if stopped:
    # 任务已取消，通知订阅者
    ...
```

### 8.4 外部任务注册

**场景**：非智能体任务（如定时任务）需要纳入追踪。

**实现**：
```python
# 注册外部任务
await task_tracker.register_external_task(run_key)

# 外部任务运行
async def external_task():
    for item in work:
        tracker.stream_from_queue(queue, run_key)
```

## 10. 常见问题

### Q1: 任务完成后缓冲区不清理？

**原因**：缓冲区仅在新订阅者附加时消费，任务完成后仍保留。

**解决方案**：可通过配置定期清理或在任务完成时主动清理。

### Q2: 附加到已完成的任务？

**行为**：`attach_or_start` 检测到 `state.task.done()` 为 True，会启动新任务而非附加。

### Q3: 多个订阅者事件顺序不一致？

**原因**：不同订阅者的队列可能处于不同消费进度。

**说明**：这是预期行为，每个订阅者独立消费缓冲区副本。

### Q4: 任务取消后仍有事件推送？

**排查**：
1. 确认 `request_stop()` 返回 `True`（任务存在且成功取消）
2. 检查 `CancelledError` 处理逻辑
3. 确认 `task.cancel()` 后任务确实停止

### Q5: 内存泄漏？

**可能原因**：
1. 订阅者断开但未调用 `detach_subscriber`
2. 缓冲区无限增长
3. 弱引用失效（tracker 被强引用持有）

**排查**：
```python
# 检查活跃任务数
active_count = sum(1 for s in tracker._runs.values() if not s.task.done())

# 检查订阅者总数
subscriber_count = sum(len(s.queues) for s in tracker._runs.values())
```

### 练习 1：实现任务超时监控

**目标：** 为长时间运行的任务设置超时自动取消。

```python
import asyncio
from qwenpaw.app.runner.task_tracker import TaskTracker

class TimeoutMonitor:
    """任务超时监控器"""

    def __init__(self, tracker: TaskTracker, default_timeout: float = 300.0):
        self.tracker = tracker
        self.default_timeout = default_timeout
        self.timeouts: dict[str, asyncio.Task] = {}

    async def watch_task(self, run_key: str, timeout: float = None):
        """监视任务并在超时后取消"""
        timeout = timeout or self.default_timeout

        async def _watch():
            await asyncio.sleep(timeout)
            # 检查任务是否仍在运行
            if await self.tracker.has_active_tasks():
                # 检查特定 run_key
                async with self.tracker._lock:
                    state = self.tracker._runs.get(run_key)
                    if state and not state.task.done():
                        print(f"Task {run_key} timed out after {timeout}s")
                        await self.tracker.request_stop(run_key)

        self.timeouts[run_key] = asyncio.create_task(_watch())

    def cancel_watch(self, run_key: str):
        """取消对特定任务的超时监视"""
        if run_key in self.timeouts:
            self.timeouts[run_key].cancel()
            del self.timeouts[run_key]

# 使用
monitor = TimeoutMonitor(tracker, default_timeout=60.0)
queue, is_new = await tracker.attach_or_start(run_key, payload, stream_fn)
if is_new:
    await monitor.watch_task(run_key)
```

### 练习 2：实现任务进度跟踪

**目标：** 跟踪任务的执行进度百分比。

```python
from dataclasses import dataclass
from typing import Optional

@dataclass
class TaskProgress:
    """任务进度跟踪"""
    total: int
    current: int
    status: str = "running"
    message: str = ""

    @property
    def percent(self) -> float:
        if self.total == 0:
            return 0.0
        return (self.current / self.total) * 100

class ProgressTracker:
    """通过缓冲区事件跟踪进度"""

    def __init__(self, tracker: TaskTracker):
        self.tracker = tracker
        self.progress: dict[str, TaskProgress] = {}

    async def track(self, run_key: str, queue: asyncio.Queue):
        """跟踪任务进度"""
        async for event in self.tracker.stream_from_queue(queue, run_key):
            # 解析 SSE 事件中的进度信息
            if event.startswith("data: "):
                data = event[6:]  # 去掉 "data: " 前缀
                if "progress" in data:
                    # 更新进度
                    self.progress[run_key] = self._parse_progress(data)
            yield event  # 继续传递事件

    def _parse_progress(self, data: str) -> TaskProgress:
        """从事件数据解析进度"""
        import json
        try:
            obj = json.loads(data)
            return TaskProgress(
                total=obj.get("total", 100),
                current=obj.get("current", 0),
                status=obj.get("status", "running"),
                message=obj.get("message", "")
            )
        except json.JSONDecodeError:
            return TaskProgress(total=100, current=0)
```

### 练习 3：实现多任务协调器

**目标：** 协调多个并行任务，等待所有完成。

```python
import asyncio

class MultiTaskCoordinator:
    """多任务协调器"""

    def __init__(self, tracker: TaskTracker):
        self.tracker = tracker
        self.tasks: dict[str, asyncio.Queue] = {}

    async def start_tasks(
        self,
        tasks: list[tuple[str, Any, Callable]]
    ) -> dict[str, bool]:
        """启动多个任务，返回每个任务是否新启动"""
        results = {}

        for run_key, payload, stream_fn in tasks:
            queue, is_new = await self.tracker.attach_or_start(
                run_key, payload, stream_fn
            )
            self.tasks[run_key] = queue
            results[run_key] = is_new

        return results

    async def wait_all(self, timeout: float = 300.0) -> bool:
        """等待所有任务完成"""
        return await self.tracker.wait_all_done(timeout=timeout)

    async def cancel_all(self):
        """取消所有运行中的任务"""
        async with self.tracker._lock:
            for run_key in list(self.tracker._runs.keys()):
                await self.tracker.request_stop(run_key)

    async def stream_all(self) -> dict[str, AsyncGenerator]:
        """返回所有任务的流式生成器"""
        streams = {}
        for run_key, queue in self.tasks.items():
            streams[run_key] = self.tracker.stream_from_queue(queue, run_key)
        return streams
```

### 练习 4：实现任务重试机制

**目标：** 失败任务自动重试。

```python
import asyncio

class RetryableTaskTracker:
    """支持自动重试的任务追踪器"""

    def __init__(
        self,
        tracker: TaskTracker,
        max_retries: int = 3,
        retry_delay: float = 1.0,
    ):
        self.tracker = tracker
        self.max_retries = max_retries
        self.retry_delay = retry_delay
        self.retry_counts: dict[str, int] = {}

    async def attach_or_start_with_retry(
        self,
        run_key: str,
        payload: Any,
        stream_fn: Callable,
    ):
        """附加或启动任务，失败时自动重试"""
        retry_count = self.retry_counts.get(run_key, 0)

        while retry_count < self.max_retries:
            queue, is_new = await self.tracker.attach_or_start(
                run_key, payload, stream_fn
            )

            if not is_new:
                return queue, False  # 附加到现有任务，不需要重试

            try:
                # 等待任务完成
                async for _ in self.tracker.stream_from_queue(queue, run_key):
                    pass
                # 成功完成
                self.retry_counts[run_key] = 0
                return queue, True

            except Exception as e:
                retry_count += 1
                self.retry_counts[run_key] = retry_count

                if retry_count >= self.max_retries:
                    raise RuntimeError(
                        f"Task {run_key} failed after {self.max_retries} retries"
                    ) from e

                # 等待后重试
                await asyncio.sleep(self.retry_delay * retry_count)
                # 重新创建任务
                payload = self._prepare_retry_payload(payload)

        return queue, True  # 不应该到达这里
```

### 练习 5：实现任务优先级调度

**目标：** 实现不同优先级的任务调度。

```python
from enum import IntEnum

class Priority(IntEnum):
    CRITICAL = 0  # 紧急命令
    HIGH = 10      # 高优先级
    NORMAL = 20    # 普通
    LOW = 30       # 低优先级

class PriorityTaskTracker:
    """支持优先级的任务追踪器"""

    def __init__(self):
        self.tracker = TaskTracker()
        self.priority_queues: dict[Priority, list] = {p: [] for p in Priority}

    async def enqueue_priority(
        self,
        run_key: str,
        payload: Any,
        stream_fn: Callable,
        priority: Priority = Priority.NORMAL,
    ):
        """按优先级入队"""
        self.priority_queues[priority].append((run_key, payload, stream_fn))

    async def process_all(self):
        """按优先级顺序处理所有任务"""
        for priority in sorted(Priority):  # 从低数值（高优先级）到高数值
            queue, is_new = await self.tracker.attach_or_start(
                run_key, payload, stream_fn
            )
            if is_new:
                async for _ in self.tracker.stream_from_queue(queue, run_key):
                    pass
```
