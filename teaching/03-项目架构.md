# 项目架构

## 整体架构

```
┌─────────────────────────────────────────────────────────┐
│                      Web Console                         │
│                   (Vue.js + Vite)                       │
└─────────────────────┬───────────────────────────────────┘
                      │ HTTP/WebSocket
┌─────────────────────▼───────────────────────────────────┐
│                     FastAPI Server                       │
│                    (Uvicorn + anyio)                    │
├──────────┬──────────┬──────────┬──────────┬────────────┤
│  Agents  │ Channels │ Providers│  Skills  │   Security │
└──────────┴──────────┴──────────┴──────────┴────────────┘
```

## 核心模块详解

### 1. 入口与初始化 (`src/qwenpaw/__init__.py`)

包初始化流程：
1. 加载环境变量 (`load_envs_into_environ`)
2. 设置日志系统 (`setup_logger`)
3. 支持 `QWENPAW_*` 和 `COPAW_*` 两种环境变量前缀（向后兼容）

关键常量：
- `WORKING_DIR`: `~/.qwenpaw`（可配置）
- `SECRET_DIR`: `~/.qwenpaw/.secret`（敏感数据存储）
- `CONFIG_FILE`: `config.json`（主配置）

### 2. 常量定义 (`src/qwenpaw/constant.py`)

重要配置项：

| 常量 | 默认值 | 说明 |
|------|--------|------|
| `WORKING_DIR` | `~/.qwenpaw` | 工作目录 |
| `SECRET_DIR` | `~/.qwenpaw/.secret` | 密钥存储目录 |
| `MEMORY_DIR` | `~/.qwenpaw/memory` | 记忆存储目录 |
| `LLM_MAX_CONCURRENT` | 10 | 最大并发 LLM 调用数 |
| `LLM_MAX_QPM` | 600 | 每分钟最大请求数 |
| `LLM_RATE_LIMIT_PAUSE` | 5.0s | 限流暂停时间 |
| `TOOL_GUARD_APPROVAL_TIMEOUT_SECONDS` | 600s | 工具守卫审批超时 |

## 核心模块

### 1. Agents 模块 (`src/qwenpaw/agents/`)

智能体核心实现，包含：
- `QwenPawAgent` - 主智能体类（继承自 `ReActAgent` + `ToolGuardMixin`）
- `tools/` - 内置工具集（Shell、FileIO、BrowserControl 等）
- `skills/` - 内置技能（17 个双语技能）
- `memory/` - 记忆管理（AgentMdManager、ReMeLightMemoryManager、主动记忆）
- `acp/` - 智能体通信协议
- `mission/` - 任务模式（自主迭代任务）
- `hooks/` - 生命周期钩子（BootstrapHook、MemoryCompactionHook）

#### QwenPawAgent 核心机制

**类继承链：**
```python
QwenPawAgent → ToolGuardMixin → ReActAgent
```

**初始化流程：**
1. `_create_toolkit()` - 注册内置工具（execute_shell_command, read_file, write_file, grep_search, glob_search, browser_use 等）
2. `_register_skills()` - 从 workspace 加载技能
3. `_build_sys_prompt()` - 构建系统提示词
4. `_setup_memory_manager()` - 配置记忆管理器
5. `_register_hooks()` - 注册生命周期钩子

**关键方法：**
- `reply()` - 处理用户消息的主入口
- `_reasoning()` - 推理循环（含多模态过滤）
- `_auto_continue_if_text_only()` - 当模型仅返回文本时自动继续

#### 核心类

**BaseChannel 基类：**
```python
class BaseChannel(ABC):
    channel: ChannelType  # 渠道类型标识

    @classmethod
    def from_env(cls, process, on_reply_sent) -> BaseChannel

    @classmethod
    def from_config(cls, process, config, **kwargs) -> BaseChannel

    async def consume_one(self, request: AgentRequest) -> None
    async def _consume_one_request(self, payload: Any) -> None
```

**ChannelManager：**
- 管理所有渠道的生命周期
- 统一消息队列（UnifiedQueueManager）
- 命令注册表（CommandRegistry）

#### 消息渲染

`MessageRenderer` 类负责将 AgentResponse 转换为渠道特定格式：
- 支持 Markdown 渲染

- 支持思考过程过滤
- 渠道特定格式化

### 5. Security 模块 (`src/qwenpaw/security/`)

安全功能：

**工具调用守卫（ToolGuard）：**
- `ToolGuardEngine` - 工具调用安全引擎
- `FilePathToolGuardian` - 文件路径守卫（阻止敏感文件访问）
- `RuleBasedToolGuardian` - 规则守卫（正则匹配检测威胁）
- `ShellEvasionGuardian` - 命令注入检测

**技能安全扫描（SkillScanner）：**
- `SkillScanner` - 技能包安全扫描器
- `PatternAnalyzer` - 模式分析器（YAML 签名匹配）
- `ScanResult` - 扫描结果

**密钥管理：**
- `SecretStore` - 加密存储（Fernet 加密 `api_key`、`jwt_secret` 等敏感字段）
- 密钥存储层级：OS Keychain > `~/.qwenpaw/.secret/.master_key`

**审批流程：**
1. 危险工具调用被拦截
2. `engine.guard()` 返回发现结果
3. 如果 `requires_user_confirmation`，创建 `SuspendedPermission`
4. 用户通过 `/approve` 或 `/deny` 决定
5. 工具执行或被阻止

## 工作区模式 (Workspace Pattern)

每个智能体运行在独立的工作区中，包含：

```
Workspace
├── runner: AgentRunner        # 请求处理器
├── channel_manager            # 渠道管理器
├── memory_manager             # 记忆管理器
├── mcp_manager                # MCP 客户端管理器
├── cron_manager               # 定时任务管理器
└── task_tracker               # 任务追踪器
```

### MultiAgentManager

管理多个工作区，根据 `X-Agent-Id` 请求头路由到正确的工作区。

### AgentRunner (`app/runner/runner.py`)

核心请求处理器，负责：
- 解析技能查询 `/[skill_name] input`
- 处理待审批工具调用
- 流式输出管理

### TaskTracker (`app/runner/task_tracker.py`)

追踪后台任务，支持 `/stop` 命令取消：

```python
class TaskTracker:
    # 注册外部任务（由 AgentApp 管理）
    async def register_external_task(run_key: str) -> None
    async def unregister_external_task(run_key: str) -> None

    # 附加到现有运行或启动新运行
    async def attach_or_start(
        run_key: str,
        payload: Any,
        stream_fn: Callable,
    ) -> tuple[asyncio.Queue, bool]

    # 请求停止
    async def request_stop(run_key: str) -> bool

    # 等待所有任务完成
    async def wait_all_done(timeout: float = 300.0) -> bool
```

## 主动记忆系统 (Proactive Memory)

### 主动触发 (`memory/proactive/proactive_trigger.py`)

```python
# 启用主动模式
enable_proactive_for_session(session_id, idle_minutes=30)

# 后台监控循环
async def proactive_trigger_loop(session_id: str) -> None:
    """每 30 秒检查一次空闲时间"""
```

### 触发条件

1. 距离上次用户交互超过 `idle_minutes`（默认 30 分钟）
2. 智能体当前不忙
3. 距离上次触发超过 60 秒（冷却时间）
4. 最后一条消息不是主动消息

### 主动响应生成

### Mission 状态文件

| 文件 | 说明 |
|------|------|

### Mission 执行流程

```
1. 创建会话目录
       ↓
2. 解析任务和验证命令
       ↓
3. 生成 PRD.md
       ↓
4. 进入循环
       ├→ 执行任务
       ├→ 运行验证命令
       ├→ 检查结果
       │     ├→ 通过 → 完成
       │     └→ 失败 → 重试
       ↓
5. 达到最大迭代 → 终止
```
