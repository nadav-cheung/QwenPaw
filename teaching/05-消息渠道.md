# 消息渠道

## 概述

QwenPaw 支持多种即时通讯渠道，可以将智能体连接到不同的平台。本文档介绍渠道配置和基本使用。

## 支持的渠道

| 渠道 | 说明 | 协议 |
|------|------|------|
| DingTalk | 钉钉 | Stream SDK |
| Feishu | 飞书/Lark | WebSocket |
| WeChat | 微信 iLink | - |
| WeCom | 企业微信 | - |
| QQ | QQ (OneBot 协议) | - |
| Discord | Discord | Gateway |
| Telegram | Telegram | Polling |
| iMessage | Apple Messages | - |
| Console | Web Console | Debug |

## 快速配置

### DingTalk 钉钉

**步骤 1**: 在钉钉开放平台创建应用

1. 访问 [钉钉开放平台](https://open.dingtalk.com/)
2. 创建企业自建应用
3. 获取 `App Key` 和 `App Secret`

**步骤 2**: 配置 QwenPaw

```bash
qwenpaw channels config dingtalk
```

或在 `config.json` 中配置：

```json
{
  "channels": {
    "dingtalk": {
      "enabled": true,
      "app_key": "your_app_key",
      "app_secret": "your_app_secret"
    }
  }
}
```

**步骤 3**: 启动测试

```bash
# 发送测试消息
qwenpaw channels test dingtalk --message "Hello"
```

## 通用配置

### 通过 CLI 配置

```bash
# 列出所有已安装的渠道
qwenpaw channels list

# 配置渠道参数
qwenpaw channels config dingtalk

# 安装新渠道
qwenpaw channels install dingtalk --from-path ./my-dingtalk

# 启用/禁用渠道
qwenpaw channels enable dingtalk
qwenpaw channels disable dingtalk

# 发送测试消息
qwenpaw channels send dingtalk --message "Hello"
```

### 渠道策略

| 策略 | 说明 |
|------|------|
| `dm_policy` | 私聊策略：`open`（开放）或 `allowlist`（白名单） |
| `group_policy` | 群聊策略：`open`（开放）或 `allowlist`（白名单） |
| `require_mention` | 是否需要 @ 机器人 |
| `filter_tool_messages` | 是否过滤工具调用消息 |
| `filter_thinking` | 是否过滤思考过程 |

### 配置示例

```json
{
  "channels": {
    "dingtalk": {
      "enabled": true,
      "app_key": "your_app_key",
      "app_secret": "your_app_secret",
      "dm_policy": "open",
      "group_policy": "allowlist",
      "allow_from": ["group_id_1", "group_id_2"]
    }
  }
}
```

## 常见问题

| 问题 | 解决方案 |
|------|----------|
| 渠道无法连接 | 检查 App Key/Secret 是否正确 |
| 消息发送失败 | 检查网络连接和防火墙设置 |
| 无法 @ 机器人 | 在群设置中确认机器人已被添加 |
