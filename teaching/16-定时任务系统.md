# 定时任务系统 (Cron)

## 概述

QwenPaw 内置定时任务系统，支持定时执行任务、定时提醒和周期性的后台任务。本文档介绍定时任务的使用方法和配置。

**源码路径**: `src/qwenpaw/app/cron/`

---

## 0. TaskTracker 后台任务追踪

### 0.1 TaskTracker 简介

`TaskTracker`（`src/qwenpaw/app/runner/task_tracker.py`）管理所有后台运行的流式任务，支持：

- **流式输出追踪**：SSE 事件缓冲与多订阅者分发
- **断线重连**：重连时自动回放缓冲区事件
- **外部任务注册**：将外部任务纳入统一管理
- **优雅清理**：Sentinel-based 队列清理

### 0.2 核心方法

```python
class TaskTracker:
    """Per-workspace tracker: run_key -> RunState"""

    async def attach_or_start(
        self,
        run_key: str,
        payload: Any,
        stream_fn: Callable[..., Coroutine],
    ) -> tuple[asyncio.Queue, bool]:
        """Attach to an existing run or start a new one.

        Returns ``(queue, is_new_run)``.
        - 如果任务已存在：返回队列（预填充缓冲区）+ is_new_run=False
        - 如果任务不存在：创建新任务 + is_new_run=True
        """

    async def stream_from_queue(
        self,
        queue: asyncio.Queue,
        run_key: str,
    ) -> AsyncGenerator[str, None]:
        """Yield SSE strings from *queue* until sentinel ``None``.

        Always detaches *queue* from *run_key* when stream ends,
        so reconnects do not leak queues.
        """
```

**`_RunState` 数据结构** (第25-31行):

```python
@dataclass
class _RunState:
    """Per-run state (task, queues, buffer)"""
    task: asyncio.Future
    queues: list[asyncio.Queue] = field(default_factory=list)
    buffer: list[str] = field(default_factory=list)
```

### 0.3 生产者-消费者模式

```python
async def _producer() -> None:
    try:
        async for sse in stream_fn(payload):  # 流式生成
            async with tracker.lock:
                run.buffer.append(sse)  # 缓冲
                for q in run.queues:
                    q.put_nowait(sse)  # 广播到所有订阅者
    finally:
        async with tracker.lock:
            for q in run.queues:
                q.put_nowait(_SENTINEL)  # 发送结束信号
            tracker._runs.pop(run_key, None)  # 清理
```

### 0.4 外部任务注册

```python
async def register_external_task(self, run_key: str) -> None:
    """注册外部管理的任务，纳入 has_active_tasks 追踪"""

async def unregister_external_task(self, run_key: str) -> None:
    """标记外部任务完成，发送 sentinel 到所有队列"""
```

## 1. 基本概念

### 1.1 什么是定时任务

定时任务是在指定时间或周期自动执行的任务，类似 Linux 的 cron。

### 1.2 与传统 cron 的区别

| 特性 | Linux cron | QwenPaw Cron |
|------|-----------|--------------|
| 执行时间 | 精确到分钟 | 精确到分钟 |
| 任务类型 | Shell 命令 | 对话、技能调用 |
| 上下文 | 无 | 有完整对话上下文 |
| 结果通知 | 邮件 | 发送到渠道 |

## 2. 使用方法

### 2.1 CLI 命令

```bash
# 列出所有定时任务
qwenpaw cron list

# 创建定时任务
qwenpaw cron create --name "morning_reminder" --schedule "0 9 * * *" --task "提醒我今天的工作"

# 删除定时任务
qwenpaw cron delete --name "morning_reminder"

# 暂停/恢复任务
qwenpaw cron pause --name "morning_reminder"
qwenpaw cron resume --name "morning_reminder"

# 查看任务执行历史
qwenpaw cron history --name "morning_reminder"
```

### 2.2 在对话中创建

```
/cron create --name daily_summary --schedule "0 18 * * *" --task "生成今日工作报告"
```

### 2.3 任务调度表达式

QwenPaw 支持标准 cron 表达式：

```
┌───────────── 分钟 (0-59)
│ ┌─────────── 小时 (0-23)
│ │ ┌─────────── 日期 (1-31)
│ │ │ ┌───────── 月份 (1-12)
│ │ │ │ ┌─────── 星期 (0-6, 0=周日)
│ │ │ │ │
* * * * *
```

### 2.4 常用调度表达式

| 表达式 | 含义 |
|--------|------|
| `0 9 * * *` | 每天 9:00 |
| `0 18 * * *` | 每天 18:00 |
| `30 8 * * 1-5` | 工作日 8:30 |
| `0 */2 * * *` | 每 2 小时 |
| `0 0 * * 0` | 每周日午夜 |
| `0 0 1 * *` | 每月 1 日午夜 |

## 3. 定时任务配置

### 3.1 配置文件

定时任务存储在 `~/.qwenpaw/config.json`：

```json
{
  "cron": {
    "enabled": true,
    "tasks": [
      {
        "name": "morning_reminder",
        "schedule": "0 9 * * *",
        "task": "提醒我今天的工作安排",
        "enabled": true,
        "channel": "dingtalk"
      },
      {
        "name": "daily_summary",
        "schedule": "0 18 * * *",
        "task": "/skill daily_summary",
        "enabled": true
      }
    ]
  }
}
```

### 3.2 任务配置字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `name` | string | 是 | 任务唯一标识 |
| `schedule` | string | 是 | cron 表达式 |
| `task` | string | 是 | 要执行的任务 |
| `enabled` | bool | 否 | 是否启用（默认 true） |
| `channel` | string | 否 | 结果发送到哪个渠道 |
| `timezone` | string | 否 | 时区（默认本地时区） |

## 7. 最佳实践

### 7.1 任务设计原则

1. **幂等性**: 任务可以安全地重复执行
2. **简短任务**: 避免执行时间过长的任务
3. **错误处理**: 任务应包含适当的错误处理
4. **日志记录**: 重要任务应有详细日志

### 7.2 性能考虑

| 场景 | 建议 |
|------|------|
| 高频任务 | 避免分钟级任务，选择更长的间隔 |
| 资源密集 | 避免在业务高峰期执行 |
| 并发控制 | 使用互斥锁防止重复执行 |

### 8.9 执行器执行流程

**源码路径**: `src/qwenpaw/app/crons/executor.py`

**CronExecutor.execute()** 执行流程:

```
收到 CronJobSpec
    │
    ▼
task_type == "text"?
    │
    ├─► 是: channel_manager.send_text()
    │         └─► 发送文本到指定渠道
    │
    └─► 否 (agent):
          │
          ▼
          runner.stream_query(req)
          │
          ▼
          async for event in stream:
          │
          ▼
          channel_manager.send_event()
                    └─► 流式发送事件到渠道
```

**执行状态更新**:

| 阶段 | 状态 | 说明 |

### 8.1 常见问题

| 任务不执行 | cron 服务未启动 | `qwenpaw doctor --check cron` |
