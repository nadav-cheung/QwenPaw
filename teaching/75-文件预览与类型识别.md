### 1.2 路径规范化

```python
# src/qwenpaw/app/routers/files.py:16
normalized = unquote(filepath)

# 处理重复的 preview 前缀
while True:
    trimmed = normalized.lstrip("/")
    prefix = "api/files/preview/"
    if trimmed.startswith(prefix):
        normalized = trimmed[len(prefix):]
        continue
    break

# Windows 路径规范化：/C:/... → C:/...
if (len(normalized) >= 4 and normalized[0] == "/"
    and normalized[2] == ":" and normalized[1].isalpha()):
    normalized = normalized[1:]
```

## 2. 权限控制

### 2.1 路径安全检查

```python
# src/qwenpaw/app/routers/files.py:28
path = Path(normalized)
if not path.is_absolute():
    path = Path("/" + normalized)
path = path.resolve()

if not path.is_file():
    raise HTTPException(status_code=404, detail="Not found")
```

## 3. 支持的预览类型

### 3.1 文件类型处理

| 类型 | 处理方式 | 返回 |
|------|----------|------|
| 文本 | 直接读取 | FileResponse |
| 图片 | base64 编码 | FileResponse |
| PDF | 提取文本/图像 | FileResponse |
| Markdown | 渲染为 HTML | HTMLResponse |
| 代码 | 语法高亮 | HTMLResponse |

### 3.2 mimetype 映射

| 扩展名 | mimetype |
|--------|----------|
| `.txt` | text/plain |
| `.md` | text/markdown |
| `.py` | text/x-python |
| `.json` | application/json |
| `.png` | image/png |
| `.jpg` | image/jpeg |
| `.pdf` | application/pdf |
