# 多智能体协作

## 概述

QwenPaw 支持多智能体协作，通过 ACP（Agent Communication Protocol）协议实现智能体间的通信和任务委托。本教程深入讲解 ACP 协议架构、多智能体协作机制、委托工具和协作模式。

---

## 1. ACP 协议架构

### 1.1 什么是 ACP

ACP（Agent Communication Protocol）是一种智能体间通信的标准化协议：

```
┌─────────────────┐                      ┌─────────────────┐
│  QwenPaw Agent  │ ◄─────── ACP ──────► │ External Agent  │
│                 │                      │  (Claude Code,   │
│  - 本地智能体    │                      │   OpenCode, etc) │
│  - 渠道消息处理  │                      └─────────────────┘
└─────────────────┘
```

### 1.2 ACP 核心组件

```
agents/acp/
├── __init__.py
├── core.py              # ACPErrors, SuspendedPermission
├── server.py           # QwenPawACPAgent, run_qwenpaw_agent()
├── client.py           # ACPHostedClient
├── service.py          # ACPService 单例
├── permissions.py      # 权限管理
└── tool_adapter.py     # 工具适配
```

## 3. ACPService 服务

### 3.1 ACPService 服务单例

**源码路径**: `src/qwenpaw/agents/acp/service.py`

```python
class ACPService:
    """ACP 服务单例，管理所有 ACP 会话"""

    def __init__(self, *, config: ACPConfig):
        self.config = config
        self._lock = asyncio.Lock()
        self._sessions: Dict[tuple[str, str], _Conversation] = {}

    async def run_turn(
        self,
        *,
        chat_id: str,
        agent: str,
        prompt_blocks: list[dict[str, Any]],
        cwd: str,
        on_message: MessageHandler,
        restart: bool = False,
        require_existing: bool = False,
    ) -> dict[str, Any]:
        """Execute one conversation turn.

        Args:
            chat_id: 聊天 ID（用于标识对话）
            agent: 智能体标识符
            prompt_blocks: 提示块列表
            cwd: 工作目录
            on_message: 消息处理器
            restart: 是否重启会话
            require_existing: 是否要求会话已存在

        Returns:
            包含结果或错误的字典
        """
        conversation = await self._get_or_create_session(
            chat_id=chat_id,
            agent=agent,
            cwd=cwd,
            restart=restart,
            require_existing=require_existing,
        )

        async with conversation.turn_lock:
            # 检查是否有待处理的权限请求
            if conversation.client.pending_permission is not None:
                raise ACPSessionError("Session is waiting for permission")

            # 启动提示
            conversation.client.start_prompt(on_message)
            conversation.prompt_task = asyncio.create_task(
                conversation.conn.prompt(
                    session_id=conversation.acp_session_id,
                    prompt=self._prompt_blocks_to_models(prompt_blocks),
                ),
            )
            return await self._wait_for_prompt_outcome(conversation)
```

**`_Conversation` 数据结构** (第32-56行):

```python
@dataclass
class _Conversation:
    """单个 ACP 会话的状态"""
    chat_id: str                    # 聊天 ID
    agent: str                      # 智能体标识
    acp_session_id: str            # ACP 会话 ID（与外部智能体通信用）
    cwd: str                        # 工作目录
    conn: Any                       # 连接对象
    process: Any                    # 子进程
    client: ACPHostedClient         # ACP 托管客户端
    exit_stack: AsyncExitStack
    turn_lock: asyncio.Lock         # 确保同一时刻只有一个 turn 在执行
    prompt_task: Optional[asyncio.Task]  # 当前 prompt 任务
```

### 3.2 权限恢复

```python
async def resume_permission(
    self,
    *,
    acp_session_id: str,
    option_id: str,
    on_message: MessageHandler,
) -> dict:
    """恢复暂停的权限请求"""
    
    conversation = await self._find_session_by_acp_id(acp_session_id)
    
    # 恢复提示
    conversation.client.resume_prompt(on_message)
    conversation.client.resolve_permission(option_id)
    await conversation.client.emit_permission_resolved()
    
    return await self._wait_for_prompt_outcome(conversation)
```

### 3.3 会话管理

```python
async def close_chat_session(self, *, chat_id: str, agent: str) -> None:
    """关闭指定会话"""
    async with self._lock:
        conversation = self._sessions.pop((chat_id, agent), None)
    
    if conversation:
        await self._close_conversation(conversation)

async def close_all_sessions(self) -> None:
    """关闭所有会话"""
    async with self._lock:
        conversations = list(self._sessions.values())
        self._sessions.clear()
    
    for conversation in conversations:
        await self._close_conversation(conversation)
```

### 5.1 delegate_external_agent

委托任务给外部 ACP 代理。

**源码路径**: `src/qwenpaw/agents/tools/delegate_external_agent.py`

**工具签名** (第431-589行):

```python
async def delegate_external_agent(
    action: str,
    runner: str,
    message: str = "",
    cwd: str = "",
    max_runtime: Optional[float] = None,
) -> ToolResponse | AsyncGenerator[ToolResponse, None]:
    """
    打开、交流、响应权限或关闭 ACP 智能体会话。
    
    1. 调用 delegate_external_agent(action="start", runner=..., message=...)
       打开新会话
    2. 调用 delegate_external_agent(action="message", runner=..., message=...)
       继续对话
    3. 出现权限请求时，先询问用户选择，然后调用
       delegate_external_agent(action="respond", runner=..., message=...)
       响应待处理的权限请求
    4. 调用 delegate_external_agent(action="close", runner=...)
       结束会话
    """
```

## 6. 多智能体协作模式

### 6.1 主从模式

```
┌──────────────┐         委托          ┌──────────────┐
│   Master     │ ─────────────────────►│   Worker     │
│   Agent      │ ◄─────────────────────│   Agent      │
│  (任务分解)   │         结果          │  (执行任务)   │
└──────────────┘                       └──────────────┘
```

```python
# 主从协作示例
async def master_worker_collaboration(task: str):
    # 1. 主智能体分解任务
    subtasks = await master.decompose_task(task)
    
    # 2. 并行委托给工作智能体
    results = await asyncio.gather(*[
        delegate_external_agent("worker_1", subtask)
        for subtask in subtasks
    ])
    
    # 3. 主智能体汇总结果
    final_result = await master.aggregate_results(results)
    
    return final_result
```

### 6.2 流水线模式

```
┌──────────────┐    阶段1结果    ┌──────────────┐
│   Stage 1   │ ───────────────►│   Stage 2   │
│   Agent      │                 │   Agent      │
│  (数据收集)   │                 │  (数据处理)   │
└──────────────┘                 └──────────────┘
                                            │
                                            ▼
                                       ┌──────────────┐
                                       │   Stage 3   │
                                       │   Agent      │
                                       │  (结果输出)  │
                                       └──────────────┘
```

### 6.3 辩论模式

```
┌──────────────┐                    ┌──────────────┐
│   Agent A   │ ◄────── 反驳 ──────│   Agent B   │
│  (正方)      │                    │  (反方)      │
└──────────────┘                    └──────────────┘
        │                                  │
        └──────────────► 仲裁 ◄────────────┘
                         │
                    ┌──────────────┐
                    │   Master     │
                    │  (裁决)       │
                    └──────────────┘
```

## 11. 故障排查

### 11.1 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 委托超时 | 外部智能体无响应 | 增加 timeout 或检查智能体状态 |
| 权限拒绝 | 权限配置错误 | 检查 ALLOWED_AGENTS 配置 |
| 会话丢失 | 智能体崩溃 | 重新启动智能体 |
| 通信失败 | ACP 协议不兼容 | 检查智能体版本 |

## 12. 最佳实践

### 12.1 协作设计原则

1. **单一职责**: 每个智能体专注于特定任务
2. **清晰接口**: 定义明确的输入输出格式
3. **错误处理**: 每个智能体都应该有错误恢复机制
4. **资源管理**: 及时关闭不需要的会话

### 12.2 性能优化

| 策略 | 说明 |
|------|------|
| 并行委托 | 独立任务并行执行 |
| 会话复用 | 避免重复创建会话 |
| 缓存结果 | 常用结果缓存复用 |
| 超时控制 | 防止单个任务阻塞 |

### 12.3 安全建议

1. **最小授权**: 只授予必要的智能体访问权限
2. **输入验证**: 验证所有委托请求的输入
3. **审计日志**: 记录所有协作活动
4. **隔离运行**: 敏感任务在隔离环境运行
