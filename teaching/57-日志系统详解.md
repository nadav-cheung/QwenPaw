# 日志系统详解

## 概述

QwenPaw 的日志系统支持文件轮转、带颜色的控制台输出、UVicorn 访问日志过滤，以及通过环境变量的灵活日志级别控制。

本章节详细解析日志配置、格式化器、日志处理器、文件轮转机制、访问日志过滤，以及完整的初始化流程。

---

## 1. 日志配置

源码路径：`src/qwenpaw/utils/logging.py`

### 1.1 核心设置

```python
# src/qwenpaw/utils/logging.py:124
def setup_logger(level: str = "info") -> None:
    """配置应用程序日志

    参数：
    - level: 日志级别 (critical, error, warning, info, debug)
    """
    logger = logging.getLogger(LOG_NAMESPACE)  # "qwenpaw"
    logger.setLevel(_LEVEL_MAP.get(level, logging.INFO))
```

### 1.2 日志级别映射

```python
# src/qwenpaw/utils/logging.py:17
_LEVEL_MAP = {
    "critical": logging.CRITICAL,  # 50
    "error": logging.ERROR,        # 40
    "warning": logging.WARNING,    # 30
    "info": logging.INFO,          # 20
    "debug": logging.DEBUG,        # 10
}
```

**级别关系：**

```
CRITICAL (50)
    ↓
ERROR (40)
    ↓
WARNING (30)
    ↓
INFO (20)       ← 默认级别
    ↓
DEBUG (10)
```

设置某级别后，只有 >= 该级别的日志会被输出。

## 2. 日志格式化

### 2.1 控制台格式 (ColorFormatter)

```python
# src/qwenpaw/utils/logging.py:54
class ColorFormatter(logging.Formatter):
    """带颜色的控制台输出

    颜色编码：
    - DEBUG: 灰色 (#888888)
    - INFO: 蓝色 (#4A90D9)
    - WARNING: 黄色 (#F5A623)
    - ERROR: 红色 (#D0021B)
    - CRITICAL: 深红色 (#8B0000)
    """

    COLORS = {
        "DEBUG": "\x1b[38;5;245m",     # 灰色
        "INFO": "\x1b[38;5;75m",      # 蓝色
        "WARNING": "\x1b[38;5;214m",   # 黄色
        "ERROR": "\x1b[38;5;196m",     # 红色
        "CRITICAL": "\x1b[38;5;124m",  # 深红
        "RESET": "\x1b[0m",
    }

    def format(self, record):
        color = self.COLORS.get(record.levelname, self.COLORS["RESET"])
        record.levelname = f"{color}{record.levelname}{self.COLORS['RESET']}"
        return super().format(record)
```

### 2.2 文件格式 (PlainFormatter)

```python
# src/qwenpaw/utils/logging.py:87
log_format = "%(asctime)s | %(levelname)s | %(name)s | %(message)s"
datefmt = "%Y-%m-%d %H:%M:%S"
# 输出: 2024-01-15 10:30:45 | INFO | qwenpaw.runner | Chat session started
```

**文件日志格式设计：**
- 包含时间戳，便于问题定位
- 包含完整模块名（`qwenpaw.runner`）
- 不含颜色代码，便于日志分析工具处理

## 3. 文件轮转

```python

_LOG_MAX_BYTES = 5 * 1024 * 1024  # 5 MiB

```

### 3.1 轮转配置

| 参数 | 值 | 说明 |
|------|-----|------|
| `_LOG_MAX_BYTES` | 5 MiB | 单个日志文件最大大小 |
| `_LOG_BACKUP_COUNT` | 3 | 保留的轮转备份数 |

### 3.2 平台差异

```python
# src/qwenpaw/utils/logging.py:182
if sys.platform == "darwin":
    # macOS: 使用 RotatingFileHandler
    handler = RotatingFileHandler(
        filename=log_path,
        maxBytes=_LOG_MAX_BYTES,
        backupCount=_LOG_BACKUP_COUNT,
    )
else:
    # Windows/Linux: 使用简单 FileHandler
    handler = FileHandler(filename=log_path)
```

**平台差异原因：**
- macOS 上 `RotatingFileHandler` 工作更稳定
- Windows/Linux 上使用简单 `FileHandler` 足够

## 5. 访问日志过滤

源码路径：`src/qwenpaw/utils/logging.py:102`

### 5.1 SuppressPathAccessLogFilter

```python
# src/qwenpaw/utils/logging.py:102
class SuppressPathAccessLogFilter(logging.Filter):
    """过滤 Uvicorn 访问日志中的路径访问

    过滤的路径：
    - /api/agents/{id}/chats (高频轮询)
    - /health (健康检查)
    - /metrics (指标收集)
    """

    SUPPRESS_PATHS = {
        "/api/agents/",
        "/health",
        "/metrics",
    }

    def filter(self, record):
        # 提取访问路径
        path = getattr(record, "path", "")
        # 检查是否应过滤
        return not any(path.startswith(p) for p in self.SUPPRESS_PATHS)
```

**过滤目的：**
- 减少无意义的访问日志
- 降低日志文件大小
- 聚焦关键日志

## 9. 设计模式

### 9.1 命名空间隔离

```python
# 所有应用日志在 "qwenpaw" 命名空间
logger = logging.getLogger(LOG_NAMESPACE)  # "qwenpaw"
```

**隔离效果：**
- 第三方库（如 uvicorn）日志不受影响
- 便于统一控制 QwenPaw 各模块日志
- 日志分析时可快速过滤

### 9.2 平台自适应

```python
# 不同平台使用不同的 Handler
if sys.platform == "darwin":
    handler = RotatingFileHandler(...)
else:
    handler = FileHandler(...)
```

**原因：**
- `RotatingFileHandler` 在 macOS 上更稳定
- Windows 上可能存在文件锁问题

### 9.3 惰性初始化

```python
# 包导入时：只设置基本 logger
setup_logger()

# 应用启动时：添加文件 Handler
add_project_file_handler()
```

**优势：**
- 包导入即可使用日志（输出到控制台）
- 文件 Handler 在需要时才添加
- 便于测试：单元测试不产生日志文件

## 11. 常见问题

### Q1: 日志文件不存在？

**原因：** 日志 Handler 未添加。

**排查：**

```python
# 检查日志配置
import logging
logger = logging.getLogger("qwenpaw")
print(logger.handlers)  # 应该包含 FileHandler

# 检查文件路径
from qwenpaw.utils.logging import LOG_FILE_PATH
print(LOG_FILE_PATH)
```

**解决：**

```python
# 手动添加文件 Handler
from qwenpaw.utils.logging import add_project_file_handler
add_project_file_handler()
```

### Q2: 日志无颜色输出？

**原因：** 终端不支持 ANSI 颜色码，或被重定向。

**解决：**

```bash
# 使用支持颜色的终端
# macOS Terminal.app 支持
# iTerm2 支持

# 强制输出颜色（如果终端支持）
export FORCE_COLOR=1
```

### Q3: 日志轮转不工作？

**原因：** Windows/Linux 上未使用 RotatingFileHandler。

**解决：**

```python
# 手动配置轮转
from logging.handlers import RotatingFileHandler
handler = RotatingFileHandler(
    "qwenpaw.log",
    maxBytes=5*1024*1024,
    backupCount=3,
)
logger.addHandler(handler)
```

### Q4: 日志占用磁盘过大？

**原因：** 日志级别设置过低 + 轮转未配置。

**解决：**

```bash
# 1. 提高日志级别
export QWENPAW_LOG_LEVEL=warning

# 2. 手动清理旧日志
rm qwenpaw.log.*

# 3. 配置日志大小限制
# 在代码中设置 maxBytes 和 backupCount
```

## 12. 最佳实践

### 12.1 日志级别使用规范

```python
# CRITICAL: 严重错误，系统不可恢复
logger.critical("Database connection lost, shutting down")

# ERROR: 错误，请求无法完成
logger.error("Failed to process request: invalid input")

# WARNING: 警告，请求可以继续但有问题
logger.warning("Rate limit approaching: %s/%s", current, limit)

# INFO: 信息，关键业务操作
logger.info("Chat session started: %s", session_id)

# DEBUG: 调试，开发/诊断用
logger.debug("Request payload: %s", payload)
```

### 12.2 日志消息格式

```python
# 推荐：结构化参数
logger.info("User %s logged in from %s", user_id, ip_address)
logger.info("Chat created: id=%s, name=%s", chat_id, chat_name)

# 避免：字符串拼接
# logger.info("User " + user_id + " logged in")  # 不推荐

# 避免：过于冗长
# logger.info("The system has successfully processed the user's request")
```

### 12.3 敏感信息处理

```python
# 避免：记录敏感信息
logger.info("Password reset for user: %s", password)  # 危险！

# 使用占位符
logger.info("Password reset requested for user ID: %s", user_id)

# 或显式脱敏
logger.info("Login attempt: user=%s, ip=%s", mask_email(email), ip)
```

### 12.4 日志性能优化

```python
# 避免：在热路径中记录大量日志
for item in large_list:
    logger.debug("Processing item: %s", item)  # 可能影响性能

# 推荐：记录摘要
logger.debug("Processing %d items", len(large_list))

# 或使用采样
if random.random() < 0.01:  # 1% 采样
    logger.debug("Processing sample item: %s", item)
```

## 13. 总结

### 核心要点

| 要点 | 说明 |
|------|------|
| **命名空间隔离** | 所有日志在 "qwenpaw" 命名空间 |
| **双格式化器** | 控制台 ColorFormatter（带颜色）+ 文件 PlainFormatter |
| **平台自适应** | macOS 用 RotatingFileHandler，其他用 FileHandler |
| **日志轮转** | 5MB + 3 个备份 |
| **访问日志过滤** | 过滤高频轮询路径 |
| **环境变量控制** | `QWENPAW_LOG_LEVEL` 灵活配置 |
| **调试端点** | `/api/debug/backend-logs` 查看日志 |
