# 心跳系统 (Heartbeat)

## 概述

QwenPaw 的心跳系统是一个后台自检机制，定期检查智能体健康状态、记忆状况，并在需要时主动向用户发送摘要或提醒。本文档介绍心跳系统的功能和使用方法。

---

## 1. 心跳简介

### 1.1 什么是心跳

心跳（Heartbeat）是智能体定时执行的自检任务，用于：

- 检查记忆系统状态
- 生成记忆摘要
- 主动向用户发送提醒或摘要
- 清理过期数据

### 1.2 心跳与定时任务的区别

| 特性 | 心跳 (Heartbeat) | 定时任务 (Cron) |
|------|------------------|-----------------|
| 触发方式 | 定时自动触发 | 手动配置 |
| 主要功能 | 健康检查、记忆整理 | 自定义任务执行 |
| 用户交互 | 主动通知用户 | 可选通知 |
| 上下文 | 有完整记忆上下文 | 可选上下文 |

## 2. 配置心跳

### 2.1 基本配置

```json
{
  "agents": {
    "default": {
      "heartbeat": {
        "enabled": true,
        "interval_minutes": 60,
        "checks": ["memory", "disk", "model"],
        "notification": {
          "enabled": true,
          "channel": "dingtalk"
        }
      }
    }
  }
}
```

### 2.2 配置字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `enabled` | bool | 否 | 是否启用心跳（默认 true） |
| `interval_minutes` | int | 否 | 检查间隔（默认 60 分钟） |
| `checks` | list | 否 | 执行哪些检查 |
| `notification` | object | 否 | 通知配置 |

### 2.3 检查项

| 检查项 | 说明 |
|--------|------|
| `memory` | 记忆状态检查和整理 |
| `disk` | 磁盘空间检查 |
| `model` | 模型可用性检查 |
| `tasks` | 后台任务状态 |
| `channels` | 渠道连接状态 |

## 3. BootstrapHook 首次引导

### 3.1 BootstrapHook 简介

`BootstrapHook`（`src/qwenpaw/agents/hooks/bootstrap.py`）在用户首次交互时检查 `BOOTSTRAP.md` 文件并显示设置引导：

```python
class BootstrapHook:
    """Hook for bootstrap guidance on first user interaction."""

    async def __call__(self, agent, kwargs) -> dict[str, Any] | None:
        # 1. 检查 .bootstrap_completed 标记文件是否存在
        if bootstrap_completed_flag.exists():
            return None

        # 2. 检查 BOOTSTRAP.md 是否存在
        if not bootstrap_path.exists():
            return None

        # 3. 检查是否首次用户交互
        if not is_first_user_interaction(messages):
            return None

        # 4. 加载引导文本并前置到首条用户消息
        bootstrap_guidance = build_bootstrap_guidance(self.language)
        prepend_to_message_content(msg, bootstrap_guidance)

        # 5. 创建完成标记
        bootstrap_completed_flag.touch()
```

**触发流程**:
```
用户首次发送消息
    ↓
检查 .bootstrap_completed 标记（不存在则继续）
    ↓
检查 BOOTSTRAP.md 是否存在
    ↓
检查是否首次用户交互（messages 为空或仅有一条）
    ↓
前置引导文本到首条用户消息
    ↓
创建 .bootstrap_completed 标记文件
```

### 3.2 build_bootstrap_guidance 引导文本

**源码路径**: `src/qwenpaw/agents/prompt.py` (第310-359行)

```python
def build_bootstrap_guidance(language: str = "zh") -> str:
    """Build bootstrap guidance message for first-time setup."""
    if language == "zh":
        return (
            "# 引导模式\n"
            "\n"
            "工作目录中存在 `BOOTSTRAP.md` — 首次设置。\n"
            "\n"
            "1. 阅读 BOOTSTRAP.md，友好地表示初次见面，"
            "引导用户完成设置。\n"
            "2. 按照 BOOTSTRAP.md 的指示，"
            "帮助用户定义你的身份和偏好。\n"
            "3. 按指南创建/更新必要文件"
            "（PROFILE.md、MEMORY.md 等）。\n"
            "4. 完成后删除 BOOTSTRAP.md。\n"
            "\n"
            "如果用户希望跳过，直接回答下面的问题即可。\n"
            "\n"
            "---\n"
        )
    return (  # English
        "# BOOTSTRAP MODE\n"
        "`BOOTSTRAP.md` exists — first-time setup.\n"
        "1. Read BOOTSTRAP.md, greet the user, and guide them through setup.\n"
        "2. Follow BOOTSTRAP.md instructions to define identity and preferences.\n"
        "3. Create/update files (PROFILE.md, MEMORY.md, etc.).\n"
        "4. Delete BOOTSTRAP.md when done.\n"
        "If the user wants to skip, answer their question directly.\n"
        "---\n"
    )
```

## 4. 心跳文件

### 4.1 HEARTBEAT.md

心跳配置可以通过工作目录的 `HEARTBEAT.md` 文件定义：

```
~/.qwenpaw/workspaces/default/
├── HEARTBEAT.md    # 心跳配置
├── MEMORY.md        # 记忆文件
├── AGENTS.md       # 智能体提示词
└── ...
```

### 3.2 HEARTBEAT.md 格式

```markdown
---
enabled: true
interval_minutes: 60
checks:
  - memory
  - disk
---

# 心跳执行时的额外指令

## 记忆整理规则
- 删除超过 30 天的临时记忆
- 保留重要的用户偏好

## 通知规则
- 只在发现问题时通知
- 重要事件立即通知
```

## 4. 心跳执行时机

### 4.1 自动触发

心跳在以下时机自动执行：

1. **定时触发**: 根据 `interval_minutes` 配置的间隔
2. **启动时**: 智能体启动完成后
3. **空闲时**: 检测到用户长时间无活动

### 4.2 手动触发

```bash
# 手动触发心跳
qwenpaw heartbeat run

# 查看心跳状态
qwenpaw heartbeat status

# 禁用心跳
qwenpaw heartbeat disable
```

## 5. 心跳功能详解

### 5.1 记忆整理

心跳执行时会自动整理记忆：

```python
async def heartbeat_memory_maintenance():
    """心跳 - 记忆整理"""
    
    # 1. 检查记忆大小
    memory_size = await get_memory_size()
    
    # 2. 如果超过阈值，执行压缩
    if memory_size > MEMORY_THRESHOLD:
        await compact_memory()
    
    # 3. 清理过期记忆
    await cleanup_expired_memories(days=30)
    
    # 4. 生成记忆摘要
    summary = await generate_memory_summary()
    
    return summary
```

### 5.2 状态检查

心跳执行系统状态检查：

| 检查项 | 阈值 | 超过阈值操作 |
|--------|------|-------------|
| 记忆大小 | 100MB | 触发压缩 |
| 磁盘空间 | 1GB | 发送警告 |
| Token 使用 | 80% | 发送警告 |
| 错误率 | 10% | 发送警告 |

### 5.3 主动通知

当检测到问题时，心跳会主动通知用户：

```json
{
  "heartbeat": {
    "notification": {
      "enabled": true,
      "channel": "dingtalk",
      "on_issue": true,
      "daily_summary": false
    }
  }
}
```

qwenpaw heartbeat set --interval 30

## 7. 最佳实践

### 7.1 配置建议

| 场景 | 建议配置 |
|------|---------|
| 个人使用 | 间隔 60 分钟，只做记忆整理 |
| 高频使用 | 间隔 30 分钟，完整检查 |
| 低配机器 | 间隔 120 分钟，避免资源占用 |

### 7.2 通知策略

- **问题通知**: 发现问题时立即通知
- **每日摘要**: 每天定时发送摘要（可配合定时任务）
- **静默模式**: 完全禁用通知

## 8. 故障排查

### 8.1 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 心跳不执行 | 心跳被禁用 | `qwenpaw heartbeat enable` |
| 通知不发送 | 渠道未配置 | 检查 `notification.channel` 配置 |
| 记忆整理失败 | 权限问题 | 检查工作目录权限 |
| 资源占用高 | 检查间隔太短 | 增加 `interval_minutes` |

### 8.2 调试命令

```bash
# 检查心跳服务状态
qwenpaw doctor --check heartbeat

# 手动执行心跳
qwenpaw heartbeat run --verbose

# 查看详细日志
qwenpaw logs | grep heartbeat
```
