## 配置加载优先级

**从高到低**：
1. **环境变量** (通过 `EnvVarLoader` 类)

```python
def load_config(config_path: Optional[Path] = None) -> Config:
    """Load config from file. Returns default Config if file is missing."""
    if config_path is None:
        config_path = get_config_path()
    if not config_path.is_file():
        return Config()  # 返回默认配置

    data = _read_config_data(config_path)  # 使用 json_repair 处理损坏的 JSON
    if data is None:
        return Config()

    data = _normalize_working_dir_bound_paths(data)  # 路径规范化
    # 向后兼容：last_api_host/last_api_port -> last_api
    return Config.model_validate(data)
```

## 核心设计模式

1. **分层配置**：根配置引用 Agent，Agent 存储完整配置
2. **向后兼容**：Legacy 字段自动迁移和合并
3. **容错设计**：`json_repair` 自动修复损坏的 JSON
4. **环境变量优先**：所有配置都可通过环境变量覆盖
5. **默认值链**：环境变量 → 配置文件 → 代码默认值
6. **路径规范化**：自动处理旧版本路径迁移

```python
from pathlib import Path

def normalize_path(old_path: str, legacy_root: str, new_root: str) -> str:
    """将旧路径转换为新路径"""
    old_path_obj = Path(old_path)

    # 处理 ~/.copaw 路径
    if str(old_path_obj).startswith(legacy_root):

    return old_path
```

### Java 开发者对照表

| Java 概念 | Python/QwenPaw 实现 | 说明 |
|-----------|---------------------|------|

### 关键差异

**1. 配置模型定义**

```java
// Java: Spring @ConfigurationProperties
@ConfigurationProperties(prefix = "server")
public class ServerConfig {
    private String host = "localhost";
    private int port = 8080;
    private boolean debug = false;

    // getters and setters
}
```

```python
# Python: QwenPaw Pydantic 模型
from pydantic import BaseModel, Field

class ServerConfig(BaseModel):
    host: str = Field(default="localhost")
    port: int = Field(default=8080, ge=1, le=65535)
    debug: bool = Field(default=False)
```

**2. 配置加载**

```java
// Java: @Value 注入
@Value("${server.host:localhost}")
private String host;

@Value("${server.port:8080}")
private int port;
```

```python
# Python: EnvVarLoader
host = EnvVarLoader.get_str("SERVER_HOST", "localhost")
port = EnvVarLoader.get_int("SERVER_PORT", 8080)
```

**3. 配置文件**

```java
// Java: application.yml
server:
  host: localhost
  port: 8080
  debug: false
```

```python
# Python: config.json
{
    "host": "localhost",
    "port": 8080,
    "debug": false
}
```

**4. 配置验证**

```java
// Java: JSR-303 验证
@Min(1) @Max(65535)
private int port;

@Pattern(regexp = "^[a-zA-Z0-9]+$")
private String host;
```

```python
# Python: Pydantic 验证
from pydantic import Field, field_validator

port: int = Field(default=8080, ge=1, le=65535)

@field_validator("host")
@classmethod
def validate_host(cls, v: str) -> str:
    if not v.isalnum():
        raise ValueError("Host must be alphanumeric")
    return v
```

### Java 开发者注意事项

1. **Pydantic vs Spring Boot**: QwenPaw 使用 Pydantic 进行配置验证，类似于 Spring Boot 的 `@ConfigurationProperties`。

2. **配置优先级**: QwenPaw 的优先级是 环境变量 > 配置文件 > 默认值，与 Spring Boot 类似。

3. **类型安全**: `EnvVarLoader.get_*()` 方法提供类型安全的环境变量访问，类似于 Spring 的 `@Value` 注解。

4. **分层配置**: QwenPaw 的 Config（根配置）和 AgentProfileConfig（Agent配置）类似于 Spring 的父子上下文。

5. **配置刷新**: QwenPaw 通过重新调用 `load_config()` 实现配置刷新，类似于 Spring 的 `@RefreshScope`。
