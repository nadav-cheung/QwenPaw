## 1. 技能系统概述

### 1.1 什么是技能

技能（Skills）是 QwenPaw 扩展能力的核心机制。每个技能可以让 AI 执行特定任务：

```
┌─────────────────────────────────────────────┐
│              QwenPaw Agent                  │
├─────────────────────────────────────────────┤
│                                             │
│  ┌─────────┐  ┌─────────┐  ┌─────────┐    │
│  │ WebSearch│  │ Weather │  │ FileOp  │    │
│  │  技能   │  │  技能   │  │  技能   │    │
│  └────┬────┘  └────┬────┘  └────┬────┘    │
│       │              │              │        │
│       └──────────────┼──────────────┘        │
│                      │                        │
│              ┌───────▼───────┐               │
│              │   Skill Scanner │              │
│              │   (安全扫描)    │              │
│              └───────────────┘               │
└─────────────────────────────────────────────┘
```

### 1.2 技能分类

| 类型 | 说明 | 示例 |
|------|------|------|
| **内置技能** | QwenPaw 自带的技能 | 文件操作、搜索 |
| **社区技能** | 社区贡献的技能 | 第三方集成 |
| **自定义技能** | 你自己开发的技能 | 业务逻辑 |

## 3. 自定义技能开发

### 3.1 技能开发流程

```
1. 需求分析 → 确定技能功能
2. 编写代码 → 实现技能逻辑
3. 安全扫描 → 检查潜在风险
4. 注册技能 → 让系统知道这个技能
5. 测试验证 → 确保正常工作
```

### 3.2 技能基本结构

```python
# my_skill.py

from typing import Dict, Any

class MySkill:
    """自定义技能示例"""

    name = "my_skill"           # 技能名称
    description = "我的技能"     # 技能描述

    def __init__(self):
        self.enabled = True

    async def execute(self, params: Dict[str, Any]) -> str:
        """执行技能"""
        result = self.do_something(params)
        return result

    def do_something(self, params: Dict[str, Any]) -> str:
        """具体实现 - 安全的字符串处理"""
        # 使用安全的字符串操作
        input_text = params.get("input", "")
        return f"处理了: {input_text}"

    def get_schema(self) -> Dict[str, Any]:
        """返回技能参数 schema（用于 Function Calling）"""
        return {
            "name": self.name,
            "description": self.description,
            "parameters": {
                "type": "object",
                "properties": {
                    "input": {
                        "type": "string",
                        "description": "输入内容"
                    }
                },
                "required": ["input"]
            }
        }
```

## 4. 技能注册

### 4.1 注册技能

将技能添加到系统中：

```python
# 在 agents/skills/ 目录下
```

在 `config.yaml` 中配置：

```yaml

  websearch:
    enabled: true
    default_engine: "duckduckgo"
```

## 5. 技能安全

### 5.1 安全扫描

QwenPaw 会对技能进行安全扫描，检测：

| 风险类型 | 说明 |
|----------|------|
| **命令注入** | 尝试执行危险命令 |
| **Prompt 注入** | 恶意指令 |
| **数据泄露** | 敏感信息外传 |
| **硬编码密钥** | API 密钥硬编码在代码中 |

### 5.2 安全最佳实践

```python
class SafeSkill:
    """安全技能开发指南"""

    # ✅ 好的做法
    # - 验证所有输入参数
    # - 限制文件操作范围
    # - 不在代码中存储密钥
    # - 使用环境变量配置

    # ❌ 危险做法
    # - 使用 subprocess 执行命令
    # - 直接拼接 Shell 命令
    # - 读取任意路径文件
    # - 暴露内部状态
```

## 6. 实战项目：开发一个翻译技能

### 6.1 需求

创建一个翻译技能：
- 支持指定目标语言
- 返回翻译结果

### 6.2 实现

```python
# translator_skill.py

import httpx
from typing import Dict, Any

class TranslatorSkill:
    """翻译技能"""

    name = "translator"
    description = "翻译文本到指定语言"

    # 支持的目标语言
    SUPPORTED_LANGS = ["en", "ja", "ko", "fr", "de", "es"]

    def __init__(self):
        self.enabled = True

    async def execute(self, params: Dict[str, Any]) -> str:
        """执行翻译"""
        text = params.get("text", "")
        target_lang = params.get("target_lang", "en")

        if not text:
            return "请提供要翻译的文本"

        if target_lang not in self.SUPPORTED_LANGS:
            return f"不支持的目标语言: {target_lang}。支持的: {self.SUPPORTED_LANGS}"

        result = await self.translate(text, target_lang)
        return result

    async def translate(self, text: str, target_lang: str) -> str:
        """翻译逻辑（示例实现）"""
        # 这里可以接入实际的翻译 API
        # 如 Google Translate, DeepL, 有道等
        # 使用 httpx 等库发送 HTTP 请求

        # 示例：返回带语言标记的原文
        return f"[{target_lang.upper()}] {text}"

    def get_schema(self) -> Dict[str, Any]:
        """返回参数 schema"""
        return {
            "name": self.name,
            "description": self.description,
            "parameters": {
                "type": "object",
                "properties": {
                    "text": {
                        "type": "string",
                        "description": "要翻译的文本"
                    },
                    "target_lang": {
                        "type": "string",
                        "description": "目标语言代码",
                        "enum": self.SUPPORTED_LANGS
                    }
                },
                "required": ["text", "target_lang"]
            }
        }
```

## 7. 小结

### 技能系统架构

```
用户对话
    ↓
Agent 理解意图
    ↓
选择合适的 Skill
    ↓
Skill Scanner 安全检查
    ↓
Skill 执行
    ↓
返回结果
```

### 开发自定义技能

| 步骤 | 说明 |
|------|------|
| 1. 定义类 | 继承基础结构 |
| 2. 实现 execute | 核心执行逻辑 |
| 3. 定义 schema | Function Calling 接口 |
| 4. 安全检查 | 验证输入输出 |
| 5. 注册技能 | 加入系统 |

### 安全原则

- 验证所有输入
- 不执行危险操作
- 使用环境变量配置
- 定期更新维护
