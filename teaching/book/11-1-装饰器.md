## 1. 装饰器基础

### 1.1 什么是装饰器

装饰器是一种在不修改原函数的情况下，给函数添加新功能的语法糖。

```
┌─────────────────────────────────────┐
│           装饰器原理                  │
├─────────────────────────────────────┤
│                                     │
│   普通函数                           │
│       │                             │
│       ▼                             │
│   ┌─────────┐                      │
│   │  包装   │ ← 装饰器添加功能     │
│   └────┬────┘                      │
│        │                            │
│        ▼                            │
│   带新功能的函数                     │
└─────────────────────────────────────┘
```

### 1.2 先理解闭包

装饰器基于闭包，先理解闭包：

```python
def outer():
    """外部函数"""
    message = "Hello"

    def inner():
        """内部函数"""
        print(message)  # 访问外部变量

    return inner

# 调用 outer，返回 inner 函数
closure = outer()
# closure 记住了 message 变量
closure()  # 输出: Hello
```

### 1.3 高阶函数

接收函数作为参数或返回函数的函数：

```python
def before():
    """执行前的操作"""
    print("before")

def after():
    """执行后的操作"""
    print("after")

def wrapper(func):
    """包装函数（高阶函数）"""
    def inner():
        before()
        func()
        after()
    return inner
```

## 2. 第一个装饰器

### 2.1 定义装饰器

```python
def my_decorator(func):
    """简单的装饰器"""
    def wrapper():
        print(">>> 函数开始执行")
        func()
        print(">>> 函数执行结束")
    return wrapper
```

### 2.2 使用装饰器

```python
@my_decorator
def say_hello():
    print("Hello!")

# 等价于
def say_hello():
    print("Hello!")
say_hello = my_decorator(say_hello)
```

### 2.3 调用

```python
say_hello()
```

**输出**：
```
>>> 函数开始执行
Hello!
>>> 函数执行结束
```

## 3. 装饰器进阶

### 3.1 带参数的装饰器

```python
def repeat(times):
    """重复执行指定次数的装饰器"""
    def decorator(func):
        def wrapper(*args, **kwargs):
            for _ in range(times):
                func(*args, **kwargs)
        return wrapper
    return decorator

@repeat(times=3)
def greet(name):
    print(f"Hello, {name}!")

greet("小明")
```

**输出**：
```
Hello, 小明!
Hello, 小明!
Hello, 小明!
```

### 3.2 functools.wraps

保留原函数元信息：

```python
def my_decorator(func):
    def wrapper(*args, **kwargs):
        """wrapper 文档"""
        print("开始")
        result = func(*args, **kwargs)
        print("结束")
        return result
    # 关键！复制原函数的信息
    wrapper.__name__ = func.__name__
    wrapper.__doc__ = func.__doc__
    return wrapper

# 或者使用 functools
import functools

def my_decorator(func):
    @functools.wraps(func)  # 自动复制元信息
    def wrapper(*args, **kwargs):
        print("开始")
        return func(*args, **kwargs)
    return wrapper
```

### 3.3 类装饰器

```python
class CallCounter:
    """计数器装饰器（类形式）"""

    def __init__(self, func):
        self.func = func
        self.count = 0
        functools.update_wrapper(self, func)

    def __call__(self, *args, **kwargs):
        self.count += 1
        print(f"函数被调用了 {self.count} 次")
        return self.func(*args, **kwargs)

@CallCounter
def say_hello():
    print("Hello!")

say_hello()  # 函数被调用了 1 次
say_hello()  # 函数被调用了 2 次
```

## 4. 常用内置装饰器

### 4.1 @property

将方法变成属性：

```python
class User:
    def __init__(self, name):
        self._name = name

    @property
    def name(self):
        """获取名称"""
        return self._name

    @name.setter
    def name(self, value):
        """设置名称"""
        if not value:
            raise ValueError("名称不能为空")
        self._name = value

user = User("小明")
print(user.name)  # 小明
user.name = "小红"
print(user.name)  # 小红
```

### 4.2 @classmethod 和 @staticmethod

```python
class MathUtils:
    @classmethod
    def add(cls, a, b):
        """类方法，可访问类属性"""
        return a + b

    @staticmethod
    def multiply(a, b):
        """静态方法，不能访问类或实例属性"""
        return a * b

# 调用
print(MathUtils.add(1, 2))      # 3
print(MathUtils.multiply(3, 4))  # 12
```

## 5. 实战：日志装饰器

### 5.1 需求

创建一个日志装饰器，记录函数调用信息。

### 5.2 实现

```python
import functools
import logging
from datetime import datetime

def log_calls(logger=None):
    """日志装饰器"""
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            log = logger or logging.getLogger()

            start_time = datetime.now()
            log.info(f"开始执行: {func.__name__}")

            try:
                result = func(*args, **kwargs)
                duration = (datetime.now() - start_time).total_seconds()
                log.info(f"执行成功: {func.__name__} (耗时 {duration:.3f}s)")
                return result
            except Exception as e:
                duration = (datetime.now() - start_time).total_seconds()
                log.error(f"执行失败: {func.__name__} (耗时 {duration:.3f}s) - {e}")
                raise

        return wrapper
    return decorator

# 使用
@log_calls()
def divide(a, b):
    """除法函数"""
    return a / b

@log_calls()
def fetch_data(url):
    """获取数据"""
    return f"Data from {url}"
```

## 6. 小结

### 装饰器语法

```python
@decorator
def func():
    pass

# 等价于
def func():
    pass
func = decorator(func)
```

### 装饰器模板

```python
import functools

def my_decorator(func):
    @functools.wraps(func)  # 保留元信息
    def wrapper(*args, **kwargs):
        # 前置操作
        result = func(*args, **kwargs)
        # 后置操作
        return result
    return wrapper

# 带参数的装饰器
def decorator_with_args(arg):
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            # 使用 arg
            return func(*args, **kwargs)
        return wrapper
    return decorator
```
