## 1. 基本对话

### 1.1 发起对话

在 Web 界面中：
1. 点击左侧「新建对话」按钮
2. 在输入框中输入问题
3. 按 Enter 或点击发送按钮

### 1.2 对话技巧

| 技巧 | 示例 | 说明 |
|------|------|------|
| 明确具体 | "帮我写一封请假邮件" | 提供具体任务 |
| 提供背景 | "我是Java开发者，想学Python" | 帮助 AI 更好理解 |
| 分步提问 | 复杂问题拆成多个问题 | 得到更精确答案 |
| 指定格式 | "用表格展示" | 控制输出格式 |

### 1.3 示例对话

```
你：我想学习 Python，能推荐一个学习计划吗？

QwenPaw：当然可以！根据你的目标，我建议：

第一阶段（1-2周）：Python 基础
- 变量和数据类型
- 条件判断和循环
- 函数定义
- 列表和字典

第二阶段（3-4周）：进阶内容
- 面向对象编程
- 文件操作
- 异常处理

第三阶段（5-6周）：实战项目
- 开发小工具
- 自动化脚本
- Web 入门
```

## 2. 模型配置

### 2.1 在 Web 界面配置

1. 打开 http://127.0.0.1:8088/
2. 点击右上角「设置」
3. 选择「模型」选项卡
4. 选择提供商
5. 输入 API 密钥
6. 选择具体模型
7. 保存

### 2.2 支持的模型

| 提供商 | 模型示例 | 特点 |
|--------|----------|------|
| **Qwen** | qwen-plus, qwen-max | 便宜、适合中文 |
| **OpenAI** | gpt-4o, gpt-4-turbo | 强大、国际化 |
| **Claude** | claude-3-opus | 长文本强 |
| **Gemini** | gemini-pro | 免费额度多 |
| **Ollama** | qwen2.5, llama3 | 本地运行 |

### 2.3 本地模型

使用 Ollama 运行本地模型：

1. 安装 Ollama：https://ollama.com/
2. 拉取模型：
   ```bash
   ollama pull qwen2.5
   ```
3. 在 QwenPaw 中配置 Ollama：
   - 地址：`http://localhost:11434`
   - 模型：`qwen2.5`

## 3. 技能系统

### 3.1 什么是技能

技能（Skills）是 QwenPaw 的扩展机制，让 AI 能够执行特定任务。

### 3.2 内置技能

| 技能 | 命令 | 功能 |
|------|------|------|
| 网页搜索 | `/skill websearch` | 搜索互联网 |
| 天气查询 | `/skill weather` | 查询天气 |
| 新闻 | `/skill news` | 获取新闻 |
| 文件处理 | `/skill file` | 处理文件 |

### 3.3 使用技能

**方式一：使用命令**
```
/skill websearch Python入门教程
```

**方式二：在对话中调用**
```
QwenPaw，查一下今天有什么科技新闻
（AI 会自动调用新闻技能）
```

### 3.4 查看可用技能

输入 `/skills` 查看所有可用技能。

## 4. 定时任务

### 4.1 心跳功能

心跳功能可以定时执行任务：

1. 配置心跳任务
2. 设置执行时间
3. QwenPaw 会自动执行

### 4.2 设置每日提醒

在对话中输入：
```
每天早上8点提醒我查看邮件
```

QwenPaw 会自动设置定时任务。

### 4.3 查看定时任务

输入 `/tasks` 或在 Web 界面查看所有定时任务。

---

## 5. 消息渠道

### 5.1 什么是渠道

渠道让 QwenPaw 可以在不同平台上接收和发送消息。

### 5.2 支持的渠道

| 渠道 | 说明 | 配置难度 |
|------|------|----------|
| **Console** | Web 界面（默认） | ⭐ |
| **钉钉** | 企业办公 | ⭐⭐ |
| **飞书** | 字节跳动办公 | ⭐⭐ |
| **微信** | 个人微信 | ⭐⭐⭐ |
| **Discord** | 社区平台 | ⭐⭐ |
| **Telegram** | 即时通讯 | ⭐⭐ |

### 5.3 配置渠道

以飞书为例：

1. 打开飞书开放平台
2. 创建企业自建应用
3. 获取 App ID 和 App Secret
4. 配置机器人
5. 在 QwenPaw 中填入配置

详细配置请参考官方文档。

## 6. 多智能体

### 6.1 什么是多智能体

创建多个 AI 助手，每个有不同角色和能力。

### 6.2 创建智能体

在 Web 界面：
1. 点击「智能体」选项卡
2. 点击「创建智能体」
3. 设置名称、角色、模型
4. 保存

### 6.3 智能体协作

```
┌─────────────┐
│  你          │
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  助手1      │  ← 专门写代码
│  (程序员)    │
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  助手2      │  ← 专门检查bug
│  (Reviewer) │
└─────────────┘
```

### 7.2 长期记忆

## 8. 实战：成为你的私人助理

### 8.1 场景一：早晨简报

```
你：每天早上8点给我发一份科技新闻摘要
QwenPaw：好的！我会：
1. 每天早上8点自动搜索科技新闻
2. 筛选重要内容
3. 整理成简洁的摘要发送给你
```

### 8.2 场景二：邮件管理

```
你：帮我处理一下邮箱，找出重要的客户邮件
QwenPaw：好的，我来帮你检查邮件...
找到了3封重要邮件：
1. [客户] 张总询问项目进度
2. [客户] 李总确认下周会议
3. [系统] 服务器告警通知
```

### 8.3 场景三：文件整理

```
你：帮我整理一下桌面的文件，按类型分类
QwenPaw：好的，我来扫描桌面...
已整理：
📁 文档类 (5个):
   - 项目报告.docx
   - 会议纪要.pdf
   ...
📁 图片类 (12个):
   - screenshot.png
   - logo.jpg
   ...
```

## 10. 小结

### 本章要点

| 功能 | 说明 |
|------|------|
| **对话** | 在输入框提问，获取 AI 回复 |
| **模型** | 支持多种云端和本地模型 |
| **技能** | 扩展 AI 能力 |
| **定时** | 自动执行任务 |
| **渠道** | 多平台接入 |
| **多智能体** | 多个 AI 协作 |

### 快速入门

1. 安装：`pip install qwenpaw`
2. 初始化：`qwenpaw init --defaults`
3. 配置模型：在 Web 界面输入 API 密钥
4. 启动：`qwenpaw app`
5. 使用：打开 http://127.0.0.1:8088/ 开始对话
