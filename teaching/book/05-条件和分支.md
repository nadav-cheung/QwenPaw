## 1. 为什么要条件判断？

### 1.1 程序能做决定

现实中的决定：

```
如果 明天不下雨
    我就去公园
否则
    我就在家看书
```

程序中的决定：

```python
weather = "下雨"

if weather == "不下雨":
    print("我去公园")
else:
    print("我在家看书")
```

### 1.2 生活处处是条件

| 场景 | 条件 | 结果 |
|------|------|------|
| 出门 | 如果下雨 | 带伞 |
| 吃饭 | 如果饿了 | 去吃饭 |
| 学习 | 如果考试 | 复习 |
| 睡觉 | 如果困了 | 睡觉 |

## 2. if 语句基础

### 2.1 最简单的 if

```python
age = 18

if age >= 18:
    print("你已经成年了")
```

**注意**：条件后面要有冒号 `:`，下一行要缩进！

### 2.2 if...else 结构

```python
age = 16

if age >= 18:
    print("你可以投票")
else:
    print("你还不能投票")
```

### 2.3 if...elif...else 结构

```python
score = 85

if score >= 90:
    print("优秀")
elif score >= 80:
    print("良好")
elif score >= 60:
    print("及格")
else:
    print("不及格")
```

### 2.4 流程图

```
         开始
           │
           ▼
      ┌─────────┐
      │ score   │
      │ >= 90?  │
      └────┬────┘
           │
      ┌────┴────┐
      │ 是       │ 否
      ▼         ▼
   ┌─────┐  ┌─────────┐
   │优秀 │  │ score   │
   └─────┘  │ >= 80?  │
            └────┬────┘
                 │
            ┌────┴────┐
            │ 是       │ 否
            ▼         ▼
         ┌─────┐  ┌─────────┐
         │良好 │  │  ...    │
         └─────┘  └─────────┘
```

## 3. 条件表达式

### 3.1 比较运算符

```python
a, b = 10, 20

# 相等和不等于
a == b    # False（等于）
a != b    # True（不等于）

# 大小比较
a > b     # False
a < b     # True
a >= b    # False
a <= b    # True
```

### 3.2 布尔运算

```python
# and：两边都成立才算 True
True and True    # True
True and False   # False
False and False # False

# or：一边成立就算 True
True or False    # True
False or True   # True
False or False  # False

# not：取反
not True         # False
not False        # True
```

### 3.3 组合条件

```python
age = 25
has_ticket = True

# 组合：年龄大于等于18 且 有票
if age >= 18 and has_ticket:
    print("可以观看电影")

# 组合：满18岁 或者 有监护人同意
if age >= 18 or has_parent_permission:
    print("可以参加")
```

### 3.4 短路运算

```python
# and 短路：第一个为 False，后面的不看了
False and print("不会执行")  # False

# or 短路：第一个为 True，后面的不看了
True or print("不会执行")    # True
```

## 4. 常见用法

### 4.1 检查是否为空

```python
name = input("请输入名字: ")

if name:  # 空字符串是 False
    print(f"你好，{name}！")
else:
    print("你没有输入名字")
```

### 4.2 检查是否为零

```python
number = int(input("请输入数字: "))

if number != 0:
    print(f"100 / {number} = {100 / number}")
else:
    print("不能除以零！")
```

### 4.3 多个条件判断

```python
age = int(input("请输入年龄: "))

if age < 0:
    print("年龄不能为负数")
elif age < 18:
    print("未成年")
elif age < 65:
    print("成年人")
else:
    print("老年人")
```

## 5. 三元表达式

### 5.1 什么是三元表达式

条件运算符：`值1 if 条件 else 值2`

```python
# 如果 age >= 18，status = "成年"，否则 = "未成年"
age = 20
status = "成年" if age >= 18 else "未成年"
print(status)  # 成年
```

### 5.2 应用场景

```python
# 简化 if...else
age = 16
print("可以投票" if age >= 18 else "不能投票")

# 取两个值中的较大者
a, b = 10, 20
max_val = a if a > b else b
print(f"较大值: {max_val}")

# 避免除零
divisor = 0
result = "无穷大" if divisor == 0 else 100 / divisor
```

## 6. 实战项目：猜数字游戏

### 6.1 需求分析

程序随机生成一个 1-100 的数字，玩家猜测，程序提示猜大了还是猜小了，直到猜对为止。

### 6.2 代码实现

```python
import random

# ========================================
# 猜数字游戏 v1.0
# ========================================

print("=" * 40)
print("  欢迎来到猜数字游戏！")
print("=" * 40)
print()
print("我想了一个 1-100 之间的数字")
print("你来猜，看看几次能猜对！")
print()

# 生成随机数
target = random.randint(1, 100)

# 游戏循环
attempts = 0
while True:
    guess_str = input("请输入你的猜测: ")

    # 检查输入是否有效
    if not guess_str.isdigit():
        print("请输入一个有效的数字！")
        continue

    guess = int(guess_str)
    attempts += 1

    # 判断
    if guess < 1 or guess > 100:
        print("数字必须在 1-100 之间！")
        attempts -= 1  # 无效猜测不计数
    elif guess < target:
        print("太小了，再大一点！")
    elif guess > target:
        print("太大了，再小一点！")
    else:
        print()
        print("=" * 40)
        print(f"🎉 恭喜你，猜对了！")
        print(f"你一共猜了 {attempts} 次")
        print("=" * 40)

        # 评价
        if attempts <= 5:
            print("太厉害了，你是高手！")
        elif attempts <= 10:
            print("不错不错，很聪明！")
        else:
            print("再接再厉，多练练！")
        break
```

### 6.3 运行效果

```

========================================

我想了一个 1-100 之间的数字
你来猜，看看几次能猜对！

请输入你的猜测: 50
太大了，再小一点！
请输入你的猜测: 25
太小了，再大一点！
请输入你的猜测: 37
太小了，再大一点！
请输入你的猜测: 43
🎉 恭喜你，猜对了！
你一共猜了 4 次
========================================
太厉害了，你是高手！
```
