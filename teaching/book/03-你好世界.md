## 1. 再探 print 函数

### 1.1 print 的基本用法

上一章我们用过 `print("你好")`，现在我们来深入了解它。

```python
# 打印文字（字符串）
print("Hello, World!")
print("你好，世界！")

# 打印数字（不需要引号）
print(42)
print(3.14)

# 打印计算结果
print(1 + 2 + 3)
print(10 * 5 - 3)
```

**运行结果**：
```
Hello, World!
你好，世界！
42
3.14
6
47
```

### 1.2 print 的高级用法

#### 1.2.1 打印多个人内容

```python
# 用逗号分隔，会自动加空格
print("姓名:", "张三", "年龄:", 25)
```

**运行结果**：
```
姓名: 张三 年龄: 25
```

#### 1.2.2 打印重复内容

```python
# 乘法可以让字符串重复
print("=" * 30)      # 打印 30 个 =
print("  居中标题  ")
print("=" * 30)
```

**运行结果**：
```
==============================
  居中标题
==============================
```

#### 1.2.3 打印特殊字符

```python
# 换行符 \n
print("第一行\n第二行\n第三行")

# 制表符 \t（相当于按 Tab）
print("姓名:\t张三")
print("电话:\t12345678")

# 引号
print("他说:\"你好\"")
print('她笑着说:\'很高兴认识你！\'')
```

**运行结果**：
```
第一行
第二行
第三行
姓名:    张三
电话:    12345678
他说:"你好"
她笑着说:'很高兴认识你！'
```

## 2. 字符串基础

### 2.1 什么是字符串？

**字符串**（String）就是文本，用引号包起来：

```python
# 三种引号都可以
单引号: 'Hello'
双引号: "Hello"
三引号: '''Hello'''  # 可以跨行
三双引号: """Hello"""
```

### 2.2 字符串拼接

```python
# 方法1：直接拼接
"Hello" + "World"      # "HelloWorld"

# 方法2：用 * 重复
"Ha" * 3               # "HaHaHa"

# 方法3：变量拼接
name = "小明"
"你好，" + name         # "你好，小明"
```

### 2.3 字符串格式化

#### 2.3.1 f-string（最推荐）

```python
name = "张三"
age = 25
height = 1.75

# f-string：直接在字符串里用变量
print(f"姓名: {name}")
print(f"年龄: {age}")
print(f"身高: {height}米")
```

**运行结果**：
```
姓名: 张三
年龄: 25
身高: 1.75米
```

```python
# f-string 里可以写表达式
a = 10
b = 20
print(f"{a} + {b} = {a + b}")
print(f"{a} * {b} = {a * b}")
```

**运行结果**：
```
10 + 20 = 30
10 * 20 = 200
```

#### 2.3.2 format 方法

```python
name = "李四"
age = 30

# 旧式方法
"姓名: {}，年龄: {}".format(name, age)
```

### 2.4 字符串方法

Python 为字符串准备了很多实用方法：

```python
text = "  Hello, Python!  "

# 去除空格
text.strip()           # "Hello, Python!"
text.lstrip()          # "Hello, Python!  "（去左边）
text.rstrip()          # "  Hello, Python!"（去右边）

# 大小写转换
text.upper()           # "  HELLO, PYTHON!  "
text.lower()           # "  hello, python!  "
text.capitalize()      # "  hello, python!  "
text.title()           # "  Hello, Python!  "

# 查找和替换
text.find("Python")    # 10（找不到返回 -1）
text.replace("Python", "World")  # "  Hello, World!  "

# 判断
text.startswith("  H") # True
text.endswith("!  ")   # True
text.isdigit()         # False
"123".isdigit()        # True
```

## 3. 注释的艺术

### 3.1 为什么要写注释？

```python
# 这段代码没有人看得懂...
result = (x + y) * z / 2

# 计算三角形的面积
# 公式：底 × 高 ÷ 2
base = 10
height = 5
area = base * height / 2  # 面积 = 底 × 高 ÷ 2
```

**注释的好处**：
- 让自己以后看得懂
- 让别人能理解你的代码
- 方便调试（注释掉某行代码）

### 3.2 单行注释

```python
# 这是一个注释
print("这行会执行")  # 行尾注释

x = 5  # 初始化变量
```

### 3.3 多行注释

```python
# 这是第一行注释
# 这是第二行注释
# 这是第三行注释

# 或者用三引号（实际上是字符串，但可以当注释用）
"""
这是多行注释
可以写很多很多内容
"""
```

### 3.4 注释的使用建议

| ✅ 好注释 | ❌ 坏注释 |
|----------|----------|
| 解释**为什么**这样做 | 重复代码说的内容 |
| 说明**复杂**的逻辑 | 写显而易见的废话 |
| 标注**重要**的变量 | 太多注释干扰阅读 |
| 解释**业务**逻辑 | 写错了的注释更糟 |

```python
# ❌ 坏例子：废话注释
x = 5  # 把5赋值给x

# ✅ 好例子：解释原因
x = 5  # 初始化计数器，避免数组越界
```

## 4. input 函数：让你的程序互动起来

### 4.1 什么是 input？

`input()` 函数可以获取用户的键盘输入：

```python
# 运行到这里程序会等待用户输入
name = input("请输入你的名字: ")

# 用户输入后，按回车确认
# 输入的内容会保存到 name 变量

print(f"你好，{name}！")
```

**运行示例**：
```
请输入你的名字: 小明
你好，小明！
```

### 4.2 input 的工作流程

```
1. 程序运行到 input()
2. 打印提示文字
3. 等待用户输入（光标闪烁）
4. 用户输入内容，按回车
5. input() 返回用户输入的内容
6. 程序继续往下执行
```

### 4.3 input 练习

#### 练习：自我介绍程序

```python

print("=" * 30)

**运行示例**：

  你的自我介绍

大家好，我叫小明，今年25岁

很高兴认识大家！
```

### 4.4 input 的注意事项

#### 4.4.1 input 总是返回字符串

```python
age = input("请输入年龄: ")
print(type(age))  # <class 'str'> - 字符串类型！

# 如果要当数字用，需要转换
age = int(input("请输入年龄: "))  # 转成整数
price = float(input("请输入价格: "))  # 转成小数
```

#### 4.4.2 类型转换

```python
# 字符串 → 整数
int("42")          # 42

# 字符串 → 小数
float("3.14")      # 3.14

# 数字 → 字符串
str(42)            # "42"
str(3.14)          # "3.14"
```

## 5. 实战项目：计算器

### 5.1 需求分析

创建一个简单的计算器，可以：
- 输入两个数字
- 选择运算（加减乘除）
- 展示结果

### 5.2 代码实现

```python
# ========================================
# 简易计算器 v1.0
# ========================================

print("=" * 30)
print("  欢迎使用简易计算器")
print("=" * 30)
print()

# 获取用户输入
num1 = float(input("请输入第一个数字: "))
num2 = float(input("请输入第二个数字: "))

print()
print("请选择运算:")
print("  1. 加法 (+)")
print("  2. 减法 (-)")
print("  3. 乘法 (×)")
print("  4. 除法 (÷)")

choice = input("请输入选项 (1/2/3/4): ")

# 计算结果
if choice == "1":
    result = num1 + num2
    symbol = "+"
elif choice == "2":
    result = num1 - num2
    symbol = "-"
elif choice == "3":
    result = num1 * num2
    symbol = "×"
elif choice == "4":
    if num2 != 0:
        result = num1 / num2
        symbol = "÷"
    else:
        print("错误：除数不能为零！")
        result = None
else:
    print("错误：无效的选项！")
    result = None

# 输出结果
if result is not None:
    print()
    print("=" * 30)
    print(f"计算结果: {num1} {symbol} {num2} = {result}")
    print("=" * 30)
```

### 5.3 运行效果

```
==============================
  欢迎使用简易计算器
==============================

请输入第一个数字: 10
请输入第二个数字: 3

请选择运算:
  1. 加法 (+)
  2. 减法 (-)
  3. 乘法 (×)
  4. 除法 (÷)
请输入选项 (1/2/3/4): 3

==============================
计算结果: 10.0 × 3.0 = 30.0
==============================
```

## 6. 常见错误与调试

### 6.1 常见错误

#### 6.1.1 引号不匹配

```python
# ❌ 错误：引号没成对
print("你好)

# ✅ 正确
print("你好")
```

#### 6.1.2 变量名拼写错误

```python
name = "小明"
print(nmae)  # ❌ NameError: name 未定义
```

#### 6.1.3 类型错误

```python
age = input("年龄: ")  # input 返回字符串
print(age + 5)  # ❌ 字符串不能和数字相加
```

### 6.2 调试技巧

#### 6.2.1 打印中间变量

```python
# 发现结果不对时，在关键位置打印变量
age = input("年龄: ")
print(f"用户输入的是: {age}")  # 调试用
age = int(age)
print(f"转换后的是: {age}")    # 调试用
```

#### 6.2.2 逐行分析

遇到错误时：
1. 仔细阅读错误信息
2. 找到出错的那一行
3. 检查那一行的代码有没有问题
4. 向前追溯，看看是不是前面的代码导致的
