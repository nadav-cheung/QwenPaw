## 1. 模块基础

### 1.1 什么是模块

**模块**是一个 Python 文件，包含函数、类、变量等。

```
my_module.py    ← 这是一个模块
    │
    ├── def greet():    ← 函数
    ├── class User:     ← 类
    └── PI = 3.14      ← 变量
```

### 1.2 为什么需要模块

| 没有模块 | 有模块 |
|----------|--------|
| 所有代码挤在一起 | 代码分门别类 |
| 难以复用 | 一次编写，多次使用 |
| 难以维护 | 修改一个模块，影响局部 |

### 1.3 标准库模块

Python 自带很多模块（标准库）：

```python
import math
print(math.pi)           # 3.141592653589793
print(math.sqrt(16))     # 4.0

import random
print(random.randint(1, 10))  # 随机整数

import datetime
print(datetime.datetime.now())  # 当前时间
```

## 2. import 用法

### 2.1 基本导入

```python
# 导入整个模块
import math
print(math.sqrt(16))

# 导入多个模块
import math, random, datetime
```

### 2.2 from...import

```python
# 从模块导入特定内容
from math import sqrt, pi
print(sqrt(16))  # 4.0
print(pi)        # 3.14

# 导入所有（不推荐）
from math import *  # 导入 math 所有内容
```

### 2.3 as 别名

```python
import math as m
print(m.sqrt(16))

from datetime import datetime as dt
print(dt.now())
```

### 2.4 模块搜索路径

Python 按以下顺序查找模块：

```
1. 当前目录
2. PYTHONPATH 环境变量
3. Python 安装目录（site-packages）
4. 系统路径
```

查看路径：
```python
import sys
print(sys.path)
```

## 3. 创建模块

### 3.1 第一个模块

创建文件 `greetings.py`：

```python
# greetings.py

def say_hello(name):
    """打招呼"""
    return f"你好，{name}！"

def say_goodbye(name):
    """道别"""
    return f"再见，{name}！"

GREETING = "欢迎来到 Python 世界"
```

### 3.2 使用自己的模块

在同一目录下创建 `main.py`：

```python
# main.py

import greetings

print(greetings.say_hello("小明"))
print(greetings.say_goodbye("小明"))
print(greetings.GREETING)
```

### 3.3 模块的特殊变量

每个模块都有一些特殊变量：

```python
# my_module.py

print(__name__)  # 模块名
print(__file__)  # 文件路径
print(__doc__)   # 文档字符串
```

```python
# 当直接运行模块时
if __name__ == "__main__":
    print("直接运行模块")
else:
    print("被导入使用")
```

## 4. 包

### 4.1 什么是包

**包**是包含 `__init__.py` 的目录，用于组织多个模块。

```
my_package/           ← 包目录
├── __init__.py      ← 包初始化文件
├── module1.py       ← 模块1
├── module2.py       ← 模块2
└── sub_package/     ← 子包
    ├── __init__.py
    └── module3.py
```

### 4.2 创建包

创建目录结构：

```
my_package/
├── __init__.py
├── utils.py
└── models/
    ├── __init__.py
    └── user.py
```

`my_package/__init__.py`：
```python
# 包的初始化代码
print("my_package 已导入")
```

`my_package/utils.py`：
```python
def add(a, b):
    return a + b
```

`my_package/models/user.py`：
```python
class User:
    def __init__(self, name):
        self.name = name
```

### 4.3 使用包

```python
# 导入整个包
import my_package

# 导入模块
from my_package import utils
from my_package.models import user

# 使用
print(utils.add(1, 2))
u = user.User("小明")
```

## 5. pip 包管理器

### 5.1 pip 基础

| 命令 | 说明 |
|------|------|
| `pip install 包名` | 安装包 |
| `pip uninstall 包名` | 卸载包 |
| `pip list` | 列出已安装的包 |
| `pip show 包名` | 显示包信息 |
| `pip freeze` | 导出依赖 |

### 5.2 安装包

```bash
# 安装单个包
pip install requests

# 安装指定版本
pip install requests==2.28.0

# 安装最新版本
pip install --upgrade requests
```

### 5.3 requirements.txt

项目依赖文件：

```
# requirements.txt
requests>=2.28.0
flask>=2.0
numpy>=1.21.0
```

批量安装：
```bash
pip install -r requirements.txt
```

## 6. 虚拟环境

### 6.1 为什么需要虚拟环境

不同项目可能需要不同版本的包，虚拟环境可以隔离依赖。

```
项目A (需要 Django 2.0)
    └── venv_A/

项目B (需要 Django 4.0)
    └── venv_B/
```

### 6.2 创建虚拟环境

```bash
# 创建
python -m venv my_env

# 激活
# Linux/macOS:
source my_env/bin/activate

# Windows:
my_env\Scripts\activate

# 激活后，pip 安装的包只在当前环境有效
pip install requests
```

### 6.3 退出虚拟环境

```bash
deactivate
```

## 7. 实战：创建一个工具包

### 7.1 项目结构

```
mytools/
├── __init__.py
├── math_utils.py
├── string_utils.py
└── date_utils.py
```

### 7.2 实现代码

`mytools/__init__.py`：
```python
"""mytools - 我的工具包"""

from .math_utils import add, subtract, multiply, divide
from .string_utils import capitalize_words, remove_duplicates
from .date_utils import get_today, get_weekday

__all__ = [
    'add', 'subtract', 'multiply', 'divide',
    'capitalize_words', 'remove_duplicates',
    'get_today', 'get_weekday'
]
```

`mytools/math_utils.py`：
```python
"""数学工具"""

def add(a, b):
    """加法"""
    return a + b

def subtract(a, b):
    """减法"""
    return a - b

def multiply(a, b):
    """乘法"""
    return a * b

def divide(a, b):
    """除法"""
    if b == 0:
        raise ValueError("除数不能为零")
    return a / b
```

`mytools/string_utils.py`：
```python
"""字符串工具"""

def capitalize_words(text):
    """首字母大写"""
    return text.title()

def remove_duplicates(text):
    """去重"""
    return ''.join(dict.fromkeys(text))
```

`mytools/date_utils.py`：
```python
"""日期工具"""
from datetime import datetime

def get_today():
    """获取今天日期"""
    return datetime.now().strftime("%Y-%m-%d")

def get_weekday():
    """获取星期几"""
    weekdays = ["一", "二", "三", "四", "五", "六", "日"]
    return weekdays[datetime.now().weekday()]
```

### 7.3 使用工具包

```python
import mytools

# 数学工具
print(mytools.add(10, 20))      # 30
print(mytools.divide(10, 2))    # 5.0

# 字符串工具
print(mytools.capitalize_words("hello world"))  # Hello World

# 日期工具
print(mytools.get_today())      # 2026-05-08
print(mytools.get_weekday())    # 五
```

## 8. 小结

### 核心概念

| 概念 | 说明 |
|------|------|
| **模块** | 一个 .py 文件 |
| **包** | 包含 `__init__.py` 的目录 |
| **import** | 导入模块/包 |

### import 用法

```python
import module
import package.module
from module import function
from package import *
import module as alias
```

### pip 命令

```bash
pip install 包名
pip uninstall 包名
pip list
pip freeze > requirements.txt
```
