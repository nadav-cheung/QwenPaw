# 《零基础学 QwenPaw 源码与开发》

## 书籍简介

本书面向**完全没有编程经验的初学者**，通过 QwenPaw 这个真实开源项目，带领读者从零开始学习 Python 编程，并逐步掌握阅读源码、参与开源开发的能力。

**学习路径**：编程基础 → Python 入门 → QwenPaw 使用 → 源码阅读 → 参与开发

## 🛠️ 技术栈

| 类别 | 技术 | 说明 |
|------|------|------|
| 核心语言 | Python 3.10+ | 整个项目用 Python 开发 |
| 智能体框架 | AgentScope | 多智能体运行时 |
| Web 服务 | FastAPI + Uvicorn | 高性能 API 服务 |
| 前端界面 | React + TypeScript | 用户界面 |
| 异步框架 | anyio + asyncio | 高效并发处理 |
| 任务调度 | APScheduler | 定时任务管理 |

## 📦 QwenPaw 源码结构

```
src/qwenpaw/
├── agents/              # 智能体核心
│   ├── react_agent.py  # QwenPawAgent 核心类
│   ├── tools/          # 内置工具
│   ├── skills/         # 内置技能
│   ├── memory/         # 记忆系统
│   └── hooks/          # 生命周期钩子
├── app/                # 应用系统
│   ├── server.py       # FastAPI 服务器
│   ├── channels/       # 消息渠道
│   ├── runner/         # 请求处理器
│   └── multi_agent_manager.py  # 多智能体管理
├── providers/          # LLM 提供商
│   ├── provider_manager.py  # 提供商管理
│   ├── openai_provider.py  # OpenAI
│   ├── ollama_provider.py  # Ollama
│   └── ...
├── security/           # 安全系统
│   ├── tool_guard/     # 工具守卫
│   ├── file_guard/     # 文件守卫
│   └── secret_store.py # 密钥存储
└── cli/                # 命令行工具
```
