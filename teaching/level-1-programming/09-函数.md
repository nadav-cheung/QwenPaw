## 1. 为什么要用函数？

### 1.1 没有函数的问题

假设你写了一个计算面积的程序，后面多处用到：

```python
# 第一次用
r = 5
area = 3.14 * r * r
print(f"圆1面积: {area}")

# 第二次用
r = 10
area = 3.14 * r * r
print(f"圆2面积: {area}")

# 第三次用
r = 3
area = 3.14 * r * r
print(f"圆3面积: {area}")
```

**问题**：
- 代码重复
- 如果要改公式（比如用更精确的 π），要改很多地方
- 代码难以阅读

### 1.2 用函数来解决

```python
# 定义函数
def calculate_circle_area(radius):
    """计算圆的面积"""
    pi = 3.14159
    area = pi * radius * radius
    return area

# 调用函数
area1 = calculate_circle_area(5)
area2 = calculate_circle_area(10)
area3 = calculate_circle_area(3)

print(f"圆1面积: {area1}")
print(f"圆2面积: {area2}")
print(f"圆3面积: {area3}")
```

**好处**：
- 代码不重复
- 改公式只需改一处
- 代码更易读

## 2. 定义和调用函数

### 2.1 基本语法

```python
def 函数名():
    """函数的说明文档"""
    函数体
    return 返回值  # 可选
```

### 2.2 无参数无返回值

```python
def say_hello():
    """打招呼"""
    print("你好！")
    print("欢迎来到 Python 世界！")

# 调用
say_hello()
```

### 2.3 有参数

```python
def greet(name):
    """向指定的人打招呼"""
    print(f"你好，{name}！")

# 调用
greet("小明")
greet("小红")
```

### 2.4 有返回值

```python
def add(a, b):
    """返回两个数的和"""
    result = a + b
    return result

# 调用
sum_val = add(3, 5)
print(f"3 + 5 = {sum_val}")
```

## 3. 参数详解

### 3.1 位置参数

按顺序传递：

```python
def introduce(name, age, city):
    print(f"我叫{name}，今年{age}岁，来自{city}")

introduce("小明", 25, "北京")
# name="小明", age=25, city="北京"
```

### 3.2 关键字参数

按名字传递：

```python
introduce(age=30, name="小红", city="上海")
# 不管顺序，按名字传递
```

### 3.3 默认参数

给参数默认值：

```python
def greet(name, greeting="你好"):
    print(f"{greeting}，{name}！")

greet("小明")           # 你好，小明！
greet("小红", "早上好") # 早上好，小红！
```

### 3.4 可变参数

不确定有多少参数：

```python
def sum_all(*numbers):
    """求所有参数的和"""
    total = 0
    for n in numbers:
        total += n
    return total

print(sum_all(1, 2, 3))        # 6
print(sum_all(10, 20, 30, 40)) # 100
```

## 4. 返回值详解

### 4.1 return 的作用

```python
def get_greeting(time):
    if time == "morning":
        return "早上好"
    elif time == "afternoon":
        return "下午好"
    else:
        return "晚上好"

msg = get_greeting("morning")
print(msg)  # 早上好
```

### 4.2 返回多个值

```python
def get_stats(numbers):
    """返回最小值、最大值、平均值"""
    min_val = min(numbers)
    max_val = max(numbers)
    avg_val = sum(numbers) / len(numbers)
    return min_val, max_val, avg_val

# 调用 - 接收多个返回值
min_num, max_num, avg_num = get_stats([1, 2, 3, 4, 5])
print(f"最小: {min_num}, 最大: {max_num}, 平均: {avg_num}")
```

### 4.3 None 返回值

没有 return 或 return 空，函数返回 None：

```python
def print_hello():
    print("你好")

result = print_hello()
print(result)  # None
```

## 5. 变量作用域

### 5.1 局部变量

在函数内部定义的变量，只在函数内部有效：

```python
def my_function():
    x = 10  # 局部变量
    print(f"函数内部 x = {x}")

my_function()
print(x)  # 错误！x 在函数外不存在
```

### 5.2 全局变量

在函数外部定义的变量：

```python
global_var = "我是全局变量"

def my_function():
    print(f"可以访问: {global_var}")

my_function()
print(f"函数外也可以访问: {global_var}")
```

### 5.3 global 关键字

在函数内修改全局变量：

```python
counter = 0

def increment():
    global counter  # 声明要使用全局变量
    counter += 1
    print(f"计数器: {counter}")

increment()  # 计数器: 1
increment()  # 计数器: 2
print(counter)  # 2
```

## 6. 实战项目：计算器模块

### 6.1 需求分析

创建一个计算器模块，包含：
- 加法
- 减法
- 乘法
- 除法
- 阶乘
- 幂运算

### 6.2 代码实现

```python
# ========================================
# 计算器模块
# ========================================

def add(a, b):
    """加法"""
    return a + b

def subtract(a, b):
    """减法"""
    return a - b

def multiply(a, b):
    """乘法"""
    return a * b

def divide(a, b):
    """除法（除数不能为零）"""
    if b == 0:
        return "错误：除数不能为零"
    return a / b

def factorial(n):
    """阶乘"""
    if n < 0:
        return "错误：负数没有阶乘"
    if n == 0 or n == 1:
        return 1
    result = 1
    for i in range(2, n + 1):
        result *= i
    return result

def power(base, exponent):
    """幂运算"""
    return base ** exponent


# ========================================
# 主程序
# ========================================

def calculator():
    """交互式计算器"""
    print("=" * 40)
    print("  欢迎使用 Python 计算器")
    print("=" * 40)
    print()
    print("支持的运算:")
    print("  1. 加法 (+)")
    print("  2. 减法 (-)")
    print("  3. 乘法 (×)")
    print("  4. 除法 (÷)")
    print("  5. 阶乘 (!)")
    print("  6. 幂运算 (^)")
    print("  0. 退出")
    print()

    while True:
        choice = input("请选择运算 (0-6): ")

        if choice == "0":
            print("感谢使用，再见！")
            break

        if choice in ["1", "2", "3", "4"]:
            try:
                a = float(input("请输入第一个数: "))
                b = float(input("请输入第二个数: "))
            except ValueError:
                print("错误：请输入有效的数字！")
                continue

        elif choice == "5":
            try:
                n = int(input("请输入一个整数: "))
            except ValueError:
                print("错误：请输入有效的整数！")
                continue

        # 执行运算
        if choice == "1":
            result = add(a, b)
            symbol = "+"
        elif choice == "2":
            result = subtract(a, b)
            symbol = "-"
        elif choice == "3":
            result = multiply(a, b)
            symbol = "×"
        elif choice == "4":
            result = divide(a, b)
            symbol = "÷"
        elif choice == "5":
            result = factorial(n)
            symbol = "!"
        elif choice == "6":
            try:
                base = float(input("请输入底数: "))
                exp = float(input("请输入指数: "))
            except ValueError:
                print("错误：请输入有效的数字！")
                continue
            result = power(base, exp)
            print(f"{base} ^ {exp} = {result}")
            continue
        else:
            print("错误：无效的选择！")
            continue

        if choice == "5":
            print(f"{n}{symbol} = {result}")
        else:
            print(f"{a} {symbol} {b} = {result}")
        print()


if __name__ == "__main__":
    calculator()
```

### 6.3 运行效果

```

========================================

支持的运算:
```

## 8. 小结

### 本章要点

| 概念 | 说明 |
|------|------|
| `def 函数名():` | 定义函数 |
| `参数` | 函数接收的输入 |
| `return 值` | 函数返回的结果 |
| `*args` | 可变位置参数 |
| `**kwargs` | 可变关键字参数 |

### 参数类型

| 类型 | 语法 | 说明 |
|------|------|------|
| 位置参数 | `func(a, b)` | 按顺序传递 |
| 关键字参数 | `func(a=1, b=2)` | 按名字传递 |
| 默认参数 | `func(a, b=10)` | 有默认值 |
| 可变参数 | `func(*args)` | 不定个数 |

### 作用域

| 变量类型 | 定义位置 | 访问范围 |
|----------|----------|----------|
| 局部变量 | 函数内部 | 仅函数内部 |
| 全局变量 | 函数外部 | 整个文件 |
