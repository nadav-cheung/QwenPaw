## 1. 什么是变量？

### 1.1 生活中的"变量"

想象一个带标签的储物盒：

```
┌─────────────────┐
│   [姓名盒]      │  ← 标签（变量名）
│                 │
│     小明        │  ← 里面装的东西（值）
└─────────────────┘
```

变量就像这样一个带标签的盒子，用来存放数据。

### 1.2 编程中的变量

```python
# 创建一个变量
name = "小明"

# 使用变量
print(name)  # 输出: 小明

# 修改变量
name = "小红"
print(name)  # 输出: 小红
```

### 1.3 变量的工作原理

```
name = "小明"
         ↓
    ┌──────────────┐
    │ name 变量    │
    │ "小明" 这个值 │
    └──────────────┘
```

| 概念 | 说明 |
|------|------|
| **变量名** | 给存储空间起的名字 |
| **赋值** | 把值存到变量里（用 `=`） |
| **取值** | 读取变量的值 |

## 2. 创建和使用变量

### 2.1 基本语法

```python
# 变量名 = 值
name = "张三"
age = 25
height = 1.75
is_student = True
```

### 2.2 变量命名规则

| 规则 | 正确示例 | 错误示例 |
|------|----------|----------|
| 字母、数字、下划线 | `name1`、`user_name` | `user-name`（不能有 `-`） |
| 不能以数字开头 | `name1` ✓ | `1name` ✗ |
| 大小写敏感 | `Name` 和 `name` 不同 | -- |
| 不能用关键字 | `if`、`for`、`class` | `for = 1` ✗ |

### 2.3 常见关键字（不能用作变量名）

```python
and       as        assert    async     await
break     class     continue  def       del
elif      else      except    False     finally
for       from      global    if        import
in        is        lambda    None      nonlocal
not       or        pass      raise     return
True      try       while     with      yield
```

### 2.4 好的命名习惯

| ❌ 坏名字 | ✅ 好名字 | 说明 |
|-----------|----------|------|
| `a` | `age` | 见名知意 |
| `x` | `user_name` | 描述清晰 |
| `tmp` | `temporary_file` | 不缩写 |
| `n1` | `first_number` | 有意义 |
| `data` | `user_data` | 更具体 |

### 2.5 命名风格

Python 社区推荐的命名风格：

```python
# 变量：小写下划线
user_name = "小明"
user_age = 25

# 常量：全大写下划线
MAX_RETRY_COUNT = 3
API_BASE_URL = "https://api.example.com"

# 类名：首字母大写
class UserProfile:
    pass

# 函数名：小写下划线
def get_user_info():
    pass
```

## 3. Python 的数据类型

### 3.1 数据类型一览

| 类型 | 说明 | 示例 |
|------|------|------|
| `int` | 整数 | `42`、`-7`、`0` |
| `float` | 小数 | `3.14`、`-0.5`、`2.0` |
| `str` | 字符串 | `"你好"`、`'hello'` |
| `bool` | 布尔值 | `True`、`False` |
| `None` | 空值 | `None` |

### 3.2 整数（int）

```python
# 整数
age = 25
year = 2026
negative = -10
zero = 0

# 支持各种进制（了解即可）
binary = 0b1010      # 二进制：10
octal = 0o12         # 八进制：10
hexadecimal = 0xA    # 十六进制：10

# 大整数
big_number = 1_000_000_000  # 下划线可读性更强
```

### 3.3 浮点数（float）

```python
# 小数
pi = 3.14159
price = 19.99
negative = -0.5

# 科学计数法
light_speed = 3e8   # 3 × 10^8 = 300000000.0
```

### 3.4 字符串（str）

```python
# 用引号包起来
name = "张三"
message = '你好'

# 三引号可以跨行
poem = """
床前明月光，
疑是地上霜。
举头望明月，
低头思故乡。
"""

# 空字符串
empty = ""
```

### 3.5 布尔值（bool）

```python
# 只有两个值：True 和 False
is_active = True
is_empty = False

# 通常用于条件判断
age = 18
is_adult = age >= 18  # True
```

### 3.6 空值（None）

```python
# None 表示"什么都没有"
result = None
print(result)  # None

# 判断是否为 None
if result is None:
    print("还没有结果")
```

## 4. 类型检查和转换

### 4.1 type() 函数

```python
# 查看变量的类型
name = "小明"
age = 25
height = 1.75
is_student = True

print(type(name))        # <class 'str'>
print(type(age))         # <class 'int'>
print(type(height))      # <class 'float'>
print(type(is_student))  # <class 'bool'>
```

### 4.2 类型转换

#### 4.2.1 转换为整数 int()

```python
# 字符串 → 整数
int("42")      # 42
int("3.14")    # ValueError! 不能直接转
int(3.14)      # 3（向下取整）
int("100", 2)  # 4（二进制转十进制）

# 浮点数 → 整数
int(3.14)      # 3（直接去掉小数部分）
int(3.99)      # 3
```

#### 4.2.2 转换为浮点数 float()

```python
# 字符串 → 浮点数
float("3.14")  # 3.14
float("42")    # 42.0

# 整数 → 浮点数
float(42)      # 42.0
```

#### 4.2.3 转换为字符串 str()

```python
# 任何都能转成字符串
str(42)        # "42"
str(3.14)      # "3.14"
str(True)       # "True"
```

### 4.3 类型转换的坑

```python
# ❌ 常见错误
age = input("年龄: ")     # input 返回字符串 "25"
print(age + 5)             # TypeError! 字符串不能加数字

# ✅ 正确做法
age = int(input("年龄: ")) # 先转成整数
print(age + 5)             # 30
```

## 5. 运算符

### 5.1 算术运算符

```python
a, b = 10, 3

print(a + b)   # 加法: 13
print(a - b)   # 减法: 7
print(a * b)   # 乘法: 30
print(a / b)   # 除法: 3.333...
print(a // b)  # 整除: 3（去掉小数）
print(a % b)   # 取余: 1（10 ÷ 3 = 3 余 1）
print(a ** b)  # 幂运算: 1000（10³）
```

### 5.2 比较运算符

```python
a, b = 10, 3

print(a == b)  # 等于: False
print(a != b)  # 不等于: True
print(a > b)   # 大于: True
print(a < b)   # 小于: False
print(a >= b)  # 大于等于: True
print(a <= b)  # 小于等于: False
```

### 5.3 逻辑运算符

```python
# and: 两边都为 True 才为 True
print(True and True)   # True
print(True and False)  # False

# or: 任一边为 True 就为 True
print(True or False)   # True
print(False or False)  # False

# not: 取反
print(not True)        # False
print(not False)       # True
```

### 5.4 运算符优先级

```python
# 从高到低: 括号 > 幂 > 乘除 > 加减 > 比较 > 逻辑
result = 2 + 3 * 4     # 14（先算乘法）
result = (2 + 3) * 4   # 20（先算括号）

# 复杂表达式
result = (2 + 3) * 4 > 10 and 5 ** 2 == 25
# 步骤：2+3=5 → 5*4=20 → 20>10=True → 5**2=25 → 25==25=True → True and True=True
```

## 6. 实战项目：个人资料管理

### 6.1 需求分析

创建一个程序来存储和展示个人资料。

### 6.2 代码实现

```python
# ========================================
# 个人资料管理 v1.0
# ========================================

print("=" * 40)
print("  欢迎使用个人资料管理系统")
print("=" * 40)
print()

# 输入个人信息
print("请输入以下信息:")
name = input("姓名: ")
age = int(input("年龄: "))           # 转成整数
height = float(input("身高(米): "))  # 转成浮点数
is_student = input("是学生吗?(是/否): ") == "是"  # 转成布尔值

# 计算 BMI（如果身高合理）
if height > 0 and height < 3:  # 基本验证
    bmi = 65 / (height ** 2)  # 假设体重65公斤
else:
    bmi = None

# 显示资料
print()
print("=" * 40)
print(f"  {name} 的个人资料")
print("=" * 40)
print()
print(f"姓名: {name}")
print(f"年龄: {age} 岁")
print(f"身高: {height} 米")
print(f"学生: {'是' if is_student else '否'}")

if bmi:
    print(f"BMI: {bmi:.2f}")  # :.2f 表示保留2位小数

print()
print("资料已保存！")
```

### 6.3 运行效果

```
========================================

========================================

请输入以下信息:
姓名: 小明
年龄: 25
身高(米): 1.75
是学生吗?(是/否): 否

========================================
  小明 的个人资料
========================================

姓名: 小明
年龄: 25 岁
身高: 1.75 米
学生: 否
BMI: 21.22

资料已保存！
```

## 8. 小结

### 本章要点

| 概念 | 说明 |
|------|------|
| **变量** | 存储数据的容器，用 `=` 赋值 |

| 数据 | Python 类型 | 示例 |

