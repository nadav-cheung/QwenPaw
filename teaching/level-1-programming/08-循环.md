## 1. 为什么要循环？

### 1.1 生活中的循环

| 场景 | 循环内容 |
|------|----------|
| 每天早起 | 起床 → 洗漱 → 吃早餐 → 出门 |
| 运动训练 | 深蹲10次（重复：弯腿 → 伸腿） |
| 看电视剧 | 第1集 → 第2集 → ... → 大结局 |

### 1.2 程序中的循环

```python
# 不用循环：重复5次打印
print("第1次")
print("第2次")
print("第3次")
print("第4次")
print("第5次")

# 用循环：简洁优雅
for i in range(5):
    print(f"第{i+1}次")
```

### 1.3 循环的威力

假设要打印 1000 次，用循环只需 2 行代码，不用循环要写 1000 行！

## 2. for 循环

### 2.1 基本语法

```python
for 变量 in 可迭代对象:
    循环体
```

### 2.2 range() 函数

`range(n)` 生成 0 到 n-1 的数字序列：

```python
# 打印 0-4
for i in range(5):
    print(i)
# 输出: 0, 1, 2, 3, 4

# 指定范围
for i in range(1, 6):  # 1 到 5
    print(i)
# 输出: 1, 2, 3, 4, 5

# 指定步长
for i in range(0, 10, 2):  # 0, 2, 4, 6, 8
    print(i)
```

### 2.3 遍历列表

```python
fruits = ["苹果", "香蕉", "橙子"]

for fruit in fruits:
    print(fruit)
# 输出: 苹果, 香蕉, 橙子
```

### 2.4 使用枚举

```python
fruits = ["苹果", "香蕉", "橙子"]

for index, fruit in enumerate(fruits):
    print(f"{index + 1}. {fruit}")
# 输出:
# 1. 苹果
# 2. 香蕉
# 3. 橙子
```

## 3. while 循环

### 3.1 基本语法

```python
while 条件:
    循环体
```

### 3.2 示例

```python
count = 0

while count < 5:
    print(f"计数: {count}")
    count += 1  # 重要！否则会无限循环

print("循环结束")
```

### 3.3 无限循环

```python
# 危险！不要轻易尝试
# while True:
#     print("这会一直打印下去")
```

### 3.4 while 循环猜数字

```python
import random

target = random.randint(1, 100)
attempts = 0

while True:
    guess = int(input("猜一个数字: "))
    attempts += 1

    if guess == target:
        print(f"猜对了！你用了 {attempts} 次")
        break  # 退出循环
    elif guess < target:
        print("太小了")
    else:
        print("太大了")
```

## 4. break 和 continue

### 4.1 break：跳出循环

```python
for i in range(10):
    if i == 5:
        break  # 遇到 5 就退出循环
    print(i)
# 输出: 0, 1, 2, 3, 4
```

### 4.2 continue：跳过本次

```python
for i in range(10):
    if i == 5:
        continue  # 跳过 5，继续下一次
    print(i)
# 输出: 0, 1, 2, 3, 4, 6, 7, 8, 9（没有 5）
```

### 4.3 对比

| 语句 | 作用 | 区别 |
|------|------|------|
| `break` | 跳出整个循环 | 循环结束 |
| `continue` | 跳过本次迭代 | 继续下一次 |

## 5. 嵌套循环

### 5.1 基本语法

```python
for i in range(3):      # 外层循环
    for j in range(3):  # 内层循环
        print(f"({i}, {j})")
```

### 5.2 输出

```
(0, 0) (0, 1) (0, 2)
(1, 0) (1, 1) (1, 2)
(2, 0) (2, 1) (2, 2)
```

### 5.3 打印九九乘法表

```python
for i in range(1, 10):
    for j in range(1, i + 1):
        print(f"{j}×{i}={i*j}", end="\t")
    print()  # 换行
```

## 6. 实战项目：猜数字游戏升级版

### 6.1 需求分析

在之前版本基础上：
- 添加猜测次数限制
- 显示历史猜测记录
- 添加积分系统

### 6.2 代码实现

```python
import random

# ========================================
# 猜数字游戏 v2.0
# ========================================

print("=" * 50)
print("  欢迎来到猜数字游戏！")
print("=" * 50)
print()
print("规则:")
print("  - 我会想一个 1-100 的数字")
print("  - 你有 10 次猜测机会")
print("  - 每次猜测我会告诉你偏大还是偏小")
print()

# 生成随机数
target = random.randint(1, 100)
max_attempts = 10
history = []

print(f"好，我准备好了！你有 {max_attempts} 次机会。")
print()

# 游戏循环
while len(history) < max_attempts:
    remaining = max_attempts - len(history)
    print(f"剩余次数: {remaining}")

    guess_str = input("请输入你的猜测: ")

    # 检查输入
    if not guess_str.isdigit():
        print("请输入有效的数字！")
        continue

    guess = int(guess_str)

    if guess < 1 or guess > 100:
        print("数字必须在 1-100 之间！")
        continue

    history.append(guess)

    # 判断
    if guess == target:
        print()
        print("🎉 恭喜你，猜对了！")
        break
    elif guess < target:
        print("📈 太大了，再小一点！")
    else:
        print("📉 太小了，再大一点！")

    print()

# 游戏结束
print("=" * 50)
if guess == target:
    # 计算得分
    attempts = len(history)
    if attempts <= 3:
        score = 100
    elif attempts <= 5:
        score = 80
    elif attempts <= 7:
        score = 60
    else:
        score = 40

    print(f"✅ 正确答案: {target}")
    print(f"📊 猜测次数: {attempts}")
    print(f"⭐ 得分: {score} 分")
else:
    print(f"❌ 很遗憾，你没有猜对！")
    print(f"✅ 正确答案是: {target}")

print()
print(f"📝 历史猜测: {history}")
```

## 8. 小结

### 本章要点

| 语法 | 说明 |
|------|------|
| `for i in range(n):` | 循环 n 次 |
| `for item in list:` | 遍历列表 |
| `while 条件:` | 条件为真时循环 |
| `break` | 跳出循环 |
| `continue` | 跳过本次 |

### range() 函数

| 用法 | 结果 |
|------|------|
| `range(5)` | 0, 1, 2, 3, 4 |
| `range(1, 6)` | 1, 2, 3, 4, 5 |
| `range(0, 10, 2)` | 0, 2, 4, 6, 8 |
