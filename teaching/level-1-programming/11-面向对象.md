## 1. 什么是面向对象？

### 1.1 两种编程范式

| 范式 | 思想 | 例子 |
|------|------|------|
| **面向过程** | 把程序看作一系列步骤 | 做菜：洗菜→切菜→炒菜→装盘 |
| **面向对象** | 把程序看作对象的集合 | 餐厅：厨师、服务员、顾客 |

### 1.2 生活中的对象

```
┌─────────────────────────────────────┐
│            汽车对象                  │
├─────────────────────────────────────┤
│  属性（特征）：                     │
│    - 颜色：红色                     │
│    - 品牌：特斯拉                   │
│    - 速度：0 km/h                   │
├─────────────────────────────────────┤
│  方法（行为）：                     │
│    - 启动()                        │
│    - 加速()                        │
│    - 刹车()                        │
│    - 熄火()                        │
└─────────────────────────────────────┘
```

### 1.3 核心概念

| 概念 | 说明 |
|------|------|
| **类（Class）** | 对象的模板/蓝图 |
| **对象（Object）** | 类的具体实例 |
| **属性（Attribute）** | 对象的特征/数据 |
| **方法（Method）** | 对象的行为/函数 |

## 2. 定义类

### 2.1 基本语法

```python
class 类名:
    """类的文档字符串"""

    def __init__(self, 参数):
        """构造函数"""
        self.属性 = 参数

    def 方法(self):
        """实例方法"""
        pass
```

### 2.2 第一个类

```python
class Dog:
    """狗类"""

    def __init__(self, name, age):
        """构造函数"""
        self.name = name      # 实例属性
        self.age = age

    def bark(self):
        """狗叫方法"""
        print(f"{self.name} 说: 汪汪汪！")

    def get_info(self):
        """获取信息"""
        return f"{self.name}，{self.age}岁"
```

### 2.3 创建对象

```python
# 创建对象
my_dog = Dog("旺财", 3)

# 调用方法
my_dog.bark()              # 旺财 汪汪汪！
print(my_dog.get_info())   # 旺财，3岁
```

## 3. self 是什么？

### 3.1 self 的含义

`self` 指向**对象本身**，类似于其他语言中的 `this`。

```python
class Dog:
    def __init__(self, name):
        self.name = name  # self.name 是对象的属性

# 创建两个对象
dog1 = Dog("旺财")
dog2 = Dog("小白")

# 每个对象的 name 属性是独立的
print(dog1.name)  # 旺财
print(dog2.name)  # 小白
```

### 3.2 self 工作原理

```
dog1 = Dog("旺财")
  │
  ├── self → dog1
  │
dog2 = Dog("小白")
  │
  ├── self → dog2
```

## 4. 构造函数 __init__

### 4.1 什么是构造函数

`__init__` 是特殊方法，在创建对象时自动调用，用于初始化对象的属性。

```python
class Dog:
    def __init__(self, name, age=0):
        """默认值参数"""
        self.name = name
        self.age = age

# 使用默认值
young_dog = Dog("小黄")      # age 默认是 0
adult_dog = Dog("大黄", 5)    # age 是 5
```

### 4.2 属性默认值

```python
class Dog:
    def __init__(self, name):
        self.name = name
        self.tricks = []  # 默认空列表

    def learn_trick(self, trick):
        self.tricks.append(trick)

dog = Dog("旺财")
dog.learn_trick("坐下")
dog.learn_trick("握手")
print(dog.tricks)  # ['坐下', '握手']
```

## 5. 类属性 vs 实例属性

### 5.1 类属性

类属性是所有对象共享的属性：

```python
class Dog:
    species = "犬科"  # 类属性

    def __init__(self, name):
        self.name = name  # 实例属性

dog1 = Dog("旺财")
dog2 = Dog("小白")

print(dog1.species)  # 犬科
print(dog2.species)  # 犬科

# 修改类属性影响所有对象
Dog.species = "猫科"  # 不推荐这样做！
print(dog1.species)  # 猫科
print(dog2.species)  # 猫科
```

### 5.2 实例属性

实例属性是每个对象独有的：

```python
class Dog:
    def __init__(self, name):
        self.name = name  # 每个对象独立

dog1 = Dog("旺财")
dog2 = Dog("小白")

dog1.name = "大旺"  # 只影响 dog1
print(dog1.name)  # 大旺
print(dog2.name)  # 小白
```

## 6. 方法类型

### 6.1 实例方法

最常见的方法，需要 `self` 参数：

```python
class Dog:
    def __init__(self, name):
        self.name = name

    def bark(self):  # self 是必须的
        print(f"{self.name} 汪汪叫")
```

### 6.2 类方法

使用 `@classmethod` 装饰器，第一个参数是类本身：

```python
class Dog:
    count = 0

    def __init__(self, name):
        self.name = name
        Dog.count += 1

    @classmethod
    def get_count(cls):
        return f"共有 {cls.count} 只狗"

dog1 = Dog("旺财")
dog2 = Dog("小白")
dog3 = Dog("大黄")

print(Dog.get_count())  # 共有 3 只狗
```

### 6.3 静态方法

使用 `@staticmethod` 装饰器，不需要 self 或 cls：

```python
class Math:
    @staticmethod
    def add(a, b):
        return a + b

    @staticmethod
    def is_positive(x):
        return x > 0

print(Math.add(3, 5))       # 8
print(Math.is_positive(10)) # True
```

## 7. 继承

### 7.1 什么是继承

继承允许我们基于已有类创建新类，复用代码：

```python
# 父类
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        pass

# 子类
class Dog(Animal):  # 括号里写父类名
    def speak(self):
        return f"{self.name} 汪汪叫"

class Cat(Animal):
    def speak(self):
        return f"{self.name} 喵喵叫"
```

### 7.2 使用继承

```python
dog = Dog("旺财")
cat = Cat("小白")

print(dog.speak())  # 旺财 汪汪叫
print(cat.speak())  # 小白 喵喵叫

# 多态
animals = [Dog("旺财"), Cat("小白"), Dog("大黄")]
for animal in animals:
    print(animal.speak())
```

### 7.3 super() 调用父类

```python
class Animal:
    def __init__(self, name):
        self.name = name

class Dog(Animal):
    def __init__(self, name, breed):
        super().__init__(name)  # 调用父类构造函数
        self.breed = breed      # 新增属性

dog = Dog("旺财", "金毛")
print(dog.name)   # 旺财
print(dog.breed)  # 金毛
```

## 8. 实战项目：银行账户系统

### 8.1 需求分析

创建银行账户系统：
- 基础账户：存钱、取钱、查询余额
- 储蓄账户：支持利息计算
- 信用账户：支持透支额度

### 8.2 代码实现

```python
# ========================================
# 银行账户系统
# ========================================

class BankAccount:
    """基础银行账户"""

    def __init__(self, account_id, owner_name, initial_balance=0):
        self.account_id = account_id
        self.owner_name = owner_name
        self.balance = initial_balance

    def deposit(self, amount):
        """存款"""
        if amount <= 0:
            print("存款金额必须为正数！")
            return False
        self.balance += amount
        print(f"存款成功！金额: {amount}，余额: {self.balance}")
        return True

    def withdraw(self, amount):
        """取款"""
        if amount <= 0:
            print("取款金额必须为正数！")
            return False
        if amount > self.balance:
            print(f"余额不足！当前余额: {self.balance}")
            return False
        self.balance -= amount
        print(f"取款成功！金额: {amount}，余额: {self.balance}")
        return True

    def get_balance(self):
        """查询余额"""
        return self.balance

    def __str__(self):
        return f"账户: {self.account_id}, 户主: {self.owner_name}, 余额: {self.balance}"


class SavingsAccount(BankAccount):
    """储蓄账户（有利息）"""

    def __init__(self, account_id, owner_name, initial_balance=0, interest_rate=0.03):
        super().__init__(account_id, owner_name, initial_balance)
        self.interest_rate = interest_rate

    def calculate_interest(self):
        """计算利息"""
        interest = self.balance * self.interest_rate
        return interest

    def apply_interest(self):
        """应用利息"""
        interest = self.calculate_interest()
        self.balance += interest
        print(f"利息已添加: {interest}，新余额: {self.balance}")
        return interest


class CheckingAccount(BankAccount):
    """支票账户（可透支）"""

    def __init__(self, account_id, owner_name, initial_balance=0, overdraft_limit=1000):
        super().__init__(account_id, owner_name, initial_balance)
        self.overdraft_limit = overdraft_limit

    def withdraw(self, amount):
        """取款（可透支）"""
        if amount <= 0:
            print("取款金额必须为正数！")
            return False
        if amount > self.balance + self.overdraft_limit:
            print(f"超过透支额度！可用额度: {self.balance + self.overdraft_limit}")
            return False
        self.balance -= amount
        print(f"取款成功！金额: {amount}，余额: {self.balance}")
        return True

    def get_available_credit(self):
        """获取可用透支额度"""
        return self.balance + self.overdraft_limit


# ========================================
# 测试代码
# ========================================

def main():
    print("=" * 50)
    print("  银行账户系统测试")
    print("=" * 50)

    # 储蓄账户
    savings = SavingsAccount("S001", "张三", 10000, 0.03)
    print("\n【储蓄账户测试】")
    print(savings)
    savings.deposit(5000)
    savings.apply_interest()

    print("\n【支票账户测试】")
    checking = CheckingAccount("C001", "李四", 2000, 1000)
    print(checking)
    checking.withdraw(2500)  # 透支
    checking.withdraw(500)   # 再透支
    checking.withdraw(1000)  # 超过额度
    print(f"可用额度: {checking.get_available_credit()}")

if __name__ == "__main__":
    main()
```

## 10. 小结

### 核心概念

| 概念 | 说明 |
|------|------|
| **类** | 对象的模板 |
| **对象** | 类的实例 |
| **属性** | 对象的特征 |
| **方法** | 对象的行为 |
| **继承** | 子类继承父类 |

### 特殊方法

| 方法 | 作用 |
|------|------|
| `__init__` | 构造函数 |
| `__str__` | 字符串表示 |

### 三个方法类型

| 类型 | 装饰器 | 参数 |
|------|--------|------|
| 实例方法 | 无 | `self` |
| 类方法 | `@classmethod` | `cls` |
| 静态方法 | `@staticmethod` | 无 |
