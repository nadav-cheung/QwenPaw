### 核心加密/解密函数

**文件**: `src/qwenpaw/security/secret_store.py:199-241`

```python
# 获取Fernet实例
def _get_fernet():
    global _cached_fernet
    if _cached_fernet is not None:
        return _cached_fernet
    from cryptography.fernet import Fernet
    raw = _get_master_key()                    # 获取32字节主密钥
    fernet_key = base64.urlsafe_b64encode(raw[:32])  # 转换为Fernet格式
    _cached_fernet = Fernet(fernet_key)
    return _cached_fernet

# 加密函数
def encrypt(plaintext: str) -> str:
    if not plaintext:
        return plaintext
    f = _get_fernet()
    token = f.encrypt(plaintext.encode("utf-8"))
    return _ENC_PREFIX + token.decode("ascii")  # 添加"ENC:"前缀

# 解密函数
def decrypt(value: str) -> str:
    if not value or not value.startswith(_ENC_PREFIX):
        return value                              # 非加密值直接返回
    try:
        f = _get_fernet()
        token = value[len(_ENC_PREFIX):].encode("ascii")
        return f.decrypt(token).decode("utf-8")
    except Exception:
        logger.warning("Failed to decrypt...")      # 失败时返回原始密文
        return value
```

## 主密钥获取 - 双重检查锁模式

**文件**: `src/qwenpaw/security/secret_store.py:154-188`

```python
def _get_master_key() -> bytes:
    """Return the 32-byte master key, creating one if it does not exist.

    Uses double-checked locking to guarantee that only one thread ever
    generates or loads the key, even when multiple FastAPI worker
    threads start up concurrently.
    """
    global _cached_master_key
    if _cached_master_key is not None:
        return _cached_master_key

    with _master_key_lock:
        if _cached_master_key is not None:
            return _cached_master_key

        key_hex = _try_keyring_get()     # 1. 尝试keychain

        if not key_hex:
            key_hex = _read_key_file()   # 2. 尝试文件
            if key_hex:
                _try_keyring_set(key_hex)  # 回填keychain

        if not key_hex:
            key_hex = _generate_master_key()  # 3. 生成新密钥
            _try_keyring_set(key_hex)
            _write_key_file(key_hex)

        _cached_master_key = bytes.fromhex(key_hex)
        return _cached_master_key
```

## 批量加密/解密字典字段

```python
# 加密
def encrypt_dict_fields(data: dict, secret_fields: frozenset[str]) -> dict:
    result = dict(data)
    for field in secret_fields:
        if (
            field in result
            and isinstance(result[field], str)
            and result[field]
            and not is_encrypted(result[field])  # 跳过已是加密的值
        ):
            result[field] = encrypt(result[field])
    return result

# 解密
def decrypt_dict_fields(data: dict, secret_fields: frozenset[str]) -> dict:
    result = dict(data)
    for field in secret_fields:
        if field in result and isinstance(result[field], str) and result[field]:
            result[field] = decrypt(result[field])  # 非加密值会直接返回
    return result
```

## 备份恢复后重载密钥

**文件**: `src/qwenpaw/security/secret_store.py:249-289`

```python
def reload_master_key_from_disk() -> None:
    """Invalidate the in-process master-key cache and re-sync the OS keyring.

    Call this after a backup restore has replaced ``SECRET_DIR/.master_key``
    on disk so that the running process and the OS keyring both pick up the
    restored key instead of continuing to use the old one.
    """
    global _cached_master_key, _cached_fernet
    try:
        with _master_key_lock:
            _cached_master_key = None
            _cached_fernet = None

            key_hex = _read_key_file()
            if not key_hex:
                logger.warning("reload_master_key_from_disk: .master_key file not found...")
                return

            _try_keyring_set(key_hex)  # 更新keychain
            logger.info("reload_master_key_from_disk: cache invalidated and keyring updated")
    except Exception:
        logger.warning("reload_master_key_from_disk: unexpected error...", exc_info=True)
```

## 核心设计要点

1. **多层密钥存储**: OS Keychain (首选) -> 文件 (备用) -> 生成新密钥
2. **线程安全**: 双重检查锁模式确保多worker并发安全
3. **自动迁移**: 明文值首次访问时自动加密 (通过 `ENC:` 前缀检测)
4. **容错设计**: 解密失败时返回原始密文而非崩溃
5. **环境适配**: 容器/CI环境下自动降级到文件存储
6. **权限控制**: 文件存储使用 `0o600` 权限
7. **缓存策略**: Fernet实例和主密钥都有进程内缓存

## 如果你来自 Java...

Java 生态中有多种密钥管理和加密存储的实现方式：

### Java KeyStore — 密钥存储标准

```java
// Java 的 KeyStore 类似 QwenPaw 的多层密钥存储
KeyStore keyStore = KeyStore.getInstance("Windows-ROOT"); // OS Keychain
keyStore.load(null, null);

// 或使用 JCA 标准方式
KeyStore secretStore = KeyStore.getInstance("JCEKS");
secretStore.load(new FileInputStream("keystore.jceks"), password.toCharArray());

// 存储密钥
SecretKeySpec key = new SecretKeySpec(keyBytes, "AES");
KeyStore.SecretKeyEntry entry = new KeyStore.SecretKeyEntry(key);
secretStore.setEntry("mykey", entry, new KeyStore.PasswordProtection(password.toCharArray()));
```

### Spring Cloud Config — 配置加密

```java
// Spring Cloud Config 提供类似 Fernet 的对称加密
// application.yml
// spring.cloud.config.server.encrypt.key=my-aes-key

// 或使用 Jasypt (Java Simplified Encryption)
// 配置: jasypt.encryptor.password=my-secret-key
// 使用: @Value("${secret.property}") String prop;
```

### 关键概念对应

| QwenPaw 概念 | Java 对应 | 说明 |
|--------------|-----------|------|
| `Fernet` | `AES/CBC` + `Mac` | 对称加密算法 |
| `keyring` | `KeyStore` | OS 密钥存储 |
| `ENC:` 前缀 | 自定义序列化格式 | 加密标识 |
| 双重检查锁 | `volatile` + `synchronized` | 多线程安全 |
| `secrets.token_hex(32)` | `SecureRandom` + `MessageDigest` | 密钥生成 |

### Java 实现特点

1. **KeyStore SPI**：多种实现（Windows, macOS, PKCS#11）
2. **JCA 标准**：`Cipher.getInstance("AES/CBC/PKCS5Padding")` 灵活配置
3. **依赖注入**：Spring 的 `@Value("${secret}")` 自动解密
4. **硬件支持**：HSM（硬件安全模块）集成
