## 2. 核心模块详解

### 2.1 agents 模块

**职责**：智能体核心实现

```
agents/
├── react_agent.py    # QwenPawAgent（核心类）
├── tools/            # 内置工具集
├── skills/           # 内置技能
├── memory/           # 记忆管理
├── hooks/            # 生命周期钩子
└── acp/              # Agent 通信协议
```

**关键类**：
- `QwenPawAgent`：主智能体类
- `AgentScope`：智能体作用域
- `Workspace`：工作区

### 2.2 app 模块

**职责**：Web 应用和消息处理

```
app/
├── _app.py           # 应用主类
├── server.py         # FastAPI 服务器
├── channels/         # 渠道实现
├── runner/           # 请求处理器
└── multi_agent_manager.py  # 多智能体
```

**关键类**：
- `create_app()`：FastAPI 应用工厂函数（`_app.py`）
- `Runner`：请求处理器
- `MultiAgentManager`：多智能体管理

### 2.3 providers 模块

**职责**：大语言模型接口抽象

```
providers/
├── provider_manager.py    # 提供商管理器（单例）
├── provider.py            # Provider 抽象基类
├── openai_provider.py    # OpenAI
├── ollama_provider.py    # Ollama
├── anthropic_provider.py  # Anthropic
└── gemini_provider.py    # Google Gemini
```

**关键类**：
- `Provider`：抽象基类（定义 `get_chat_model_instance`, `check_connection`, `list_models` 等接口）
- `ProviderManager`：管理所有提供商（单例模式）

## 3. 入口文件解析

### 3.1 命令行入口

```bash
qwenpaw app
```

入口：`src/qwenpaw/cli/main.py`

```python
# cli/main.py
import click
from qwenpaw.app._app import create_app

@click.group()
def cli():
    """QwenPaw CLI — 启动入口: qwenpaw app"""
    pass

@cli.command()
def app():
    """启动 QwenPaw 应用"""
    from qwenpaw.app._app import create_app
    import uvicorn
    app = create_app()
    uvicorn.run(app, host="127.0.0.1", port=8088)

if __name__ == "__main__":
    cli()
```

### 3.2 应用入口

`src/qwenpaw/app/_app.py`

```python
# _app.py 的核心是 create_app() 工厂函数（非 class）
# 通过 lifespan 事件管理初始化顺序：

# 1. load_envs_into_environ()       — 加载持久化环境变量
# 2. load_config()                  — 加载 YAML 配置
# 3. MultiAgentManager.start_all()  — 启动所有 Agent Workspace
# 4. ProviderManager.init()         — 初始化 LLM 提供商
# 5. LocalModelManager.init()       — 初始化本地模型
# 6. PluginLoader.load_all()        — 加载所有插件
# 7. 注册 API 路由 + 中间件
```

```

       │
       ▼
┌─────────────┐

       │
       ▼
┌─────────────┐
│  Agents     │  ← 核心层

       │
       ▼
┌─────────────┐     ┌─────────────┐
│ Providers   │     │  Security   │

       │                    │
       ▼                    ▼
```

### 4.2 依赖说明

| 模块 | 被依赖 | 依赖 |
