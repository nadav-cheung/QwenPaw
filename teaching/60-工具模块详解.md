# 工具模块详解

## 概述

QwenPaw 的工具系统位于 `src/qwenpaw/utils/`，提供命令执行、日志、遥测、控制台静态资源解析等核心基础设施。

本章节详细解析每个工具模块的功能、使用方法和配置选项。

---

## 1. 工具模块一览

```
src/qwenpaw/utils/
├── __init__.py           # 公共 API 导出
├── command_runner.py      # 进程执行管理
├── console_static.py     # 控制台静态资源路径
├── logging.py            # 日志配置
├── startup_display.py     # 启动横幅
├── stdio.py              # 标准流保护
├── system_info.py        # 硬件检测
└── telemetry.py          # 遥测收集
```

| 模块 | 职责 |
|------|------|
| `command_runner` | 进程执行和生命周期管理 |
| `console_static` | 控制台 UI 资源路径解析 |

| `startup_display` | 启动横幅显示 |
| `stdio` | 标准流保护 |
| `system_info` | 硬件信息检测 |

## 2. command_runner — 进程执行

源码路径：`src/qwenpaw/utils/command_runner.py`

### 2.1 核心类型

```python
# src/qwenpaw/utils/command_runner.py
@dataclass(frozen=True)
class CommandResult:
    """命令执行结果"""
    returncode: int
    stdout: str
    stderr: str

    def combined_output(self) -> str:
        """合并 stdout 和 stderr"""
        if self.stderr:
            return f"{self.stdout}\n[stderr]\n{self.stderr}"
        return self.stdout

@dataclass(frozen=True)
class ShutdownResult:
    """进程关闭结果"""
    exited: bool                        # 进程是否已退出
    terminated_gracefully: bool         # 是否优雅终止 (SIGTERM)
    killed: bool                        # 是否强制杀死 (SIGKILL)
    timed_out: bool                     # 是否超时
```

### 2.2 主要函数

| 函数 | 签名 | 用途 |
|------|------|------|
| `run_command()` | `(cmd, timeout, cwd) → CommandResult` | 同步命令执行（带超时） |
| `run_command_async()` | `(cmd, timeout, cwd) → CommandResult` | 异步命令执行 |
| `start_command_async()` | `(cmd, cwd) → (proc, pid)` | 启动长期运行命令 |
| `shutdown_process()` | `(pid, timeout) → ShutdownResult` | 优雅终止（SIGTERM→SIGKILL） |

### 2.3 使用示例

```python
# 同步执行
result = run_command(
    cmd=["python", "-c", "print('hello')"],
    timeout=10,
    cwd="/project"
)
print(result.stdout)

# 异步执行
result = await run_command_async(
    cmd=["npm", "run", "build"],
    timeout=300,
)

# 启动长期进程
proc, pid = await start_command_async(
    cmd=["python", "server.py"],
    cwd="/project"
)

# 优雅关闭
shutdown_result = await shutdown_process(pid, timeout=30)
print(f"优雅终止: {shutdown_result.terminated_gracefully}")
```

## 3. console_static — 静态资源

源码路径：`src/qwenpaw/utils/console_static.py`

### 3.1 资源路径解析

```python
# src/qwenpaw/utils/console_static.py
def resolve_console_static_dir() -> Path:
    """解析控制台 index.html 位置

    优先级：
    1. QWENPAW_CONSOLE_STATIC_DIR 环境变量
    2. 包内 qwenpaw/console/ 目录
    3. Repo console/dist/ 目录
    4. CWD console/dist/ 或 console_dist/
    """
```

**路径解析优先级：**

| 优先级 | 路径 | 说明 |
|--------|------|------|
| 1 | `QWENPAW_CONSOLE_STATIC_DIR` 环境变量 | 最高优先级，允许完全自定义 |
| 2 | `qwenpaw/console/` | 包内静态资源 |
| 3 | `console/dist/` | 构建输出目录 |
| 4 | `console/dist/` 或 `console_dist/` | 工作目录查找 |

### 3.2 使用场景

```python
# 获取控制台资源路径
console_dir = resolve_console_static_dir()
index_html = console_dir / "index.html"

# 用于 FastAPI 静态文件服务
app.mount("/console", StaticFiles(directory=str(console_dir)))
```

## 5. stdio — 标准流保护

源码路径：`src/qwenpaw/utils/stdio.py`

### 5.1 标准流保护

```python
# src/qwenpaw/utils/stdio.py
def ensure_standard_streams() -> None:
    """用 /dev/null 替换损坏的 stdout/stderr

    场景：
    - 标准输出被重定向到不存在的管道
    - 流被关闭但仍有写入
    - 写入时触发 BrokenPipeError

    解决方案：
    - 检测流是否损坏
    - 替换为 /dev/null 或 StringIO
    """
```

**问题场景：**

```
场景 1: 输出重定向到已关闭的管道
$ python app.py | head -n 1
# head 关闭管道后，app.py 继续输出会 BrokenPipe

场景 2: 标准流被意外关闭
import sys
sys.stdout.close()  # 之后所有 print() 失败
```

### 5.2 使用场景

```python
# 在应用启动时调用
ensure_standard_streams()

# 之后所有 print() 和 logging 不会因流损坏而崩溃
print("This will never fail even if stdout is broken")
```

### 6.1 系统信息函数

| 函数 | 返回值 | 说明 |
|------|--------|------|
| `get_os_name()` | `Literal["windows", "macos", "linux"]` | 操作系统 |
| `get_architecture()` | `Literal["x64", "arm64"]` | CPU 架构 |
| `get_cuda_version()` | `str | None` | NVIDIA CUDA 版本 |
| `get_memory_size_gb()` | `float` | 系统 RAM (GB) |
| `get_vram_size_gb()` | `float | None` | GPU VRAM (GB) |
| `get_system_info()` | `dict` | 组合系统信息 |

### 6.2 使用示例

```python
# 获取完整系统信息
info = get_system_info()
print(info)

# 输出示例
{
    "os": "macos",
    "arch": "arm64",
    "python_version": "3.11.0",
    "cuda_version": "12.2",
    "memory_gb": 32.0,
    "vram_gb": 8.0,
    "gpu_name": "Apple M2 Pro"
}

# 检查 CUDA 是否可用
cuda = get_cuda_version()
if cuda:
    print(f"CUDA {cuda} available")
else:
    print("CUDA not available")
```

### 6.3 应用场景

## 7. telemetry — 遥测收集

源码路径：`src/qwenpaw/utils/telemetry.py`

### 7.1 遥测端点

```python
# src/qwenpaw/utils/telemetry.py
TELEMETRY_ENDPOINT = "https://qwenpawelemetry-sukzkbfzhc.ap-southeast-1.fcapp.run"
```

### 7.2 收集的数据

```python
# src/qwenpaw/utils/telemetry.py
def collect_and_upload_telemetry() -> None:
    """收集并上传匿名使用信息

    收集内容：
    - install_id: 匿名安装 ID (UUID)
    - version: QwenPaw 版本
    - install_method: 安装方式 (pip/docker/desktop)
    - os: 操作系统
    - python_version: Python 版本
    - arch: CPU 架构
    - has_gpu: 是否有 GPU
    """
```

**隐私保护：**
- 不收集用户名、文件路径、API 密钥等敏感信息
- 使用随机 UUID 作为安装 ID
- 用户可随时退出遥测

### 7.3 退出机制

```python
# 退出文件位置
# ~/.qwenpaw/.telemetry_collected

# 退出文件内容
{
    "opted_out": true,
    "opted_out_at": "2024-01-15T10:30:00Z"
}
```

### 7.4 使用场景

```python
# 检查是否已选择退出
telemetry_file = Path("~/.qwenpaw/.telemetry_collected").expanduser()
if telemetry_file.exists():
    data = json.loads(telemetry_file.read_text())
    if data.get("opted_out"):
        # 用户选择退出，不收集遥测
        return

# 收集并上传
collect_and_upload_telemetry()
```

## 8. 设计模式

### 8.1 惰性初始化

```python
# console_static.py
# 静态资源路径在首次访问时才解析
# 不浪费启动时间

_console_static_dir = None

def resolve_console_static_dir() -> Path:
    global _console_static_dir
    if _console_static_dir is None:
        _console_static_dir = _do_resolve()
    return _console_static_dir
```

### 8.2 平台检测

```python
# system_info.py
# 跨平台系统信息获取

def get_os_name() -> str:
    if sys.platform == "win32":
        return "windows"
    elif sys.platform == "darwin":
        return "macos"
    else:
        return "linux"
```

### 8.3 异常隔离

```python
# stdio.py
# 标准流损坏不应导致应用崩溃

def ensure_standard_streams():
    try:
        sys.stdout.write("")
    except (AttributeError, ValueError):
        sys.stdout = open(os.devnull, "w")
```

## 10. 常见问题

### Q1: print() 在某些环境下崩溃？

**原因：** 标准输出被重定向到损坏的管道。

**解决：**

```python
from qwenpaw.utils.stdio import ensure_standard_streams
ensure_standard_streams()
```

### Q2: 遥测收集影响性能？

**原因：** 网络请求可能阻塞。

**解决：**

```python
# 遥测在后台线程中收集
import threading
threading.Thread(target=collect_and_upload_telemetry, daemon=True).start()
```

### Q3: 控制台静态资源找不到？

**排查：**

```python
from qwenpaw.utils.console_static import resolve_console_static_dir
path = resolve_console_static_dir()
print(f"Console dir: {path}")
print(f"Exists: {path.exists()}")
```

### Q4: system_info 在某些平台上获取失败？

**原因：** 平台特定 API 不可用。

**解决：**

```python
from qwenpaw.utils.system_info import get_system_info

try:
    info = get_system_info()
except Exception as e:
    # 返回默认值
    info = {"error": str(e)}
```

## 12. 总结

### 核心要点

| 模块 | 核心功能 | 使用场景 |
|------|----------|----------|
| `command_runner` | 进程执行管理 | Shell 命令、后台任务 |
| `console_static` | 静态资源路径 | FastAPI 挂载控制台 |
| `logging` | 应用日志 | 问题诊断、性能分析 |
| `startup_display` | 启动横幅 | 用户体验 |
| `stdio` | 标准流保护 | 防止输出崩溃 |
| `system_info` | 硬件检测 | GPU 加速、资源限制 |
| `telemetry` | 匿名遥测 | 使用统计（可选） |

### 启动流程中的使用

```
main()
    │
    ├── ensure_standard_streams()  ← 保护标准流
    │
    ├── setup_logger()             ← 配置日志
    │
    ├── get_system_info()          ← 硬件检测
    │
    ├── resolve_console_static_dir()  ← 解析资源路径
    │
    ├── print_ready_banner()       ← 显示启动横幅
    │
    └── (start telemetry thread)   ← 后台遥测
```
