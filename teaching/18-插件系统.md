# 插件系统

## 概述

QwenPaw 支持插件扩展机制，允许开发者通过插件添加新功能、集成外部服务或自定义行为。本文档介绍插件系统的架构、使用方法和开发指南。

---

## 1. 插件系统架构

### 1.1 插件目录结构

```
~/.qwenpaw/plugins/
├── my_plugin/              # 插件目录
│   ├── __init__.py       # 插件入口
│   ├── config.json        # 插件配置
│   ├── mcp.json          # MCP 服务器配置（可选）
│   └── ...
```

### 1.2 核心组件

```
src/qwenpaw/plugins/
├── manager.py           # 插件管理器
├── loader.py            # 插件加载器
├── registry.py         # 插件注册表
└── hooks.py            # 插件钩子
```

## 2. 使用插件

### 2.1 安装插件

```bash
# 从目录安装
qwenpaw plugin install ./my_plugin

# 从 URL 安装
qwenpaw plugin install --from-url https://example.com/plugin.zip

# 从市场安装
qwenpaw plugin install my_plugin --from-market
```

### 2.2 管理插件

```bash
# 列出已安装插件
qwenpaw plugin list

# 启用/禁用插件
qwenpaw plugin enable my_plugin
qwenpaw plugin disable my_plugin

# 更新插件
qwenpaw plugin update my_plugin

# 卸载插件
qwenpaw plugin uninstall my_plugin
```

### 2.3 查看插件信息

```bash
# 查看插件详情
qwenpaw plugin info my_plugin

# 查看插件配置
qwenpaw plugin config my_plugin
```

## 3. 开发插件

### 3.1 创建插件结构

```bash
mkdir -p ~/.qwenpaw/plugins/my_plugin
cd ~/.qwenpaw/plugins/my_plugin
```

### 3.2 插件配置文件

`config.json`:

```json
{
  "name": "my_plugin",
  "version": "1.0.0",
  "description": "我的自定义插件",
  "author": "Your Name",
  "entry_point": "my_plugin:main",
  "dependencies": [],
  "permissions": ["network", "filesystem"]
}
```

### 3.3 插件入口文件

`__init__.py`:

```python
"""我的自定义插件"""

from qwenpaw.plugins import Plugin, PluginManager

class MyPlugin(Plugin):
    """插件类"""
    
    name = "my_plugin"
    version = "1.0.0"
    
    def on_load(self) -> None:
        """插件加载时调用"""
        print(f"插件 {self.name} 已加载")
    
    def on_unload(self) -> None:
        """插件卸载时调用"""
        print(f"插件 {self.name} 已卸载")
    
    def on_agent_start(self, agent_id: str) -> None:
        """智能体启动时调用"""
        pass
    
    def on_agent_message(self, agent_id: str, message: dict) -> None:
        """智能体消息处理时调用"""
        pass

def main():
    """插件入口函数"""
    return MyPlugin()
```

## 4. 插件功能

### 4.1 MCP 服务器集成

插件可以包含 MCP 服务器配置：

`mcp.json`:

```json
{
  "mcp_servers": {
    "my_mcp": {
      "command": "python",
      "args": ["/path/to/mcp_server.py"],
      "env": {},
      "cwd": "/path/to"
    }
  }
}
```

### 4.2 自定义工具

插件可以注册自定义工具：

```python
class MyPlugin(Plugin):
    
    def register_tools(self, toolkit: Toolkit) -> None:
        """注册自定义工具"""
        toolkit.register_tool_function(
            my_custom_tool,
            name="my_tool",
            description="我的自定义工具"
        )
```

### 4.3 生命周期钩子

| 钩子 | 触发时机 | 用途 |
|------|---------|------|
| `on_load` | 插件加载 | 初始化资源 |
| `on_unload` | 插件卸载 | 清理资源 |
| `on_agent_start` | 智能体启动 | 准备环境 |
| `on_agent_stop` | 智能体停止 | 清理状态 |
| `on_message` | 消息处理 | 消息拦截/处理 |

## 5. 权限控制

### 5.1 权限声明

插件需要在 `config.json` 中声明所需权限：

```json
{
  "permissions": [
    "network",        # 网络访问
    "filesystem",     # 文件系统访问
    "agent_control",  # 控制智能体
    "tool_execute"    # 执行工具
  ]
}
```

### 5.2 权限说明

| 权限 | 说明 |
|------|------|
| `network` | 允许网络请求 |
| `filesystem` | 允许读写文件系统 |
| `agent_control` | 允许控制智能体 |
| `tool_execute` | 允许执行工具 |

## 7. 故障排查

### 7.1 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 插件无法加载 | 缺少依赖 | `pip install -r requirements.txt` |
| 权限被拒绝 | 权限不足 | 检查 `config.json` 权限配置 |

### 8.10 前端插件加载机制

**前端加载流程** (`usePluginLoader.ts` 第82-99行):

```
1. GET /api/plugins 获取插件列表
         │
         ▼
2. 过滤有 frontend_entry 的插件
         │
         ▼
3. GET /plugins/{plugin_id}/files/{frontend_entry}
         │
         ▼
4. 将 JS bundle 包装为同源 Blob URL
         │
         ▼
5. dynamic import() 动态导入
         │
         ▼
6. 立即 revoke Blob URL 释放内存
```

**Blob URL 包装** (第49-57行):
```typescript
const blob = new Blob([bundle], { type: "application/javascript" });
const url = URL.createObjectURL(blob);
try {
    await import(/* @vite-ignore */ url);
} finally {
    URL.revokeObjectURL(url);
}
```

**Host 暴露接口** (`hostExternals.ts`):

window.QwenPaw.registerToolRender(pluginId, renderers)
window.QwenPaw.modules  // 170个注册模块 (vite-plugin-patchable)
