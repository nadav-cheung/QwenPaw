QwenPaw 的环境变量系统支持类型安全访问、COPAW_ 遗留前缀兼容、双层持久化（JSON + os.environ），以及启动时的 bootstrap 安全注入。

**核心设计理念**：环境变量是配置系统的基础，采用双层持久化确保配置既安全又便捷，同时通过加密保护敏感信息。

| 行号 | 函数名 | 说明 |

| 198 | `save_envs` | 加密所有值后写入 envs.json，并同步到 os.environ |
| 223 | `set_env_var` | 设置单个环境变量 |
| 234 | `delete_env_var` | 删除单个环境变量 |
| 242 | `load_envs_into_environ` | 启动时调用：将持久化的 envs 加载到 os.environ（跳过保护键） |

### 1.2 环境变量加载流程

```
load_envs()
  ├─ path = get_envs_json_path()
  ├─ _migrate_legacy_envs_json(path)  （首次迁移旧文件）
  ├─ open(path, "r") → json.load()
  ├─ raw = {k: str(v) for k, v in data.items()}
  ├─ has_plaintext = any(v and not is_encrypted(v) for v in raw.values())
  ├─ decrypted = {k: decrypt(v) for k, v in raw.items()}
  ├─ if has_plaintext: _rewrite_encrypted(path, decrypted)
  └─ return decrypted

load_envs_into_environ()
  ├─ envs = load_envs()
  ├─ bootstrap_envs = {k:v for k,v in envs if k not in _PROTECTED_BOOTSTRAP_KEYS}
  ├─ _apply_to_environ(bootstrap_envs, overwrite=False)
  └─ return envs
```

### 1.3 加密机制

**与 secret_store.py 的交互**：
- `decrypt`: `load_envs` 中遍历 raw 字典时对每个值调用
- `encrypt`: `save_envs` 和 `_rewrite_encrypted` 中对每个值调用
- `is_encrypted`: 判断值是否已是密文，避免重复加密

```python
# envs/store.py:168-170
decrypted = {k: decrypt(v) for k, v in raw.items()}
if has_plaintext:
    _rewrite_encrypted(path, decrypted)
```

**加密特点**：
- 使用 Fernet 对称加密
- 自动检测明文并触发迁移
- 对调用方完全透明

### 1.5 遗留数据迁移

**文件**: `src/qwenpaw/envs/store.py:41-62`

```python
def _migrate_legacy_envs_json(path: Path) -> None:
    """Copy old envs.json into secret dir once (best effort)."""
    for legacy in _LEGACY_ENVS_JSON_CANDIDATES:
        if not legacy.is_file() or _same_path(legacy, path):
            continue
        try:
            _prepare_secret_parent(path)
            shutil.copy2(legacy, path)
            _chmod_best_effort(path, 0o600)
            return
        except OSError as exc:
            logger.warning("Failed to migrate legacy envs.json...", exc)
```

**迁移逻辑**：`load_envs()` 首次加载时会调用 `_migrate_legacy_envs_json(path)`，遍历旧版 `envs.json` 的候选路径（旧版安装目录等），找到后复制到新的 secret 目录。采用 best-effort 策略，失败仅打日志不中断启动。

### 1.6 文件权限安全

**文件**: `src/qwenpaw/envs/store.py:28-39`

```python
def _chmod_best_effort(path: Path, mode: int) -> None:
    try:
        os.chmod(path, mode)
    except OSError:
        # Some systems/filesystems may not support chmod semantics.
        pass

def _prepare_secret_parent(path: Path) -> None:
    path.parent.mkdir(parents=True, exist_ok=True)
    _chmod_best_effort(path.parent, 0o700)  # 目录权限 700
```

**权限策略**：
| 路径 | 权限 | 说明 |
|------|------|------|
| `~/.qwenpaw/.secret/` (目录) | `0o700` | 仅所有者可访问 |
| `envs.json` (文件) | `0o600` | 仅所有者可读写 |

`_chmod_best_effort` 采用容错设计：某些文件系统（如 Windows FAT、容器内挂载卷）不支持 Unix 权限语义，此时静默忽略而非抛出异常。

```python
# src/qwenpaw/constant.py:12
def _get_env(key: str, default: str = "") -> str:
    """查找环境变量，自动回退到 COPAW_ 前缀变体"""
    if key in os.environ:
        return os.environ[key]
    if key.startswith("QWENPAW_"):
        legacy_key = "COPAW_" + key[len("QWENPAW_"):]
        if legacy_key in os.environ:
            return os.environ[legacy_key]
    return default
```

```
    │         ├─ 找到 → 返回 COPAW_XXX 的值
    │         └─ 未找到 → 返回默认值
    └─ NO → 返回 QWENPAW_XXX 的值
```

## 2B. 环境变量加载器详解

> 本节深入分析 EnvVarLoader 各取值方法的完整实现和设计考量。

### 2B.1 类型安全取值方法实现

**get_bool 实现**：

```python
# src/qwenpaw/constant.py:35
@staticmethod
def get_bool(env_var: str, default: bool = False) -> bool:
    val = _get_env(env_var, str(default)).lower()
    return val in ("true", "1", "yes")
```

只有 `"true"`、`"1"`、`"yes"`（不区分大小写）被视为真值，其他所有值均返回 `False`。

**get_int 实现**：

```python
# src/qwenpaw/constant.py:53
@staticmethod
def get_int(env_var: str, default: int = 0,
             min_value: int = None, max_value: int = None) -> int:
    value = int(_get_env(env_var, str(default)))
    if min_value is not None and value < min_value:
        return min_value
    if max_value is not None and value > max_value:
        return max_value
    return value
```

`min_value`/`max_value` 是**防御性编程**的体现：即使配置值超出合理范围，也会被钳制到边界值，防止异常配置扩散到系统其他部分。

**get_float 实现**：

```python
# src/qwenpaw/constant.py:39
@staticmethod
def get_float(env_var: str, default: float = 0.0,
              min_value: float = None, max_value: float = None,
              allow_inf: bool = False) -> float:
    value = float(_get_env(env_var, str(default)))
    if min_value is not None and value < min_value:
        return min_value
    if max_value is not None and value > max_value:
        return max_value
    if not allow_inf and (value == float("inf") or value == float("-inf")):
        return default
    return value
```

`get_float` 相比 `get_int` 多了一个 `allow_inf` 参数。当 `allow_inf=False`（默认）时，若解析结果为正无穷或负无穷，则返回 `default` 值而非无穷大。这在超时配置等场景中可防止 `inf` 导致的异常行为。

**get_str 实现**：

```python
@staticmethod
def get_str(env_var: str, default: str = "") -> str:
    return _get_env(env_var, default)
```

`get_str` 无特殊处理，直接返回 `_get_env` 的结果。

### 2B.2 前缀解析优先级

`_get_env` 的前缀回退设计是向后兼容的典范：新品牌上继续支持旧前缀，避免用户升级时配置失效。

| 前缀 | 优先级 | 说明 |
|------|--------|------|
| `QWENPAW_*` | 优先 | 新版前缀 |
| `COPAW_*` | 回退 | 兼容旧版 |

```bash
QWENPAW_API_KEY=xxx    # 优先使用
COPAW_API_KEY=xxx       # 仅当 QWENPAW_ 未设置时生效
```

### 2B.3 .env 文件路径定位

```python
_env_path = Path(__file__).resolve().parent.parent.parent / ".env"
# 相当于: /path/to/project/.env
```

`.env` 文件通过 `Path(__file__)` 相对于**源文件位置**而非 CWD（当前工作目录）定位，确保无论从哪个目录启动应用，都能正确找到 `.env` 文件。

### 3.2 加载逻辑

```python
# envs/store.py:142
def load_envs() -> dict[str, str]:
    """从 envs.json 加载，解密值透明解密"""
    with open(_ENVS_JSON, "r", encoding="utf-8") as f:
        data = json.load(f)
    return decrypt_dict_fields(data, _PROTECTED_KEYS)
```

### 3.3 保存逻辑

```python
# envs/store.py:198
def save_envs(envs: dict[str, str]) -> None:
    """写入 envs.json（加密）并同步到 os.environ"""
    data = encrypt_dict_fields(envs, _PROTECTED_KEYS)
    # 原子写入
    with open(_ENVS_JSON + ".tmp", "w") as f:
        json.dump(data, f, ...)
    os.replace(_ENVS_JSON + ".tmp", _ENVS_JSON)
    # 同步到 os.environ
    _apply_to_environ(envs)
```

**原子写入**：
1. 写入到 `.tmp` 文件
2. 调用 `os.replace()` 原子替换
3. 确保崩溃不会导致文件损坏

## 10. 常见问题

### Q1: 环境变量未生效？

**排查步骤**：
```bash
# 1. 检查 .env 文件是否存在
cat .env

# 2. 检查 envs.json 中的值
curl http://localhost:8080/api/envs

# 3. 重启服务
systemctl restart qwenpaw
```

### Q2: 加密后的值显示为乱码？

**原因**：这是正常现象，加密后的值确实不是人类可读的。

**验证方式**：
```python
# 解密验证
from qwenpaw.security.secret_store import decrypt
decrypted = decrypt("ENC:xxx...")
```

### Q3: 保护键被覆盖？

**原因**：`QWENPAW_WORKING_DIR` 和 `QWENPAW_SECRET_DIR` 被故意保护，不允许通过 API 修改。

**正确做法**：通过启动参数或配置文件设置。

### Q4: 批量导入环境变量？

**方法**：
```bash
# 通过 API 批量保存
curl -X PUT http://localhost:8080/api/envs \
  -H "Content-Type: application/json" \
  -d '{"KEY1": "value1", "KEY2": "value2"}'
```

### 练习 3: 双层持久化实现

**目标**: 模拟双层持久化存储机制。

```python
# 练习: 实现一个简单的双层持久化存储
import json
import os
from pathlib import Path
from qwenpaw.security.secret_store import encrypt, decrypt, is_encrypted

class SimpleStore:
    def __init__(self, path: Path):
        self.path = path
        self._memory = {}

    def save(self, data: dict) -> None:
        """加密保存到文件"""
        encrypted = {k: encrypt(v) if v and not is_encrypted(v) else v
                     for k, v in data.items()}
        with open(self.path, "w") as f:
            json.dump(encrypted, f, indent=2)
        self._memory = data

    def load(self) -> dict:
        """从文件加载并解密"""
        if not self.path.exists():
            return {}
        with open(self.path, "r") as f:
            encrypted = json.load(f)
        return {k: decrypt(v) for k, v in encrypted.items()}

# 测试
store = SimpleStore(Path("/tmp/test_store.json"))
test_data = {"API_KEY": "secret123", "DEBUG": "true"}

store.save(test_data)
loaded = store.load()

print(f"保存: {test_data}")
print(f"加载: {loaded}")
assert loaded == test_data, "加载的数据应该等于保存的数据"
```

### 练习 4: COPAW 遗留兼容

**目标**: 理解前缀兼容机制。

```python
# 练习: 模拟 COPAW_ 前缀回退逻辑
import os

def get_env_with_fallback(key: str, default: str = "") -> str:
    """查找环境变量，支持 QWENPAW_ -> COPAW_ 回退"""
    # 首先查找原键
    if key in os.environ:
        return os.environ[key]

    # 如果是 QWENPAW_ 前缀，尝试 COPAW_ 回退
    if key.startswith("QWENPAW_"):
        legacy_key = "COPAW_" + key[len("QWENPAW_"):]
        if legacy_key in os.environ:
            return os.environ[legacy_key]

    return default

# 测试
os.environ["QWENPAW_DEBUG"] = "true"
os.environ["COPAW_OLD_KEY"] = "legacy_value"

print(get_env_with_fallback("QWENPAW_DEBUG"))  # true
print(get_env_with_fallback("COPAW_OLD_KEY"))  # legacy_value
print(get_env_with_fallback("QWENPAW_OLD_KEY"))  # legacy_value (回退)
print(get_env_with_fallback("NONEXISTENT", "default"))  # default
```

### Java 开发者对照表

| Java 概念 | Python/QwenPaw 实现 | 说明 |
|-----------|---------------------|------|
| `System.getenv("KEY")` | `os.getenv("KEY")` | 获取环境变量 |
| `System.setProperty()` | `os.environ["KEY"] = value` | 设置环境变量 |
| `Properties` 文件 | `.env` + `python-dotenv` | 配置文件 |
| `@Value` 注解 | `EnvVarLoader.get_*()` | 类型安全配置注入 |

| `@RefreshScope` | `load_envs_into_environ()` | 配置刷新 |
| `bootstrap.yml` | `envs.json` | 引导配置 |

### 关键差异

**1. 环境变量处理**

```java
// Java: System.getenv() 是只读的快照
String home = System.getenv("HOME");
// Java 不支持进程内修改 System.getenv()
System.setProperty("key", "value"); // 这是系统属性，不是环境变量
```

```python
# Python: os.environ 是实时字典
import os
home = os.environ.get("HOME")
os.environ["MY_VAR"] = "value"  # 立即生效，对子进程可见
```

**2. 类型安全配置**

```java
// Java: Spring @Value 注解
@Value("${app.port:8080}")
private int port;

@Value("${app.debug:false}")
private boolean debug;
```

```python
# Python: QwenPaw EnvVarLoader
from qwenpaw.constant import EnvVarLoader

port = EnvVarLoader.get_int("APP_PORT", 8080)
debug = EnvVarLoader.get_bool("APP_DEBUG", False)
```

**3. 配置加密**

```java
// Java: Jasypt 加密属性
@Value("${encrypted.property}")
private String encryptedProp;

// 配置启用加密
// spring.datasource.password=ENC(加密值)
```

```python
# Python: QwenPaw secret_store
from qwenpaw.security.secret_store import encrypt

encrypted = encrypt("my_secret")
# 存储时自动加密，加载时自动解密
```

**4. 引导配置**

```java
// Java: bootstrap.yml
spring:
  application:
    name: myapp
  cloud:
    config:
      uri: ${CONFIG_SERVER_URL}
```

```python
# Python: envs.json 引导配置
# ~/.qwenpaw/.secret/envs.json
# 启动时自动加载到 os.environ
```

### Java 开发者注意事项

1. **Python 环境变量是进程级的**: 修改 `os.environ` 只影响当前进程和子进程，不像 Java 需要重启 JVM。

2. **加密是透明的**: QwenPaw 的 `encrypt/decrypt` 在存储和加载时自动处理，不需要手动加密/解密。

3. **配置文件格式**: Python 传统使用 `.env` 文件配合 `python-dotenv`，QwenPaw 使用加密的 `envs.json`。

4. **热重载**: Python 配置通常需要重启，而 QwenPaw 的 `load_envs_into_environ()` 可在运行时重新加载。

5. **遗留兼容**: QwenPaw 的 COPAW_ 前缀回退类似于 Java 的配置迁移机制。
