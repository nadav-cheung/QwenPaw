# 环境变量系统

## 概述

QwenPaw 的环境变量系统支持类型安全访问、COPAW_ 遗留前缀兼容、双层持久化（JSON + os.environ），以及启动时的 bootstrap 安全注入。

**核心设计理念**：环境变量是配置系统的基础，采用双层持久化确保配置既安全又便捷，同时通过加密保护敏感信息。

## 1. envs/store.py 持久化存储

源码路径：`src/qwenpaw/envs/store.py:1-263`

### 1.1 关键函数

| 行号 | 函数名 | 说明 |
|------|--------|------|
| 142 | `load_envs` | 从 envs.json 加载环境变量（解密），检测明文并触发加密迁移 |
| 183 | `_rewrite_encrypted` | 将明文值重新加密写入磁盘（迁移助手） |
| 198 | `save_envs` | 加密所有值后写入 envs.json，并同步到 os.environ |
| 223 | `set_env_var` | 设置单个环境变量 |
| 234 | `delete_env_var` | 删除单个环境变量 |
| 242 | `load_envs_into_environ` | 启动时调用：将持久化的 envs 加载到 os.environ（跳过保护键） |

### 1.2 环境变量加载流程

```
load_envs()
  ├─ path = get_envs_json_path()
  ├─ _migrate_legacy_envs_json(path)  （首次迁移旧文件）
  ├─ open(path, "r") → json.load()
  ├─ raw = {k: str(v) for k, v in data.items()}
  ├─ has_plaintext = any(v and not is_encrypted(v) for v in raw.values())
  ├─ decrypted = {k: decrypt(v) for k, v in raw.items()}
  ├─ if has_plaintext: _rewrite_encrypted(path, decrypted)
  └─ return decrypted

load_envs_into_environ()
  ├─ envs = load_envs()
  ├─ bootstrap_envs = {k:v for k,v in envs if k not in _PROTECTED_BOOTSTRAP_KEYS}
  ├─ _apply_to_environ(bootstrap_envs, overwrite=False)
  └─ return envs
```

### 1.3 加密机制

**与 secret_store.py 的交互**：
- `decrypt`: `load_envs` 中遍历 raw 字典时对每个值调用
- `encrypt`: `save_envs` 和 `_rewrite_encrypted` 中对每个值调用
- `is_encrypted`: 判断值是否已是密文，避免重复加密

```python
# envs/store.py:168-170
decrypted = {k: decrypt(v) for k, v in raw.items()}
if has_plaintext:
    _rewrite_encrypted(path, decrypted)
```

**加密特点**：
- 使用 Fernet 对称加密
- 自动检测明文并触发迁移
- 对调用方完全透明

### 1.4 保护键名单

```python
# envs/store.py:86-91
_PROTECTED_BOOTSTRAP_KEYS = frozenset(
    {
        "QWENPAW_WORKING_DIR",
        "QWENPAW_SECRET_DIR",
    },
)
# 这些键不注入 os.environ，防止覆盖启动时路径
```

**保护键说明**：
| 键名 | 用途 | 为什么不注入 |
|------|------|-------------|
| `QWENPAW_WORKING_DIR` | 工作目录 | 启动时由系统设置 |
| `QWENPAW_SECRET_DIR` | 密钥目录 | 启动时由系统设置 |

### 2.2 COPAW_ 遗留兼容

```python
# src/qwenpaw/constant.py:12
def _get_env(key: str, default: str = "") -> str:
    """查找环境变量，自动回退到 COPAW_ 前缀变体"""
    if key in os.environ:
        return os.environ[key]
    if key.startswith("QWENPAW_"):
        legacy_key = "COPAW_" + key[len("QWENPAW_"):]
        if legacy_key in os.environ:
            return os.environ[legacy_key]
    return default
```

**兼容逻辑**：
```
查找 QWENPAW_XXX
    ↓
未找到？
    ├─ YES → 查找 COPAW_XXX（遗留前缀）
    │         ├─ 找到 → 返回 COPAW_XXX 的值
    │         └─ 未找到 → 返回默认值
    └─ NO → 返回 QWENPAW_XXX 的值
```

### 3.2 加载逻辑

```python
# envs/store.py:142
def load_envs() -> dict[str, str]:
    """从 envs.json 加载，解密值透明解密"""
    with open(_ENVS_JSON, "r", encoding="utf-8") as f:
        data = json.load(f)
    return decrypt_dict_fields(data, _PROTECTED_KEYS)
```

### 3.3 保存逻辑

```python
# envs/store.py:198
def save_envs(envs: dict[str, str]) -> None:
    """写入 envs.json（加密）并同步到 os.environ"""
    data = encrypt_dict_fields(envs, _PROTECTED_KEYS)
    # 原子写入
    with open(_ENVS_JSON + ".tmp", "w") as f:
        json.dump(data, f, ...)
    os.replace(_ENVS_JSON + ".tmp", _ENVS_JSON)
    # 同步到 os.environ
    _apply_to_environ(envs)
```

**原子写入**：
1. 写入到 `.tmp` 文件
2. 调用 `os.replace()` 原子替换
3. 确保崩溃不会导致文件损坏

## 4. 渠道过滤

源码路径：`src/qwenpaw/app/routers/config.py`

### 4.1 环境变量过滤

```python
# src/qwenpaw/config/utils.py:343
def get_available_channels() -> Tuple[str, ...]:
    """返回启用的渠道键"""
    raw_enabled = EnvVarLoader.get_str("QWENPAW_ENABLED_CHANNELS", "").strip()
    if raw_enabled:
        enabled = {ch.strip() for ch in raw_enabled.split(",")}
        return tuple(k for k in all_keys if k in enabled)

    raw_disabled = EnvVarLoader.get_str("QWENPAW_DISABLED_CHANNELS", "").strip()
    if raw_disabled:
        disabled = {ch.strip() for ch in raw_disabled.split(",")}
        return tuple(k for k in all_keys if k not in disabled)
```

**过滤逻辑**：
| 变量 | 行为 |
|------|------|
| `QWENPAW_ENABLED_CHANNELS` | 仅启用列出的渠道 |
| `QWENPAW_DISABLED_CHANNELS` | 禁用列出的渠道 |

## 7. 设计模式

### 7.1 类型安全访问

```python
# 统一的类型转换接口

EnvVarLoader.get_int("PORT", 8080)
```

**优势**：
- 避免手动类型转换
- 提供默认值支持
- 统一错误处理

```python
# 自动回退到 COPAW_ 前缀
QWENPAW_WORKING_DIR → COPAW_WORKING_DIR
```

**目的**：平滑迁移，不破坏已有配置。

### 7.3 原子写入

```python
# 先写 .tmp，再原子替换

    json.dump(data, f)
os.replace(path + ".tmp", path)
```

**优势**：崩溃不会导致配置文件损坏。

## 10. 常见问题

### Q1: 环境变量未生效？

**排查步骤**：
```bash
# 1. 检查 .env 文件是否存在
cat .env

# 2. 检查 envs.json 中的值
curl http://localhost:8080/api/envs

# 3. 重启服务
systemctl restart qwenpaw
```

### Q2: 加密后的值显示为乱码？

**原因**：这是正常现象，加密后的值确实不是人类可读的。

**验证方式**：
```python
# 解密验证
from qwenpaw.security.secret_store import decrypt
decrypted = decrypt("ENC:xxx...")
```

### Q3: 保护键被覆盖？

**原因**：`QWENPAW_WORKING_DIR` 和 `QWENPAW_SECRET_DIR` 被故意保护，不允许通过 API 修改。

**正确做法**：通过启动参数或配置文件设置。

### Q4: 批量导入环境变量？

**方法**：
```bash
# 通过 API 批量保存
curl -X PUT http://localhost:8080/api/envs \
  -H "Content-Type: application/json" \
  -d '{"KEY1": "value1", "KEY2": "value2"}'
```
