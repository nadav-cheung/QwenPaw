# 快速开始指南

## 安装方式

### 方式一：pip 安装（推荐）

```bash
pip install qwenpaw
```

### 方式二：脚本安装

```bash
curl -fsSL https://qwenpaw.agentscope.io/install.sh | bash
```

### 方式三：Docker

```bash
docker run -p 8088:8088 agentscope/qwenpaw:latest
```

### 方式四：源码安装

```bash
git clone https://github.com/agentscope-ai/QwenPaw.git
cd QwenPaw
cd console && npm ci && npm run build && cd ..
mkdir -p src/qwenpaw/console && cp -R console/dist/. src/qwenpaw/console/
pip install -e .
```

## 初始化配置

```bash
qwenpaw init --defaults
```

## 启动应用

```bash
qwenpaw app
```

启动后访问 http://127.0.0.1:8088/ 进行配置。

## 常用 CLI 命令

| 命令 | 功能 |
|------|------|
| `qwenpaw init` | 初始化配置 |
| `qwenpaw app` | 启动 Web 应用 |
| `qwenpaw agents` | 管理智能体 |
| `qwenpaw channels` | 配置消息渠道 |
| `qwenpaw skills` | 管理技能 |
| `qwenpaw cron` | 调度任务 |
| `qwenpaw doctor` | 诊断检查 |
