## 概述

QwenPaw 的 EnvVarLoader 支持从 `.env` 文件和环境变量加载配置，支持 `QWENPAW_` 和 `COPAW_` 两种前缀（旧版兼容），提供类型安全的取值方法。

`★ Insight ─────────────────────────────────────`
- `_get_env` 的**前缀回退设计**是向后兼容的典范：新品派上继续支持旧前缀，避免用户升级时配置失效
- `get_int`/`get_float` 的 `min_value`/`max_value` 限制是**防御性编程**：防止配置错误导致异常值扩散
- `.env` 文件路径通过 `Path(__file__)` 相对于**源文件位置**而非 CWD 定位，确保无论从哪里启动都能找到
`─────────────────────────────────────────────────`

## 2. 前缀解析

源码路径：`src/qwenpaw/constant.py:18`

### 2.1 _get_env 函数

```python
# src/qwenpaw/constant.py:18
def _get_env(key: str, default: str = "") -> str:
    """查找环境变量，自动回退到 COPAW_ 旧前缀"""
    if key in os.environ:
        return os.environ[key]

    # QWENPAW_* → COPAW_* 回退
    if key.startswith("QWENPAW_"):
        legacy_key = "COPAW_" + key[len("QWENPAW_"):]
        if legacy_key in os.environ:
            return os.environ[legacy_key]

    return default
```

### 2.2 前缀优先级

| 前缀 | 优先级 | 说明 |
|------|--------|------|
| `QWENPAW_*` | 优先 | 新版前缀 |
| `COPAW_*` | 回退 | 兼容旧版 |

### 2.3 示例

```bash
QWENPAW_API_KEY=xxx    # 优先使用
COPAW_API_KEY=xxx       # 仅当 QWENPAW_ 未设置时生效
```

## 3. 类型安全取值

### 3.1 get_bool

```python
# src/qwenpaw/constant.py:35
@staticmethod
def get_bool(env_var: str, default: bool = False) -> bool:
    val = _get_env(env_var, str(default)).lower()
    return val in ("true", "1", "yes")
```

### 3.2 get_int

```python
# src/qwenpaw/constant.py:53
@staticmethod
def get_int(env_var: str, default: int = 0,
             min_value: int = None, max_value: int = None) -> int:
    value = int(_get_env(env_var, str(default)))
    if min_value is not None and value < min_value:
        return min_value
    if max_value is not None and value > max_value:
        return max_value
    return value
```

### 3.3 get_float

```python
# src/qwenpaw/constant.py:39
@staticmethod
def get_float(env_var: str, default: float = 0.0,
              min_value: float = None, max_value: float = None,
              allow_inf: bool = False) -> float:
    value = float(_get_env(env_var, str(default)))
    if min_value is not None and value < min_value:
        return min_value
    if max_value is not None and value > max_value:
        return max_value
    if not allow_inf and (value == float("inf") or value == float("-inf")):
        return default
    return value
```

### 3.4 类型安全验证

```python
# get_str 无特殊处理，直接返回
@staticmethod
def get_str(env_var: str, default: str = "") -> str:
    return _get_env(env_var, default)
```

## 6. 应用场景

### 6.1 多环境配置隔离

```bash
# .env.development
QWENPAW_WORKING_DIR=~/.qwenpaw-dev
QWENPAW_LOG_LEVEL=debug

# .env.production
QWENPAW_WORKING_DIR=/data/qwenpaw
QWENPAW_LOG_LEVEL=warning

# 启动时加载对应环境
load_dotenv(".env.production")
```

### 6.2 类型安全取值

```python
from qwenpaw.constant import EnvVarLoader

# 布尔值：容错解析
is_auth_enabled = EnvVarLoader.get_bool("QWENPAW_AUTH_ENABLED", default=False)

# 整数值：范围限制
max_retries = EnvVarLoader.get_int("QWENPAW_MAX_RETRIES", default=3, min_value=1, max_value=10)

# 浮点值：防止无穷大
timeout = EnvVarLoader.get_float("QWENPAW_TIMEOUT", default=30.0, min_value=0.1, max_value=300.0)
```

### 6.3 版本迁移

从旧版 COPAW 升级到 QwenPaw 时，无需修改 `.env` 文件中的 `COPAW_*` 变量名，QwenPaw 会自动识别并回退使用。

## 7. 最佳实践

1. **优先环境变量而非硬编码**：所有可配置项都应通过 `EnvVarLoader` 读取，不在代码中硬编码
2. **使用 `.env` 文件管理本地配置**：敏感信息（API Key）放在 `.env` 中，并加入 `.gitignore`
3. **`min/max_value` 防止配置错误扩散**：设置合理范围，避免异常配置值导致系统不稳定
4. **旧前缀兼容时记录警告**：迁移完成后逐步替换 `COPAW_` 为 `QWENPAW_`
5. **容器环境用环境变量**：容器内不挂载 `.env` 文件，直接用 `-e` 传入环境变量

## 8. 常见问题

### Q1: `.env` 文件放在哪里？

`.env` 文件放在 `src/qwenpaw/` 目录的父级父级父级（即项目根目录）。路径通过 `Path(__file__)` 相对于 `constant.py` 定位：

```python
_env_path = Path(__file__).resolve().parent.parent.parent / ".env"
# 相当于: /path/to/project/.env
```

### Q2: 环境变量和 `.env` 文件哪个优先？

环境变量**优先**于 `.env` 文件。`_get_env` 先查 `os.environ`，查不到才用 `.env` 中的值。

### Q3: `COPAW_*` 和 `QWENPAW_*` 同时存在会怎样？

`QWENPAW_*` 优先。只有当 `QWENPAW_X` 不存在时，才会回退查找 `COPAW_X`。

### Q4: `get_float` 的 `allow_inf=False` 时返回什么？

返回 `default` 值。例如 `allow_inf=False, default=30.0` 时，若配置值为 `inf`，则返回 `30.0`。
