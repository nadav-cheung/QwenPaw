# 智能体核心架构 (Agent Core Architecture)

## 概述

QwenPaw 的智能体系统构建于 AgentScope 框架之上，通过组合多个核心组件实现了一个功能完备的 AI Agent。本教程深入讲解智能体的核心架构，包括 AgentScope 框架、QwenPawAgent 核心类、工具系统、记忆系统和模型工厂。

## 1. AgentScope 框架介绍

### 1.1 什么是 AgentScope

AgentScope 是 QwenPaw 依赖的基础多智能体框架，提供了智能体的核心抽象和运行时环境。

**源码路径**: `agentscope/`

### 1.2 核心组件

```
AgentScope
├── Agent (智能体基类)
├── Memory (记忆管理)
├── Model (模型封装)
├── Toolkit (工具集合)
└── Formatter (消息格式化)
```

### 1.3 ReActAgent 架构

QwenPawAgent 继承自 AgentScope 的 `ReActAgent`，采用 ReAct (Reasoning + Acting) 模式：

```
用户输入 → 推理(Reasoning) → 决策(Acting) → 工具执行 → 响应
                ↓
           循环迭代直到任务完成
```

**关键方法**:
- `_reasoning()`: 推理阶段，模型决定下一步行动
- `_acting()`: 执行阶段，调用工具执行具体操作
- `reply()`: 主入口，协调推理和执行循环

```python
    """带有多模态过滤的推理方法"""
    # 1. 主动过滤层：模型不支持多模态时提前移除媒体块
```

```python
async def _decide_guard_action(self, tool_call: dict[str, Any]) -> "_GuardAction | None":
    """决定守卫动作（锁保护下运行）"""
    engine = self._tool_guard_engine
    tool_name = str(tool_call.get("name", ""))
    tool_input = tool_call.get("input", {})
    
    # 1. 检查是否在拒绝列表 → 自动拒绝
    if engine.is_denied(tool_name):
        return _GuardAction("auto_denied", tool_name, tool_input)

    # 2. 检查是否在保护范围且已预批准
    guarded = engine.is_guarded(tool_name)
    if guarded and await self._consume_preapproval(tool_name, tool_input):
        return _GuardAction("preapproved", tool_name, tool_input)

    # 3. 运行所有守护者检查
    guard_result = engine.guard(tool_name, tool_input, only_always_run=not guarded)
    if guard_result.findings and self._should_require_approval():
        return _GuardAction("needs_approval", tool_name, tool_input, guard_result)
    return None
```

**守卫决策流程**:
```
工具调用 → 是否在拒绝列表? → 自动拒绝
              ↓ 否
         是否在守卫范围? → 检查预审批 → 已预审批 → 执行
              ↓ 否               ↓ 否
         运行守卫规则 → 发现问题? → 需要用户审批
              ↓ 否
         正常执行
```

### 2.6 自动继续机制 (Auto-Continue)

当模型仅返回文本但任务未完成时，自动继续推理：

```python
_auto_continue_hint = "上轮助手仅文字、未调工具..."

async def _auto_continue_if_text_only(self, msg, tool_choice):
    if msg.has_content_blocks("tool_use"):
        return msg  # 有工具调用，正常返回

    # 注入提示并重新推理
    hint_msg = Msg("user", self._auto_continue_hint, "user")
    await self.memory.add(hint_msg, marks=_MemoryMark.HINT)
    return await super()._reasoning(tool_choice=tool_choice)
```

### 2.7 多模态媒体处理

三层媒体块处理机制：

1. **主动层**: 模型不支持多模态时，在调用前移除媒体块
2. **被动层**: 调用失败时移除媒体块并重试
3. **自动继续层**: 文本响应时自动继续推理

```python
_media_block_types = {"image", "audio", "video"}

def _strip_media_blocks_from_memory(self) -> int:
    """从记忆中移除媒体块并返回移除数量"""
    for msg, _marks in self.memory.content:
        if not isinstance(msg.content, list):
            continue
        new_content = []
        for block in msg.content:
            if block.get("type") in self._media_block_types:
                total_stripped += 1
                continue  # 跳过媒体块
            new_content.append(block)
        msg.content = new_content
    return total_stripped
```

### 3.2.3 工具执行拦截流程

**ToolGuardMixin** (`tool_guard_mixin.py`) 安全拦截层：

```
┌─────────────────────────────────────────────────────────────────┐
│                    QwenPawAgent._acting()                        │
│  (via ToolGuardMixin override)                                   │
├─────────────────────────────────────────────────────────────────┤
│  1. _decide_guard_action() - 检查工具是否被拒绝/守卫            │
│     ├── is_denied() → auto_denied result                        │
│     ├── is_guarded() → check pre-approval → guard() scan       │
│     └── findings exist → needs_approval                          │
│                                                                  │
│  2. _execute_guard_action() - 执行决定的动作                    │
│     ├── auto_denied → return denial message                      │
│     ├── preapproved → super()._acting()                         │
│     └── needs_approval → create pending, return denial           │
│                                                                  │
│  3. super()._acting() → ReActAgent._acting()                   │
│     └── Calls toolkit.execute_tool() → tool function             │
└─────────────────────────────────────────────────────────────────┘
```

**守卫决策** (`_decide_guard_action` 方法):

| 决策 | 条件 | 结果 |
|------|------|------|
| `auto_denied` | 工具在拒绝列表 | 直接返回拒绝消息 |

```python
        async with self._semaphore:
            for attempt in range(max_retries):

                    if attempt == max_retries - 1:
```

### 8.5 StdIO 生命周期任务模式

**问题**: FastAPI/uvicorn 中 `connect()` 在任务 A 调用 `AsyncExitStack.__aenter__()`，`close()` 在任务 B 调用 `__aexit__()`，导致 `anyio.CancelScope` 错误，进程清理失败。

**解决方案**: 在单个后台任务中运行整个生命周期。

```python
async def _run_lifecycle(self) -> None:
    """在单个任务中运行，避免跨任务 CancelScope 问题"""
    while not self._stop_event.is_set():
        async with AsyncExitStack() as stack:
            # 所有上下文管理器 enter/exit 在同一任务
            context = await stack.enter_async_context(stdio_client(params))
            self.session = await stack.enter_async_context(
                ClientSession(read_stream, write_stream)
            )
            self.is_connected = True
            self._ready_event.set()

            # 等待 reload 或 stop 信号
            while not self._reload_event.is_set():
                await asyncio.sleep(0.1)
```

### 9.1 任务追踪机制

TaskTracker 追踪后台任务，支持 `/stop` 命令取消：

```python
class TaskTracker:
    async def attach_or_start(
        self,
        session_id: str,
        payload: Any,
        stream_fn: Callable,
    ) -> AsyncIterator:
        """附加到现有任务或启动新任务"""
        # 1. 检查是否有运行中的任务
        if session_id in self._tasks:
            return self.stream_from_queue(...)

        # 2. 创建新任务
        task = asyncio.create_task(self._run_task(...))
        self._tasks[session_id] = task

        # 3. 返回流式迭代器
        return self.stream_from_queue(...)

    async def stream_from_queue(
        self,
        queue: asyncio.Queue,
        session_id: str,
    ) -> AsyncIterator:
        """从队列流式输出"""
        while True:
            item = await queue.get()
            yield item
            if self._is_final(item):
                break
```

```python
    return False
```

### 9.5 SSE 流式机制

**SSE 格式**:
```json
data: {"event": "message", "content": [...]}\n\n
```

**生产者端** (`attach_or_start` 内部 `_producer`):

```python
async def _producer() -> None:
    try:
        async for sse in stream_fn(payload):
            async with tracker.lock:
                run.buffer.append(sse)          # 存储用于重连回放
                for q in run.queues:
                    q.put_nowait(sse)          # 广播到所有订阅者
    except asyncio.CancelledError:
        logger.debug("run cancelled run_key=%s", run_key)
    except Exception:
        err_sse = "data: " + json.dumps({'error': 'internal server error'}) + "\n\n"
        async with tracker.lock:
            run.buffer.append(err_sse)
            for q in run.queues:
                q.put_nowait(err_sse)
    finally:
        async with tracker.lock:
            for q in run.queues:
                q.put_nowait(_SENTINEL)        # 信号流结束
            tracker._runs.pop(run_key, None)
```

**消费者端** (`stream_from_queue`):

```python
async def stream_from_queue(
    queue: asyncio.Queue,
    run_key: str,
) -> AsyncGenerator[str, None]:
    try:
        while True:
            event = await queue.get()
            if event is _SENTINEL:
                break
            yield event
    finally:
        await self.detach_subscriber(run_key, queue)  # 断开时清理
```

**关键特性**:
1. **缓冲回放**: 重连时 `attach()` 预填充队列所有缓冲的 SSE 事件
2. **多订阅者**: 每个 SSE 广播到所有订阅者队列
3. **清洁断开**: 客户端断开时 `detach_subscriber` 移除队列
4. **哨兵信号**: `_SENTINEL = None` 标记流结束

**attach_or_start 完整流程**:
```

         │
         ▼
    Acquire _lock
         │
         ▼
```

```python
    skill = await self.skill_service.get_skill(skill_name)
    if not skill:
        return query, False

    # 3. 创建技能消息
    skill_msg = Msg(
        name="user",
        role="user",
        content=f"/{skill_name} {skill_input}",
    )

    # 4. 替换消息列表中的用户消息
    # 5. 返回修改后的查询（通常是技能输入）
    return skill_input, True
```

**_parse_skill_query 解析函数** (第103-128行):

```python
def _parse_skill_query(self, query: str) -> tuple[str, str]:
    """解析技能查询，返回 (技能名, 输入)"""
    # 括号形式: /[file reader] ./notes.txt → ("file reader", "./notes.txt")
    # 普通形式: /pdf 分析这份文件 → ("pdf", "分析这份文件")
    if query.startswith("/["):
        # 括号形式
        match = re.match(r"/\[([^\]]+)\]\s*(.*)", query[2:])
        if match:
            return match.group(1).strip(), match.group(2).strip()
    elif query.startswith("/"):
        # 普通形式
        parts = query[1:].split(maxsplit=1)
        return parts[0], parts[1] if len(parts) > 1 else ""
    return "", ""
```

**执行流程**:

```python
# PRD 验证逻辑 (第129-156行)
def validate_prd(prd: dict[str, Any]) -> list[str]:
    """Validate a PRD dict and return a list of problems (empty = valid)."""
    problems = []
    if "userStories" not in prd:
        problems.append("Missing required field: userStories")
    else:
        for i, story in enumerate(prd["userStories"]):
            required = ["id", "title", "description", "acceptanceCriteria", "priority"]
            for field in required:
                if field not in story:
                    problems.append(f"Story {i} missing required field: {field}")
    return problems
```

## 12. 小结

QwenPaw 的智能体架构具有以下特点：

3. **丰富的工具生态**: 内置 + 技能扩展 + MCP 集成
4. **智能记忆管理**: 短期 + 长期 + 自动压缩 + Dream 优化
5. **安全守卫**: 工具调用审批机制
6. **多模态支持**: 图像、视频、音频处理
7. **跨平台兼容**: Windows/Linux/macOS

理解这些核心组件后，你可以：
- 自定义工具扩展智能体能力
- 实现新的记忆管理器
- 集成第三方 MCP 服务
