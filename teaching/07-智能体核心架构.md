# 智能体核心架构 (Agent Core Architecture)

## 概述

QwenPaw 的智能体系统构建于 AgentScope 框架之上，通过组合多个核心组件实现了一个功能完备的 AI Agent。本教程深入讲解智能体的核心架构，包括 AgentScope 框架、QwenPawAgent 核心类、工具系统、记忆系统和模型工厂。

## 1. AgentScope 框架介绍

### 1.1 什么是 AgentScope

AgentScope 是 QwenPaw 依赖的基础多智能体框架，提供了智能体的核心抽象和运行时环境。

**源码路径**: `agentscope/`

### 1.2 核心组件

```
AgentScope
├── Agent (智能体基类)
├── Memory (记忆管理)
├── Model (模型封装)
├── Toolkit (工具集合)
└── Formatter (消息格式化)
```

### 1.3 ReActAgent 架构

QwenPawAgent 继承自 AgentScope 的 `ReActAgent`，采用 ReAct (Reasoning + Acting) 模式：

```
用户输入 → 推理(Reasoning) → 决策(Acting) → 工具执行 → 响应
                ↓
           循环迭代直到任务完成
```

**关键方法**:
- `_reasoning()`: 推理阶段，模型决定下一步行动
- `_acting()`: 执行阶段，调用工具执行具体操作
- `reply()`: 主入口，协调推理和执行循环

### 2.4 重写的方法

#### `_reasoning()` - 推理覆盖

```python
async def _reasoning(self, tool_choice=None) -> Msg:
    """带有多模态过滤的推理方法"""
    # 1. 主动过滤层：模型不支持多模态时提前移除媒体块
    if not get_active_model_supports_multimodal():
        self._proactive_strip_media_blocks()
    
    # 2. 被动回退层：模型调用失败时移除媒体块并重试
    try:
        msg = await super()._reasoning(tool_choice=tool_choice)
    except Exception as e:
        if self._is_bad_request_or_media_error(e):
            self._set_formatter_media_strip(True)
            msg = await super()._reasoning(tool_choice=tool_choice)
    
    # 3. 自动继续：文本响应但任务未完成时继续推理
    return await self._auto_continue_if_text_only(msg, tool_choice)
```

#### `reply()` - 主入口覆盖

```python
async def reply(self, msg: Msg | list[Msg] | None = None, ...) -> Msg:
```

### 2.5 工具安全守卫 (ToolGuardMixin)

```python
class ToolGuardMixin:
    """工具安全守卫混入类"""

    async def _acting(self, tool_call) -> dict | None:
        """拦截敏感工具调用"""
        # 1. 检查是否在拒绝列表
        if engine.is_denied(tool_name):
            return await self._acting_auto_denied(...)

        # 2. 检查是否需要审批
        guard_result = engine.guard(tool_name, tool_input)
        if guard_result.findings:
            return await self._acting_with_approval(...)

        # 3. 正常执行
        return await super()._acting(tool_call)
```

**守卫决策流程**:
```
工具调用 → 是否在拒绝列表? → 自动拒绝
              ↓ 否
         是否在守卫范围? → 检查预审批 → 已预审批 → 执行
              ↓ 否               ↓ 否
         运行守卫规则 → 发现问题? → 需要用户审批
              ↓ 否
         正常执行
```

### 2.7 多模态媒体处理

三层媒体块处理机制：

1. **主动层**: 模型不支持多模态时，在调用前移除媒体块
2. **被动层**: 调用失败时移除媒体块并重试
3. **自动继续层**: 文本响应时自动继续推理

```python
_media_block_types = {"image", "audio", "video"}

def _strip_media_blocks_from_memory(self) -> int:
    """从记忆中移除媒体块并返回移除数量"""
    for msg, _marks in self.memory.content:
        if not isinstance(msg.content, list):
            continue
        new_content = []
        for block in msg.content:
            if block.get("type") in self._media_block_types:
                total_stripped += 1
                continue  # 跳过媒体块
            new_content.append(block)
        msg.content = new_content
    return total_stripped
```

### 5.6 RetryChatModel 重试机制

```python
class RetryChatModel:
    """重试包装器，处理限流和瞬时故障"""

    async def chat(self, messages, **kwargs):
        # 1. 获取信号量（限流）
        async with self._semaphore:
            for attempt in range(max_retries):
                try:
                    return await self._model.chat(messages, **kwargs)
                except RateLimitError as e:
                    if attempt == max_retries - 1:
                        raise
                    # 指数退避 + 抖动
                    await asyncio.sleep(
                        min(backoff_base * (2 ** attempt), backoff_cap)
                        + random.uniform(0, jitter)
                    )
```

## 9. 任务追踪系统 (TaskTracker)

**源码路径**: `src/qwenpaw/app/runner/task_tracker.py`

### 9.1 任务追踪机制

TaskTracker 追踪后台任务，支持 `/stop` 命令取消：

```python
class TaskTracker:
    async def attach_or_start(
        self,
        session_id: str,
        payload: Any,
        stream_fn: Callable,
    ) -> AsyncIterator:
        """附加到现有任务或启动新任务"""
        # 1. 检查是否有运行中的任务
        if session_id in self._tasks:
            return self.stream_from_queue(...)

        # 2. 创建新任务
        task = asyncio.create_task(self._run_task(...))
        self._tasks[session_id] = task

        # 3. 返回流式迭代器
        return self.stream_from_queue(...)

    async def stream_from_queue(
        self,
        queue: asyncio.Queue,
        session_id: str,
    ) -> AsyncIterator:
        """从队列流式输出"""
        while True:
            item = await queue.get()
            yield item
            if self._is_final(item):
                break
```

### 9.2 取消任务

```python
async def cancel_task(self, session_id: str) -> bool:
    """取消指定会话的任务"""
    if session_id in self._tasks:
        self._tasks[session_id].cancel()
        return True
    return False
```
