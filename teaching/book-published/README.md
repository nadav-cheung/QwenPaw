# 《QwenPaw 实战与源码解读》

## 从零基础到开源贡献者的完整学习路径

---

## 书籍简介

本书面向**完全没有编程经验的初学者**，通过 QwenPaw 这个真实开源项目，带领读者从零开始学习 Python 编程，并逐步掌握阅读源码、参与开源开发的能力。

**学习路径**：编程基础 → Python 入门 → QwenPaw 使用 → 源码阅读 → 参与开发

---

## 本书特色

### 1. 循序渐进的学习路径

本书设计了七部分内容，从编程基础开始，逐步深入到 QwenPaw 源码解读：

- **第一部分（编程入门）**：为零基础读者量身打造，无需任何编程经验
- **第二部分（Python 进阶）**：深入理解 Python 的高级特性
- **第三部分（QwenPaw 入门）**：快速上手使用 QwenPaw
- **第四部分（QwenPaw 开发）**：理解核心架构和开发技能
- **第五部分（系统深入）**：掌握安全、配置、部署等进阶主题
- **第六部分（架构与最佳实践）**：学习架构思维和工程实践
- **第七部分（实战与贡献）**：从需求到代码的完整流程

### 2. 理论与实践结合

每章都包含：
- **本章导读**：学习目标、前置知识、预计时长、难度等级
- **正文讲解**：概念引入、架构设计、核心机制、实战应用
- **知识检查**：概念题、判断题、场景题
- **实战演练**：基础练习、进阶练习、挑战练习
- **延伸阅读**：相关章节和资源链接

### 3. Java 开发者视角

书中多处包含"来自 Java 的你"专栏，帮助有 Java 经验的开发者快速理解 Python 和 QwenPaw 的设计思路。

### 4. 真实开源项目驱动

所有内容都围绕 QwenPaw 这个真实的开源项目展开，读者不仅学习编程，还能：
- 理解 AI 助手的工作原理
- 掌握开源项目的代码结构
- 学会参与开源贡献

## QwenPaw 源码结构

```
src/qwenpaw/
├── agents/              # 智能体核心
│   ├── react_agent.py  # QwenPawAgent 核心类
│   ├── tools/          # 内置工具
│   ├── skills/         # 内置技能
│   ├── memory/         # 记忆系统
│   └── hooks/          # 生命周期钩子
├── app/                # 应用系统
│   ├── server.py       # FastAPI 服务器
│   ├── channels/       # 消息渠道
│   ├── runner/         # 请求处理器
│   └── multi_agent_manager.py  # 多智能体管理
├── providers/          # LLM 提供商
│   ├── provider_manager.py  # 提供商管理
│   ├── openai_provider.py  # OpenAI
│   ├── ollama_provider.py  # Ollama
│   └── ...
├── security/           # 安全系统
│   ├── tool_guard/     # 工具守卫
│   ├── file_guard/     # 文件守卫
│   └── secret_store.py # 密钥存储
└── cli/                # 命令行工具
```
