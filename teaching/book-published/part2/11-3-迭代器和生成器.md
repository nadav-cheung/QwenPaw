## 1. 迭代器基础

### 1.1 可迭代对象

可以用 `for` 循环遍历的对象：

```python
# 列表
for i in [1, 2, 3]:
    print(i)

# 字符串
for c in "hello":
    print(c)

# 字典
for k in {"a": 1, "b": 2}:
    print(k)
```

### 1.2 迭代器协议

```
┌────────────────────────────────────┐
│           迭代器协议                 │
├────────────────────────────────────┤
│                                    │
│  iter(obj)  → 获取迭代器           │
│  next(it)   → 获取下一个元素        │
│  StopIteration → 迭代结束           │
│                                    │
└────────────────────────────────────┘
```

### 1.3 手写迭代器

```python
# 获取迭代器
my_list = [1, 2, 3]
iterator = iter(my_list)

# 获取下一个元素
print(next(iterator))  # 1
print(next(iterator))  # 2
print(next(iterator))  # 3

# 迭代结束
print(next(iterator))  # StopIteration 异常
```

## 2. 自定义迭代器

### 2.1 实现迭代器类

```python
class Counter:
    """计数器迭代器"""

    def __init__(self, start, end):
        self.current = start
        self.end = end

    def __iter__(self):
        """返回迭代器本身"""
        return self

    def __next__(self):
        """返回下一个元素"""
        if self.current >= self.end:
            raise StopIteration
        value = self.current
        self.current += 1
        return value

# 使用
counter = Counter(1, 5)
for i in counter:
    print(i)
```

**输出**：
```
1
2
3
4
```

### 2.2 无限迭代器

```python
class InfiniteCounter:
    """无限计数器"""

    def __init__(self, start=0):
        self.current = start

    def __iter__(self):
        return self

    def __next__(self):
        value = self.current
        self.current += 1
        return value

# 使用（需要手动停止）
counter = InfiniteCounter(10)
print(next(counter))  # 10
print(next(counter))  # 11
print(next(counter))  # 12
```

## 3. 生成器基础

### 3.1 什么是生成器

生成器是简化迭代器创建的语法糖，使用 `yield` 返回值。

```python
def my_generator():
    """简单生成器"""
    yield 1
    yield 2
    yield 3

# 使用
gen = my_generator()
print(next(gen))  # 1
print(next(gen))  # 2
print(next(gen))  # 3
print(next(gen))  # StopIteration
```

### 3.2 生成器 vs 列表

| 特性 | 列表 | 生成器 |
|------|------|--------|
| 内存 | 一次性加载所有元素 | 按需生成 |
| 速度 | 创建慢 | 创建快 |
| 遍历 | 可重复 | 只能遍历一次 |
| 适用 | 小数据 | 大数据/无限序列 |

```python
# 列表：一次性创建
numbers_list = [x ** 2 for x in range(1000000)]  # 占用大量内存

# 生成器：按需生成
numbers_gen = (x ** 2 for x in range(1000000))  # 几乎不占内存
```

### 3.3 生成器函数

```python
def count_up_to(n):
    """计数到 n"""
    i = 1
    while i <= n:
        yield i
        i += 1

for num in count_up_to(5):
    print(num)
```

## 4. 生成器进阶

### 4.1 yield from

委托给另一个生成器：

```python
def values():
    """生成值"""
    yield from [1, 2, 3]
    yield from [4, 5, 6]

# 等价于
def values():
    for v in [1, 2, 3]:
        yield v
    for v in [4, 5, 6]:
        yield v

# 使用
for v in values():
    print(v)
```

### 4.2 生成器表达式

```python
# 类似列表推导式，但用圆括号
squares = (x ** 2 for x in range(10))

print(next(squares))  # 0
print(next(squares))  # 1

# 转换为列表
print(list(squares))  # [4, 9, 16, 25, 36, 49, 64, 81]
```

### 4.3 协程 vs 生成器

```python
def simple_coroutine():
    """协程示例"""
    while True:
        received = yield
        print(f"收到: {received}")

# 创建协程
 coro = simple_coroutine()
next(coro)  # 启动协程

coro.send("Hello")  # 发送值
coro.send("World")   # 发送值
coro.close()         # 关闭协程
```

## 5. 实战：处理大数据

### 5.1 读取大文件

```python
def read_large_file(filename, chunk_size=1024):
    """分块读取大文件"""
    with open(filename, 'r') as f:
        while True:
            chunk = f.read(chunk_size)
            if not chunk:
                break
            yield chunk

# 使用：处理几 GB 的文件也不会内存溢出
for chunk in read_large_file("huge_log.txt"):
    process(chunk)
```

### 5.2 管道处理

```python
def generate_numbers(n):
    """生成数字"""
    for i in range(n):
        yield i

def filter_even(numbers):
    """过滤偶数"""
    for n in numbers:
        if n % 2 == 0:
            yield n

def square(numbers):
    """平方"""
    for n in numbers:
        yield n ** 2

def take(n, sequence):
    """取前 n 个"""
    for i, v in enumerate(sequence):
        if i >= n:
            break
        yield v

# 链式处理
result = take(5, square(filter_even(generate_numbers(20))))
print(list(result))  # [0, 4, 16, 36, 64]
```

## 6. 小结

### 迭代器协议

```python
class MyIterator:
    def __iter__(self):
        return self

    def __next__(self):
        if 条件:
            raise StopIteration
        return value
```

### 生成器函数

```python
def my_generator():
    yield value1
    yield value2

# 使用
gen = my_generator()
next(gen)  # value1
next(gen)  # value2
next(gen)  # StopIteration

# 或 for 循环
for v in my_generator():
    print(v)
```

### yield from

```python
def gen():
    yield from [1, 2, 3]  # 委托
```

### 生成器优势

| 优势 | 说明 |
|------|------|
| 节省内存 | 按需生成 |
| 惰性计算 | 延迟执行 |
| 可组合 | 管道式处理 |
| 无限序列 | 可表示无限数据 |
