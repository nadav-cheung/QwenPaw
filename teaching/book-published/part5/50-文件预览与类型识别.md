### 1.2 路径规范化

```python
# src/qwenpaw/app/routers/files.py:16
normalized = unquote(filepath)

# 处理重复的 preview 前缀
while True:
    trimmed = normalized.lstrip("/")
    prefix = "api/files/preview/"
    if trimmed.startswith(prefix):
        normalized = trimmed[len(prefix):]
        continue
    break

# Windows 路径规范化：/C:/... → C:/...
if (len(normalized) >= 4 and normalized[0] == "/"
    and normalized[2] == ":" and normalized[1].isalpha()):
    normalized = normalized[1:]
```

## 来自 Java 的你

### 核心概念对照

| Java | Python / QwenPaw | 说明 |
|------|-------------------|------|
| `MimetypesFileTypeMap` / `URLConnection.guessContentTypeFromName()` | `mimetypes` 模块 | Java 用 JAF (JavaBeans Activation Framework) 检测 MIME 类型，Python 标准库自带 `mimetypes` 模块 |
| `URLConnection.guessContentTypeFromStream()` | Magic bytes 检测 | Java 通过读取流前几个字节猜测类型，文件预览通过扩展名映射确定 Content-Type |
| `HttpServlet` + `doGet()` | FastAPI `@router.api_route()` | Java 用 HttpServlet 的 `doGet` 方法处理请求，FastAPI 用装饰器声明路由 |
| `java.nio.file.Path` / `Files` | `pathlib.Path` | Java NIO.2 的 Path/Files API 做文件操作，Python 用 `pathlib.Path` 提供类似的链式操作 |
| `FileResponse` (Spring) | `FileResponse` (FastAPI) | Spring 用 `Resource` + `ResponseEntity` 返回文件，FastAPI 直接用 `FileResponse` 封装 |

### 关键差异

Java 的 `java.nio.file.Path.resolve()` 和 `Path.normalize()` 提供强类型的路径操作；Python 的 `pathlib.Path` 功能类似但更简洁。Java 开发者需要注意：文件预览的路径安全检查使用 `Path.resolve()` 后直接检查 `is_file()`，没有 Spring Security 的 URL 安全过滤器链，安全边界在路由函数内通过路径规范化实现。
