### 1.2 启动隧道

```python
# src/qwenpaw/tunnel/cloudflare.py:52
async def start(self, local_port: int) -> TunnelInfo:
    """启动隧道并返回连接信息。

    阻塞直到从 cloudflared 输出检测到公网 URL
    （通常 2-5 秒）。
    """
    binary = await self._binary_mgr.get_binary_path()

    self._process = await asyncio.create_subprocess_exec(
        binary, "tunnel", "--url", f"http://localhost:{local_port}",
        stdout=asyncio.subprocess.DEVNULL,
        stderr=asyncio.subprocess.PIPE,
    )

    url = await self._wait_for_url(timeout=30)
```


### 1.4 健康检查

```python
# src/qwenpaw/tunnel/cloudflare.py:109
async def health_check(self) -> bool:
    """检查 tunnel 进程是否运行"""
    return self._process is not None and self._process.returncode is None
```

## 🐍 来自 Java 的你

### 核心概念对照

| Java | Python / QwenPaw | 说明 |
|------|-------------------|------|
| Spring Cloud (Service Discovery) | Cloudflare Tunnel | Spring Cloud 通过 Eureka/Consul 实现服务注册发现；QwenPaw 通过 Cloudflare Tunnel 暴露本地服务 |
| Twilio Java SDK | Twilio Python SDK | Java SDK 通过 Maven 依赖引入；Python SDK 通过 pip 安装，API 调用风格一致但更简洁 |
| @FeignClient (声明式 HTTP) | httpx / aiohttp | @FeignClient 通过接口定义+注解自动生成 HTTP 客户端；QwenPaw 使用 httpx（同步）或 aiohttp（异步）直接调用 |
| RestTemplate / WebClient | httpx / aiohttp | RestTemplate 是同步阻塞式；WebClient 是响应式；QwenPaw 根据场景选择 httpx 或 aiohttp |
| Service Registry (Eureka) | DNS Tunnel (Cloudflare) | Java 微服务通过注册中心动态发现；QwenPaw 通过 Cloudflare 的 DNS 隧道实现外部可达 |

### 关键差异

Java 微服务生态依赖重量级基础设施（注册中心、配置中心、API 网关），而 QwenPaw 采用轻量级集成策略——通过 Cloudflare Tunnel 实现零配置的外网暴露，无需搭建额外的服务注册和发现机制。HTTP 客户端方面，Java 的 FeignClient 提供声明式抽象，而 Python 生态更倾向于显式的 httpx/aiohttp 调用，代码更直接透明。
