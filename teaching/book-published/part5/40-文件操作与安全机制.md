```python
def _resolve_file_path(file_path: str) -> str:
    """相对路径解析到工作区，绝对路径直接使用"""
    path = Path(file_path).expanduser()
    if path.is_absolute():
        return str(path)
    else:
        workspace_dir = get_current_workspace_dir() or WORKING_DIR
        return str(workspace_dir / file_path)
```

**解析规则：**

| 输入类型 | 处理方式 | 示例 |

| `~` 开头 | 展开 home 目录 | `~/Documents/file.txt` → `/Users/name/Documents/file.txt` |
| 相对路径 | 拼接 workspace 目录 | `file.txt` → `{workspace}/file.txt` |

```python
def _get_encoding_for_file(file_path: str) -> str:
```

```python
def _is_sensitive(self, abs_path: str) -> bool:
    path_obj = Path(abs_path)
```

## 4. Zip Slip 防护

源码路径：`src/qwenpaw/backup/_utils/safe_swap.py:126`

### 4.1 攻击原理

**Zip Slip** 是一种目录遍历攻击：
- 恶意 ZIP 文件包含 `../../etc/passwd` 类条目
- 解压时覆盖系统文件

### 4.2 防护实现

```python
# src/qwenpaw/backup/_utils/safe_swap.py:126
def _extract_zip_to(zf, prefix, tmp_dst, base_resolved) -> None:
    for info in zf.infolist():
        rel = os.path.relpath(os.path.join(prefix, info.filename), start=prefix)

        # 关键检查：解析后的路径必须在基准目录下
        if not (base_resolved / rel).resolve().is_relative_to(base_resolved):
            logger.warning("Skipping suspicious path: %s", info.filename)
            continue  # 跳过而非抛出异常

        # 安全解压
        zf.extract(info, tmp_dst)
```

**防护原理：**
- 使用 `resolve()` 解析所有符号链接
- 使用 `is_relative_to()` 验证最终路径
- 任何试图穿越基准目录的条目都被跳过

### 9.1 安全读取 — read_file_safe

源码路径：`src/qwenpaw/agents/tools/utils.py:129`

```python
async def read_file_safe(
    file_path: str,
    max_bytes: int = MAX_FILE_READ_BYTES,
) -> str:
    """Read file with Unicode error handling and memory protection.

    Args:
        file_path: Path to the file.
        max_bytes: Maximum bytes to read into memory (default 1GB).

    Returns:
        File content as string (up to max_bytes).
    """
    # Use utf-8-sig to auto-remove BOM if present
    try:
        async with aiofiles.open(
            file_path,
            "r",
            encoding="utf-8-sig",
        ) as f:
            return await f.read(max_bytes)
    except UnicodeDecodeError:
        # Fallback: ignore encoding errors
        async with aiofiles.open(
            file_path,
            "r",
            encoding="utf-8-sig",
            errors="ignore",
        ) as f:
            return await f.read(max_bytes)
```

**特性**：
- **BOM 处理**：自动移除 UTF-8 BOM (`﻿`)，兼容 Windows Excel
- **编码容错**：首次失败后使用 `errors="ignore"` 忽略无效字符
- **内存保护**：通过 `max_bytes` 限制读取大小

### 9.2 智能截断 — truncate_text_output

```python
def truncate_text_output(
```

**截断策略**：

## 12. 常见问题

### Q1: 文件访问被拒绝如何排查？

**常见原因：**
1. 文件在工作区外
2. 文件在敏感目录内
3. 路径包含 `..` 试图遍历

**排查步骤：**

```python
# 1. 检查解析后的路径
resolved = _resolve_file_path("/path/to/file")
print(f"解析后路径: {resolved}")

# 2. 检查是否在敏感目录
from qwenpaw.security.tool_guard import FileGuardian
guardian = FileGuardian()
is_sensitive = guardian._is_sensitive(resolved)
print(f"敏感目录: {is_sensitive}")
```

### Q2: Unicode 编码问题导致文件找不到？

**原因：** macOS 使用 NFD 归一化，路径匹配失败。

**解决：**

```python
import unicodedata
# 归一化路径
normalized = unicodedata.normalize('NFC', original_path)
await read_file(normalized)
```

### Q3: 写入大文件失败？

**原因：** 超过内存限制或磁盘空间不足。

**解决：**

```python
# 1. 检查文件大小
import os
size = os.path.getsize(file_path)
print(f"文件大小: {size / 1024 / 1024:.2f} MB")

# 2. 分块写入
chunk_size = 1024 * 1024  # 1MB
for i in range(0, len(content), chunk_size):
    await append_file(path, content[i:i+chunk_size])
```

### Q4: Zip Slip 防护如何工作？

**原理：**
- 检查 ZIP 条目的**解析后**路径
- 使用 `resolve()` 处理符号链接
- 使用 `is_relative_to()` 验证最终位置

**示例：**

```python
# 恶意 ZIP 条目
#  filename: "../../etc/passwd"

# base_resolved = /safe/dir
# rel = "../../etc/passwd"
# (base_resolved / rel).resolve() = "/etc/passwd"
# /etc/passwd.is_relative_to(/safe/dir) = False
# → 被拒绝
```

## 13. 最佳实践

```python
path = Path(file_path).expanduser()
```

```python
# 推荐：先读取验证再编辑
content = await read_file(path)

await edit_file(path, old, new)

# 推荐：使用 edit_file 而非 write_file（保留文件属性）
```

```python
# 推荐：净化用户输入的路径
import re
safe_name = re.sub(r'[^a-zA-Z0-9._-]', '_', user_input)
```

### 13.4 大文件处理

```python
# 分块读取大文件
async def read_large_file(path, chunk_size=1000):
    offset = 0
    while True:
        content = await read_file(path, line_start=offset, line_end=offset+chunk_size)
        if not content:
            break
```

## 来自 Java 的你

### 核心概念对照

| Java | Python / QwenPaw | 说明 |
|------|-------------------|------|
| `java.io.File` / `java.nio.file.Path` | `pathlib.Path` | Python 的 `pathlib.Path` 是面向对象的路径操作，支持 `/` 运算符拼接 |
| `SecurityManager` (已废弃) | `FileGuard` / `FilePathGuardian` | QwenPaw 通过 Guardian 类实现文件访问控制，而非 JVM 级安全策略 |
| `FilePermission` | Workspace 隔离 | QwenPaw 使用工作区目录 + 敏感目录黑名单实现文件隔离 |
| `ZipEntry` 安全检查 | Zip Slip 防护 (`_extract_zip_to`) | QwenPaw 使用 `resolve()` + `is_relative_to()` 检测路径穿越 |
| Java NIO (`Files.walk`, `AsynchronousFileChannel`) | `asyncio` + `aiofiles` | Python 的异步文件操作通过 `aiofiles` 库实现，API 更简洁 |

### 关键差异

Java 的 `SecurityManager` 是 JVM 级别的全局安全策略，已在 Java 17 中标记废弃。QwenPaw 的文件安全通过应用层 Guardian 实现，基于路径解析 + 黑名单检查，粒度更细但范围限于应用内部。

## 知识检查

1. **路径解析安全**：给定相对路径 `../../etc/passwd`，`_resolve_file_path()` 会如何处理？如果 workspace 目录是 `/home/user/project`，最终路径是什么？FilePathGuardian 是否能拦截此访问？

2. **Zip Slip 防护**：为什么 `_extract_zip_to()` 使用 `resolve()` 而不是直接比较路径字符串？攻击者如何构造一个看似在基准目录下但实际穿越的路径？

3. **敏感目录优先级**：如果 workspace 目录恰好是 `~/.qwenpaw/`，文件操作是否可以访问 `~/.qwenpaw.secret/`？请解释黑名单优先于 workspace 边界的设计原理。

## 10. Contributor 指南

### 10.1 适合新手修改的文件

| 文件 | 难度 | 原因 |
|------|------|------|
| `agents/tools/file_io.py` 的工具函数 | ⭐ | 相对独立的文件操作 |
| `agents/tools/file_search.py` 的搜索逻辑 | ⭐ | 独立的搜索算法 |
| `agents/tools/view_text_file.py` 的文本查看 | ⭐ | 简单的文件读取 |

### 10.2 危险区域（绝对不要轻易修改）

| 文件/模块 | 危险原因 |
|-----------|----------|
| `file_io.py` 的 `_resolve_file_path()` | 错误会导致路径穿越漏洞 |
| `file_io.py` 的 Zip Slip 防护 | 错误会让恶意压缩包攻击系统 |
| `file_io.py` 的敏感目录黑名单 | 错误会导致密钥文件被访问 |

### 10.3 调试方法

**测试路径解析**
```python
from qwenpaw.agents.tools.file_io import _resolve_file_path

resolved = _resolve_file_path("../../etc/passwd", "/home/user/project")
print(f"Resolved path: {resolved}")
```

```python
content = await read_file({"path": "/home/user/file.txt"})
print(f"Content length: {len(content)}")
```

**测试 Zip Slip 防护**

```python
from qwenpaw.agents.tools.file_io import _extract_zip_to

# 恶意压缩包测试
await _extract_zip_to(zip_path, "/home/user/extract")
```

### 10.4 如何避免破坏架构

**路径安全原则**：
- 所有文件路径必须经过 `resolve()` 解析
- 解析后必须验证是否在 workspace 内或黑名单外
- 使用 `is_relative_to()` 而非字符串比较

**压缩包安全原则**：
- 解压时必须检查每个文件的实际路径
- 禁止直接使用压缩包内的路径字符串
- 必须验证解压后路径在目标目录内

**测试要求**：
- 文件操作必须测试路径穿越场景
- 压缩包处理必须测试恶意文件名校验
- 敏感目录检查必须测试黑名单覆盖
