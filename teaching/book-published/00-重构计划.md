## 源码架构分析

```
src/qwenpaw/
├── agents/              # 智能体核心 (ReAct 模式)
│   ├── react_agent.py   # QwenPawAgent 主类
│   ├── tool_guard_mixin.py
│   ├── model_factory.py
│   ├── skills_manager.py
│   ├── skills_hub.py
│   ├── multi_agent_manager.py
│   ├── hooks/           # 生命周期钩子
│   ├── memory/          # 记忆系统
│   ├── skills/          # 内置技能
│   ├── tools/           # 内置工具
│   └── mission/         # Mission 模式
├── app/                 # 应用系统
│   ├── server.py        # FastAPI 服务器
│   ├── runner/          # 请求处理器
│   ├── channels/        # 消息渠道 (钉钉/飞书/微信等)
│   ├── routers/         # API 路由
│   ├── acp/             # ACP 协议
│   └── md_files/        # 知识文件
├── providers/           # LLM 提供商
│   ├── provider_manager.py
│   ├── openai_provider.py
│   ├── ollama_provider.py
│   └── ...
├── security/           # 安全系统
│   ├── tool_guard/      # 工具守卫
│   ├── skill_scanner/   # 技能安全扫描
│   └── secret_store.py  # 密钥存储
├── cli/                 # 命令行工具
├── config/              # 配置系统
└── plugins/            # 插件系统
```

## 章节标准模板

每章必须包含：
1. **学习目标** - 学完后能做什么
2. **背景问题** - 为什么这个模块存在
3. **源码入口** - 文件路径、类名、方法名
4. **架构定位** - 模块职责、生命周期、数据流
5. **核心源码分析** - 按调用链分析
6. **可视化结构** - Mermaid 图
7. **工程经验** - 设计原因、坑、实际生产问题
8. **Contributor 指南** - 调试方法、危险区域、测试方法
