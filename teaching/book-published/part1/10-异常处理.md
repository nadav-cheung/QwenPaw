## 1. 什么是异常？

### 1.1 程序中的错误

程序运行时可能会遇到各种错误：

```python
# 除零错误
result = 10 / 0  # ZeroDivisionError

# 索引错误
numbers = [1, 2, 3]
print(numbers[5])  # IndexError

# 类型错误
num = "hello"
print(num + 5)  # TypeError

# 文件不存在
open("not_exist.txt")  # FileNotFoundError
```

### 1.2 异常 vs 普通错误

| 类型 | 说明 | 处理方式 |
|------|------|----------|
| **语法错误** | 代码写错了 | 编译前检查 |
| **运行时异常** | 程序运行出错 | try/except |
| **逻辑错误** | 程序结果不对 | Debug |

### 1.3 异常传播

```python
def level3():
    return 10 / 0

def level2():
    return level3()

def level1():
    return level2()

try:
    result = level1()
except ZeroDivisionError:
    print("捕获到除零错误！")
```

## 2. try/except 处理异常

### 2.1 基本语法

```python
try:
    # 可能出错的代码
    risky_code()
except 异常类型:
    # 处理异常
    handle_error()
```

### 2.2 示例

```python
try:
    age = int(input("请输入年龄: "))
    print(f"你的年龄是 {age}")
except ValueError:
    print("输入无效，请输入数字！")
```

### 2.3 捕获多种异常

```python
try:
    num = int(input("请输入数字: "))
    result = 10 / num
    print(f"10 / {num} = {result}")
except ValueError:
    print("输入无效！")
except ZeroDivisionError:
    print("不能除以零！")
```

### 2.4 捕获所有异常

```python
try:
    # 可能出错的代码
    risky_code()
except Exception as e:
    print(f"出错了: {e}")
```

### 2.5 else 子句

```python
try:
    num = int(input("请输入数字: "))
except ValueError:
    print("输入无效！")
else:
    # 只有在没有异常时执行
    print(f"你输入的是 {num}")
```

## 3. finally 子句

### 3.1 语法

```python
try:
    file = open("data.txt")
    content = file.read()
except FileNotFoundError:
    print("文件不存在！")
finally:
    # 无论是否异常都会执行
    print("清理工作...")
    if 'file' in dir():
        file.close()
```

### 3.2 典型用法

```python
try:
    # 尝试获取资源
    connection = connect_to_database()
    data = connection.query("SELECT * FROM users")
    process(data)
except DatabaseError as e:
    print(f"数据库错误: {e}")
finally:
    # 无论如何都要关闭连接
    if connection:
        connection.close()
```

## 4. 抛出异常

### 4.1 raise 语句

```python
def divide(a, b):
    if b == 0:
        raise ValueError("除数不能为零！")
    return a / b

try:
    result = divide(10, 0)
except ValueError as e:
    print(f"错误: {e}")  # 错误: 除数不能为零！
```

### 4.2 自定义异常

```python
class InvalidAgeError(Exception):
    """无效年龄异常"""
    pass

def set_age(age):
    if age < 0 or age > 150:
        raise InvalidAgeError(f"无效的年龄: {age}")
    print(f"年龄设置为: {age}")

try:
    set_age(200)
except InvalidAgeError as e:
    print(f"捕获异常: {e}")
```

### 4.3 异常链

```python
try:
    # 原始操作
    int("not a number")
except ValueError as e:
    # 转换为新的异常
    raise RuntimeError("转换失败") from e
```

## 6. 实战项目：计算器升级版

### 6.1 需求分析

改进计算器，增加异常处理：
- 处理无效输入
- 处理除零错误
- 显示友好的错误信息

### 6.2 代码实现

```python
# ========================================
# 计算器 v3.0（带异常处理）
# ========================================

class CalculatorError(Exception):
    """计算器异常基类"""
    pass

class InvalidInputError(CalculatorError):
    """无效输入异常"""
    pass

class DivisionByZeroError(CalculatorError):
    """除零异常"""
    pass

def get_number(prompt):
    """获取数字输入"""
    while True:
        try:
            value = float(input(prompt))
            return value
        except ValueError:
            print("❌ 输入无效，请输入数字！")

def get_operation():
    """获取运算选择"""
    operations = {
        "1": ("加法", "+", lambda a, b: a + b),
        "2": ("减法", "-", lambda a, b: a - b),
        "3": ("乘法", "×", lambda a, b: a * b),
        "4": ("除法", "÷", lambda a, b: a / b if b != 0 else None),
        "5": ("幂运算", "^", lambda a, b: a ** b),
    }

    while True:
        print("\n请选择运算:")
        print("  1. 加法 (+)")
        print("  2. 减法 (-)")
        print("  3. 乘法 (×)")
        print("  4. 除法 (÷)")
        print("  5. 幂运算 (^)")
        print("  0. 退出")

        choice = input("\n请选择 (0-5): ").strip()

        if choice == "0":
            return None

        if choice not in operations:
            print("❌ 无效选择，请重试！")
            continue

        return operations[choice]

def calculator():
    """计算器主函数"""
    print("=" * 50)
    print("  计算器 v3.0（带异常处理）")
    print("=" * 50)

    while True:
        op = get_operation()
        if op is None:
            print("\n感谢使用，再见！")
            break

        name, symbol, func = op

        try:
            a = get_number("请输入第一个数字: ")
            b = get_number("请输入第二个数字: ")

            # 特殊检查
            if symbol == "÷" and b == 0:
                raise DivisionByZeroError("除数不能为零！")

            result = func(a, b)
            print(f"\n✅ {a} {symbol} {b} = {result}")

        except DivisionByZeroError as e:
            print(f"\n❌ 错误: {e}")

        except Exception as e:
            print(f"\n❌ 未知错误: {e}")

if __name__ == "__main__":
    calculator()
```

## 8. 小结

### 异常处理语法

```python
try:
    # 可能出错的代码
    risky_code()
except 异常类型1:
    # 处理异常1
    handle1()
except 异常类型2:
    # 处理异常2
    handle2()
else:
    # 没有异常时执行
    success()
finally:
    # 无论是否有异常都执行
    cleanup()
```

### raise 抛出异常

```python
raise ValueError("错误信息")
raise CustomError("自定义错误")
```

### 最佳实践

| 做法 | 说明 |
|------|------|
| 捕获具体异常 | 避免 bare except |
| 保留异常信息 | 使用 `as e` |
| 提供友好提示 | 不要暴露内部信息 |
| 适当清理 | 使用 finally |
