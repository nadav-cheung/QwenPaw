## 2. Windows 用户安装 Python

### 2.1 下载 Python

1. 打开浏览器，访问 **https://www.python.org/downloads/**

2. 点击黄色按钮 **Download Python 3.12.x**（3.12 是当前稳定版本）

   ```
   注意：下载的是最新版本的 Python 3。如果页面显示其他版本，用那个也行，差别不大。
   ```

3. 文件会自动下载到浏览器设置的下载目录（通常是"下载"文件夹）

### 2.2 安装 Python

1. 找到下载的安装文件（文件名类似 `python-3.12.x.exe`），双击运行

2. **重要**：安装界面底部有个选项 **"Add Python to PATH"**，**一定要勾选它！**

   ```
   ☑ Add Python to PATH        ← 必须勾选！
   ```

3. 点击 **"Install Now"**（立即安装）

4. 如果弹出权限提示，点击 **"Yes"**

5. 等待安装完成（约 2-3 分钟），点击 **"Close"**

### 2.3 验证安装

1. 按 **Windows键 + R**，输入 `cmd`，回车打开命令行

2. 在命令行中输入：
   ```
   python --version
   ```

3. 如果显示类似 `Python 3.12.x`，说明安装成功！

   ```
   C:\Users\你的用户名> python --version
   Python 3.12.8
   ```

### 2.4 常见问题

| 问题 | 解决方法 |
|------|----------|
| "python 不是内部或外部命令" | 重新安装，确保勾选了 "Add Python to PATH" |
| 下载太慢 | 使用国内镜像：https://mirrors.aliyun.com/pypi/get/python-3.12.8amd64.exe |

## 3. macOS 用户安装 Python

### 3.1 使用安装包

1. 打开浏览器，访问 **https://www.python.org/downloads/**

2. 点击 **Download Python 3.12.x**

3. 下载完成后，双击 `.pkg` 文件

4. 按照提示一路点击"继续"即可

### 3.2 使用 Homebrew（推荐）

如果你已经安装了 Homebrew（很多 Mac 开发者都用），可以用更简单的方式：

1. 打开 **终端**（Terminal）

2. 输入以下命令：
   ```bash
   brew install python@3.12
   ```

3. 等待安装完成

### 3.3 验证安装

打开终端，输入：
```bash
python3 --version
```

应该显示 `Python 3.12.x`。

## 5. 运行 Python 的两种方式

### 5.1 方式一：交互式环境

**交互式环境**像一个"对话窗口"，你输入一行代码，Python 立刻执行并显示结果。

**适合**：快速测试、实验想法、学习阶段

#### Windows 打开方式

1. 按 **Windows键 + R**，输入 `cmd`，回车
2. 输入 `python`，回车

#### macOS / Linux 打开方式

1. 打开终端
2. 输入 `python3`（或 `python`），回车

#### 你的第一个对话

你会看到类似这样的界面：

```
Python 3.12.8 (tags/v3.12.8:3cc8ad8, Dec  8 2024, 14:33:52)
[Clang 15.0.0 (clang-1500.4.9.4)] on darwin
Type "help", "copyright", "credits" or "license" for more information.
>>>
```

`>>>` 符号表示 Python 在等待你输入指令。

#### 动手试试

在 `>>>` 后面输入：

```python
>>> print("Hello, Python!")
Hello, Python!
```

**恭喜！你刚刚运行了第一个 Python 程序！**

再试试：

```python
>>> 2 + 3
5
>>> "你好" + "世界"
'你好世界'
```

输入 `exit()` 可以退出交互式环境。

### 5.2 方式二：脚本文件

**脚本文件**是把代码保存到一个文件中，然后让 Python 执行整个文件。

**适合**：写完整的程序、保存代码、分享给他人

#### 创建你的第一个脚本

1. 打开记事本（Windows）或 TextEdit（macOS）

2. 输入以下内容：
   ```python
   # 我的第一个 Python 脚本
   # 日期：2026年5月

   print("=" * 30)
   print("  你好，Python 世界！")
   print("=" * 30)
   print()
   print("这是我的第一个程序")
   print("我很兴奋在学习编程！")
   ```

3. 把文件保存为 `hello.py`（注意扩展名是 `.py`，不是 `.txt`）

   **Windows 保存方法**：
   - 文件 → 另存为
   - 文件名：`hello.py`
   - 保存类型：所有文件 (*.*)
   - 编码：UTF-8

#### 运行脚本

打开命令行，进入文件所在目录，运行：

```bash
python hello.py
```

你应该能看到输出：

```
==============================
  你好，Python 世界！
==============================

这是我的第一个程序
我很兴奋在学习编程！
```

## 6. 代码编辑器介绍

### 6.1 什么是代码编辑器？

虽然记事本可以写代码，但代码编辑器是专门为编程设计的工具，能让你写代码更轻松：

- **代码高亮**：不同内容显示不同颜色，一目了然
- **自动补全**：写一半代码，编辑器帮你补全
- **错误提示**：写错了会提醒你
- **快捷方便**：一键运行代码

### 6.2 推荐编辑器

| 编辑器 | 特点 | 适合人群 |
|--------|------|----------|
| **VS Code** | 免费、强大、插件丰富 | 初学者首选 |
| **PyCharm** | 专业、功能全面 | 专业的 Python 开发者 |
| **Thonny** | 极简、专为初学者设计 | 完全新手 |

### 6.3 安装 VS Code（推荐）

1. 访问 **https://code.visualstudio.com/**

2. 点击绿色按钮下载

3. 安装并打开 VS Code

4. 安装 Python 插件：
   - 按 `Ctrl + Shift + X`（macOS 是 `Cmd + Shift + X`）打开扩展
   - 搜索 "Python"
   - 点击第一个结果 "Python"（微软出品），点击"安装"

### 6.4 用 VS Code 运行 Python

1. 在 VS Code 中按 `Ctrl + N` 新建文件

2. 输入你的代码，比如：
   ```python
   print("VS Code + Python = ❤️")
   ```

3. 保存文件（`Ctrl + S`），命名为 `my_first.py`

4. 按 `F5` 或点击右上角的绿色三角按钮运行

5. 底部的终端会显示输出结果

## 7. 第一个程序的解读

### 7.1 代码解析

让我们看看刚才写的代码：

```python
# 我的第一个 Python 脚本
# 日期：2026年5月

print("=" * 30)
print("  你好，Python 世界！")
print("=" * 30)
print()
print("这是我的第一个程序")
print("我很兴奋在学习编程！")
```

| 代码 | 含义 |
|------|------|
| `# 开头的内容` | **注释**，解释代码做什么，计算机不会执行 |
| `print(...)` | **打印函数**，把内容显示出来 |
| `"=" * 30` | 把 `=` 重复 30 次 |

### 7.2 print 函数

`print()` 是 Python 最常用的函数之一。它的作用是把括号里的内容显示出来。

```python
print("你好")        # 显示文字
print(123)          # 显示数字
print(1 + 2)        # 显示计算结果
print("a", "b", "c") # 显示多个内容
```

### 7.3 注释的作用

注释是用来解释代码的，对计算来说相当于"透明"的（计算机完全忽略它）。

```python
# 这是一个注释
print("这行会执行")  # 这也是注释
```

写注释是个好习惯，能帮助自己以后回顾代码，也能让别人看懂你的代码。

## 9. 常见问题

### 9.1 安装失败怎么办？

**Windows**：
1. 确认下载的是正确版本（.exe 文件）
2. 关闭杀毒软件后再安装（有些杀软会拦截）
3. 重启电脑后再试

**macOS**：
1. 如果提示"无法安装"，去系统设置允许安装

### 9.2 pip 是什么？

`pip` 是 Python 的包管理工具，相当于 Python 的"应用商店"。以后安装第三方库时会用到它。

安装 Python 时 pip 通常会自动安装。验证方法：

```bash
pip --version
```

### 9.3 遇到不懂的错误信息怎么办？

1. **仔细阅读错误信息**：Python 会告诉你哪里出错了
2. **复制错误信息到搜索引擎**：很多人遇到过同样的问题
3. **问 AI 助手**：你可以用 QwenPaw 问问

### 本章要点

| 技能 | 操作 |
|------|------|
| **安装 Python** | 从 python.org 下载安装包，Windows 用户要勾选 "Add to PATH" |
