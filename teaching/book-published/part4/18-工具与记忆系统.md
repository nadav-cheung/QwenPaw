## 概述

工具系统和记忆系统是智能体的两大核心子系统。工具系统让智能体能够与外部世界交互（执行命令、操作文件、浏览网页等），记忆系统则管理对话上下文和长期知识存储。本章从源码层面深入分析这两个系统的设计与实现。

### 1.5 工具执行拦截流程

**ToolGuardMixin** (`tool_guard_mixin.py`) 安全拦截层：

```
┌─────────────────────────────────────────────────────────────────┐
│                    QwenPawAgent._acting()                        │
│  (via ToolGuardMixin override)                                   │
├─────────────────────────────────────────────────────────────────┤
│  1. _decide_guard_action() - 检查工具是否被拒绝/守卫            │
│     ├── is_denied() → auto_denied result                        │
│     ├── is_guarded() → check pre-approval → guard() scan       │
│     └── findings exist → needs_approval                          │
│                                                                  │
│  2. _execute_guard_action() - 执行决定的动作                    │
│     ├── auto_denied → return denial message                      │
│     ├── preapproved → super()._acting()                         │
│     └── needs_approval → create pending, return denial           │
│                                                                  │
│  3. super()._acting() → ReActAgent._acting()                   │
│     └── Calls toolkit.execute_tool() → tool function             │
└─────────────────────────────────────────────────────────────────┘
```

**守卫决策** (`_decide_guard_action` 方法):

| 决策 | 条件 | 结果 |
|------|------|------|
| `auto_denied` | 工具在拒绝列表 | 直接返回拒绝消息 |
| `preapproved` | 工具已预批准 | 正常执行 |
| `needs_approval` | 守卫扫描发现问题 | 等待用户审批 |
| `None` | 无问题 | 正常执行 |

### Shell 工具 (`shell.py`)

```python
async def execute_shell_command(
    command: str,
    timeout: float = 60.0,
    cwd: Optional[Path] = None,
) -> ToolResponse:
    """执行 Shell 命令"""
    # 1. 处理跨平台命令差异
    cmd = _collapse_embedded_newlines(command)

    # 2. 设置工作目录
    working_dir = get_current_workspace_dir() or WORKING_DIR

    # 3. 确保 venv Python 在 PATH 中
    env = os.environ.copy()
    env["PATH"] = f"{python_bin_dir}:{existing_path}"

    # 4. 执行命令（跨平台处理）
    if sys.platform == "win32":
        returncode, stdout, stderr = await asyncio.to_thread(
            _execute_subprocess_sync, cmd, working_dir, timeout, env
        )
    else:
        proc = await asyncio.create_subprocess_shell(
            cmd, stdout=PIPE, stderr=PIPE, ...
        )
        stdout, stderr = await asyncio.wait_for(proc.communicate(), timeout)

    # 5. 返回结果
    return ToolResponse(content=[TextBlock(type="text", text=output)])
```

### 2.2 BaseMemoryManager 抽象基类

```python
class BaseMemoryManager(ABC):
    """记忆管理器抽象接口"""

    @abstractmethod
    async def start(self) -> None:
        """启动记忆管理器"""

    @abstractmethod
    async def close(self) -> bool:
        """关闭记忆管理器"""

    @abstractmethod
    async def compact_memory(
        self,
        messages: list[Msg],
        previous_summary: str = "",
        extra_instruction: str = "",
    ) -> str:
        """压缩对话记忆"""

    @abstractmethod
    async def summary_memory(self, messages: list[Msg]) -> str:
        """生成记忆摘要"""

    @abstractmethod
    async def memory_search(
        self,
        query: str,
        max_results: int = 5,
        min_score: float = 0.1,
    ) -> ToolResponse:
        """搜索记忆"""
```

### 2.6 AgentMdManager

用于读写工作目录中的 Markdown 文件：

```python
class AgentMdManager:
    """Agent Markdown 文件管理器"""

    def __init__(self, working_dir: str | Path):
        self.working_dir = Path(working_dir)
        self.memory_dir = self.working_dir / "memory"

    def read_working_md(self, md_name: str) -> str:
        """读取工作目录中的 .md 文件"""
        if not md_name.endswith(".md"):
            md_name += ".md"
        return (self.working_dir / md_name).read_text()

    def write_memory_md(self, md_name: str, content: str):
        """写入 memory/ 目录下的 .md 文件"""
        if not md_name.endswith(".md"):
            md_name += ".md"
        (self.memory_dir / md_name).write_text(content)
```

| `Method` 对象 | 函数对象 (callable) | Python 工具是普通函数，通过 `toolkit.register_tool_function(fn)` 注册 |
| JPA / Hibernate | ReMeLight Memory | QwenPaw 的记忆系统基于向量检索而非关系型 ORM，无需 `@Entity` 映射 |
| Hibernate 二级缓存 | Dream 优化 | Dream 通过 AI 智能归纳压缩记忆，而非简单的 LRU 缓存淘汰 |
| `@Entity` / `@Table` | `dataclass` | Python 使用 `@dataclass` 定义数据结构，无需 JPA 注解和 EntityManager |

### 关键差异

Java 工具系统通常通过接口 + 反射实现插件化，QwenPaw 直接将 Python 函数注册为工具，函数签名即 API 契约。记忆系统不使用 SQL 数据库，而是基于向量存储 + Markdown 文件的混合方案。

### 8.4 如何避免破坏架构

**工具注册规则**：
- 新工具必须使用 `@function_tool` 装饰器
- 工具名称必须唯一，避免与内置工具冲突
- 敏感工具必须注册到 ToolGuard 系统

**记忆系统规则**：
- 不要直接修改 `memory.content`，使用 `memory.add()` 和 `memory.get()`
- 记忆压缩操作必须在 `MemoryCompactionHook` 中进行
- 向量存储后端切换需要测试数据迁移

**测试要求**：
- 修改工具函数后，必须运行 `pytest tests/agents/tools/ -v`
- 修改记忆管理器后，必须运行 `pytest tests/agents/memory/ -v`
- 添加新工具需要同步更新 `_create_toolkit()` 中的映射表
