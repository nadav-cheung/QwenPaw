## 学习路径（Level 1-9）

```
Level 1: 知道项目是干什么的

Level 3: 理解模块边界

```

## 章节标准模板

每章必须包含：

### 1. 学习目标
- 学完后能做什么
- 解决什么问题
- 与后续章节关系

### 2. 背景问题
- 为什么这个模块存在
- 它解决了什么问题

### 3. 源码入口
- 文件路径
- 类名
- 方法名
- 调用入口
- 初始化位置

### 4. 架构定位
- 模块职责
- 生命周期
- 与其它模块关系
- 数据流向
- 控制流向

### 5. 核心源码分析
- 按真实调用链分析
- 解释关键代码
- 解释设计原因
- 解释历史包袱
- 解释工程权衡

### 6. 可视化结构
```mermaid
# 时序图/模块图/状态机
```

### 7. 工程经验
- 为什么这么设计
- 替代方案是什么
- 为什么没采用
- 会出现问题
- 实际生产中的问题

### 8. Contributor 指南
- 哪些文件适合新手修改
- 哪些逻辑危险
- 如何调试
- 如何加日志
- 如何写测试
- 如何避免破坏架构
