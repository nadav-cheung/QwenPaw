## 2. 核心模块详解

### 2.1 agents 模块

**职责**：智能体核心实现

```
agents/
├── react_agent.py    # QwenPawAgent（核心类）
├── tools/            # 内置工具集
├── skills/           # 内置技能
├── memory/           # 记忆管理
├── hooks/            # 生命周期钩子
└── acp/              # Agent 通信协议
```

**关键类**：
- `QwenPawAgent`：主智能体类
- `AgentScope`：智能体作用域
- `Workspace`：工作区

### 2.2 app 模块

**职责**：Web 应用和消息处理

```
app/
├── _app.py           # 应用主类
├── server.py         # FastAPI 服务器
├── channels/         # 渠道实现
├── runner/           # 请求处理器
└── multi_agent_manager.py  # 多智能体
```

**关键类**：
- `QwenPawApp`：应用主类
- `Runner`：请求处理器
- `MultiAgentManager`：多智能体管理

### 2.3 providers 模块

**职责**：大语言模型接口抽象

```
providers/
├── provider_manager.py    # 提供商管理器
├── base_provider.py      # 基类
├── openai_provider.py    # OpenAI
├── ollama_provider.py    # Ollama
└── qwen_provider.py      # Qwen
```

**关键类**：
- `BaseProvider`：提供商基类
- `ProviderManager`：管理所有提供商

## 3. 入口文件解析

### 3.1 命令行入口

```bash
qwenpaw app
```

入口：`src/qwenpaw/cli/main.py`

```python
# cli/main.py
import click
from qwenpaw.app import QwenPawApp

@click.group()
def cli():
    """QwenPaw CLI"""
    pass

@cli.command()
def app():
    """启动 QwenPaw 应用"""
    app = QwenPawApp()
    app.run()

if __name__ == "__main__":
    cli()
```

### 3.2 应用入口

`src/qwenpaw/app/_app.py`

```python
class QwenPawApp:
    """QwenPaw 应用主类"""

    def __init__(self):
        self.config = load_config()
        self.agent_manager = MultiAgentManager()
        self.runner = Runner()
        self.server = FastAPI()

    async def run(self):
        """启动应用"""
        await self.initialize()
        await self.start_server()
```

## 4. 模块依赖关系

### 4.1 依赖图

```
┌─────────────┐
│   CLI      │  ← 入口层
└──────┬──────┘
       │
       ▼
┌─────────────┐
│   App       │  ← 应用层
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  Agents     │  ← 核心层
└──────┬──────┘
       │
       ▼
┌─────────────┐     ┌─────────────┐
│ Providers   │     │  Security   │
└──────┬──────┘     └──────┬──────┘
       │                    │
       ▼                    ▼
┌─────────────────────────────┐
│        Utils               │
└─────────────────────────────┘
```

### 4.2 依赖说明

| 模块 | 被依赖 | 依赖 |
|------|--------|------|
| `cli` | 无 | `app` |
| `app` | `cli` | `agents`, `providers`, `security` |
| `agents` | `app` | `providers`, `security` |
| `providers` | `agents` | 无 |
| `security` | `agents`, `app` | 无 |
