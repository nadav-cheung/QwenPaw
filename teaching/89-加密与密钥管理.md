## 概述

QwenPaw 使用 Fernet（AES-128-CBC + HMAC-SHA256）对称加密保护敏感配置，通过 4 层密钥解析、双重检查锁定和 OS Keychain 实现安全的密钥管理。敏感数据（如 Provider API 密钥）在持久化到磁盘前自动加密。

**核心特性：**
- **Fernet 加密：** AES-128-CBC + HMAC-SHA256，保证机密性和完整性
- **4 层密钥解析：** 环境变量 → Keychain → 文件 → 自动生成
- **双重检查锁定：** 线程安全，避免重复生成密钥
- **透明加密：** 敏感字段自动加解密，对应用代码透明

**源码路径：** `src/qwenpaw/security/`

## 1. SecretStore

源码路径：`src/qwenpaw/security/secret_store.py`

### 1.1 加密机制

```python
# src/qwenpaw/security/secret_store.py
# Fernet = AES-128-CBC + HMAC-SHA256
# 加密后格式：ENC:<base64-ciphertext>
_ENC_PREFIX = "ENC:"

def encrypt(plaintext: str) -> str:
    """加密并返回 ENC:<base64-ciphertext>"""
    f = _get_fernet()
    token = f.encrypt(plaintext.encode("utf-8"))
    return _ENC_PREFIX + token.decode("ascii")

def decrypt(value: str) -> str:
    """解密，失败时返回原始值（容错）"""
    if not value.startswith(_ENC_PREFIX):
        return value  # 未加密的值直接返回
    f = _get_fernet()
    return f.decrypt(token).decode("utf-8")
```

### 1.2 加密格式说明

```
原始值: sk-1234567890abcdef
加密后: ENC:gAAAAABh5iOzCJ4cDQE8jZ...（base64 编码的密文）
```

## 2. 密钥解析优先级

源码路径：`src/qwenpaw/security/secret_store.py:130`

### 2.1 四层解析

```python
# src/qwenpaw/security/secret_store.py:130
def _get_master_key() -> bytes:
    """返回 32 字节主密钥，按以下顺序解析："""

    # 第 1 层：进程内缓存（快速路径，无锁）
    if _cached_master_key is not None:
        return _cached_master_key

    # 第 2 层：OS Keychain（通过 keyring 库）
    key_hex = _try_keyring_get()

    # 第 3 层：文件 SECRET_DIR/.master_key
    if not key_hex:
        key_hex = _read_key_file()

    # 第 4 层：生成新密钥
    if not key_hex:
        key_hex = _generate_master_key()
        _try_keyring_set(key_hex)  # 优先存 keychain
        _write_key_file(key_hex)   # 回退存文件
```

### 2.2 密钥解析流程图

```
_get_master_key()
    │
    ├── [缓存命中] → 直接返回
    │
    └── [缓存未命中]
          │
          ▼
    ┌─────────────────┐
    │ 尝试 Keychain  │ ── 命中 → 使用 Keychain 密钥
    └────────┬────────┘
             │ 未命中
             ▼
    ┌─────────────────┐
    │ 尝试 .master_key │ ── 命中 → 使用文件密钥
    └────────┬────────┘
             │ 未命中
             ▼
    ┌─────────────────┐
    │ 生成新密钥       │
    │ 保存到 Keychain │
    │ 保存到文件      │
    └─────────────────┘
```

### 2.3 密钥生成

```python
# src/qwenpaw/security/secret_store.py:113
def _generate_master_key() -> str:
    """生成 32 字节随机主密钥（hex 编码 64 字符）"""
```

## 3. 双重检查锁定

源码路径：`src/qwenpaw/security/secret_store.py:130`

### 3.1 实现模式

```python
# src/qwenpaw/security/secret_store.py:45
_cached_master_key: Optional[bytes] = None
_master_key_lock = threading.Lock()

def _get_master_key() -> bytes:
    global _cached_master_key

    # 第一次检查（无锁，快速路径）
    if _cached_master_key is not None:
        return _cached_master_key

    with _master_key_lock:
        # 第二次检查（有锁，线程安全）
        if _cached_master_key is not None:
            return _cached_master_key

        # ... 加载或生成密钥 ...
        _cached_master_key = bytes.fromhex(key_hex)
        return _cached_master_key
```

### 3.2 为什么需要双重检查

```
线程 A                      线程 B
   │                           │
   ├─ 第一次检查: None          │
   │                           ├─ 第一次检查: None
   │                           ├─ 获取锁
   │                           ├─ 第二次检查: None
   │                           ├─ 生成密钥...
   │                           ├─ 释放锁
   ├─ 获取锁                    │
   ├─ 第二次检查: 有值!          │
   ├─ 直接返回                   │
   │                           │
   ▼                           ▼
  不重复生成密钥              不重复生成密钥
```

**目的：** 避免多个线程同时检测到密钥不存在，导致重复生成。

## 4. OS Keychain 集成

### 4.1 keyring 库

```python
# src/qwenpaw/security/secret_store.py:50
_KEYRING_SERVICE = "qwenpaw"
_KEYRING_ACCOUNT = "master_key"

def _try_keyring_get() -> Optional[str]:
    """从 OS Keychain 读取主密钥"""
    import keyring
    return keyring.get_password(_KEYRING_SERVICE, _KEYRING_ACCOUNT)

def _try_keyring_set(key_hex: str) -> bool:
    """存储主密钥到 OS Keychain"""
    import keyring
    keyring.set_password(_KEYRING_SERVICE, _KEYRING_ACCOUNT, key_hex)
```

### 4.2 支持的 Keychain 后端

| 操作系统 | Keychain 后端 |
|----------|---------------|
| macOS | Keychain |
| Windows | Windows Credential Locker |
| Linux | Secret Service (GNOME) / kwallet |
| 容器/CI | 跳过 Keychain |

### 4.3 跳过 Keychain 的场景

```python
# src/qwenpaw/security/secret_store.py:37
def _should_skip_keyring() -> bool:
    """以下环境跳过 Keychain："""
    if EnvVarLoader.get_bool("QWENPAW_RUNNING_IN_CONTAINER"):
        return True  # 容器环境
    if sys.platform == "linux" and not os.environ.get("DISPLAY"):
        return True  # Linux 无 GUI
    if os.environ.get("CI", "").lower() in ("true", "1"):
        return True  # CI 环境
    return False
```

### 6.3 字典字段加解密

```python
# src/qwenpaw/security/secret_store.py:218
def encrypt_dict_fields(data: dict, secret_fields: frozenset[str]) -> dict:
    """加密字典中的敏感字段"""
    result = dict(data)
    for field in secret_fields:
        if field in result and isinstance(result[field], str):
            if not is_encrypted(result[field]):  # 避免重复加密
                result[field] = encrypt(result[field])
    return result

def decrypt_dict_fields(data: dict, secret_fields: frozenset[str]) -> dict:
    """解密字典中的敏感字段"""
    result = dict(data)
    for field in secret_fields:
        if field in result and isinstance(result[field], str):
            result[field] = decrypt(result[field])
    return result
```

### 6.4 透明加密示例

```python
# Provider 配置保存时自动加密
provider_config = {
    "id": "openai",
    "api_key": "sk-xxx"  # 自动加密
}
encrypted = encrypt_dict_fields(provider_config, PROVIDER_SECRET_FIELDS)
# 结果: {"id": "openai", "api_key": "ENC:gAAAA..."}

# Provider 配置加载时自动解密
decrypted = decrypt_dict_fields(encrypted, PROVIDER_SECRET_FIELDS)
# 结果: {"id": "openai", "api_key": "sk-xxx"}
```

## 7. 密钥重载

### 7.1 reload_master_key_from_disk

```python
# src/qwenpaw/security/secret_store.py:176
def reload_master_key_from_disk() -> None:
    """清除进程内缓存并从磁盘重新同步 OS Keychain。

    用于备份恢复后重新加载新密钥。
    """
    global _cached_master_key, _cached_fernet

    with _master_key_lock:
        _cached_master_key = None
        _cached_fernet = None

        key_hex = _read_key_file()
        if key_hex:
            _try_keyring_set(key_hex)  # 同步到 Keychain
```

### 7.2 密钥轮换

```bash
# 1. 备份旧密钥
cp ~/.qwenpaw/.master_key ~/.qwenpaw/.master_key.bak

# 2. 生成新密钥（删除旧文件触发重新生成）
rm ~/.qwenpaw/.master_key

# 3. 重启 QwenPaw
# 旧加密数据将无法解密（需注意）
```

## 8. 应用场景

### 场景 1: 安全存储 Provider API 密钥

**问题：** API 密钥不能明文存储在配置文件中

**解决方案：**
```python
# 保存 Provider 配置时
provider_data = {
    "id": "openai",
    "api_key": "sk-xxx"
}
encrypted = encrypt_dict_fields(provider_data, PROVIDER_SECRET_FIELDS)
save_to_file(encrypted)  # 密文存储

# 加载 Provider 配置时
encrypted = load_from_file()
provider_data = decrypt_dict_fields(encrypted, PROVIDER_SECRET_FIELDS)
```

### 场景 2: Docker 容器环境密钥管理

**问题：** 容器环境中无法使用 Keychain

**解决方案：**
```bash

docker run -e QWENPAW_MASTER_KEY="your-master-key" qwenpaw

# 或挂载密钥文件
docker run -v ~/.qwenpaw/.master_key:/app/.qwenpaw/.master_key qwenpaw
```

### 场景 3: CI/CD 环境密钥注入

**问题：** CI 环境需要安全注入密钥

**解决方案：**

## 10. 常见问题

### Q1: 解密失败，密钥不匹配

**原因：**
- 主密钥发生变化
- 加密数据使用旧密钥生成

**解决方案：**
```bash
# 恢复旧密钥
cp ~/.qwenpaw/.master_key.bak ~/.qwenpaw/.master_key
# 重启 QwenPaw
```

### Q2: 容器环境无法加载密钥

**原因：**
- 未设置 QWENPAW_MASTER_KEY
- 密钥文件路径不正确

**解决方案：**
```bash
# 方案 1: 设置环境变量
docker run -e QWENPAW_MASTER_KEY="$(cat ~/.qwenpaw/.master_key)" qwenpaw

# 方案 2: 挂载密钥文件
docker run -v ~/.qwenpaw:/root/.qwenpaw qwenpaw
```

### Q3: Linux Keychain 不可用

**原因：**
- 未安装 keyring 后端
- 没有图形环境

**解决方案：**
```bash
# 安装 GNOME Keyring
sudo apt install gnome-keyring

# 或设置跳过 Keychain
export QWENPAW_RUNNING_IN_CONTAINER=true
```

### Q4: 加密后数据无法使用

**原因：**
- 重复加密（数据已 ENC: 前缀）
- 加密字段不是字符串

**解决方案：**
```python
# 检查是否已加密
if not is_encrypted(value):
    value = encrypt(value)

# 确保字段是字符串
if isinstance(value, bytes):
    value = value.decode("utf-8")
```

## 12. 总结

**核心要点：**

1. **加密算法：** Fernet（AES-128-CBC + HMAC-SHA256）
2. **密钥解析：** 环境变量 → Keychain → 文件 → 自动生成
3. **双重检查锁定：** 线程安全，避免重复生成密钥
4. **透明加密：** encrypt_dict_fields/decrypt_dict_fields 自动处理
5. **Keychain 支持：** macOS/Windows/Linux 原生密钥链

**加密字段：**
- `PROVIDER_SECRET_FIELDS`: api_key
- `AUTH_SECRET_FIELDS`: jwt_secret

**最佳实践：**
- 生产环境使用环境变量配置主密钥
- 设置 .master_key 文件权限为 0600
- 容器环境设置 QWENPAW_RUNNING_IN_CONTAINER=true
- 密钥轮换时注意旧数据无法解密
