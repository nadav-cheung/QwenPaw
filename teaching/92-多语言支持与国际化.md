# 多语言支持与国际化

## 概述

QwenPaw 支持 4 种语言（中文/英文/俄文/日文），通过 i18n 模块实现界面和消息的本地化。主要应用于 ToolGuard 安全系统的提示信息，支持审批界面、风险提示和错误消息的多语言显示。

### 2.1 翻译函数

**源码路径**: `src/qwenpaw/agents/tool_guard_mixin.py:40`

```python
def _tool_guard_t(lang: str, key: str) -> str:
    """Localized string for tool-guard user messages."""
    blob = _TOOL_GUARD_I18N.get(lang) or _TOOL_GUARD_I18N["en"]
    return blob.get(key) or _TOOL_GUARD_I18N["en"].get(key, key)
```

**翻译函数逻辑说明**：
1. 尝试获取指定语言的翻译键
2. 如果语言不存在，回退到 English
3. 如果键不存在，返回 English 版本的键值
4. 如果 English 也没有，返回原始键名

## 4. 语言检测

**源码路径**: `src/qwenpaw/agents/tool_guard_mixin.py:30`

```python
def _resolve_lang(lang: str) -> str:
    """Resolve language code to supported language."""
    if lang in ("zh", "en", "ru", "ja"):
        return lang
    for prefix in ("zh", "ru", "ja", "en"):
        if lang.startswith(prefix):
            return prefix
    return "en"
```

**语言检测优先级**：
1. 精确匹配：完全符合 `zh`/`en`/`ru`/`ja` 时直接返回
2. 前缀匹配：检测 `zh-CN`、`zh-TW`、`en-US`、`ru-RU`、`ja-JP` 等
3. 默认回退：以上都不匹配时返回 `en`

## 6. 使用场景

### 6.1 风险检测消息

当 ToolGuard 检测到风险时，向用户显示的消息：

```python
risk_detected = _tool_guard_t(lang, "risk_detected")
# → "⚠️ **Risk detected**" (en)
# → "⚠️ **检测到风险**" (zh)
```

### 6.2 等待审批消息

```python
wait_title = _tool_guard_t(lang, "wait_title")
approve_hint = _tool_guard_t(lang, "approve_hint")
# → "⏳ Waiting for approval" + "Type `/approve` to approve..."
```

### 6.3 严重性显示

```python
severity_key = f"sev_{severity.value}"
severity_label = _tool_guard_t(lang, severity_key)
# → "Critical" (en) / "危急" (zh)
```

## 7. 最佳实践

### 7.1 新增翻译键

在 `i18n.py` 中添加新的翻译键时，需要同步更新所有 4 种语言：

```python
_TOOL_GUARD_I18N = {
    "en": {"new_key": "New message"},
    "zh": {"new_key": "新消息"},
    "ru": {"new_key": "Новое сообщение"},
    "ja": {"new_key": "新しいメッセージ"},
}
```

### 7.2 翻译占位符

消息中包含动态参数时，使用 Python f-string 格式化：

```python
# 翻译值中包含占位符
"zh": {"greeting": "欢迎 {username}，您有 {count} 条消息"}
"en": {"greeting": "Welcome {username}, you have {count} messages"}

# 调用时
message = _tool_guard_t(lang, "greeting").format(username="Alice", count=5)
```

### 7.3 语言测试

添加新翻译后，验证回退机制是否正常工作：

```python
def test_language_fallback():
    # 不支持的语言应回退到英文
    result = _tool_guard_t("unsupported_lang", "risk_detected")
    assert result == _TOOL_GUARD_I18N["en"]["risk_detected"]

    # 支持的语言应正常返回
    result = _tool_guard_t("zh", "risk_detected")
    assert result == "⚠️ **检测到风险**"
```

## 8. 常见问题

### 8.1 部分语言翻译缺失

**问题**：某些键在特定语言下返回空字符串。

**原因**：翻译数据中键名拼写不一致。

**解决**：检查 `i18n.py` 中所有语言版本的键名是否完全一致。

### 8.2 语言回退到错误语言

**问题**：配置了 `zh-CN` 但回退到了俄语。

**原因**：前缀匹配逻辑中俄语 `ru` 的前缀匹配了 `ru-CN`。

**解决**：前缀匹配按固定顺序检测，当前实现为 `("zh", "ru", "ja", "en")`。

### 8.3 新语言添加

**问题**：需要添加第 5 种语言。

**解决**：
1. 在 `_TOOL_GUARD_I18N` 中添加新语言字典
2. 在 `_resolve_lang` 中添加新的精确匹配
3. 在 `agent.json` 的 language 字段中增加选项
