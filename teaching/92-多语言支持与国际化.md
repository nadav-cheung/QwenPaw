# 多语言支持与国际化

## 概述

QwenPaw 支持 4 种语言（中文/英文/俄文/日文），通过 i18n 模块实现界面和消息的本地化。主要应用于 ToolGuard 安全系统的提示信息，支持审批界面、风险提示和错误消息的多语言显示。

```python
def _tool_guard_t(lang: str, key: str) -> str:
    """Localized string for tool-guard user messages."""
    blob = _TOOL_GUARD_I18N.get(lang) or _TOOL_GUARD_I18N["en"]
    return blob.get(key) or _TOOL_GUARD_I18N["en"].get(key, key)
```

**翻译函数逻辑说明**：
1. 尝试获取指定语言的翻译键
2. 如果语言不存在，回退到 English
3. 如果键不存在，返回 English 版本的键值
4. 如果 English 也没有，返回原始键名

## 4. 语言检测

**源码路径**: `src/qwenpaw/agents/tool_guard_mixin.py:30`

```python
def _resolve_lang(lang: str) -> str:
    """Resolve language code to supported language."""
    if lang in ("zh", "en", "ru", "ja"):
        return lang
    for prefix in ("zh", "ru", "ja", "en"):
        if lang.startswith(prefix):
            return prefix
    return "en"
```

**语言检测优先级**：
1. 精确匹配：完全符合 `zh`/`en`/`ru`/`ja` 时直接返回
2. 前缀匹配：检测 `zh-CN`、`zh-TW`、`en-US`、`ru-RU`、`ja-JP` 等
3. 默认回退：以上都不匹配时返回 `en`

## 8. 常见问题

### 8.1 部分语言翻译缺失

**问题**：某些键在特定语言下返回空字符串。

**原因**：翻译数据中键名拼写不一致。

**解决**：检查 `i18n.py` 中所有语言版本的键名是否完全一致。

### 8.2 语言回退到错误语言

**问题**：配置了 `zh-CN` 但回退到了俄语。

**原因**：前缀匹配逻辑中俄语 `ru` 的前缀匹配了 `ru-CN`。

**解决**：前缀匹配按固定顺序检测，当前实现为 `("zh", "ru", "ja", "en")`。

### 8.3 新语言添加

**问题**：需要添加第 5 种语言。

**解决**：
1. 在 `_TOOL_GUARD_I18N` 中添加新语言字典
2. 在 `_resolve_lang` 中添加新的精确匹配
3. 在 `agent.json` 的 language 字段中增加选项

**目标：** 在运行时动态切换 Agent 语言。

```python
class LanguageSwitcher:
    def __init__(self, agent):
        self.agent = agent
        self.current_lang = agent._language

    async def switch_language(self, new_lang: str):
        resolved = _resolve_lang(new_lang)
        if resolved == self.current_lang:
            return  # 语言未变化

        self.current_lang = resolved
        self.agent._language = resolved

        # 通知用户语言已切换
        notification = _tool_guard_t(resolved, "language_switched")
        await self.agent.send_message(notification)

    async def get_available_languages(self) -> list[dict]:
        return [

            {"code": "zh", "name": "简体中文"},
            {"code": "ru", "name": "Русский"},
            {"code": "ja", "name": "日本語"},
        ]
```

### 练习 4：复数形式处理

**目标：** 实现不同语言的复数形式支持。

```python
# 英语复数规则: 1 -> singular, 其他 -> plural
# 俄语复数规则更复杂: 1%10==1 && 1%100!=11 -> singular, 2-4%10==... -> paucal, 其他 -> plural

_PLURAL_RULES = {
    "en": lambda n: 0 if n == 1 else 1,  # 0=singular, 1=plural
    "zh": lambda n: 0,                    # 中文没有复数
    "ru": lambda n: (
        0 if (n % 10 == 1 and n % 100 != 11) else
        1 if (n % 10 in (2, 3, 4) and n % 100 not in (12, 13, 14)) else
        2
    ),
    "ja": lambda n: 0,                  # 日语没有复数
}

_MESSAGES_PLURAL = {
    "en": ["%d file remaining", "%d files remaining"],
    "zh": ["还剩 %d 个文件", "还剩 %d 个文件"],  # 中文不区分复数
    "ru": ["Остался %d файл", "Осталось %d файла", "Осталось %d файлов"],
}

def get_plural_message(lang: str, key: str, count: int) -> str:
    rule = _PLURAL_RULES.get(lang, _PLURAL_RULES["en"])
    index = rule(count)
    messages = _MESSAGES_PLURAL.get(key, {}).get(lang, [""] * 3)
    return messages[index] % count

# 使用
print(get_plural_message("en", "files", 1))  # "1 file remaining"
print(get_plural_message("en", "files", 5))  # "5 files remaining"
print(get_plural_message("ru", "files", 1))  # "Остался 1 файл"
print(get_plural_message("ru", "files", 5))  # "Осталось 5 файлов"
```

### 练习 5：浏览器语言自动检测

**目标：** 从 HTTP Accept-Language 头自动推断用户语言。

```python
from typing import Optional
import re

def parse_accept_language(header: str) -> Optional[str]:
    """从 Accept-Language 头解析首选语言"""
    if not header:
        return None

    # 解析: "en-US,en;q=0.9,zh-CN;q=0.8"
    languages = []
    for part in header.split(","):
        part = part.strip()
        match = re.match(r"^([a-z]{2}(?:-[A-Z]{2})?)(?:;q=([0-9.]+))?$", part, re.I)
        if match:
            lang, q = match.groups()
            q = float(q) if q else 1.0
            languages.append((lang, q))

    # 按 q 值降序排列
    languages.sort(key=lambda x: -x[1])

    # 映射到支持的语言
    for lang, _ in languages:
        resolved = _resolve_lang(lang)
        if resolved != "en" or True:  # en 总是可用的
            return resolved

    return "en"

# 使用
header = "zh-CN,en;q=0.9,ja;q=0.8"
print(parse_accept_language(header))  # "zh"
```

```python
from babel import Locale
from babel.support import Translations

# 加载翻译文件
translations = Translations.load("locale/", ["zh"])

# 翻译
_ = translations.gettext
print(_("Hello, world!"))
```

QwenPaw 选择自定义字典实现是为了避免额外依赖，保持轻量级。

**总结：** QwenPaw 的 i18n 实现比 Java Spring 简洁得多，采用 Python 字典作为翻译存储、无外部依赖，适合中小型项目。对于大规模项目，建议使用 Babel 或 Python-i18n 库获得更完整的复数、日期、货币格式化支持。
