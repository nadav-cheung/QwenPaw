## 1. 部署方式

### 1.1 pip install 本地部署

```bash
# 安装
pip install qwenpaw

# 初始化配置目录
qwenpaw init

# 启动服务
qwenpaw app
```

### 1.2 Docker 部署

```dockerfile
# Dockerfile
FROM python:3.11-slim
WORKDIR /app

# 安装系统依赖
RUN apt-get update && apt-get install -y \
    curl \
    && rm -rf /var/lib/apt/lists/*

# 安装 qwenpaw
RUN pip install qwenpaw

# 创建工作目录
RUN qwenpaw init

# 暴露端口
EXPOSE 8000

# 启动命令
CMD ["qwenpaw", "app", "--host", "0.0.0.0"]
```

### 1.3 Docker Compose 部署

```yaml
# docker-compose.yml
version: '3.8'
services:
  qwenpaw:
    build: .
    ports:
      - "8000:8000"
    environment:
      - QWENPAW_AUTH_ENABLED=true
      - QWENPAW_TOOL_GUARD_ENABLED=true
    volumes:
      - qwenpaw-data:/home/qwenpaw/.qwenpaw
    restart: unless-stopped

volumes:
  qwenpaw-data:
```

### 1.4 Desktop 桌面应用

```bash
# 安装桌面版
pip install qwenpaw[desktop]

# 启动桌面应用
qwenpaw desktop
```

## 4. 运维命令详解

### 4.1 qwenpaw app

```bash
# 启动服务
qwenpaw app

# 指定端口
qwenpaw app --port 8080

# 指定主机
qwenpaw app --host 0.0.0.0

# 后台运行
qwenpaw app --daemon
```

### 4.2 qwenpaw doctor

```bash
# 只读诊断
qwenpaw doctor

# 深度检查（包括网络连通性）
qwenpaw doctor --deep

# 修复问题
qwenpaw doctor fix

# 预览修复计划
qwenpaw doctor fix --dry-run
```

### 4.3 qwenpaw init

```bash
# 初始化工作目录
qwenpaw init

# 初始化到指定目录
qwenpaw init --dir /path/to/dir
```

### 4.4 qwenpaw shutdown

```bash
# 关闭服务
qwenpaw shutdown

# 强制关闭
qwenpaw shutdown --force
```

### 4.5 qwenpaw clean

```bash
# 清理缓存
qwenpaw clean

# 清理特定类型
qwenpaw clean --type logs
qwenpaw clean --type sessions
qwenpaw clean --type all
```

## 5. 服务管理

### 5.1 systemd 服务配置

```ini
# /etc/systemd/system/qwenpaw.service
[Unit]
Description=QwenPaw Agent
After=network.target
Wants=network-online.target

[Service]
Type=simple
User=qwenpaw
Group=qwenpaw
WorkingDirectory=/home/qwenpaw
Environment="QWENPAW_API_KEY=your-api-key"
Environment="QWENPAW_AUTH_ENABLED=true"
ExecStart=/usr/local/bin/qwenpaw app --host 0.0.0.0 --port 8000
Restart=always
RestartSec=5
StandardOutput=journal
StandardError=journal
SyslogIdentifier=qwenpaw

# 安全加固
NoNewPrivileges=true
ProtectSystem=strict
ProtectHome=true
ReadWritePaths=/home/qwenpaw/.qwenpaw

[Install]
WantedBy=multi-user.target
```

### 5.2 systemd 操作命令

```bash
# 重载 systemd 配置
sudo systemctl daemon-reload

# 启动服务
sudo systemctl start qwenpaw

# 停止服务
sudo systemctl stop qwenpaw

# 重启服务
sudo systemctl restart qwenpaw

# 查看状态
sudo systemctl status qwenpaw

# 查看日志
sudo journalctl -u qwenpaw -f
```

### 5.3 生命周期

```
qwenpaw init        # 创建工作目录和初始配置
    ↓
qwenpaw app         # 启动服务（两阶段启动）
    ↓
... 运行中 ...
    ↓
qwenpaw shutdown    # 优雅关闭
```

## 6. 最佳实践

### 6.1 生产环境配置

```bash
# 使用环境变量文件
# .env 文件（不要提交到版本控制）
QWENPAW_API_KEY=sk-xxx
QWENPAW_AUTH_ENABLED=true
QWENPAW_TOOL_GUARD_ENABLED=true
QWENPAW_LOG_LEVEL=INFO
```

```bash
# 启动时加载环境变量
export $(cat .env | grep -v '^#' | xargs)
qwenpaw app
```

### 6.2 日志轮转配置

```ini
# /etc/logrotate.d/qwenpaw
/home/qwenpaw/.qwenpaw/logs/*.log {
    daily
    rotate 14
    compress
    delaycompress
    notifempty
    create 0640 qwenpaw qwenpaw
    sharedscripts
    postrotate
        systemctl reload qwenpaw > /dev/null 2>&1 || true
    endscript
}
```

### 6.3 健康检查配置

```bash
# 定时健康检查 Cron
# /etc/cron.d/qwenpaw-health-check
*/5 * * * * root curl -f http://localhost:8000/api/version || systemctl restart qwenpaw
```

### 6.4 备份策略

```bash
# 备份脚本
#!/bin/bash
BACKUP_DIR="/backup/qwenpaw"
WORKING_DIR="/home/qwenpaw/.qwenpaw"

# 创建备份目录
mkdir -p "$BACKUP_DIR/$(date +%Y%m%d)"

# 备份配置文件
tar czf "$BACKUP_DIR/$(date +%Y%m%d)/config.tar.gz" \
    "$WORKING_DIR/config.json" \
    "$WORKING_DIR/agent.json"

# 备份会话数据
tar czf "$BACKUP_DIR/$(date +%Y%m%d)/sessions.tar.gz" \
    "$WORKING_DIR/sessions/"

# 保留最近 30 天备份
find "$BACKUP_DIR" -type d -mtime +30 -exec rm -rf {} +
```

## 7. 常见问题

### 7.1 服务无法启动

**问题**：`qwenpaw app` 无响应或报错。

**排查步骤**：
1. 检查端口占用：`lsof -i :8000`
2. 检查配置文件：`qwenpaw doctor`
3. 查看日志：`tail -f ~/.qwenpaw/logs/qwenpaw.log`

### 7.2 容器内运行问题

**问题**：在 Docker 容器中运行异常。

**解决**：设置容器标志：
```bash
export QWENPAW_RUNNING_IN_CONTAINER=true
qwenpaw app
```

### 7.3 版本更新失败

**问题**：`qwenpaw update` 失败。

**解决**：
```bash
# 手动更新
pip install --upgrade qwenpaw

# 验证版本
qwenpaw --version
```
