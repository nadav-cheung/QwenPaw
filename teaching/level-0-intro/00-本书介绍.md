## 1. 本书目标

### 1.1 培养真实 Contributor

本书的**终极目标**是让你成为 QwenPaw 项目的真实 Contributor。

这不是一本只教你"如何使用"的书，而是一本教你"如何理解、如何修改、如何贡献"的书。

```
学习路径：
知道项目是干什么的 (Level 1)
    ↓
能运行项目 (Level 2)
    ↓
理解模块边界 (Level 3)
    ↓
理解核心数据流 (Level 4)
    ↓
能跟踪源码调用链 (Level 5)
    ↓
能修改小功能 (Level 6)
    ↓
能独立开发模块 (Level 7)
    ↓
能提交高质量 PR (Level 8)
    ↓
能参与架构讨论 (Level 9)
```

### 1.2 源码即权威

本书的所有内容都**以源码为唯一事实来源**。

当你发现本书描述与源码不一致时，**以源码为准**。

这意味着：
- 每章都有明确的源码路径对应
- 每个结论都有代码依据
- 每个设计都有工程解释

## 3. 如何学习

### 3.1 按顺序学习

本书设计了**明确的依赖关系**：

```
01 → 02 → 03 → ... → 13 → 14 → ... → 46
 │    │    │
 │    │    └─ Level 1: 编程基础
 │    └─ Level 0: 前言
 └─ 依赖后续章节的前置知识
```

如果你有 Python 基础，可以**跳过 Level 1**。
如果你用过类似的 AI 助手，可以**跳过 Level 2 部分内容**。

### 3.2 动手实践

每章都有**实战演练**：

```
┌─────────────────────────────────────┐
│  🟢 基础练习                         │
│     验证性任务，确保理解基本概念          │
├─────────────────────────────────────┤
│  🟡 进阶练习                         │
│     分析性任务，理解源码结构             │
├─────────────────────────────────────┤
│  🔴 挑战练习                         │
│     创造性任务，修改现有功能             │
└─────────────────────────────────────┘
```

### 3.3 调试和验证

遇到问题时：

1. **查看日志** - QwenPaw 有详细的日志系统
2. **查看源码** - 用 IDE 追踪调用链
3. **运行测试** - `make test` 或 `pytest`
4. **寻求帮助** - 社区 Discord

## 5. 质量承诺

### 5.1 源码一致性

本书的每个结论都经过**源码验证**：

- 每个类名、方法名都与源码一致
- 每个调用链都可以在源码中追踪
- 每个设计决策都有工程解释

### 5.2 教学有效性

本书经过**教学设计**：

- 从问题出发，不是从概念出发
- 循序渐进，不跳步骤
- 强调实践，不只讲理论

### 5.3 工程真实性

本书强调**真实工程**：

- 边界条件
- 错误处理
- 性能影响
- 维护成本

## 6. 常见问题

### 6.1 需要多长时间学完？

| 背景 | 预计时间 |
|------|----------|
| 有 Python 基础 | 2-3 周 |
| 有其他语言基础 | 1-2 个月 |
| 零基础 | 2-3 个月 |

### 6.2 可以只看不练吗？

**不可以**。本书的实战练习是学习的重要组成部分。

看懂了 ≠ 会做了。只有真正动手，才能理解源码。

### 6.3 遇到不懂的内容怎么办？

1. 先标记，继续往下看
2. 有时后面章节会解释前面的问题
3. 带着问题去源码中寻找答案
4. 在 Discord 中提问
