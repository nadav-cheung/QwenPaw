## 1. QwenPaw 的诞生

### 1.1 从 CoPaw 到 QwenPaw

QwenPaw 原名 **CoPaw**，诞生于 2024 年，是一个开源的个人 AI 助手项目。

2026 年，项目与 Qwen 开源生态深度整合，正式更名为 **QwenPaw**：

- **Qwen**：代表与 Qwen 开源生态的深度整合，聚焦模型层
- **Paw**：代表"爪子"，象征温暖、陪伴的伙伴

正如项目 slogan 所说：**"Works for you, grows with you."**（为你工作，与你共同成长）

### 1.2 名字的含义

**QwenPaw** 有两层含义：

1. **Qwen Personal Agent Workstation**：Qwen 个人智能体工作站
2. **Qwen + Paw**：Qwen 的智慧 + 爪子般的温暖陪伴

这不是一个冰冷的工具，而是一个有温度的智能助手。

## 2. 什么是 QwenPaw？

### 2.1 一句话定义

**QwenPaw 是一个开源的个人 AI 助手，可以在你自己的电脑上运行，完全控制你的数据和隐私。**

### 2.2 生活中的类比

| 传统 AI 助手（如 Siri、小爱同学） | QwenPaw |
|----------------------------------|---------|
| 数据上传到云端服务器 | 数据保存在你自己的电脑 |
| 只能使用官方指定的功能 | 可以无限扩展功能 |
| 不能自定义和修改 | 完全开源，可以定制 |
| 无法了解内部如何工作 | 源码开放，可以学习 |

### 2.3 核心定位

QwenPaw 的定位是：

```
┌─────────────────────────────────────────────────┐
│            面向开发者的本地化 AI 助手框架           │
├─────────────────────────────────────────────────┤
│  隐私可控  │  技能可扩展  │  渠道可接入  │  多智能体  │
└─────────────────────────────────────────────────┘
```

## 3. QwenPaw 能做什么？

### 3.1 日常助手功能

QwenPaw 可以成为你的私人助理：

| 功能类别 | 具体能力 | 举例 |
|----------|----------|------|
| **信息获取** | 追踪热点新闻、整理 RSS 订阅 | "每天早上给我推送科技新闻" |
| **社交媒体** | 小红书/知乎/Reddit 热帖摘要 | "帮我看看今天有什么科技热点" |
| **视频总结** | YouTube/B站视频内容摘要 | "帮我总结这个视频讲了什么" |
| **邮件处理** | 重要邮件识别、自动分类 | "帮我筛选出今天的紧急邮件" |
| **文件管理** | 整理搜索本地文件、文档摘要 | "帮我找一下上周的会议纪要" |
| **日程提醒** | 日历事件、定时提醒 | "下午3点提醒我开会" |

### 3.2 开发者功能

如果你会编程，QwenPaw 更是强大的工具：

| 功能类别 | 具体能力 |
|----------|----------|
| **代码助手** | 写代码、Debug、代码审查 |
| **自动化任务** | 定时执行、自定义工作流 |
| **API 集成** | 连接各种第三方服务 |
| **智能体协作** | 多个 AI 助手协同工作 |

### 3.3 实际使用场景

**场景 1：睡前布置任务，早上看结果**

```
你（晚上 11 点）："帮我研究一下 RAG 技术，明天早上给我报告"

QwenPaw（深夜）：
  → 自动搜索相关资料
  → 阅读论文和文章
  → 整理成报告

你（早上 8 点）：
  → 收到完整的技术报告
  → 可以直接用于工作会议
```

**场景 2：多渠道消息聚合**

```
你："把飞书里的客户反馈整理成表格"

QwenPaw：
  → 连接飞书渠道
  → 读取客户消息
  → 自动分类整理
  → 输出表格
```

## 4. QwenPaw 的核心特点

### 4.1 六大核心特点

| 特点 | 说明 | 为什么重要 |
|------|------|------------|
| **隐私优先** | 所有数据保存在本地 | 不用担心隐私泄露 |
| **高度可扩展** | 通过 Skills 扩展功能 | 想做什么功能都能加 |
| **多渠道支持** | 钉钉、飞书、微信、Discord 等 | 在你习惯的地方使用 |
| **多智能体** | 创建多个可以协作的 AI | 处理复杂任务 |
| **安全可靠** | 多层安全防护 | 防止误操作和攻击 |
| **本地部署** | 支持 Ollama 等本地模型 | 不需要 API 密钥 |

### 4.2 隐私优先

**传统 AI 助手**：
```
你的问题 → 上传到云端 → 返回答案
     ↓
   服务器保存了你的数据
```

**QwenPaw**：
```
你的问题 → 在本地处理 → 返回答案
     ↓
   只有你自己能访问数据
```

### 4.3 Skills 技能系统

Skills 是 QwenPaw 的核心扩展机制：

```
Skills 就像手机的 App
├── 内置 Skills：开箱即用的基础功能
├── 社区 Skills：别人开发的共享技能
└── 自定义 Skills：你自己写的独特功能
```

**Skills 能做什么？**
- 处理文件（PDF、Word、Excel）
- 搜索网页获取信息
- 发送消息到各种平台
- 执行定时任务
- 调用外部 API
- ……几乎是无限的！

## 5. QwenPaw 的技术架构

### 5.1 技术栈

| 层级 | 技术 | 作用 |
|------|------|------|
| **核心语言** | Python 3.10+ | 整个项目用 Python 开发 |
| **智能体框架** | AgentScope | 多智能体运行时 |
| **Web 服务** | FastAPI + Uvicorn | 高性能 API 服务 |
| **前端界面** | React + TypeScript | 用户界面 |
| **异步框架** | anyio + asyncio | 高效并发处理 |
| **任务调度** | APScheduler | 定时任务管理 |

### 5.2 主要模块

| 模块 | 位置 | 功能 |
|------|------|------|
| **agents** | `src/qwenpaw/agents/` | 智能体核心、工具、技能管理 |
| **app** | `src/qwenpaw/app/` | Web 服务、渠道管理 |
| **providers** | `src/qwenpaw/providers/` | 大语言模型接口 |
| **cli** | `src/qwenpaw/cli/` | 命令行工具 |
| **security** | `src/qwenpaw/security/` | 安全机制 |
| **console** | `console/` | 前端界面 |

### 5.3 为什么用 Python？

Python 是 AI 领域最流行的语言：

1. **简洁易学**：语法简单，适合初学者
2. **AI 生态**：TensorFlow、PyTorch、各种 LLM 库都用 Python
3. **社区活跃**：遇到问题容易找到帮助
4. **开发效率**：用更少代码做更多事

QwenPaw 选择 Python，让任何人都能参与到项目中来。

## 8. 快速体验

### 8.1 安装 QwenPaw

最简单的安装方式（需要 Python 3.10+）：

```bash
pip install qwenpaw
```

### 8.2 初始化和运行

```bash
qwenpaw init --defaults  # 初始化配置
qwenpaw app              # 启动应用
```

### 8.3 打开浏览器

启动后，打开浏览器访问 **http://127.0.0.1:8088/**

## 9. 常见问题

### 9.1 QwenPaw 和 Qwen 是什么关系？

- **Qwen**：阿里云的开源大语言模型系列（如 Qwen2、Qwen2.5）
- **QwenPaw**：使用 Qwen 等模型作为"大脑"的个人 AI 助手

QwenPaw 支持多种模型，Qwen 只是其中之一。

### 9.2 需要 GPU 才能运行吗？

不一定：
- **使用云端模型**（如 OpenAI、Qwen API）：不需要 GPU
- **使用本地模型**（如 Ollama）：CPU 可以运行，但会慢一些；有 GPU 会快很多

### 9.3 完全免费吗？

QwenPaw 本身是免费的。但：
- 如果使用云端 LLM API，需要支付 API 费用（按用量收费）
- 如果使用本地模型（Ollama），完全免费

### 9.4 需要编程基础吗？

- **使用 QwenPaw**：不需要，写说话就行
- **扩展 QwenPaw**：需要一点 Python 基础（本书会教）
