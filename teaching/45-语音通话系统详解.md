# 语音通话系统详解

## 概述

QwenPaw 语音通话基于 Twilio ConversationRelay，通过 Cloudflare Tunnel 暴露公网 WebSocket，支持语音识别（STT）、语音合成（TTS）和全双工中断。

**核心设计理念**：将传统电话网络与 AI 智能体无缝连接，用户只需拨打电话即可与 AI 进行自然对话，无需安装任何应用程序。

## 4. ConversationRelayHandler

源码路径：`src/qwenpaw/app/channels/voice/conversation_relay.py:29`

### 4.1 消息类型

**Twilio → QwenPaw**：

| 消息类型 | 说明 | 字段 |
|----------|------|------|
| `setup` | 初始化会话 | `callSid`, `from`, `to` |
| `prompt` | 语音转文字 | `voicePrompt` |
| `interrupt` | 用户打断 | - |
| `dtmf` | 按键输入 | `digit` |

**QwenPaw → Twilio**：

| 消息类型 | 说明 | 字段 |
|----------|------|------|
| `text` + `last=false` | 流式文本令牌 | `token` |
| `text` + `last=true` | 触发 TTS 播放 | `token` |
| `end` | 结束播放 | - |

### 4.2 主循环

```python
async def handle(self) -> None:
    while not self._closed:
        raw = await self.ws.receive_text()
        msg = json.loads(raw)
        match msg.get("type"):
            case "setup":
                await self._handle_setup(msg)
            case "prompt":
                await self._process_and_stream(request)
            case "interrupt":
                await self._handle_interrupt(msg)
            case "dtmf":
                await self._handle_dtmf(msg)
```

**循环流程**：
```
建立 WebSocket
    ↓
等待 Twilio 消息
    ↓
┌─────────────────────────────┐
│ setup    → 注册会话          │
│ prompt   → 处理语音 → 流式响应│
│ interrupt → 处理打断          │
│ dtmf     → 处理按键          │
└─────────────────────────────┘
    ↓
循环直到通话结束
```

### 4.3 流式响应

```python
async def _send_token(self, token: str, *, last: bool = False) -> None:
    await self.ws.send_text(json.dumps({
        "type": "text",
        "token": token,
        "last": last,  # last=true 触发 TTS 播放
    }))
```

**流式机制**：
- AI 生成的每个 token 立即发送给 Twilio
- `last=true` 表示文本结束，触发 TTS 播放
- 用户可以随时打断（TTS 停止）

## 8. Cloudflare Tunnel 配置

```python
# Cloudflare Tunnel 暴露公网 WebSocket
tunnel = CloudflareTunnelDriver()
tunnel_url = tunnel.get_tunnel_url()  # 返回 trycloudflare.com URL
wss_url = f"{tunnel_url}/voice/ws"
```

**为什么需要 Cloudflare Tunnel**：
- QwenPaw 运行在本地网络
- Twilio 需要公网 WebSocket URL
- Cloudflare Tunnel 提供免费、快速的公网访问

## 11. 常见问题

### Q1: 电话拨打无人接听？

**排查步骤**：
```bash
# 1. 检查 Twilio 配置
curl -X GET https://api.twilio.com/.../IncomingPhoneNumbers

# 2. 检查 Webhook URL 是否可达
curl -X POST https://your-domain.com/voice/incoming

# 3. 检查 Cloudflare Tunnel 状态
curl https://your-tunnel.trycloudflare.com/health
```

### Q2: 语音识别不准确？

**优化方案**：
1. 使用更好的 STT 提供商（Deepgram 优于 Google）
2. 调整 `language` 参数匹配说话语言
3. 减少背景噪音

### Q3: TTS 播放延迟？

**原因**：流式响应未正确配置。

**检查**：
- `last=true` 是否正确发送
- 网络延迟是否过高
- TTS 提供商响应速度

### Q4: 无法打断 TTS？

**检查**：
- `interruptible` 参数是否为 `true`
- `interrupt` 消息是否正确处理

### Q5: Cloudflare Tunnel 断开？

**解决方案**：
- 配置 Tunnel 自动重连
- 使用稳定的 Tunnel 服务
- 考虑使用 ngrok 作为替代
