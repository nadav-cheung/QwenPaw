## 核心方法实现

### 🐍 来自 Java 的你

| Java | Python | 说明 |
|------|--------|------|
| `DispatcherServlet` | `AgentRunner.query_handler` | 请求入口分发器 |
| `@Controller` / `@RestController` | `AgentRunner` | 请求处理类 |
| `@RequestMapping` | `_is_command()` / 命令路由 | 路由匹配 |
| `HandlerInterceptor` / `Filter` | `_resolve_pending_approval()` | 请求前后置处理 |
| `ModelAndView` | `yield msg, last` | 响应返回方式 |
| `@SessionAttributes` | `SafeJSONSession` | 会话状态管理 |
| `HandlerExceptionResolver` | `convert_model_exception()` | 统一异常处理 |
| `ContentNegotiatingViewResolver` | 流式响应 (`AsyncGenerator`) | 多格式响应 |
| `RedirectAttributes` | Mission Phase | 重定向/阶段状态传递 |
| `FilterChain.doFilter()` | `yield` 传递控制 | 责任链模式 |

**关键理解**：
- Java 用 **Servlet API** + **HandlerInterceptor** 做请求处理链，Python 用 **async generator** + **中间件** 做请求流
- Java 的 `DispatcherServlet.doDispatch()` 对应 Python 的 `query_handler` 核心调度
- Java 用注解（`@RequestMapping`）做路由匹配，Python 用字符串模式匹配（`_is_command()`）
- 会话管理：Java 的 `@SessionAttributes` vs Python 的 `SafeJSONSession`（文件持久化）
- 异常处理：Java 的 `HandlerExceptionResolver` vs Python 的 `convert_model_exception()`
- 响应方式：Java 的 `ModelAndView` vs Python 的 `yield (msg, last)` 流式元组

```python
async def _resolve_pending_approval(
    self,
    session_id: str,
    query: str | None,
) -> tuple[Msg | None, bool, dict[str, Any] | None]:
    """Check for a pending tool-guard approval for *session_id*."""
    if not session_id:
        return None, False, None

    from ..approvals import get_approval_service
    svc = get_approval_service()
    pending = await svc.get_pending_by_session(session_id)

    elapsed = time.time() - pending.created_at
    if elapsed > self._APPROVAL_TIMEOUT_SECONDS:
        # 超时拒绝
        await svc.resolve_request(
            pending.request_id,
            ApprovalDecision.TIMEOUT,
        )
        return (timeout_msg, True, None)

    normalized = (query or "").strip().lower()
    if _is_approval(normalized):
        # 用户批准
        resolved = await svc.resolve_request(
            pending.request_id,
            ApprovalDecision.APPROVED,
        )
        return None, True, approved_tool_call

    # 用户拒绝
    await svc.resolve_request(
        pending.request_id,
        ApprovalDecision.DENIED,
    )
    return (denied_msg, True, None)
```

### _stream_printing_messages_interruptible 可中断流式消息

**文件**: `src/qwenpaw/app/runner/runner.py:56-111`

```python
async def _stream_printing_messages_interruptible(
    *,
    agents: list[Any],
    coroutine_task: Coroutine[Any, Any, Msg],
) -> AsyncGenerator[tuple[Msg, bool], None]:
    """Like agentscope.stream_printing_messages, but cancel the agent task
    promptly when the outer stream is stopped or closed.
    """
    queue: asyncio.Queue = asyncio.Queue()
    for agent in agents:
        agent.set_msg_queue_enabled(True, queue)

    task = asyncio.create_task(coroutine_task)

    try:
        while True:
            printing_msg = await queue.get()
            if isinstance(printing_msg, str) and printing_msg == _PRINT_END_SIGNAL:
                break
            msg, last, _ = printing_msg
            yield msg, last

        exception = task.exception()
        if exception is not None:
            raise exception from None
    except asyncio.CancelledError:
        await _cancel_streaming_agent_task(task)
        raise
    finally:
        await _cancel_streaming_agent_task(task)
```

## 核心职责总结

1. **请求入口**：接收来自 `stream_query` 基类方法的请求
2. **审批流程**：处理工具_guard 的待定审批（超时、批准、拒绝）
3. **命令路由**：识别并处理系统命令（`/approve`, `/stop`, `/new` 等）
4. **技能注入**：解析并执行技能命令（`/skill_name input`）
5. **任务模式**：支持 Mission Mode 的阶段性执行
6. **会话管理**：通过 `SafeJSONSession` 持久化会话状态
7. **错误恢复**：统一异常转换和错误转储

### 练习 4: 命令路由

**目标**: 实现简单的命令路由系统。

```python
# 练习: 实现命令路由
from dataclasses import dataclass

@dataclass
class AgentRequest:
    query: str
    session_id: str = ""
    user_id: str = ""

class CommandRouter:
    def __init__(self):
        self.commands = {}

    def register(self, command: str, handler):
        """注册命令处理器"""
        self.commands[command.lower()] = handler

    async def route(self, query: str) -> str:
        """路由命令"""
        if not query.startswith("/"):
            return "不是命令"

        parts = query.strip()[1:].split(None, 1)
        cmd = parts[0].lower()

        if cmd in self.commands:
            return await self.commands[cmd](parts[1] if len(parts) > 1 else "")
        return f"未知命令: {cmd}"

# 测试
router = CommandRouter()

@router.register("stop")
async def handle_stop(args):
    return "停止处理"

@router.register("new")
async def handle_new(args):
    return f"创建新会话"

async def main():
    print(await router.route("/stop"))
    print(await router.route("/new"))
    print(await router.route("/unknown"))

asyncio.run(main())
```
