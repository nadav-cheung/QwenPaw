class ToolGuardEngine:
    """Orchestrates pre-tool-call security guarding."""

    def __init__(
        self,
        guardians: list[BaseToolGuardian] | None = None,
        *,
        enabled: bool | None = None,
    ) -> None:
        self._enabled = enabled if enabled is not None else _guard_enabled()
        self._guardians = guardians or self._default_guardians()

### 1.2 默认 Guardian 列表

```python

@staticmethod
def _default_guardians() -> list[BaseToolGuardian]:
    guardians: list[BaseToolGuardian] = []
    guardians.append(FilePathToolGuardian())
    guardians.append(RuleBasedToolGuardian())
    guardians.append(ShellEvasionGuardian())
    return guardians
```

### 1.3 启用优先级

```python
# src/qwenpaw/security/tool_guard/engine.py:38
# 优先级：环境变量 > config.json > 默认值 (True)
def _guard_enabled() -> bool:
    env_val = EnvVarLoader.get_str("QWENPAW_TOOL_GUARD_ENABLED") or None
    if env_val is not None:
        return env_val.lower() in {"true", "1", "yes"}
    try:
        cfg = load_config()
        return cfg.security.tool_guard.enabled
    except Exception:
        return True
```

## 8. 常见问题

### 8.1 ToolGuard 误拦截正常请求

**问题**：合法工具调用被错误拦截。

**原因**：规则过于严格或规则正则匹配了合法命令。

**解决**：
1. 检查 `config.json` 中的 `tool_guard.rules` 配置
2. 将误拦截的命令添加到 `pre_approved_tools` 列表
3. 调低规则的 `severity` 等级

### 8.2 审批超时设置不当

**问题**：长时间运行的工具在审批后仍然超时。

**原因**：默认超时 10 分钟可能不够。

**解决**：在 `agent.json` 中调整：
```json
{
  "security": {
    "approval_timeout_minutes": 30
  }
}
```

### 8.3 FilePathToolGuardian 保护路径不足

**问题**：某些敏感路径未被保护。

**原因**：默认只保护 `.qwenpaw.secret` 和 `.copaw.secret`。

**解决**：在 `config.json` 中添加自定义保护路径：
```json
{
  "security": {
    "file_guard": {
      "protected_paths": [
        ".qwenpaw.secret",
        ".copaw.secret",
        "/etc/qwenpaw/secrets",
        ".env"
      ]
    }
  }
}
```

### 8.4 Skill Scanner 性能问题

**问题**：技能加载时扫描速度慢。

**原因**：深度代码扫描耗时较长。

**解决**：使用白名单机制跳过可信技能：
```bash
curl -X POST /api/config/security/skill-scanner/whitelist \
  -d '{"skill_name": "trusted-skill"}'
```
