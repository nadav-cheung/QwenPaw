## 1. ToolGuard 三层防护概述

ToolGuardEngine 编排三层 Guardian 链，在工具调用前依次执行安全检查：

1. **FilePathToolGuardian** — 文件路径保护（Zip Slip、路径遍历检测）
2. **RuleBasedToolGuardian** — 危险命令规则匹配（`rm -rf`、`curl | bash`、反向 Shell 等）
3. **ShellEvasionGuardian** — Shell 混淆检测（命令替换、ANSI-C 引号、反斜杠转义等）

启用优先级：环境变量 `QWENPAW_TOOL_GUARD_ENABLED` > `config.json` > 默认值 `True`。

> 各 Guardian 的详细实现、规则引擎和配置方法，详见 [38-工具Guard安全系统](./38-工具Guard安全系统.md)。

## 6. 常见问题

### 6.1 ToolGuard 误拦截正常请求

**问题**：合法工具调用被错误拦截。

**原因**：规则过于严格或规则正则匹配了合法命令。

**解决**：
1. 检查 `config.json` 中的 `tool_guard.rules` 配置
2. 将误拦截的命令添加到 `pre_approved_tools` 列表
3. 调低规则的 `severity` 等级

### 6.2 审批超时设置不当

**问题**：长时间运行的工具在审批后仍然超时。

**原因**：默认超时 10 分钟可能不够。

**解决**：在 `agent.json` 中调整：
```json
{
  "security": {
    "approval_timeout_minutes": 30
  }
}
```

### 6.3 FilePathToolGuardian 保护路径不足

**问题**：某些敏感路径未被保护。

**原因**：默认只保护 `.qwenpaw.secret` 和 `.copaw.secret`。

**解决**：在 `config.json` 中添加自定义保护路径：
```json
{
  "security": {
    "file_guard": {
      "protected_paths": [
        ".qwenpaw.secret",
        ".copaw.secret",
        "/etc/qwenpaw/secrets",
        ".env"
      ]
    }
  }
}
```

### 6.4 Skill Scanner 性能问题

**问题**：技能加载时扫描速度慢。

**原因**：深度代码扫描耗时较长。

**解决**：使用白名单机制跳过可信技能：
```bash
curl -X POST /api/config/security/skill-scanner/whitelist \
  -d '{"skill_name": "trusted-skill"}'
```

## 🐍 来自 Java 的你

### 核心概念对照

| Java | Python / QwenPaw | 说明 |
|------|-------------------|------|
| OWASP Java (ESAPI) | Python OWASP 最佳实践 | Java 生态有 ESAPI 等成熟安全库；Python 遵循 OWASP 原则但依赖更轻量的防护方案 |
| Spring Security Config | ToolGuard YAML 配置 | Spring Security 通过 Java Config 或 XML 配置安全规则；QwenPaw 通过 YAML 定义工具调用守卫规则 |
| KeyStore (JKS/PKCS12) | SecretStore | KeyStore 存储 Java 密钥和证书；QwenPaw 的 SecretStore 管理敏感配置的加密存储 |
| @RolesAllowed / @Secured | 权限规则 (ToolGuard) | Java 通过注解实现方法级权限控制；QwenPaw 通过 Guardian 引擎对工具调用进行权限检查 |
| Security Filter Chain | 三层防护 (Shell/Path/Tool) | Spring Security 的 FilterChain 处理认证授权；QwenPaw 的三层 Guardian 分别防护 Shell 注入、路径遍历、工具滥用 |

### 关键差异

Spring Security 是一套通用的 Web 安全框架，覆盖认证、授权、CSRF、Session 管理等方方面面，配置复杂度高。QwenPaw 的安全体系聚焦于 AI Agent 场景特有的风险——Shell 命令注入、文件路径遍历和工具调用滥用，三层防护设计更加精准和轻量，但防护范围也更专一。
