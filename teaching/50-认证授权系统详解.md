# 认证授权系统详解

## 概述

QwenPaw 的认证系统采用 HMAC-SHA256 签名 Token、单用户设计、支持 Token 撤销和全局吊销，所有敏感数据通过 Fernet 加密存储。

**核心设计理念**：认证是系统安全的第一道防线，采用简洁高效的单用户模式，满足大多数场景的安全需求，同时通过加密和撤销机制确保安全性。

## 1. AuthMiddleware

源码路径：`src/qwenpaw/app/auth.py:567`

### 1.1 中间件核心

```python
# src/qwenpaw/app/auth.py:567
class AuthMiddleware(BaseHTTPMiddleware):
    async def dispatch(self, request: Request, call_next):
        if self._should_skip_auth(request):
            return await call_next(request)

        token = self._extract_token(request)
        if not token:
            return Response(status_code=401)

        user = verify_token(token)
        if user is None:
            return Response(status_code=401)

        request.state.user = user
        return await call_next(request)
```

**认证流程**：
```
请求进入
    ↓
检查是否跳过认证？
    ├─ YES → 直接处理
    └─ NO
        ↓
提取 Token
        ↓
验证 Token
        ├─ 失败 → 401 Unauthorized
        └─ 成功 → 将用户信息注入 request.state
            ↓
继续处理请求
```

## 2. Token 生成与验证

### 2.1 JWT Secret 管理

```python
# src/qwenpaw/app/auth.py:115-123
def _get_jwt_secret() -> bytes:
    """获取 JWT 签名密钥，不存在则自动生成"""
    data = _load_auth_data()
    secret = data.get("jwt_secret")
    if not secret:
        secret = secrets.token_hex(32)  # 32字节随机密钥
        data["jwt_secret"] = secret
        _save_auth_data(data)
    return secret.encode()
```

**密钥生成**：
- 首次调用时自动生成
- 32 字节（256 位）随机密钥
- 持久化到 `auth.json`

### 2.2 Token 生成

```python
# src/qwenpaw/app/auth.py:146-163
def create_token(username: str, expiry_seconds: Optional[int] = None) -> str:
    """Token 格式: base64url(payload).hmac_hex_signature

    payload 字段: sub(用户名), exp(过期时间戳), iat(签发时间戳), jti(token ID)
    """
    secret = _get_jwt_secret()
    token_id = secrets.token_hex(16)  # jti 用于撤销
    payload = json.dumps({
        "sub": username,
        "exp": int(time.time()) + expiry_seconds,
        "iat": int(time.time()),
        "jti": token_id,
    })
    payload_b64 = base64.urlsafe_b64encode(payload.encode()).decode()
    sig = hmac.new(secret, payload_b64.encode(), hashlib.sha256).hexdigest()
    return f"{payload_b64}.{sig}"
```

**Token 格式说明**：
```
base64url(payload).hmac_hex_signature
     ↓              ↓
  编码的 JSON   HMAC-SHA256 签名
```

**Payload 字段**：
| 字段 | 说明 |
|------|------|
| `sub` | 用户名 |
| `exp` | 过期时间戳 |
| `iat` | 签发时间戳 |
| `jti` | Token ID（用于撤销） |

**时间常量**：
| 常量 | 值 | 说明 |
|------|-----|------|
| `TOKEN_EXPIRY_SECONDS` | 7*24*3600 | 默认 7 天 |
| `TOKEN_EXPIRY_MAX` | 100年 | 最大有效期 |

```python

    # 1. 验证签名 (HMAC-SHA256)
    # 2. 检查过期时间 (exp < now)
    # 3. 检查撤销列表 (jti in revoked_tokens_meta)
```

**验证流程**：
```
Token 解析
    ↓
分割 payload 和 signature
    ↓
使用 HMAC-SHA256 验证签名
    ├─ 失败 → 返回 None
    └─ 成功
        ↓
检查过期时间 (exp < now)
    ├─ 已过期 → 返回 None
    └─ 未过期
        ↓
检查撤销列表 (jti in revoked_tokens_meta)
    ├─ 已撤销 → 返回 None
    └─ 未撤销
        ↓
返回用户名
```

## 3. 密码处理

```python
# src/qwenpaw/app/auth.py:93
def _hash_password(password: str, salt: Optional[str] = None) -> tuple[str, str]:
    if salt is None:
        salt = secrets.token_hex(16)
    h = hashlib.sha256((salt + password).encode("utf-8")).hexdigest()
    return h, salt

def verify_password(password: str, stored_hash: str, salt: str) -> bool:
    h, _ = _hash_password(password, salt)
    return hmac.compare_digest(h, stored_hash)
```

**密码安全特性**：
| 特性 | 说明 |
|------|------|
| 加盐 | 每个密码使用独立随机盐 |
| SHA-256 | 强哈希算法 |
| 常数时间比较 | 防止时序攻击 |

```python
def _load_auth_data() -> dict:
    with open(auth_path, "r", encoding="utf-8") as f:
        data = json.load(f)
    # 检测明文并触发迁移
    needs_rewrite = any(
        isinstance(data.get(field), str) and data.get(field)
        and not is_encrypted(data[field])
        for field in AUTH_SECRET_FIELDS
    )
    data = decrypt_dict_fields(data, AUTH_SECRET_FIELDS)
    return data
```

## 12. 常见问题

### Q1: 忘记密码怎么办？

**方案**：重置 auth.json（会删除所有用户）
```bash
rm ~/.qwenpaw.secret/auth.json
# 然后重新注册
```

### Q2: Token 过期怎么办？

**方案**：重新登录获取新 Token
```bash
curl -X POST http://localhost:8080/api/auth/login \
  -d '{"username": "admin", "password": "xxx"}'
```

### Q3: 多人使用如何管理？

**当前限制**：QwenPaw 仅支持单用户。

**替代方案**：
- 使用反向代理添加认证层
- 使用 VPN 限制访问
- 配置防火墙规则

### Q4: 认证数据泄露怎么办？

**紧急处理**：
1. 立即调用 `POST /api/auth/revoke-all-tokens`
2. 变更密码（通过 `/api/auth/update-profile`）
3. 检查系统日志

### Q5: 认证不工作？

**排查步骤**：
```bash
# 1. 检查认证是否启用
curl http://localhost:8080/api/auth/status

# 2. 检查 auth.json 是否存在
cat ~/.qwenpaw.secret/auth.json

# 3. 检查日志
tail -f logs/qwenpaw.log | grep auth
```

## 13. 总结

**核心要点**：

| 要点 | 说明 |
|------|------|
| HMAC-SHA256 Token | 无需外部 JWT 库，简单可靠 |
| 单用户设计 | 满足大多数场景需求 |
| Token 撤销 | 基于 jti 的 O(1) 检查 |
| 全局吊销 | 轮换密钥使所有 Token 失效 |
| Fernet 加密 | 敏感数据安全存储 |
| 常数时间比较 | 防止时序攻击 |

**进阶主题**：
- 多用户支持（自定义认证后端）
- LDAP/OAuth 集成
- 登录审计日志
- 双因素认证
