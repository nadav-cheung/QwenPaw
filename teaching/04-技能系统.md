# 技能系统 (Skills)

## 概述

Skills 是 QwenPaw 扩展智能体能力的核心机制。每个 Skill 是一个独立的功能模块，可以让智能体执行特定任务。

## 技能来源

技能可以从多个来源安装：

| 来源 | 示例 URL | 说明 |
|------|----------|------|
| ClawHub | `clawhub.ai` | 主要技能市场 |
| GitHub | `github.com/user/repo` | 直接从 Git 仓库安装 |
| LobeHub | `market.lobehub.com` | LobeHub 市场 |
| ModelScope | `modelscope.cn` | 模型scope市场 |
| skills.sh | `skills.sh` | Another skill registry |
| skillsmp.com | `skillsmp.com` | Yet another registry |

### URL 解析逻辑

`_resolve_bundle_from_url()` 根据 URL 模式分发到不同的获取器：
- GitHub URL → GitHub API
- 本地路径 → 本地文件系统
- ZIP URL → 下载解压

### 语言选择逻辑

```python
get_builtin_skill_language_preference()
# 1. 读取 settings.json 的 builtin_skill_language
# 2. 回退到 UI 语言设置
# 3. 默认英文
```

## 自定义技能

### 技能结构

```
my_skill/
├── SKILL.md      # 技能入口（包含 YAML frontmatter 元数据 + Markdown 描述）
├── scripts/      # 辅助脚本（可选）
├── LICENSE.txt   # 许可协议
└── references/   # 参考文档（可选）
```

### SKILL.md 结构示例

每个技能以 `SKILL.md` 文件为核心，采用 YAML frontmatter 存储元数据：

```yaml
---
name: my_skill
description: 我的自定义技能
version: "1.0"
metadata:
  builtin_skill_version: "1.0"
  qwenpaw:
    requires:
      bins: ["soffice"]       # 所需系统命令
      envs: ["PATH"]          # 所需环境变量
---
```

```markdown
## 功能说明

描述技能的具体功能和使用方法。

## 使用示例

\`\`\`python
# 示例代码
\`\`\`
```

### 技能需求系统

技能可以在 frontmatter 中声明依赖：

| 依赖类型 | 说明 |
|----------|------|
| `bins` | 所需系统命令（如 `["soffice"]`） |
| `envs` | 所需环境变量（如 `["PATH"]`） |

系统会在激活技能前检查依赖是否满足。

## 安装技能

```bash
# 从内置技能池导入
qwenpaw skills install pdf

# 从本地路径安装自定义渠道
qwenpaw channels install my_channel --from-path ./my_channel

# 从 URL 安装
qwenpaw channels install my_channel --from-url https://example.com/channel.zip
```

## 管理技能

```bash
# 列出所有技能
qwenpaw skills list

# 查看技能详情
qwenpaw skills info pdf

# 配置技能
qwenpaw skills config pdf
```

## 安全扫描

所有技能在安装时都会经过安全扫描，确保：
- 没有恶意代码（`SkillScanner` 模式分析器）
- 文件访问权限合理（`FilePathToolGuardian` 路径守卫）
- 网络请求安全（`RuleBasedToolGuardian` 规则守卫）
