## 1. Python vs Java：核心差异

### 1.1 语法层面

对比 Java，Python 语法更加简洁，但概念相通。以下是主要差异：

| 特性 | Java | Python |
|------|------|--------|
| 类型系统 | 静态类型（编译时检查） | 动态类型 + 类型提示（可选） |
| 代码块 | 花括号 `{}` | 缩进 |
| 方法定义 | `public void method()` | `def method():` |
| 变量声明 | `String name = "Java"` | `name = "Python"` |
| 空值 | `null` | `None` |
| 布尔值 | `true` / `false` | `True` / `False` |
| 字符串拼接 | `"Hello " + name` | `f"Hello, {name}"` |
| 循环 | `for (int i : list)` | `for item in list:` |
| 类定义 | `public class Foo {}` | `class Foo:` |
| 接口实现 | `implements Interface` | 直接继承或多继承 |
| 访问控制 | `public`/`private`/`protected` | `_`/`__` 前缀约定 |

### 1.2 思维层面

**对比 Java**：Java 是纯静态类型语言，所有变量必须声明类型。Python 是动态类型语言，变量可以随时指向不同类型的对象。

```python
# Python 变量可以是任意类型
name = "Alice"      # str
name = 25            # int，完全合法！
name = [1, 2, 3]     # list，也合法
```

**类型提示的作用**：Python 3.5+ 引入的类型提示（Type Hints）让动态类型也能享受静态检查的好处：

```python
# 类型提示不影响运行时，但让 IDE 和 mypy 能进行类型检查
name: str = "Alice"  # 提示应该是字符串
age: int = 25        # 提示应该是整数
```

**缩进即代码块**：Python 用缩进代替 Java 的花括号，保持代码整洁但需要 IDE 辅助：

```python
# Python - 缩进定义代码块
if x > 0:
    print("positive")
    if x > 10:
        print("large")
else:
    print("non-positive")
```

```java
// Java - 花括号界定代码块
if (x > 0) {
    System.out.println("positive");
    if (x > 10) {
        System.out.println("large");
    }
} else {
    System.out.println("non-positive");
}
```

**Everything is an Object**：Python 中一切皆为对象，包括函数和类：

```python
# Python 函数也是对象
def greet():
    return "Hello"

say = greet          # 函数可以赋值给变量
print(say())         # 输出: Hello
```

## 2. 异步编程：async/await

### 2.1 Java 的异步模型

对比 Java：Java 使用 `CompletableFuture` 处理异步任务，通过回调链式调用。

```java
// Java CompletableFuture
CompletableFuture.supplyAsync(() -> {
    return fetchData();
}).thenApply(data -> {
    return process(data);
}).thenCompose(result -> {
    return save(result);
});
```

Java 的异步基于线程池，每个 `CompletableFuture` 可能在不同线程执行。

### 2.2 Python 的异步模型

Python 的 `async/await` 是单线程协作式并发模型，语法更简洁：

```python
import asyncio

async def fetch_data():
    """异步函数定义使用 async def"""
    await asyncio.sleep(1)  # 异步等待，不阻塞事件循环
    return "data"

async def main():
    """主异步函数"""
    result = await fetch_data()  # await 等待异步结果
    print(result)

asyncio.run(main())
```

**核心概念**：

- `async def` 定义异步函数，调用时返回协程对象
- `await` 等待协程完成，让出控制权给其他任务
- `asyncio.run()` 入口函数，类似于 Java 的 `CompletableFuture.get()`

### 2.3 对比总结

| 特性 | Java CompletableFuture | Python async/await |
|------|------------------------|-------------------|
| 语法 | `supplyAsync().thenApply()` | `async def` / `await` |
| 线程模型 | 多线程（线程池） | 单线程（事件循环） |
| 并发数量 | 受线程池限制 | 轻量级，可运行数千协程 |
| 阻塞方式 | `future.get()` 阻塞线程 | `await` 挂起协程，不阻塞事件循环 |
| 组合方式 | `thenCompose`, `allOf` | `asyncio.gather` |
| 锁机制 | `ReentrantLock` | `asyncio.Lock` |

**并发执行示例**：

```python
async def sequential():
    """顺序执行 - 总耗时 = sum(所有延迟)"""
    await fetch_data(1.0)  # 等待 1 秒
    await fetch_data(1.0)  # 再等 1 秒
    # 总耗时: 2 秒

async def parallel():
    """并发执行 - 总耗时 = max(最长延迟)"""
    await asyncio.gather(
        fetch_data(1.0),
        fetch_data(1.0),
    )
    # 总耗时: 1 秒
```

## 3. 类型提示系统

### 3.1 基本类型提示

对比 Java：Python 类型提示在运行时不起作用，但配合 `mypy` 可以实现编译时检查。

```python
# 基本类型提示
def greet(name: str) -> str:
    return f"Hello, {name}"

# 变量类型提示
age: int = 25
is_active: bool = True
items: list[str] = ["a", "b"]  # Python 3.9+
```

**常用类型**：

```python
from typing import Optional, List, Dict, Set, Tuple

# 可空类型（相当于 Java 的 Optional）
result: Optional[str] = None
result: str | None = None  # Python 3.10+ 简化写法

# 列表
numbers: List[int] = [1, 2, 3]

# 字典
config: Dict[str, str] = {"host": "localhost"}

# 集合
tags: Set[str] = {"python", "java"}

# 元组（固定长度和类型）
point: Tuple[float, float] = (10.5, 20.3)
```

### 3.2 泛型类型提示

```python
from typing import List, Optional, Callable, TypeVar

T = TypeVar('T')

# 泛型函数
def first_element(lst: List[T]) -> Optional[T]:
    return lst[0] if lst else None

# 函数类型
def apply(func: Callable[[int], int], value: int) -> int:
    return func(value)
```

## 4. 数据类与装饰器

### 4.1 Java 实体类

对比 Java：Java 需要手动编写构造函数、getter/setter、equals、hashCode、toString。

```java
// Java 实体类
public class User {
    private String name;
    private int age;

    public User(String name, int age) {
        this.name = name;
        this.age = age;
    }

    public String getName() { return name; }
    public void setName(String name) { this.name = name; }
    public int getAge() { return age; }
    public void setAge(int age) { this.age = age; }

    @Override
    public String toString() {
        return "User{name='" + name + "', age=" + age + "}";
    }
}
```

### 4.2 Python dataclass

Python 的 `@dataclass` 装饰器自动生成 `__init__`、`__repr__`、`__eq__` 等方法：

```python
from dataclasses import dataclass

@dataclass
class User:
    name: str
    age: int

# 自动生成:
# __init__(name: str, age: int)
# __repr__() -> "User(name='Alice', age=25)"
# __eq__(other) -> bool

user = User(name="Alice", age=25)
print(user)              # User(name='Alice', age=25)
print(user.name)         # Alice
```

**dataclass 进阶用法**：

```python
from dataclasses import dataclass, field
import time

@dataclass
class Task:
    name: str
    status: str = "pending"
    created_at: float = field(default_factory=time.time)  # 可变默认值
    tags: list[str] = field(default_factory=list)         # 避免共享默认值
```

### 4.3 装饰器

对比 Java：Python 装饰器类似于 Java 的注解（Annotation）+ AOP，但更强大。

**基本装饰器**：

```python
def log_calls(func):
    """记录函数调用的装饰器"""
    def wrapper(*args, **kwargs):
        print(f"Calling {func.__name__}")
        return func(*args, **kwargs)
    return wrapper

@log_calls
def hello():
    print("Hello!")

hello()
# 输出:
# Calling hello
# Hello!
```

**装饰器链**：

```python
@a
@b
@c
def my_function():
    pass
# 等价于: my_function = a(b(c(my_function)))
```

**常用内置装饰器**：

| 装饰器 | 作用 | Java 对比 |
|--------|------|----------|
| `@staticmethod` | 静态方法 | `static` 方法 |
| `@classmethod` | 类方法 | 静态工厂方法 |
| `@property` | 属性访问器 | getter 方法 |
| `@abstractmethod` | 抽象方法 | `abstract` 方法 |
| `@functools.lru_cache` | 缓存结果 | `ConcurrentHashMap` 缓存 |

**property 示例**：

```python
class Workspace:
    @property
    def workspace_dir(self) -> Path:
        """直接访问属性，不需要括号"""
        return self._workspace_dir

# 使用
print(ws.workspace_dir)  # 而非 ws.get_workspace_dir()
```

## 6. 常见陷阱

### 6.1 可变默认参数

**对比 Java**：Java 中默认参数不常见，但 Python 的可变默认参数是一个经典陷阱。

```python
# 危险！默认参数在函数定义时创建，所有调用共享同一个对象
def add_item(item, items=[]):
    items.append(item)
    return items

print(add_item("a"))  # ['a']
print(add_item("b"))  # ['a', 'b'] — 预期之外！

# 正确做法：使用 None
def add_item(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items
```

### 6.2 浅拷贝 vs 深拷贝

| 操作 | Java | Python |
|------|------|--------|
| 创建副本 | `clone()` | `copy.copy()` 浅拷贝 |
| 深拷贝 | 序列化或第三方库 | `copy.deepcopy()` |
| 列表拷贝 | `new ArrayList<>(old)` | `list(old)` 或 `old.copy()` |

### 6.3 GIL（全局解释器锁）

**对比 Java**：Java 没有 GIL 概念。Python 的 GIL 限制了多线程的 CPU 并行性。

```python
# CPU 密集型任务：多线程在 Python 中无法真正并行
# 解决方案：使用 multiprocessing 或 asyncio

# I/O 密集型任务：多线程仍然有效，因为 GIL 会在 I/O 时释放
import threading

def fetch_urls(urls):
    with ThreadPoolExecutor(max_workers=10) as executor:
        results = list(executor.map(requests.get, urls))
```

### 6.4 == vs is

| 操作符 | 含义 | Java 对应 |
|--------|------|----------|
| `==` | 值相等 | `equals()` |
| `is` | 对象身份（内存地址） | `==`（基本类型） |

```python
a = [1, 2, 3]
b = [1, 2, 3]
print(a == b)  # True（值相等）
print(a is b)  # False（不同对象）

c = a
print(a is c)  # True（同一个对象）
```
