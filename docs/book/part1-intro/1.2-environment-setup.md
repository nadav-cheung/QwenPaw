## 1. 系统要求

### 1.1 硬件要求

| 要求 | 最低配置 | 推荐配置 |
|------|---------|---------|
| 内存 | 4 GB | 8 GB 或更多 |
| 磁盘 | 2 GB 可用空间 | 10 GB 或更多 |

### 1.2 软件要求

| 要求 | 版本说明 |
|------|---------|
| **Python** | 3.10 - 3.13（推荐 3.11 或更高） |
| **pip** | Python 3.4+ 自带 |

> **Java 开发者对比**：Python 的 pip 类似于 Java 的 Maven/Gradle，负责依赖管理。而 venv 类似于 Maven 的 `.m2` 本地仓库或 Gradle 的 wrapper，提供隔离的运行环境。

### 1.3 前置检查

```bash
# 检查 Python 版本
python --version  # 或 python3 --version

# 如果没有 Python，官网下载：https://www.python.org/downloads/
```

---

## 2. 安装方式

### 2.1 pip 安装

最简单的方式，适合大多数用户：

```bash
pip install qwenpaw
```

> **Java 开发者对比**：`pip install qwenpaw` 类似于 Maven 的 `mvn install` 或 Gradle 的 `gradle build`，直接拉取并安装依赖包。

### 2.2 源码安装

适合二次开发或需要最新功能的情况：

```bash
git clone https://github.com/agentscope-ai/QwenPaw
cd QwenPaw
pip install -e .
```

> **Java 开发者对比**：源码安装类似于从 GitHub clone 项目后执行构建命令，确保你能修改和调试源码。

### 2.3 验证安装

```bash
qwenpaw --version
```

---

## 3. 初始化配置

### 3.1 首次初始化

安装完成后，运行初始化向导：

```bash
qwenpaw init
```

向导会依次询问：
- 工作目录位置（默认 `~/.qwenpaw`）
- LLM 提供商选择
- API Key 配置
- 默认渠道选择

### 3.2 自动初始化

使用默认配置快速初始化：

```bash
qwenpaw init --defaults
```

### 3.3 配置说明

配置存储在 `~/.qwenpaw/config.json`，主要配置项：

```yaml
# config.yaml 示例
model:
  provider: dashscope
  model: qwen3-max
channels:
  - type: console
```

常用配置命令：

```bash
# 查看当前配置
qwenpaw config show

# 配置模型
qwenpaw models set --provider dashscope --model qwen3-max
```

## 4. 运行与验证

### 4.1 启动应用

```bash
qwenpaw run
```

启动后打开浏览器访问：**http://127.0.0.1:8088/**

### 4.2 验证安装

运行诊断命令检查环境：

```bash
qwenpaw doctor
```

确认输出无错误项，即表示环境搭建成功。

### 4.3 自定义端口

如果端口 8088 被占用：

```bash
qwenpaw run --port 9000
```

---

## 5. 常见问题

| 问题 | 解答 |
|------|------|
| 端口 8088 被占用 | 使用 `qwenpaw run --port 9000` 指定其他端口，或通过 `lsof -i :8088` 查找并关闭占用进程 |
| Python 版本不对 | 使用 `python --version` 确认是 3.10-3.13，建议使用 3.11+ |
| API Key 无效 | 检查 Key 是否正确、是否有足够配额、网络能否访问对应 API |
| 权限错误 | Linux/macOS 下执行 `chmod -R 755 ~/.qwenpaw` |
