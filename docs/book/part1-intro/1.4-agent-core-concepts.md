## 1. 智能体概述

### 1.1 什么是 AI 智能体

AI 智能体（Agent）是一种能够自主理解目标、规划行动、执行任务并根据反馈调整行为的智能系统。与简单的指令执行不同，智能体具备：

- **自主规划**：分解复杂任务为可执行的步骤
- **工具使用**：调用外部工具完成特定操作
- **记忆管理**：保持对话上下文和长期知识
- **自我反思**：根据执行结果调整后续行动

### 1.2 QwenPaw 智能体架构

QwenPaw 的智能体构建于 AgentScope 框架之上，采用 **ReAct** (Reasoning + Acting) 模式：

```
┌─────────────────────────────────────────────────────────────┐
│                      QwenPawAgent                          │
│  ┌─────────────────────────────────────────────────────┐   │
│  │              ToolGuardMixin (安全拦截)                │   │
│  └─────────────────────────────────────────────────────┘   │
│                           ↑                                 │
│  ┌─────────────────────────────────────────────────────┐   │
│  │              ReActAgent (AgentScope)                 │   │
│  │    ┌──────────┐    ┌──────────┐    ┌──────────┐   │   │
│  │    │ Agent    │    │  Runner  │    │  Memory  │   │   │
│  │    │ (智能体) │    │ (执行器) │    │  (记忆)  │   │   │
│  │    └──────────┘    └──────────┘    └──────────┘   │   │
│  │                      ↓                             │   │
│  │              ┌──────────────┐                      │   │
│  │              │   Toolkit    │                      │   │

│  └─────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
```

**源码路径**: `src/qwenpaw/agents/react_agent.py`

## 2. ReAct 模式

ReAct 模式是 QwenPaw 智能体的核心运行范式，将任务处理分为**推理（Reasoning）**和**执行（Acting）**两个交替进行的阶段。

### 2.1 推理-执行循环

```
用户输入
    ↓
┌───────────────────────────────────────────────────────┐
│                    推理阶段 (Reasoning)                │
│  ┌─────────────────────────────────────────────────┐  │
│  │  模型分析用户意图，决定下一步行动                 │  │
│  │  - 需要调用工具？→ 生成工具调用                  │  │
│  │  - 直接回答？→ 生成文本响应                      │  │
│  └─────────────────────────────────────────────────┘  │
└───────────────────────────────────────────────────────┘
    ↓ 决定执行工具
┌───────────────────────────────────────────────────────┐
│                    执行阶段 (Acting)                    │
│  ┌─────────────────────────────────────────────────┐  │
│  │  调用工具执行具体操作                             │  │
│  │  - 读取文件、执行命令、搜索内容等                │  │
│  │  - 返回执行结果给推理阶段                        │  │
│  └─────────────────────────────────────────────────┘  │
└───────────────────────────────────────────────────────┘
    ↓ 结果反馈
    ↓ 继续推理或返回响应
循环迭代直到任务完成
```

### 2.2 源码分析

**源码路径**: `src/qwenpaw/agents/react_agent.py`

```python
# QwenPawAgent 继承自 ReActAgent，覆盖了核心推理和执行方法
class QwenPawAgent(ToolGuardMixin, ReActAgent):
    """QwenPaw 核心智能体类"""

    async def _reasoning(self, tool_choice=None) -> Msg:
        """推理阶段：决定下一步行动"""
        # 1. 主动过滤层：模型不支持多模态时移除媒体块
        if not get_active_model_supports_multimodal():
            self._proactive_strip_media_blocks()

        # 2. 被动回退层：调用失败时移除媒体块并重试
        try:
            msg = await super()._reasoning(tool_choice=tool_choice)
        except Exception as e:
            if self._is_bad_request_or_media_error(e):
                self._set_formatter_media_strip(True)
                msg = await super()._reasoning(tool_choice=tool_choice)

        # 3. 自动继续：文本响应但任务未完成时继续推理
        return await self._auto_continue_if_text_only(msg, tool_choice)
```

## 3. 核心组件

### 3.1 Agent（智能体）

Agent 是智能体的核心抽象，负责协调推理、记忆和工具使用。

```python
class QwenPawAgent(ToolGuardMixin, ReActAgent):
    """
    QwenPaw 智能体核心类

    MRO (方法解析顺序):
    QwenPawAgent → ToolGuardMixin → ReActAgent → Agent
    """

    def __init__(self, agent_config: "AgentProfileConfig", ...):
        # 1. 配置提取
        self._running_config = agent_config.running

        # 2. 工具包创建
        self.toolkit = self._create_toolkit()

        # 3. 记忆管理器
        self.memory_manager = self._setup_memory_manager()

        # 4. 钩子注册
        self._register_hooks()
```

**核心职责**:
- 管理智能体的生命周期
- 协调推理和执行循环
- 处理工具调用的安全拦截

### 3.2 Runner（执行器）

Runner 负责请求处理和命令路由，是智能体与外部系统的桥梁。

**源码路径**: `src/qwenpaw/app/runner/runner.py`

```python
class AgentRunner:
    """负责请求处理和命令路由"""

    async def query_handler(self, request: AgentRequest) -> AsyncGenerator:
        # 1. 审批检查
        await self._resolve_pending_approval(request)

        # 2. 命令检测（/new, /compact, /clear 等）
        if self.command_handler.is_command(query):
            return await self.command_handler.handle_command(query)

        # 3. 创建/获取智能体实例
        agent = await self._get_or_create_agent(request)

        # 4. 执行推理-执行循环
        async for msg in agent.reply(request):
            yield msg
```

**请求处理流程**:
```
AgentRequest 输入
    ↓
1. Tool-Guard 审批检查
    ↓
2. 命令检测 (/new, /compact, /clear, /stop 等)
    ↓
3. Mission 模式检查
    ↓
4. 智能体创建/获取
    ↓
5. 执行模式（标准或 Mission）
    ↓
6. 流式 Yield 响应
    ↓
7. 会话持久化
```

### 3.3 Memory（记忆）

```python
class BaseMemoryManager(ABC):
    """记忆管理器抽象接口"""

    @abstractmethod
    async def compact_memory(self, messages: list[Msg], ...) -> str:
        """压缩对话记忆"""

    @abstractmethod
    async def memory_search(self, query: str, ...) -> ToolResponse:
        """搜索记忆"""

    @abstractmethod
    async def summary_memory(self, messages: list[Msg]) -> str:
        """生成记忆摘要"""
```

```
    │       ├─→ 技能加载 (_register_skills)

    │

    │       └─→ 包装 RetryChatModel + TokenRecordingModelWrapper
    │
    ├─→ 父类初始化 (ReActAgent)
    │       └─→ 初始化 memory, max_iters
    │
    ├─→ 记忆管理器初始化 (_setup_memory_manager)
    │       └─→ ReMeLightMemoryManager
    │
    ├─→ 命令处理器初始化 (CommandHandler)
    │
    └─→ 钩子注册 (_register_hooks)
            ├─→ BootstrapHook (首次引导)
            └─→ MemoryCompactionHook (上下文压缩)
```

### 4.2 请求处理流程

```
接收请求 (AgentRequest)
    ↓
_runner.query_handler()
    ↓
1. 审批检查 → 解决挂起的工具审批
    ↓
2. 命令检测 → 解析 /new, /compact 等命令
    ↓
3. Skill 注入 → 处理 /skill_name 技能调用
    ↓
4. 智能体执行 → agent.reply() 执行 ReAct 循环
    ↓
5. 流式响应 → yield Msg 给客户端
    ↓
6. 会话持久化 → 保存对话历史
```

## 5. 钩子系统（Hooks）

钩子系统允许在智能体核心方法前后注入自定义逻辑，实现无侵入式扩展。

**源码路径**: `src/qwenpaw/agents/hooks/`

### 5.1 钩子类型

| 钩子类型 | 触发时机 | 源码位置 |
|----------|----------|----------|
| `pre_reasoning` | `_reasoning()` 执行前 | `hooks/bootstrap.py` |
| `post_reasoning` | `_reasoning()` 执行后 | - |
| `pre_acting` | `_acting()` 执行前 | - |
| `post_acting` | `_acting()` 执行后 | - |

### 5.2 内置钩子

**BootstrapHook**: 首次交互时检测 `BOOTSTRAP.md` 并插入引导文本。

**MemoryCompactionHook**: 上下文窗口接近上限时自动压缩旧消息。

```python
class MemoryCompactionHook:
    """上下文满时自动压缩记忆"""

    _REENTRANCY_ATTR = "_memory_compact_hook_running"

    async def __call__(self, agent, kwargs) -> dict | None:
        # 重入保护：防止元类多层包装导致重复执行
        if getattr(agent, self._REENTRANCY_ATTR, False):
            return None
        setattr(agent, self._REENTRANCY_ATTR, True)
        try:
            # 检查 token 余量
            # 执行压缩
            ...
        finally:
            setattr(agent, self._REENTRANCY_ATTR, False)
        return None
```

### 5.3 钩子执行流程

```
用户消息
    ↓
reply() ←─ pre_reply hooks
    ↓
┌───────────────────────────────────────┐
│  _reasoning()                         │
│      ↑ pre_reasoning hooks            │
│      ↓                                │
│  [BootstrapHook]                      │
│  [MemoryCompactionHook]               │
│      ↓                                │
│  _reasoning 核心推理                   │
│      ↓                                │
│  _acting() ← pre_acting hooks        │
│      ↓                                │
│  [执行工具]                           │
│      ↓ post_acting hooks             │
└───────────────────────────────────────┘
    ↓
post_reasoning hooks
    ↓
reply() 返回 ← post_reply hooks
    ↓
响应消息
```

## 7. 常见问题

| 问题 | 解答 |
|------|------|
| ReAct 模式和其他模式有什么区别？ | ReAct 强调推理与执行的交替迭代，模型不仅生成推理步骤，还会根据需要调用工具执行操作 |
| ToolGuardMixin 的作用是什么？ | 在工具执行前进行安全检查，拦截高风险操作（如删除文件、执行危险命令） |
| 记忆压缩是什么时候触发的？ | 当上下文 token 数超过 `memory_compact_threshold` 配置值时，由 MemoryCompactionHook 自动触发 |
| 如何自定义工具？ | 使用 `@function_tool` 装饰器注册工具函数，参考 `src/qwenpaw/agents/tools/` 中的示例 |
| 钩子和装饰器有什么区别？ | 钩子通过元类自动注入，在原方法前后自动触发；装饰器需要显式调用包装函数 |
