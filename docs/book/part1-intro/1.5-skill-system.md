## 1. 技能系统概述

### 1.1 什么是技能

技能（Skill）是 QwenPaw 扩展智能体能力的模块。每个技能是一个独立功能模块，可以让智能体执行特定任务，如处理 PDF 文档、创建 Word 文件、执行浏览器自动化等。

```
用户请求 → 技能触发 → 智能体调度 → 任务执行 → 返回结果
```

### 1.2 技能 vs 工具

| 对比项 | 工具 (Tool) | 技能 (Skill) |
|--------|-------------|--------------|
| 粒度 | 原子操作 | 复杂任务 |
| 调用方式 | 直接调用 | 通过 Agent 调度 |
| 组合性 | 单一功能 | 可包含多个脚本 |
| 示例 | file_read, web_search | pdf, docx, summarize |

### 1.3 技能来源

技能可以从多个来源安装：

| 来源 | 示例 | 说明 |
|------|------|------|
| 内置 | pdf, docx, xlsx | QwenPaw 自带 |
| ClawHub | clawhub.ai | 主要技能市场 |
| GitHub | github.com/user/repo | 直接从 Git 仓库安装 |
| LobeHub | market.lobehub.com | LobeHub 市场 |

## 2. 内置技能

### 2.1 常用内置技能

| 技能 | 功能 | 触发词 |
|------|------|--------|
| pdf | PDF 文档处理（读取、写入、合并、分割） | `/pdf` |
| docx | Word 文档创建与编辑 | `/docx` |
| xlsx | Excel 电子表格操作 | `/xlsx` |
| pptx | PowerPoint 演示文稿 | `/pptx` |
| browser_visible | 可见浏览器自动化 | `/browser` |
| file_reader | 文件读取和摘要 | `/file_reader` |
| summarize | 文本摘要 | `/summarize` |
| translate | 翻译 | `/translate` |

### 2.2 查看可用技能

```bash
# 列出所有可用技能
qwenpaw skills list

# 查看技能详情
qwenpaw skills info pdf
```

### 2.3 使用内置技能

在对话中直接使用技能触发词：

```
/pdf 请帮我总结这个文档的内容

/docx 创建一个包含会议纪要的 Word 文档

/xlsx 分析这个销售数据表格
```

### 2.4 技能触发语法

| 语法 | 示例 | 说明 |
|------|------|------|
| `/skill_name input` | `/pdf 分析这份文件` | 调用技能并传递输入 |
| `/skill_name` | `/pdf` | 仅显示技能信息 |
| `[skill name] input` | `[file reader] ./notes.txt` | 空格名称格式 |

## 3. 安装和管理技能

### 3.1 安装技能

```bash
# 从内置技能池安装
qwenpaw skills install pdf

# 从 ClawHub 安装
qwenpaw skills install my_skill --from-hub clawhub

# 从 GitHub 安装
qwenpaw skills install my_skill --from-url https://github.com/user/repo
```

### 3.2 管理技能

```bash
# 启用技能
qwenpaw skills enable pdf

# 禁用技能
qwenpaw skills disable pdf

# 查看技能状态
qwenpaw skills status
```

## 4. 自定义技能

### 4.1 技能结构

每个技能是一个独立目录，包含以下文件：

```
my_skill/
├── SKILL.md           # 技能描述（必需）
├── references/        # 参考文档（可选）
│   └── guide.md
└── scripts/          # Python 脚本（可选）
    ├── main.py
    └── utils.py
```

### 4.2 SKILL.md 基本格式

技能的核心是 `SKILL.md` 文件，采用 Frontmatter 格式：

```markdown
---
name: my_skill
description: "这是一个自定义技能，用于处理 XYZ 任务..."
metadata:
  qwenpaw:
    emoji: "🔧"
---

# 我的技能

## 何时使用

当用户需要处理 XYZ 任务时使用此技能。

## 使用方法

### 脚本调用

```bash
python scripts/main.py
```

## 注意事项

- 需要配置 API_KEY 环境变量
```

### 4.3 技能实现示例

**源码路径**: `src/qwenpaw/agents/skills/hello_skill/`

```python
# scripts/hello.py
#!/usr/bin/env python3
"""简单技能示例"""

import sys

def main():
    name = sys.argv[1] if len(sys.argv) > 1 else "World"
    print(f"Hello, {name}! This is a custom skill.")

if __name__ == "__main__":
    main()
```

## 5. 实战：创建第一个技能

### 5.1 创建技能目录

```bash
mkdir -p my_first_skill/{references,scripts}
```

### 5.2 编写 SKILL.md

```markdown
---
name: hello
description: "一个简单的问候技能"
metadata:
  qwenpaw:
    emoji: "👋"
---

# Hello Skill

## 功能

向用户发送友好的问候。

## 使用方式

```
/hello
/hello Alice
```
```

### 5.3 编写脚本

```python
#!/usr/bin/env python3
# scripts/say_hello.py

import sys

def main():
    name = sys.argv[1] if len(sys.argv) > 1 else "Friend"
    messages = [
        f"Hello, {name}! Have a great day!",
        f"Hi there, {name}!",
        f"Greetings, {name}!",
    ]
    # 简单轮换
    idx = hash(name) % len(messages)
    print(messages[idx])

if __name__ == "__main__":
    main()
```

### 5.4 安装和使用

```bash
# 安装技能
qwenpaw skills install ./my_first_skill

# 在对话中使用
/hello
/hello Alice
```

## 6. 常见问题

| 问题 | 解答 |
|------|------|
| 技能无法激活 | 检查依赖是否安装：`qwenpaw doctor --check skills` |
| 技能无响应 | 查看日志：`qwenpaw logs | grep skill` |
| 安装失败 | 检查网络连接，或使用 `--from-path` 本地安装 |
| 技能冲突 | 使用 `qwenpaw skills list` 查看是否有同名技能 |
