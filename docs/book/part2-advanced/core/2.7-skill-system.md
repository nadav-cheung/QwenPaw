## 1. 技能系统架构

### 1.1 设计理念

QwenPaw 的 Skills 系统旨在为智能体提供**可插拔、可扩展**的能力增强机制。核心设计理念包括：

| 特性 | 说明 |
|------|------|
| **模块化** | 每个 Skill 是独立的目录包，包含完整的描述和脚本 |
| **安全优先** | 所有 Skill 必须通过安全扫描才能激活 |
| **多渠道支持** | Skill 可配置在特定渠道（console、discord、telegram 等）生效 |
| **版本管理** | 支持内置 Skill 的版本追踪和更新 |
| **全球化** | 支持多语言 Skill（en/zh）变体 |

### 1.2 核心组件

```
SkillManager → SkillRegistry → SkillLoader → SkillExecutor
```

| 组件 | 文件路径 | 职责 |
|------|----------|------|
| `SkillService` | `agents/skills_manager.py` | 工作空间级别的 Skill 生命周期管理 |
| `SkillPoolService` | `agents/skills_manager.py` | 共享 Skill 池管理 |
| `SkillScanner` | `security/skill_scanner/scanner.py` | 安全扫描编排器 |
| `PatternAnalyzer` | `security/skill_scanner/analyzers/pattern_analyzer.py` | 正则签名模式匹配分析器 |
| `SkillsHub` | `agents/skills_hub.py` | Skill 市场客户端 |

### 1.3 类图

**源码路径**: `src/qwenpaw/agents/skills/`

```
BaseSkill (抽象基类)
├── EchoSkill
├── BrowserSkill

```

### 1.4 技能来源与优先级

| 优先级 | 来源 | 说明 |
|--------|------|------|
| 1 | 内置 (Builtin) | 系统内置的原生技能 (pdf-zh, pdf-en, ...) |
| 2 | 技能池 (Pool) | 用户安装的共享技能 |
| 3 | 工作空间 (Workspace) | 当前项目本地技能 |

当多个来源提供同名技能时，系统按优先级选择。

## 2. BaseSkill 抽象

### 2.1 基类定义

```python
from abc import ABC, abstractmethod
from dataclasses import dataclass
from typing import TYPE_CHECKING

if TYPE_CHECKING:
    from qwenpaw.agents.agent import QwenPawAgent

@dataclass
class SkillResult:
    """技能执行结果"""
    success: bool
    output: str = ""
    error: str = ""
    metadata: dict = None

class BaseSkill(ABC):
    """技能抽象基类"""

    name: str  # 技能名称
    description: str  # 技能描述
    version: str = "1.0.0"  # 版本

    @abstractmethod
    async def execute(self, context: "SkillContext") -> SkillResult:
        """执行技能的核心方法"""
        pass

    async def on_register(self, agent: "QwenPawAgent") -> None:
        """技能注册时的回调"""
        pass

    async def on_unregister(self) -> None:
        """技能注销时的回调"""
        pass
```

## 3. 技能注册

### 3.1 SkillRegistry

**源码路径**: `src/qwenpaw/agents/skills/registry.py`

```python
class SkillRegistry:
    """技能注册表 - 核心的类级别注册机制"""

    _skills: dict[str, type[BaseSkill]] = {}
    _aliases: dict[str, str] = {}  # 别名映射

    @classmethod
    def register(cls, name: str, skill_class: type[BaseSkill]) -> None:
        """注册技能类

        Args:
            name: 技能名称 (唯一标识)
            skill_class: 技能类 (必须是 BaseSkill 的子类)
        """
        if name in cls._skills:
            raise ValueError(f"Skill '{name}' already registered")
        cls._skills[name] = skill_class

    @classmethod
    def get(cls, name: str) -> type[BaseSkill] | None:
        """获取技能类

        Args:
            name: 技能名称或别名

        Returns:
            技能类，如果不存在返回 None
        """
        # 检查别名
        if name in cls._aliases:
            name = cls._aliases[name]
        return cls._skills.get(name)

    @classmethod
    def list_all(cls) -> list[str]:
        """列出所有已注册的技能名称"""
        return list(cls._skills.keys())

    @classmethod
    def alias(cls, alias_name: str, skill_name: str) -> None:
        """为技能添加别名"""
        cls._aliases[alias_name] = skill_name
```

### 3.2 自动注册装饰器

```python
def register_skill(name: str):
    """技能注册装饰器

    用法:
        @register_skill("my_skill")
        class MySkill(BaseSkill):
            ...
    """
    def decorator(cls: type[BaseSkill]) -> type[BaseSkill]:
        SkillRegistry.register(name, cls)
        return cls
    return decorator

# 使用示例
@register_skill("my_skill")

    name = "my_skill"
    description = "示例技能"

    async def execute(self, context: SkillContext) -> SkillResult:
        return SkillResult(success=True, output="Done!")
```

## 4. 技能扫描

### 4.1 扫描流程

**源码路径**: `src/qwenpaw/agents/skills/scanner.py`

```python
class SkillScanner:
    """扫描并加载技能"""

    def __init__(self, policy: ScanPolicy | None = None):
        self.policy = policy or ScanPolicy()

    async def scan(self, paths: list[str]) -> list[BaseSkill]:
        """扫描目录中的技能"""
        skills = []
        for path in paths:
            skill_dir = Path(path)
            if not skill_dir.exists():
                continue

            # 查找所有包含 SKILL.md 的子目录
            for skill_path in skill_dir.rglob("SKILL.md"):
                skill = await self._load_skill(skill_path.parent)
                if skill:
                    skills.append(skill)

        return skills

    async def _load_skill(self, skill_dir: Path) -> BaseSkill | None:
        """加载单个技能"""
        # 1. 验证 SKILL.md 存在
        skill_md = skill_dir / "SKILL.md"
        if not skill_md.exists():
            return None

        # 2. 解析元数据
        metadata = self._parse_skill_md(skill_md)

        # 3. 安全扫描
        if not await self._security_check(skill_dir):
            return None

        # 4. 动态加载技能类
        return self._instantiate_skill(metadata, skill_dir)
```

### 5.2 PatternAnalyzer 实现

**源码路径**: `security/skill_scanner/analyzers/pattern_analyzer.py`

```python
class PatternAnalyzer(BaseAnalyzer):
    """基于 YAML 正则签名的模式匹配分析器"""

    def __init__(self, rules_path: Path | None = None, *, policy: ScanPolicy | None = None) -> None:
        super().__init__(name="pattern", policy=policy)
        loader = RuleLoader(rules_path)
        self._rules = loader.load_rules()

    def analyze(self, skill_dir: Path, files: list[SkillFile],
                *, skill_name: str | None = None) -> list[Finding]:
        findings: list[Finding] = []
        for sf in files:
            content = sf.read_content()
            is_doc = self.policy.is_doc_path(sf.relative_path)
            applicable = self._get_rules(sf.file_type)

            for rule in applicable:
                if self.policy.is_rule_disabled(rule.id):
                    continue

                matches = rule.scan_content(content, file_path=sf.relative_path)
                for match in matches:
                    severity = rule.severity
                    override = self.policy.get_severity_override(rule.id)
                    if override:
                        severity = Severity(override)

                    findings.append(Finding(
                        rule_id=rule.id,
                        title=rule.title,
                        severity=severity,
                        file_path=sf.relative_path,
                        line_number=match.line_number,
                        remediation=rule.remediation,
                    ))

        return findings
```

```markdown
## 何时使用

## 使用方法

### 基本调用

```

### 6.3 创建技能实现

**源码路径**: `src/qwenpaw/agents/skills/api_processor.py`

```python
import os
import json
import subprocess
from typing import Any

from .base import BaseSkill, SkillContext, SkillResult

class ApiProcessorSkill(BaseSkill):
    """API 处理器技能"""

    name = "api_processor"
    description = "API 数据处理器 - 调用外部 API 并处理响应数据"
    version = "1.0.0"

    async def execute(self, context: SkillContext) -> SkillResult:
        try:
            # 解析输入
            parts = context.user_input.split(maxsplit=1)
            if len(parts) < 1:
                return SkillResult(
                    success=False,
                    error="用法: /api_processor <method> <path> [body]"
                )

            method = parts[0].upper()
            path = parts[1] if len(parts) > 1 else "/"

            # 获取配置
            endpoint = os.environ.get("API_ENDPOINT", "")
            token = os.environ.get("API_TOKEN", "")

            if not endpoint:
                return SkillResult(success=False, error="API_ENDPOINT 未配置")

            # 构建请求
            url = f"{endpoint.rstrip('/')}/{path.lstrip('/')}"
            headers = ["-H", f"Authorization: Bearer {token}"] if token else []

            # 执行请求
            cmd = ["curl", "-s", "-X", method, url] + headers
            result = subprocess.run(cmd, capture_output=True, text=True, timeout=30)

            if result.returncode != 0:
                return SkillResult(success=False, error=result.stderr)

            # 解析响应
            try:
                data = json.loads(result.stdout)
                output = json.dumps(data, indent=2, ensure_ascii=False)
            except json.JSONDecodeError:
                output = result.stdout[:1000]

            return SkillResult(
                success=True,
                output=output,
                metadata={"url": url, "method": method}
            )

        except subprocess.TimeoutExpired:
            return SkillResult(success=False, error="请求超时")
        except Exception as e:
            return SkillResult(success=False, error=str(e))

    async def on_register(self, agent) -> None:
        """注册时检查依赖"""
        endpoint = os.environ.get("API_ENDPOINT")
        if not endpoint:
            agent.logger.warning(
                f"Skill '{self.name}' 需要配置 API_ENDPOINT 环境变量"
            )
```

## 7. 设计意图

### 7.1 为什么要技能化

| 价值 | 说明 |
|------|------|
| **可组合性** | 智能体可以按需加载不同技能，灵活应对多变的任务需求 |
| **职责分离** | 技能作为独立模块，核心系统无需了解具体实现细节 |
| **可测试性** | 每个技能可以独立开发、测试和部署 |
| **可分享性** | 通过 SKILL.md 标准化描述，技能易于分享和复用 |
| **安全性** | 统一的安全扫描机制确保所有技能都经过验证 |

### 7.2 权衡取舍

| 维度 | 灵活性 | 安全性 |
|------|--------|--------|
| **动态加载** | 高 - 可运行时添加新技能 | 低 - 需要额外安全扫描 |
| **静态注册** | 中 - 需要重启生效 | 高 - 启动时验证 |
| **外部来源** | 高 - 支持 Hub 扩展 | 中 - 依赖扫描质量 |
| **内置技能** | 低 - 不可修改 | 高 - 经过充分测试 |

### 7.3 扩展点

| 扩展点 | 说明 |
|--------|------|
| 自定义分析器 | 实现 `BaseAnalyzer` 接口添加新的扫描逻辑 |
| 新数据格式 | 支持除 YAML 外的其他配置文件格式 |
| 技能市场 | 实现 `SkillsHub` 接口接入新的 Hub 源 |
