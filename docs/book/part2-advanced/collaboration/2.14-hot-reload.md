## 1. 热重载概述

### 1.1 为什么需要热重载

传统配置管理要求在修改配置后重启服务才能生效，这会导致：
- **服务中断**：正在处理的任务被终止
- **用户体验差**：用户请求失败
- **运维成本高**：频繁变更配置需要反复重启

热重载允许运行时动态更新配置，在不中断服务的情况下使配置变更立即生效。

## 2. AgentConfigWatcher — 核心监听器

### 2.1 设计理念

**源码路径**: `src/qwenpaw/app/agent_config_watcher.py:43`

AgentConfigWatcher 采用**轮询 + 哈希快速拒绝**的双层检测机制：

```
┌─────────────────────────────────────────────────────────────┐
│                    双层检测机制                              │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  第一层：mtime 轮询（O(1)）                                    │
│  ┌─────────────────────────────────────────────────────┐    │
│  │  stat().st_mtime ──▶ 是否变化？                      │    │
│  └─────────────────────────────────────────────────────┘    │
│              │ mtime 变化         │ mtime 未变化            │
│              ▼                    ▼                         │
│  第二层：哈希比较（O(1)）      快速跳过                       │
│  ┌─────────────────────────────────────────────────────┐    │
│  │  hash(config) ──▶ 是否变化？                          │    │
│  └─────────────────────────────────────────────────────┘    │
│              │ 真正变化           │ 无变化                   │
│              ▼                    ▼                         │
│        触发热重载              快速跳过                       │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

这种设计的**核心优势**：
- **mtime 比较**：仅需一次系统调用，无需解析文件内容
- **哈希比较**：O(1) 时间复杂度，避免深比较的性能损失

### 2.2 核心类实现

```python
# src/qwenpaw/app/agent_config_watcher.py:43
class AgentConfigWatcher:
    """轮询 agent.json mtime 并自动重载变更的配置。

    此监视器是 agent 作用域的，监视特定 agent 的
    workspace/agent.json 文件的配置文件变更。
    """

    def __init__(
        self,
        agent_id: str,
        workspace_dir: Path,
        channel_manager: Any,
        cron_manager: Any = None,
        poll_interval: float = DEFAULT_POLL_INTERVAL,  # 2.0 秒
    ):
        self._agent_id = agent_id
        self._workspace_dir = workspace_dir
        self._config_path = workspace_dir / "agent.json"  # 监控路径
        self._channel_manager = channel_manager
        self._cron_manager = cron_manager
        self._poll_interval = poll_interval
        
        # 状态
        self._last_mtime: float = 0
        self._last_channels_hash: int = 0
        self._last_heartbeat_hash: int = 0
        self._last_memory_job_hash: int = 0
```

### 2.3 哈希辅助函数

```python
# src/qwenpaw/app/agent_config_watcher.py:28
def _heartbeat_hash(hb: Optional[HeartbeatConfig]) -> int:
    """心跳配置的哈希，用于变更检测。"""
    if hb is None:
        return hash("None")
    return hash(str(hb.model_dump(mode="json")))

def _memory_job_hash(memory_summary: Optional[Any]) -> int:
    """记忆任务配置的哈希，用于变更检测。"""
    if memory_summary is None:
        return hash("None")
    cron_expr = getattr(memory_summary, "dream_cron", "")
    return hash(str(cron_expr))
```

### 2.4 轮询循环

```python

async def _poll_loop(self) -> None:
    """主轮询循环"""
    while True:
        try:
            await asyncio.sleep(self._poll_interval)  # 默认 2.0s
```

### 2.5 变更检测

```python
# src/qwenpaw/app/agent_config_watcher.py:288
async def _check(self) -> None:
    """检查配置变更并在需要时重载"""
    # 第一层：mtime 检测
    try:
        mtime = self._config_path.stat().st_mtime
    except FileNotFoundError:
        return

    if mtime == self._last_mtime:
        return  # mtime 未变化，快速跳过

    self._last_mtime = mtime  # 更新 mtime

    # 加载新配置
    try:
        agent_config = load_agent_config(self._agent_id)
    except Exception:
        logger.exception("Failed to load config")
        return

    # 第二层：哈希检测
    new_channels_hash = self._channels_hash(agent_config.channels)
    if new_channels_hash != self._last_channels_hash:
        await self._apply_channel_changes(agent_config)

    new_hb_hash = _heartbeat_hash(agent_config.heartbeat)
    if new_hb_hash != self._last_heartbeat_hash:
        await self._apply_heartbeat_change(agent_config)
```

## 3. 配置变更处理

### 3.1 渠道热重载 — 克隆替换策略

**核心原则**：不修改现有实例，而是克隆新实例后原子替换。

```python
# src/qwenpaw/app/agent_config_watcher.py:191
async def _apply_channel_changes(self, agent_config: Any) -> None:
    """diff 渠道并重载变更的渠道"""
    if not agent_config.channels:
        return

    new_hash = self._channels_hash(agent_config.channels)
    if new_hash == self._last_channels_hash:
        return  # 哈希未变，快速跳过

    # 遍历可用渠道，检测变更
    for name in get_available_channels():
        new_ch = getattr(agent_config.channels, name, None)
        old_ch = getattr(self._current_channels, name, None)
        
        if self._channel_dump(new_ch) != self._channel_dump(old_ch):
            await self._reload_one_channel(name, new_ch, agent_config.channels)
```

**单渠道重载实现**：

```python
# src/qwenpaw/app/agent_config_watcher.py:162
async def _reload_one_channel(
    self, name: str, new_ch: Any, new_channels: Any, old_ch: Any
) -> None:
    """重载单个渠道，失败时回退"""
    try:
        old_channel = await self._channel_manager.get_channel(name)
        new_channel = old_channel.clone(new_ch)  # 用新配置克隆
        await self._channel_manager.replace_channel(new_channel)
        logger.info(f"channel '{name}' reloaded")
    except Exception:
        logger.exception(f"failed to reload channel '{name}'")
        setattr(new_channels, name, old_ch)  # 失败时回退
```

### 3.2 原子替换 — ChannelManager.replace_channel

```python
# src/qwenpaw/app/channels/manager.py:704
async def replace_channel(self, new_channel: BaseChannel) -> None:
    """按名称替换单个渠道"""
    # 1) 在锁外启动新渠道（可能较慢）
    await new_channel.start()

    # 2) 在锁内交换 + 停止旧渠道
    async with self._lock:
        for i, ch in enumerate(self.channels):
            if ch.channel == new_channel.channel:
                self.channels[i] = new_channel  # 原子替换
                await old_channel.stop()  # 优雅停止
```

**锁外启动的关键优势**：
- 减少锁持有时间
- 允许并发操作
- 降低死锁风险

### 3.3 心跳热重载

```python
# src/qwenpaw/app/agent_config_watcher.py:231
async def _apply_heartbeat_change(self, agent_config: Any) -> None:
    """更新心跳哈希并在变更时重新调度"""
    new_hb_hash = _heartbeat_hash(agent_config.heartbeat)
    if new_hb_hash != self._last_heartbeat_hash:
        self._last_heartbeat_hash = new_hb_hash
        try:
            await self._cron_manager.reschedule_heartbeat()
            logger.info("heartbeat rescheduled")
        except Exception:
            logger.exception("failed to reschedule heartbeat")
```

## 4. 服务复用机制

### 4.1 热重载触发 — schedule_agent_reload

**源码路径**: `src/qwenpaw/app/utils.py:17`

当通过 API 更新配置时，使用异步后台任务触发重载：

```python
# src/qwenpaw/app/utils.py:17
def schedule_agent_reload(request: "Request", agent_id: str) -> None:
    """在后台调度 Agent 重载（非阻塞）。"""
    manager = request.app.state.multi_agent_manager

    async def reload_in_background():
        try:
            await manager.reload_agent(agent_id)
        except Exception as e:
            logger.warning(f"Background reload failed: {e}")

    asyncio.create_task(reload_in_background())  # 非阻塞
```

**为什么使用 `asyncio.create_task` 而不是直接 await？**
- API 响应无需等待重载完成
- 用户立即得到成功响应
- 重载在后台异步进行

### 4.2 MultiAgentManager.reload_agent

```python
# 重载完整流程
async def reload_agent(self, agent_id: str) -> None:
    # 1. 获取当前 workspace
    workspace = self._workspaces.get(agent_id)

    # 2. 获取可复用服务（停止旧 workspace 前）
    old_reusable = workspace.service_manager.get_reusable_services()

    # 3. 停止旧 workspace（非 final 服务）
    await workspace.service_manager.stop_all(final=False)

    # 4. 重新加载配置
    agent_config = load_agent_config(agent_id)

    # 5. 重建 workspace
    new_workspace = await self._create_workspace(agent_id, agent_config)

    # 6. 复用可复用服务
    for name, instance in old_reusable.items():
        await new_workspace.service_manager.set_reusable(name, instance)

    # 7. 启动新 workspace
    await new_workspace.service_manager.start_all()

    # 8. 更新 workspaces 字典
    self._workspaces[agent_id] = new_workspace
```

```python
# src/qwenpaw/app/workspace/service_manager.py:94
async def set_reusable(self, name: str, instance: Any) -> None:
    """将服务标记为从旧 workspace 复用。"""
    if name not in self.descriptors:
        return

    descriptor = self.descriptors[name]
    if not descriptor.reusable:
        return  # 非可复用服务，不处理

    self.services[name] = instance
    self.reused_services.add(name)

    # 调用 reload_func（如果提供）
    if descriptor.reload_func is not None:
        result = descriptor.reload_func(self.workspace, instance)
        if asyncio.iscoroutine(result):
            await result
```

## 5. 回滚机制

### 5.1 失败回滚原理

当配置变更失败时，系统自动回退到旧配置，保证服务连续性：

```python
async def _reload_one_channel(
    self, name: str, new_ch: Any, new_channels: Any, old_ch: Any
) -> None:
    """重载单个渠道，失败时回退"""
    try:
        old_channel = await self._channel_manager.get_channel(name)
        new_channel = old_channel.clone(new_ch)
        await self._channel_manager.replace_channel(new_channel)
    except Exception:
        logger.exception(f"failed to reload channel '{name}'")
        setattr(new_channels, name, old_ch)  # 回退到旧配置
```

### 6.2 哈希合并优化

热重载中的"合并"实际上是通过**哈希比较**来决策是否需要合并：

```python
def _channels_hash(self, channels: Any) -> int:
    """计算渠道配置的哈希"""
    if not channels:
        return hash("None")
    return hash(str(channels.model_dump(mode="json")))
```

只有当哈希变化时才进行实际的 diff 和合并操作，避免每次轮询都执行昂贵的合并计算。

## 8. 设计意图分析

### 8.1 轮询 vs 事件驱动

**当前实现：轮询（Polling）**

| 方案 | 原理 | 延迟 | 资源消耗 | 实现复杂度 |
|------|------|------|----------|-----------|
| Polling（当前） | 定时检查 mtime | 轮询间隔 | 低 | 简单 |
| inotify/FSEvents | 内核事件通知 | 毫秒级 | 极低 | 中等 |
| Watchdog 库 | 跨平台封装 | 毫秒级 | 低 | 中等 |

**选择轮询的原因**：
- **跨平台可靠**：不依赖特定操作系统的文件监控 API
- **实现简单**：无需额外依赖
- **足够高效**：2 秒间隔对配置变更场景足够

### 8.2 锁外启动的权衡

```python
# 当前实现
await new_channel.start()      # 锁外（可能较慢）
async with self._lock:         # 锁内（快速）
    self.channels[i] = new_channel
    await old_channel.stop()
```

**优势**：
- 锁持有时间最小化
- 新渠道启动期间其他操作不受阻塞
- 降低死锁风险

**权衡**：
- 短时间内存在两个渠道实例
- 内存使用略有增加

### 8.3 服务复用 vs 完全重建

| 方案 | 优势 | 劣势 |
|------|------|------|
| 完全重建 | 状态干净 | 数据丢失、服务中断 |
| 服务复用 | 零停机、数据保留 | 需要正确设计 reload_func |
