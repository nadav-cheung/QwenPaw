## 1. 密钥管理概述

### 1.1 为什么需要密钥管理

QwenPaw 需要管理多种密钥：API Key、数据库密码、TLS 证书、签名密钥等。这些密钥一旦泄露，将导致严重的安全问题。

### 1.2 密钥类型

| 类型 | 说明 | 示例 |
|------|------|------|
| API Key | 服务密钥 | OpenAI API Key |
| Database | 数据库凭证 | PostgreSQL 密码 |
| TLS Cert | 传输加密 | SSL 证书 |
| Signing | 签名密钥 | JWT 签名 |

### 1.3 QwenPaw 的加密策略

QwenPaw 使用 **Fernet** 对称加密方案：
- **算法**：AES-128-CBC + HMAC-SHA256
- **主密钥长度**：32 字节（256 位）
- **密文格式**：`ENC:<base64-ciphertext>`

## 2. SecretStore

### 2.1 核心类

**源码路径**: `src/qwenpaw/security/secret_store.py`

```python
class SecretStore:
    """密钥存储核心类"""

    def __init__(self, master_key: bytes = None):
        self.store: dict[str, EncryptedSecret] = {}
        self._master_key = master_key or self._derive_master_key()

    def set(self, key: str, value: str, category: str = "default") -> None:
        """存储密钥"""
        ciphertext, nonce, tag = self._encrypt(value)
        self.store[key] = EncryptedSecret(
            key=key,
            ciphertext=ciphertext,
            nonce=nonce,
            tag=tag,
            version=1,
            created_at=datetime.now(),
            updated_at=datetime.now()
        )

    def get(self, key: str) -> str:
        """获取密钥"""
        secret = self.store.get(key)
        if not secret:
            raise KeyError(f"Key not found: {key}")
        return self._decrypt(secret.ciphertext, secret.nonce, secret.tag)

    def delete(self, key: str) -> None:
        """删除密钥"""
        del self.store[key]
```

### 2.2 存储结构

```python

    ciphertext: bytes  # 加密后的值
    nonce: bytes  # 随机数
    tag: bytes  # 认证标签
    version: int  # 版本号

    updated_at: datetime
```

## 3. 加密机制

### 3.1 Fernet 加密

**源码路径**: `src/qwenpaw/security/secret_store.py:196`

```python
# src/qwenpaw/security/secret_store.py
_cached_fernet: Optional[object] = None
_ENC_PREFIX = "ENC:"

def _get_fernet():
    """返回由主密钥支持的缓存 Fernet 实例"""
    global _cached_fernet
    if _cached_fernet is not None:
        return _cached_fernet

    from cryptography.fernet import Fernet
    raw = _get_master_key()
    fernet_key = base64.urlsafe_b64encode(raw[:32])  # 仅使用前 32 字节
    _cached_fernet = Fernet(fernet_key)
    return _cached_fernet

def encrypt(plaintext: str) -> str:
    """加密 plaintext 并返回 ENC:<base64-ciphertext>"""
    if not plaintext:
        return plaintext
    f = _get_fernet()
    token = f.encrypt(plaintext.encode("utf-8"))
    return _ENC_PREFIX + token.decode("ascii")

def decrypt(value: str) -> str:
    """如果值带有 ENC: 前缀则解密，否则透传"""
    if not value or not value.startswith(_ENC_PREFIX):
        return value
    try:
        f = _get_fernet()
        token = value[len(_ENC_PREFIX):].encode("ascii")
        return f.decrypt(token).decode("utf-8")
    except Exception:
        logger.warning("解密失败，返回原始密文")
        return value
```

### 3.2 加密流程

```
用户输入明文 (如 "sk-abc123")
        │
        ▼
encrypt("sk-abc123")
        │
        ├─ 空字符串? → 直接返回 ""
        │
        ▼
_get_fernet() 获取 Fernet 实例
        │
        ├─ 检查 _cached_fernet 缓存
        └─ 无缓存? → 用 master_key 生成新的 Fernet
        │
        ▼
fernet.encrypt("sk-abc123".encode("utf-8"))
        │
        ▼
base64 编码 → "gAAAAABh..." (Fernet token)
        │
        ▼
返回 "ENC:" + token → "ENC:gAAAAABh..."
```

### 3.3 算法选择

| 场景 | 算法 | 说明 |
|------|------|------|
| 对称加密 | AES-128-CBC + HMAC-SHA256 | Fernet 规范，保证机密性和完整性 |
| 主密钥长度 | 32 字节 (256 位) | 足够的安全强度 |
| 密钥生成 | secrets.token_hex(32) | 密码学安全随机数 |

## 4. 四级密钥解析链

### 4.1 解析顺序

**源码路径**: `src/qwenpaw/security/secret_store.py:154`

```python
def _get_master_key() -> bytes:
    """返回 32 字节主密钥，按以下顺序解析：

    解析顺序：
    1. 进程内缓存（快速路径，无锁）
    2. OS keychain（通过 keyring）
    3. 文件 SECRET_DIR/.master_key
    4. 生成新的 → 存储到 keychain（优先）和文件（后备）
    """
    global _cached_master_key
    if _cached_master_key is not None:
        return _cached_master_key  # 步骤 1

    with _master_key_lock:
        if _cached_master_key is not None:
            return _cached_master_key

        key_hex = _try_keyring_get()  # 步骤 2
        if not key_hex:
            key_hex = _read_key_file()  # 步骤 3
            if key_hex:
                _try_keyring_set(key_hex)  # 同步 keyring

        if not key_hex:
            key_hex = _generate_master_key()  # 步骤 4
            _try_keyring_set(key_hex)
            _write_key_file(key_hex)

        _cached_master_key = bytes.fromhex(key_hex)
        return _cached_master_key
```

### 4.2 流程图

```
_get_master_key()
    │
    ├── [缓存命中] → 直接返回
    │
    └── [缓存未命中]
          │
          ▼
    ┌─────────────────┐
    │ 尝试 Keychain  │ ── 命中 → 使用 Keychain 密钥
    └────────┬────────┘
             │ 未命中
             ▼
    ┌─────────────────┐
    │ 尝试 .master_key │ ── 命中 → 使用文件密钥
    └────────┬────────┘
             │ 未命中
             ▼
    ┌─────────────────┐
    │ 生成新密钥       │
    │ 保存到 Keychain │
    │ 保存到文件      │
    └─────────────────┘
```

### 4.3 为什么不重复生成？

**问题**：如果没有双重检查锁定，多个线程可能同时检测到密钥不存在，导致重复生成。

**解决方案**：双重检查锁定（Double-Check Locking Pattern）

## 5. 双重检查锁定 (DCLP)

### 5.1 实现模式

**源码路径**: `src/qwenpaw/security/secret_store.py:116-130`

```python
_cached_master_key: Optional[bytes] = None
_master_key_lock = threading.Lock()

def _get_master_key() -> bytes:
    global _cached_master_key

    # 第一层：进程内缓存（无锁，快速路径）
    if _cached_master_key is not None:
        return _cached_master_key

    with _master_key_lock:  # 第二层：线程锁
        # 双重检查
        if _cached_master_key is not None:
            return _cached_master_key

        # ... 加载或生成密钥 ...
        _cached_master_key = bytes.fromhex(key_hex)
        return _cached_master_key
```

### 5.2 为什么需要双重检查

```
线程 A                      线程 B
   │                           │
   ├─ 第一次检查: None          │
   │                           ├─ 第一次检查: None
   │                           ├─ 获取锁
   │                           ├─ 第二次检查: None
   │                           ├─ 生成密钥...
   │                           ├─ 释放锁
   ├─ 获取锁                    │
   ├─ 第二次检查: 有值!          │
   ├─ 直接返回                   │
   │                           │
   ▼                           ▼
  不重复生成密钥              不重复生成密钥
```

**目的**：避免多个线程同时检测到密钥不存在，导致重复生成。

## 6. 主密钥管理

### 6.1 主密钥派生

**源码路径**: `src/qwenpaw/security/master_key.py`

```python
class MasterKeyManager:
    """主密钥管理"""

    def _derive_master_key(self) -> bytes:
        """从密码派生主密钥"""
        # 使用 secrets.token_hex 生成 32 字节随机密钥
        return secrets.token_hex(32).encode()
```

### 6.2 Keyring 访问

```python
_KEYRING_SERVICE = "qwenpaw"
_KEYRING_ACCOUNT = "master_key"

def _try_keyring_get() -> Optional[str]:
    """从 OS keychain 读取主密钥"""
    if _should_skip_keyring():
        return None
    try:
        import keyring
        value = keyring.get_password(_KEYRING_SERVICE, _KEYRING_ACCOUNT)
        return value or None
    except Exception:
        return None

def _try_keyring_set(key_hex: str) -> bool:
    """存储主密钥到 OS keychain"""
    if _should_skip_keyring():
        return False
    try:
        import keyring
        keyring.set_password(_KEYRING_SERVICE, _KEYRING_ACCOUNT, key_hex)
        return True
    except Exception:
        return False
```

### 6.3 跳过 Keyring 的条件

```python
def _should_skip_keyring() -> bool:
    """当 OS keychain 不太可能可用时返回 True"""
    if EnvVarLoader.get_bool("QWENPAW_RUNNING_IN_CONTAINER"):
        return True  # Docker 容器
    if sys.platform == "linux" and not (
        os.environ.get("DISPLAY") or os.environ.get("WAYLAND_DISPLAY")
    ):
        return True  # 无显示器的 Linux 服务器
    if os.environ.get("CI", "").lower() in ("true", "1"):
        return True  # CI 环境
    return False
```

### 6.4 主密钥轮换

```python
async def rotate_master_key(self, new_password: str) -> None:
    """轮换主密钥"""
    # 1. 解密所有密钥
    secrets = self._decrypt_all()

    # 2. 用新密钥重新加密
    self._master_key = self._derive_master_key(new_password)
    for secret in secrets:
        self._encrypt_and_store(secret)
```

### 7.2 字典字段加解密

```python
def encrypt_dict_fields(data: dict, secret_fields: frozenset[str]) -> dict:
    """返回 data 的浅拷贝，secret_fields 被加密。

    防重复加密：如果字段已加密（ENC: 前缀），跳过
    """
    result = dict(data)
    for field in secret_fields:
        if (
            field in result
            and isinstance(result[field], str)
            and result[field]
        ):
            if not is_encrypted(result[field]):  # 已加密的不重复加密
                result[field] = encrypt(result[field])
    return result

def decrypt_dict_fields(data: dict, secret_fields: frozenset[str]) -> dict:
    """返回 data 的浅拷贝，secret_fields 被解密。"""
    result = dict(data)
    for field in secret_fields:
        if (
            field in result
            and isinstance(result[field], str)
            and result[field]
        ):
            result[field] = decrypt(result[field])
    return result

def is_encrypted(value: str) -> bool:
    """判断值是否已加密（带 ENC: 前缀）"""
    return bool(value and value.startswith(_ENC_PREFIX))
```

### 7.3 透明加密示例

```python
# Provider 配置保存时自动加密
provider_config = {
    "id": "openai",
    "api_key": "sk-xxx"  # 自动加密
}
encrypted = encrypt_dict_fields(provider_config, PROVIDER_SECRET_FIELDS)
# 结果: {"id": "openai", "api_key": "ENC:gAAAA..."}

# Provider 配置加载时自动解密
```

## 8. 安全最佳实践

### 8.1 存储安全

- 密钥加密存储，不明文保存
- 使用独立的密钥存储文件
- 限制文件访问权限 (`chmod 600`)
- 优先使用 OS Keychain 存储主密钥

### 8.2 传输安全

- 内存中解密后立即使用
- 避免日志中打印密钥
- 使用后及时清理内存

### 8.3 环境特定的密钥管理

| 环境 | 密钥存储方式 |
|------|-------------|
| macOS | OS Keychain |
| Windows | Windows Credential Locker |
| Linux (有 GUI) | GNOME Keyring / kwallet |
| 容器/CI | 文件存储 (跳过 Keychain) |

### 8.4 容器环境配置

```bash
# 设置跳过 Keyring
```

## 10. 设计意图

### 10.1 加密策略

Fernet 方案选择的原因：
- **AES-128-CBC**：对称加密，兼顾安全性和性能
- **HMAC-SHA256**：保证密文完整性，防止篡改
- **ENC: 前缀**：明文标记加密值，实现透明加解密

### 10.2 四级密钥解析链设计

1. **进程内缓存**：无锁快速路径，避免每次访问都加锁
2. **OS Keychain**：操作系统级安全存储
3. **文件后备**：Keychain 不可用时的降级方案
4. **自动生成**：首次运行时的零配置体验

### 10.3 权衡取舍

| 权衡 | 选择 | 理由 |
|------|------|------|
| 算法强度 vs 性能 | AES-128 vs AES-256 | AES-128 在大多数场景足够快 |
| 安全性 vs 易用性 | 自动生成密钥 | 零配置体验 |
| 可用性 vs 严格安全 | 优雅降级 | 解密失败返回原始密文 |
