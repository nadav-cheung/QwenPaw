## 1. 定时任务概述

### 1.1 为什么需要定时任务

定时任务用于自动化运维和周期性操作，是保持智能体持续活跃的关键机制。QwenPaw 的定时任务系统实现：

- **定时提醒**：每日推送天气、日报等主动通知
- **心跳保持**：定期触发交互防止会话冷却
- **记忆整理**：定时执行 Dream 优化历史对话
- **健康检查**：监控系统各组件状态

### 1.2 定时任务类型

| 类型 | 说明 | 源码路径 |
|------|------|---------|
| Cron | Cron 表达式 | `app/crons/manager.py` |
| Interval | 间隔执行 | `app/crons/heartbeat.py` |
| OneShot | 单次执行 | REST API 手动触发 |
| Delayed | 延迟执行 | `asyncio.wait_for` |

### 1.3 核心架构

```
┌─────────────────────────────────────────────────────┐
│                    CronManager                       │
│  ┌──────────────────────────────────────────────┐   │
│  │           AsyncIOScheduler (APScheduler)       │   │
│  │                                                   │   │
```

## 2. CronManager

### 2.1 核心类

**源码路径**: `src/qwenpaw/app/crons/manager.py`

```python
class CronManager:
    """定时任务管理器 — 基于 APScheduler.AsyncIOScheduler"""

    def __init__(
        self,
        *,
        repo: BaseJobRepository,
        runner: Any,
        channel_manager: Any,
        timezone: str = "UTC",
        agent_id: Optional[str] = None,
    ):
        self._repo = repo                      # 任务持久化仓库
        self._runner = runner                    # AgentRunner 实例
        self._channel_manager = channel_manager  # 渠道管理器
        self._scheduler = AsyncIOScheduler(timezone=timezone)  # APScheduler
        self._executor = CronExecutor(
            runner=runner,
            channel_manager=channel_manager,
        )
        self._lock = asyncio.Lock()            # 线程安全锁
        self._states: Dict[str, CronJobState] = {}  # 运行时状态
        self._rt: Dict[str, _Runtime] = {}     # 每任务信号量
        self._started = False
```

### 2.2 启动流程

```python
async def start(self) -> None:
    """启动调度器 — 从仓库加载所有任务并注册"""
    jobs = await self._repo.load()             # 从 JSON 文件加载任务
    for spec in jobs.jobs:
        if not spec.enabled:
            continue
        await self._register_or_update(spec)

    # 注册心跳任务（如果启用）
    hb_cfg = get_heartbeat_config(self._agent_id)
    if hb_cfg and hb_cfg.enabled:
        await self._register_heartbeat(hb_cfg)

    # 注册 Dream 记忆整理任务
    dream_cron = get_dream_cron(self._agent_id)
    if dream_cron:
        await self._register_dream(dream_cron)

    self._scheduler.start()                     # 启动 APScheduler
    self._started = True
```

### 2.3 任务注册

```python
async def _register_or_update(self, spec: CronJobSpec) -> None:
    """注册或更新一个定时任务到 APScheduler"""
    # 1. 验证 cron 表达式（必须是5字段）
    if len(spec.schedule.cron.split()) != 5:
        raise ValueError(f"Invalid cron: {spec.schedule.cron}")

    # 2. 创建并发控制信号量
    self._rt[spec.id] = _Runtime(
        sem=asyncio.Semaphore(spec.runtime.max_concurrency),
    )

    # 3. 注册到 APScheduler
    self._scheduler.add_job(
        func=self._execute_once,
        trigger=CronTrigger.from_cron(spec.schedule.cron),
        args=(spec,),
        id=spec.id,
        replace_existing=True,
        misfire_grace_time=spec.runtime.misfire_grace_seconds,
        timezone=spec.schedule.timezone,
    )
```

### 2.4 并发控制

每个任务拥有独立的 `asyncio.Semaphore`，避免不同任务互相阻塞：

```python
async def _execute_once(self, spec: CronJobSpec) -> None:
    """执行一个定时任务（由 APScheduler 调用）"""
    rt = self._rt.get(spec.id)
    if rt is None:
        return

    # 获取信号量（控制并发）
    if not rt.sem.locked():
        async with rt.sem:
            await self._do_execute(spec)
    else:
        # 任务已在运行，跳过本次触发
        rt.state.last_status = "skipped"
```

### 2.5 CronJob 数据模型

```python
@dataclass
class CronJobSpec:
    """定时任务规格"""
    id: str
    name: str
    enabled: bool = True
    schedule: ScheduleSpec       # Cron 表达式
    task_type: Literal["text", "agent"]  # 任务类型

class ScheduleSpec:
```

### 5.3 MemoryCompactionHook

**源码路径**: `src/qwenpaw/agents/hooks/memory_compaction.py`

```python
class MemoryCompactionHook:
    """Hook for automatic memory compaction when context is full."""

    _REENTRANCY_ATTR = "_memory_compact_hook_running"

    async def __call__(self, agent: ReActAgent, kwargs: dict[str, Any]) -> None:
        # 防重入：防止同一轮对话中重复压缩
        if getattr(agent, self._REENTRANCY_ATTR, False):
            return None
        setattr(agent, self._REENTRANCY_ATTR, True)

        try:
            # 1. 检查上下文是否需要压缩
            messages_to_compact, _, is_valid = await self.memory_manager.check_context(...)

            if not is_valid:
                # 2. 执行压缩
                compact_content = await self.memory_manager.compact_memory(
                    messages=messages_to_compact,
                    previous_summary=memory.get_compressed_summary(),
                )

                # 3. 标记消息为已压缩
                await memory.mark_messages_compressed(messages_to_compact)
                await memory.update_compressed_summary(compact_content)
        finally:
            setattr(agent, self._REENTRANCY_ATTR, False)
```

**关键设计**:
- **防重入**: 使用 `_memory_compact_hook_running` 属性防止重复执行
- **保留最近**: `MEMORY_COMPACT_KEEP_RECENT` 保留最近的消息
- **异步摘要**: 使用 `add_async_summary_task()` 不阻塞主流程

## 6. 钩子系统

### 6.1 BootstrapHook

**源码路径**: `src/qwenpaw/agents/hooks/bootstrap.py`

`BootstrapHook` 在用户首次交互时检查 `BOOTSTRAP.md` 文件并显示设置引导：

```python
class BootstrapHook:
    """Hook for bootstrap guidance on first user interaction."""

    async def __call__(self, agent, kwargs: dict[str, Any]) -> None:
        # 1. 检查 .bootstrap_completed 标记文件
        bootstrap_completed_flag = self.working_dir / ".bootstrap_completed"
        if bootstrap_completed_flag.exists():
            return None

        # 2. 检查 BOOTSTRAP.md 是否存在
        bootstrap_path = self.working_dir / "BOOTSTRAP.md"
        if not bootstrap_path.exists():
            return None

        # 3. 检查是否首次用户交互
        messages = await agent.memory.get_memory()
        if not is_first_user_interaction(messages):
            return None

        # 4. 加载引导文本并前置到首条用户消息
        bootstrap_guidance = build_bootstrap_guidance(self.language)
        prepend_to_message_content(msg, bootstrap_guidance)

        # 5. 创建完成标记
        bootstrap_completed_flag.touch()
```

### 6.2 钩子执行时机

**推理前钩子（Pre-reasoning Hooks）**:

| 钩子 | 触发时机 | 功能 |
|------|---------|------|
| `BootstrapHook` | 首次用户交互 | 显示设置引导 |
| `MemoryCompactionHook` | 每次推理前 | 检查并压缩上下文 |
| `AgentContextHook` | 每次推理前 | 设置 agent/session 上下文 |

**执行顺序**:
```
用户消息到达
    ↓
BootstrapHook (仅首次)
    ↓
MemoryCompactionHook (每次)
    ↓
AgentContextHook (每次)
    ↓
开始推理 (_reasoning)
```

## 7. 持久化

### 7.1 JsonJobRepository

**源码路径**: `src/qwenpaw/app/crons/repo/json_repo.py`

```python
class JsonJobRepository(BaseJobRepository):
    """JSON 文件持久化 — 支持原子写入"""

    async def save(self, jobs_file: JobsFile) -> None:
        """原子写入：先写 .tmp，再 move"""
        tmp_path = self._path.with_suffix(self._path.suffix + ".tmp")
        payload = jobs_file.model_dump(mode="json")
        tmp_path.write_text(
            json.dumps(payload, ensure_ascii=False, indent=2),
            encoding="utf-8",
        )
        shutil.move(str(tmp_path), str(self._path))  # 原子替换
```

**原子写入的意义**：避免在写入过程中程序崩溃导致文件损坏。

### 7.2 CRON 表达式兼容性

APScheduler v3 使用 ISO 8601 星期编号（0=周一...6=周日），而标准 crontab 使用（0=周日...6=周六）。系统自动转换：

| crontab 表达式 | 转换后 | 说明 |
|---------------|--------|------|
| `0 9 * * 0` | `0 9 * * sun` | crontab 0=周日 → sun |
| `0 9 * * 1-3` | `0 9 * * mon-wed` | 范围转换 |

## 10. 设计意图

### 10.1 调度策略

| 策略 | 适用场景 | 说明 |
|------|---------|------|
| Cron | 固定时间点 | `0 9 * * *` 每天9点 |
| Interval | 固定间隔 | `every: "30m"` 每30分钟 |
| misfire_grace | 延迟容忍 | 60秒内的延迟会补执行 |

### 10.2 并发控制设计

每个任务拥有独立 `Semaphore` 而非全局锁的原因：

- **隔离性**：Job A 的慢不应阻塞 Job B
- **公平性**：不同任务有不同的执行频率和耗时
- **可配置**：通过 `max_concurrency` 为不同任务设置不同的并发限制

### 10.3 状态机

```
[触发]
   │
   ▼
[获取信号量]
   │
   ├─── 已锁定 ──► skipped（跳过）
   │
   └─── 可用 ──► running
                    │
            ┌───────┴───────┐
            ▼               ▼
         success          error
            │               │
            ▼               ▼
       last_error=None  last_error=repr(e)
            │               │
            └───────┬───────┘
                    ▼
              last_run_at=now
```
