# 《QwenPaw 智能体开发实战》

> Java 开发者的 AI Agent 转型指南

## 书籍简介

本书系统讲解 QwenPaw 智能体开发框架，从环境搭建到项目实战，帮助 Java 开发者快速掌握 Python 异步编程和 AI Agent 开发技能。

## 目标读者

- Java 开发工程师转行 Python/AI 领域
- 对 LLM 和 Agent 技术感兴趣的开发者
- 希望基于 QwenPaw 构建智能应用的工程师
