# 《QwenPaw 智能体开发实战》书籍重构设计

## 1. 概述

### 1.1 项目背景

QwenPaw 是一个开源的本地化个人 AI 助手项目，现有 78 个教学文件散落于 `teaching/` 目录，组织松散、编号跳跃、格式不统一。本设计文档旨在将现有教程重构为可发版的书籍。

### 1.2 书籍定位

| 属性 | 值 |
|------|-----|
| **书名** | 《QwenPaw 智能体开发实战》 |
| **目标读者** | Java 开发工程师转行 Python/AI 领域 |
| **风格** | 原理优先，理论 + 实战 |
| **输出格式** | Markdown（可渲染为 GitBook/MKDocs） |
| **输出路径** | `docs/book/` |

### 1.3 设计原则

- **YAGNI**: 只包含必要内容，不做过度设计
- **关注点分离**: 清晰的三篇结构，层层递进
- **Java 对比**: 需要时插入"来自 Java 的你"提示框，不刻意贯穿全文
- **源码驱动**: 原理讲解配合源码路径标注，代码片段不超过 50 行

### 3.2 难度等级定义

| 等级 | 符号 | 适用场景 |
|------|------|---------|

### 3.3 代码块规范

1. **长度限制**: 单个代码块不超过 50 行
2. **路径标注**: 源码块前标注 `**源码路径**: path/to/file.py:行号`
3. **注释意图**: 用注释说明"为什么这样写"，而非"代码在做什么"
4. **完整示例**: 完整可运行的代码放在实战篇，章节内只放精华片段

### 3.4 标题规范

- **章节标题**: `# 第 X.Y 章 标题`（中文数字）
- **一级节**: `## X.Y.Z 标题`（阿拉伯数字）
- **二级节**: `### X.Y.Z.1 标题`
- **专有名词**: 首次出现时用**粗体**，后续用普通文本
- **代码/路径**: 用 `` ` `` 反引号包裹

## 6. 风险与应对

| 风险 | 影响 | 应对方案 |
|------|------|---------|
| 78 个文件优化工作量巨大 | 时间超出预期 | 优先处理核心章节，附录简化 |
