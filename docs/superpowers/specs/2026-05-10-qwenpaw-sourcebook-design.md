# QwenPaw 源码探秘 — 书籍设计文档

## 目标

写一本类似《网络是怎么连接的》风格的源码分析书。读者读完能分阶段成为项目贡献者：

- **卷一后**：能定位 bug、修小问题
- **卷二后**：能独立添加新功能模块（Tool / Skill / Provider / Channel / Plugin）
- **卷三后**：能参与架构讨论、理解设计权衡

## 核心叙事手法

借鉴《网络是怎么连接的》三点核心手法：

1. **问题驱动** — 不是先讲理论再讲实践，而是先问"接下来发生了什么？"，自然引出技术
2. **逐层深入** — 第一遍只讲主线，后面章节回头深挖之前跳过的细节
3. **动手验证** — 每章有可运行的实验（curl、pytest、断点），理论立刻被实践锚定

## 全书的叙事线

**用户在 Web 界面输入一句话 → 追踪它经历的每一步 → 直到 AI 回复显示在屏幕上**

这条线自然穿越所有核心模块，在追踪过程中遇到什么讲什么。

## 每章内部结构

1. **问题** — 一个具体的追问（"消息怎么到达 QwenPaw？"）
2. **探索** — 沿源码追踪，展示真实调用链（代码引用 + Mermaid 图）
3. **实验** — 可运行的验证命令（curl、pytest、断点）
4. **工程权衡** — 为什么这样设计？trade-off 是什么？
5. **动手环节** — 本章对应的 Contributor 技能练习

## 源码素材复用

当前 `teaching/` 目录包含 46 章初稿，作为素材库使用：

- **保留可复用的**：源码路径引用、Mermaid 图、实际调用链分析、工程权衡描述
- **丢弃不用的**：旧章节结构、Level 分类体系、Python 基础教学（Level 1，不适合这种叙事）、审查元数据（已清理）
- **需要新写的**：每章的"问题/探索/实验"叙事框架、将模块式讲解转为追踪式叙事

## 范围边界

- **不包含**：Python 基础语法教学（读者需要具备基本的 Python 阅读能力）
- **不包含**：AgentScope 框架的深入讲解（仅在必要时简要说明）
- **以源码为权威**：所有描述必须与 `src/qwenpaw/` 下的实际代码一致
