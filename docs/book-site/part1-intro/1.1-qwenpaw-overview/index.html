    第 1.1 章 QwenPaw 概述¶

    本章导览¶

    项目 内容
    学习目标 1) 说出 QwenPaw 是什么及其核心理念 2) 列举 QwenPaw 的五大核心特点 3) 识别 QwenPaw 的主要模块及其职责
    前置知识 无
    预计时长 20 分钟
    难度等级 ⭐
    核心关键词 QwenPaw 智能体 本地部署 多渠道 Skills

    本章概述：QwenPaw 是一个开源的本地化个人 AI 助手，通过技能扩展和多渠道接入，为你提供隐私可控的智能化服务。

    1. 概念引入¶

    1.1 什么是 QwenPaw¶

    QwenPaw (Qwen Personal Agent Workstation) 是一个开源的个人 AI 助手，完全运行在你的本地环境中。原名 CoPaw，后因深度集成 Qwen 开源生态而更名。

    核心理念：懂你所需，伴你左右。

    1.2 核心特点¶

    特点 说明
    隐私优先 数据保存在本地，无需第三方托管
    高度可扩展 通过 Skills 扩展功能，无限可能
    多渠道支持 支持钉钉、飞书、微信、Discord、Telegram 等
    多智能体 创建多个可以协作的智能体
    本地部署 支持 Ollama、LM Studio 等本地模型

    2. 技术架构¶

    2.1 技术栈¶

    层级 技术 说明
    语言 Python 3.10-3.13 核心开发语言
    智能体框架 AgentScope 多智能体运行时
    Web UI React 18, TypeScript, Ant Design 5 前端界面
    Web 服务器 FastAPI, Uvicorn 后端 API 服务
    异步 I/O anyio 异步编程框架
    任务调度 APScheduler 定时任务管理

    2.2 模块结构¶

    模块 路径 功能
    agents src/qwenpaw/agents/ 智能体核心实现、工具和技能管理
    app src/qwenpaw/app/ Web 应用、渠道管理、API 端点
    providers src/qwenpaw/providers/ LLM 提供商集成
    cli src/qwenpaw/cli/ 命令行界面
    security src/qwenpaw/security/ 安全工具、权限控制
    console console/ 前端 Web UI

    3. 源码分析¶

    3.1 核心入口¶

    源码路径: src/qwenpaw/agents/react_agent.py

    class QwenPawAgent(ToolGuardMixin, ReActAgent):
    """QwenPaw 核心智能体类，采用 ReAct 推理模式"""

    def __init__(self, config: AgentConfig):
        super().__init__(config)
        self.workspace = Workspace(config.workspace_id)
        self.memory = MemoryManager(self.workspace)
        self.skills = SkillService(self.workspace)

    4. 快速开始¶

    4.1 安装¶

    pip install qwenpaw

    4.2 首次运行¶

    qwenpaw init
qwenpaw run

    5. 常见问题¶

    问题 解答
    QwenPaw 和 ChatGPT 有什么区别？ QwenPaw 完全运行在本地，数据不经过第三方服务器，更加隐私可控
    支持哪些本地模型？ 支持 Ollama 和 LM Studio 等本地部署的模型
    可以同时使用多个渠道吗？ 可以，QwenPaw 支持多渠道同时接入
