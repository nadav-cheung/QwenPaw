    1. 记忆系统概述¶

    1.1 什么是记忆系统¶

    记忆系统让 Agent 能够跨会话记住信息，是实现持续性智能对话的基础。没有记忆，Agent 每次对话都如同全新，无法理解用户偏好、历史决策或已完成的工种。

    QwenPaw 的记忆系统不仅是简单的数据存储，还包含： - 上下文压缩：当对话长度超过阈值时自动压缩 - 智能检索：通过向量搜索和全文搜索找回相关记忆 - 主动优化：Dream 机制在空闲时整理和归纳记忆

    1.2 三层记忆模型¶

    层级 类型 说明
    短期 Working Memory 当前会话的上下文，存储在内存中
    中期 Episodic Memory 最近交互的记忆，通过压缩保留关键信息
    长期 Semantic Memory 持久化的知识，存储在文件或向量数据库中

                            ↓ 上下文超限 / 定期压缩

    3. 主动记忆机制¶

    3.1 什么是主动记忆¶

    主动记忆是 Agent 根据上下文自动决定是否记住某些信息的机制。与被动存储不同，主动记忆会在适当的时机（如空闲时）分析、整理和归纳记忆，确保记忆的质量和可用性。

    主动记忆的核心价值: - 去冗整合：将零碎信息归纳为简洁的条目 - 状态覆写：用新状态替换旧状态（如用户偏好变更） - 智能筛选：只保留高价值、可复用的信息

    3.2 Dream 优化¶

    源码路径: src/qwenpaw/agents/memory/reme_light_memory_manager.py

    Dream 是 QwenPaw 的 AI 驱动记忆优化机制，在空闲时对记忆进行深度整理：

    class Dream:
    """Dream 模块：定期整理和归纳记忆"""

    async def compact(self, memory: list[Msg]) -> list[Msg]:
        """将多个记忆压缩为摘要"""

    Dream 工作流程:

    1. 备份: 在执行优化前备份当前的 MEMORY.md
    2. 创建 Dream Agent: 使用专门的系统提示词创建临时 Agent
    3. 执行优化: 让 Dream Agent 读取并分析记忆文件
    4. 覆写更新: 用优化后的内容替换原有记忆

    Dream 提示词原则:

    原则 说明
    极简去冗 只保留"核心业务决策"、"确认的用户偏好"、"高价值可复用经验"
    状态覆写 用新状态替换旧状态
    归纳整合 将零碎规则提炼为通用条目
    废弃剔除 删除已证伪的假设

    触发时机:

    TRIGGER_CONDITIONS = {
    "idle_time_minutes": 30,       # 空闲 30 分钟后
    "dream_cron": "0 23 * * *",    # 每日 23 点执行
}

    4. 记忆整理¶

    4.1 整理策略¶

    策略 说明 触发条件
    Full 全部重写，生成全新摘要 会话结束
    Incremental 增量更新，只处理新增内容 token 超限
    Summary 生成摘要，保留关键信息 超过阈值

    压缩配置 (ContextCompactConfig):

    配置项 默认值 说明
    memory_compact_ratio 0.75 上下文达到 75% 时触发压缩
    memory_reserve_ratio 0.1 压缩后保留最近 10% 内容
    compact_with_thinking_block True 压缩时包含思考块

    4.2 源码实现¶

    源码路径: src/qwenpaw/agents/memory/reme_light_memory_manager.py

    async def compact_memory(
    self,
    messages: list[Msg],
    previous_summary: str = "",
    extra_instruction: str = "",
    **_kwargs,
) -> str:
    """根据策略压缩记忆"""
    self._prepare_model_formatter()
    agent_config = load_agent_config(self.agent_id)
    cc = agent_config.running.context_compact

    result = await self._reme.compact_memory(
        messages=messages,
        as_llm=self.chat_model,
        as_llm_formatter=self.formatter,
        as_token_counter=get_token_counter(agent_config),
        language=agent_config.language,
        max_input_length=agent_config.running.max_input_length,
        compact_ratio=cc.memory_compact_ratio,
        previous_summary=previous_summary,
        return_dict=True,
        add_thinking_block=cc.compact_with_thinking_block,
        extra_instruction=extra_instruction,
    )
    return result.get("history_compact", "")

    源码路径: src/qwenpaw/agents/hooks/memory_compaction.py

    """推理前钩子，检查并压缩记忆"""

    async def __call__(self, agent, kwargs) -> None:

            running_config.memory_compact_threshold - str_token_count

    5. Token 管理¶

    5.1 Token 计数¶

    def count_tokens(text: str) -> int:
    """计算文本的 token 数量（估算）"""
    # 粗略估算：中文约 2 字符/token，英文约 4 字符/token
    chinese_chars = len([c for c in text if ord(c) > 0x4e00])
    other_chars = len(text) - chinese_chars
    return chinese_chars // 2 + other_chars // 4

    5.2 上下文窗口¶

    Agent 的上下文窗口是有限的，当记忆接近上限时：

    1. 触发压缩: MemoryCompactionHook 检测到 token 超过阈值
    2. 生成摘要: 将旧消息压缩为简洁摘要
    3. 保留最近: memory_reserve_ratio 确保最新内容不被压缩

    压缩不是删除：压缩是把旧消息变成摘要保留关键信息（如决策、结论），而不是简单删除。长时间运行的任务不会丢失"记忆"，只是变得更浓缩。

    6. 混合搜索机制¶

    6.1 向量搜索 + 全文搜索¶

    ReMeLight 支持混合搜索，结合向量语义相似度和关键词精确匹配：

    搜索模式 权重 说明
    向量搜索 (Vector) 0.7 使用嵌入模型进行语义相似度匹配
    BM25 全文搜索 0.3 传统关键词匹配，确保精确术语命中

    6.2 搜索参数¶

    参数 有效范围 说明
    max_results [1, 100] 最大返回结果数
    min_score [0.001, 0.999] 最小相似度分数

    7. 设计意图¶

    7.1 为什么要主动记忆¶

    如果没有主动记忆机制，Agent 会面临以下问题： - 记忆膨胀：随着对话进行，上下文无限增长 - 关键信息丢失：简单截断会导致重要决策被遗忘 - 无法利用历史：没有整理机制，历史记忆难以检索

    主动记忆通过 Dream 优化解决了这些问题，确保记忆始终保持精简和可用。

    7.2 权衡取舍¶

    维度 权衡
    记忆精度 vs 计算成本 完整保留精度高但成本高，摘要成本低但可能有信息损失
    即时性 vs 整理质量 实时压缩影响响应速度，延迟整理影响搜索质量
    存储空间 vs 召回率 保留更多记忆占用空间，但搜索结果更全面

    8. 知识检查¶
