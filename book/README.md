# QwenPaw 源码探秘

本书带你像侦探一样追踪 QwenPaw 源码。从一个用户请求开始，逐层深入，直到你能够作为 Contributor 向项目提交代码。

## 阅读方式

全书围绕一条主线展开：**你在 Web 界面输入一句话，按下回车，然后发生了什么？**

建议按顺序阅读。每一章都建立在前一章的基础上。如果你跳过了某章，可能会在后面的"探索"中遇到不熟悉的概念。

## 你需要的准备

- 能够阅读 Python 代码（不需要精通）
- 安装了 QwenPaw（序章会教你）
- 一个可以运行终端命令的环境

## 每章的结构

每章围绕一个追问展开，包含五个部分：

1. **问题** — 一个让你产生好奇心的追问
2. **探索** — 沿源码追踪，展示真实调用链
3. **实验** — 你可以自己跑的验证命令
4. **工程权衡** — 为什么这样设计？trade-off 是什么？
5. **动手环节** — 本章对应的 Contributor 技能练习

## 源码权威

本书所有内容以 `src/qwenpaw/` 下的实际代码为唯一事实来源。如果你发现书中描述与源码不一致，以源码为准。
