# 序章：启程之前

> 本章操作的文件：无（我们在自己的电脑上操作）
> 本章追踪的源码文件：无（我们先让 QwenPaw 跑起来）

准备出发

你面前有一个开源项目——**QwenPaw**（Qwen Personal Agent Workstation）。它是一个用 Python 写的个人 AI 助手，跑在你自己的电脑上，数据不离开本地。你可以通过网页、钉钉、Telegram 等渠道跟它聊天，它能调用工具（搜索网页、读写文件、执行命令）来完成复杂任务，还支持同时运行多个 Agent 协作。底层用 FastAPI 做 Web 服务、AgentScope 做智能体框架、支持 OpenAI/Qwen/Ollama 等多种大模型。

它躺在 GitHub 上，几万行 Python 代码，几十个模块，层层叠叠的抽象。

你打开任何一个文件，都会迷失在 import、类定义、异步调用和 Mixin 继承链里。

从哪里开始？

这本书的回答是：**从一条请求开始。**

在浏览器里输入一句话，按下回车，然后跟着这句话的足迹，穿过 HTTP 路由、Runner 调度、Agent 推理、LLM 调用、工具执行，直到它变成 AI 的回复出现在屏幕上。

但在出发之前，我们需要把 QwenPaw 装好，让它跑起来。这一章就做这件事。

## 安装

### 你需要什么

QwenPaw 用 Python 写的，所以你只需要 Python 和 pip。

打开终端，确认 Python 版本：

```bash
python3 --version
```

需要 3.10 或以上。如果版本太旧或者提示找不到命令，先去 [python.org](https://www.python.org/downloads/) 装一个。

### 一行命令

```bash
pip install qwenpaw
```

等它下载完。安装成功后验证一下：

```bash
qwenpaw --version
```

应该输出类似 `qwenpaw 1.1.2` 的版本号。如果看到这个，说明装好了。

> **遇到 `pip: command not found`？** 试试 `python3 -m pip install qwenpaw`。如果还不行，先升级 pip：`python3 -m pip install --upgrade pip`。

### 还有另一种装法

如果不想手动装 Python，QwenPaw 提供了安装脚本。macOS 或 Linux 上运行：

```bash
curl -fsSL https://qwenpaw.agentscope.io/install.sh | bash
```

Windows PowerShell 里运行：

```powershell
irm https://qwenpaw.agentscope.io/install.ps1 | iex
```

这个脚本会自动下载 Python、安装 QwenPaw、配好环境。对新手更友好。

## 初始化

装好之后，QwenPaw 还不能直接用。它需要知道：工作目录放哪？用哪个模型？API 密钥是什么？

运行初始化向导：

```bash
qwenpaw init --defaults
```

`--defaults` 让它用默认配置，跳过交互式询问。适合快速体验。

> **术语：工作目录**
> QwenPaw 的"家"——所有配置、记忆、技能都住在里面。就像每个人的书桌抽屉，东西都放在一个固定的地方。

初始化做了什么？它在你的用户目录下创建了 `~/.qwenpaw/` 文件夹：

```
~/.qwenpaw/
├── config.json          # 主配置文件
├── HEARTBEAT.md         # 心跳任务清单
├── workspaces/          # 各个 Agent 的工作空间
│   └── default/         # 默认 Agent
│       ├── agents/      # 智能体配置
│       ├── memory/      # 记忆存储
│       └── skills/      # 技能文件
├── .qwenpaw.secret/     # 加密的密钥存储
└── .qwenpaw.backups/    # 自动备份
```

注意，配置文件是 `config.json`，不是 YAML。QwenPaw 用 JSON 存配置，读写都方便。

> 如果你好奇每个配置项的含义，附录 A 有完整的环境变量速查。现在不用管它。

## 配置模型

QwenPaw 需要一个"大脑"——一个大语言模型。两个选择：

**选择一：云端模型（推荐）** 去 [阿里云 DashScope](https://dashscope.console.aliyun.com/) 注册，拿到 API 密钥。或者用 OpenAI、Gemini——关键是拿到一个 API 密钥。

**选择二：本地模型（免费）** 有显卡的话，装个 [Ollama](https://ollama.com/)，下载模型：

```bash
ollama pull qwen2.5
```

本地模型数据不离开电脑，但需要显卡，速度取决于硬件。

> **术语：Provider**
> Provider 就是"模型供应商"的抽象。不管是 OpenAI、Qwen 还是本地的 Ollama，QwenPaw 都把它们当成一个 Provider 来调用。就像手机充电器——不管你是苹果还是安卓，插上就能充，因为充电器适配了不同的接口。

### 在 Web 界面输入密钥

先启动 QwenPaw：

```bash
qwenpaw app
```

你会看到：

```
QwenPaw 正在启动...
服务已就绪
请访问 http://127.0.0.1:8088/
```

打开浏览器，访问 **http://127.0.0.1:8088/**。你应该能看到 QwenPaw 的 Web 界面。

在界面右上角找到「设置」（齿轮图标），进入「模型」选项卡：
1. 选择提供商（Qwen / OpenAI / Ollama）
2. 输入 API 密钥（如果用云端模型）
3. 保存并启用

> **找不到设置按钮？** 有些版本的设置入口在左下角。如果界面布局和你看到的不一样，随便点点——QwenPaw 的界面不大，不会迷路。

## 验证：发送第一条消息

配置好模型后，在聊天框输入：

```
Hello, what can you do?
```

按下回车。

你应该在几秒内看到 AI 的回复。如果看到了——恭喜，QwenPaw 已经跑起来了。

如果没看到回复：
1. 运行 `qwenpaw doctor` 检查配置问题
2. 检查 API 密钥是否正确（没有多余空格）
3. 确认密钥有足够的额度
4. 看看终端有没有错误日志

> **术语：qwenpaw doctor**
> QwenPaw 的"体检医生"。它会检查工作目录是否正确、配置文件是否合法、模型能不能连通、权限有没有问题。出了问题先跑它，十有八九能找到原因。

序章的主要目的就是这个：让你处于"刚输入一句话、按下回车"的状态。接下来的 26 章，我们将跟随这句话，穿越 QwenPaw 的每一层代码。

## 我们将会经历什么

这本书不会按模块目录来讲。那种讲法就像先告诉你人体有骨骼系统、循环系统、神经系统，然后让你自己拼出一个完整的人——你永远不知道食物从嘴巴进去后经过了哪些器官。

我们会像侦探一样，跟着一条请求的足迹追踪。

**卷一·启程（第 1-8 章）**，我们跟着消息走完一整趟旅程：

```
用户在浏览器输入 "Hello, what can you do?"
    |  第 1 章
HTTP 请求到达 FastAPI 服务器
    |  第 2 章
Runner 找到对应的 Agent
    |  第 3 章
Agent 诞生——一个对象被创建出来
    |  第 4 章
Agent 组装系统提示词，准备"思考"
    |  第 5 章
进入 ReAct 循环：思考 -> 行动 -> 观察 -> 再思考
    |  第 6 章
调用大语言模型，发送请求，等待回复
    |  第 7 章
如果模型说要调用工具，Agent 就去执行
    |  第 8 章
回复被格式化成流式输出，一行一行回到浏览器
```

八章之后，你完整地追踪了一条请求的生命周期。那时候你已经能定位 bug、在正确的文件里找到正确的代码。

**卷二·图纸（第 9-14 章）**，我们退后一步，像登上山顶俯瞰走过的路。源码模块之间是什么关系？为什么用 Mixin 而不是普通继承？Provider 为什么是可替换的抽象层？理解了设计，你就能读懂任意模块。

**卷三·工坊（第 15-19 章）**，给 QwenPaw 装上新的能力——写新工具、新技能、接入新模型、新频道，最后整理成 PR 提交。

**卷四·纵深（第 20-26 章）**，深入工程纵深：配置、记忆、自治任务、多智能体协作、插件、部署、测试。读完这些，你就能参与架构讨论，提交高质量的 PR。

## 动手环节

在进入第一章之前，做这件事：

1. 确保 QwenPaw 能正常启动，能在浏览器里发送消息并收到回复
2. 打开终端，进入 QwenPaw 的源码目录（如果你还没 clone，运行 `git clone https://github.com/agentscope-ai/QwenPaw.git`）
3. 在 IDE 里打开源码目录，大致浏览一下 `src/qwenpaw/` 下的文件夹名称

把 QwenPaw 跑起来，把源码打开——我们马上要出发了。
